# Getter

Getter 就是 store 中 state 的计算属性值。通过 `defineStore()` 中的 `getters` 属性来定义。



## 类型推导

大多数时候，getter 仅依赖 state。此时如果通过 `this` 访问 getters 实例，则必须显式定义返回类型，而通过 `state` 访问 store 时，ts 会自动进行类型推导。

::: code-group

```typescript [useAppStore] {10,14}
export const useAppStore = defineStore("app", {
  state: (): State => {
    return {
      count: 1,
      userInfo: {},
    };
  },
  getters: {
    // 使用 state 时，类型会自动推导为 number
    doubleCount(state) {
      return state.count * 2;
    },
    // 使用 this 时，需要显式指定返回值类型
    doublePlusOne(): number {
      return this.doubleCount + 1;
    },
  },
  actions: {},
});
```

```vue [index.vue]
<script lang="ts" setup>
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();

  console.log(appStore.doubleCount);   // 2
  console.log(appStore.doublePlusOne); // 3
</script>
```

:::



## 向 getter 传递参数

Getter 只是幕后的计算属性，所以不可以向它直接传递任何参数。

不过，可以从 getter 返回一个函数，通过该函数便可以传递参数。但请注意，**此时的 getter 将不会再被缓存**。

::: code-group

```typescript [useAppStore] {8-10}
export const useAppStore = defineStore("app", {
  state: () => {
    return {
      numbers: [1, 2, 3, 4, 5],
    };
  },
  getters: {
    double: (state) => {
      return (n: number) => state.numbers.find(d => d === n);
    },
  },
  actions: {},
});
```

```vue [index.vue（不解构）] {2,10}
<template>
	<div> number is {{ appStore.double(5) }}</div>
</template>

<script lang="ts" setup>
  import { useAppStore } from "@/stores/app.ts";

  const appStore = useAppStore();

  const target = appStore.double(5);
  console.log(target); // 5
</script>
```

```vue [index.vue（解构）] {3,10,13}
<template>
  <!-- template模板中，不需要 .value -->
  <div> number is {{ double(5) }}</div>
</template>

<script lang="ts" setup>
  import { useAppStore } from "@/stores/app.ts";
  import { storeToRefs } from "pinia";

  const { double } = storeToRefs(useAppStore());

  // 使用解构语法时，需要通过 .value 调用
  const target = double.value(5);
  console.log(target); // 5
</script>
```

:::



## 使用其他 store 的 getter

想要使用另一个 store 的 getter 的话，直接引入使用就好了。

```typescript {11}
import { useCounterStore } from "@/stores/counter.ts";

export const useAppStore = defineStore("app", {
  state: () => {
    return {
      number: 10,
    };
  },
  getters: {
    double: (state) => {
      const counterStore = useCounterStore();
      return state.number + counterStore.count;
    },
  },
  actions: {},
});
```
