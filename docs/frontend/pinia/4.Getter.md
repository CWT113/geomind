# Getter

Getter 就是 store 中 state 的计算属性值。通过 `defineStore()` 中的 `getters` 属性来定义。



## 类型推导

大多数时候，getter 仅依赖 state。此时如果通过 `this` 访问 getters 实例，则必须显式定义返回类型，而通过 `state` 访问 store 时，ts 会自动进行类型推导。

::: code-group

```typescript {10,14}
export const useAppStore = defineStore("app", {
  state: (): State => {
    return {
      count: 1,
      userInfo: {},
    };
  },
  getters: {
    // 使用 state 时，类型会自动推导为 number
    doubleCount(state) {
      return state.count * 2;
    },
    // 使用 this 时，需要显式指定返回值类型
    doublePlusOne(): number {
      return this.doubleCount + 1;
    },
  },
  actions: {},
});
```

```vue
<script lang="ts" setup>
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();

  console.log(appStore.doubleCount);   // 2
  console.log(appStore.doublePlusOne); // 3
</script>
```

:::
