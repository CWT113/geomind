# Action

Action 相当于组件的 method。它通过 `defineStore()` 中的 `actions` 属性来定义，并且它是 **定义业务逻辑的最佳选择**。

在 actions 中也通过 `this` 访问整个 store，不同于 getter 中使用 `this` 访问 store 的是，**actions 中支持完整的类型推导**。

并且，actions 可以是 **异步** 的，这意味着你可以在它里面使用 `await` 调用异步的 API。

::: code-group

```typescript [useAppStore.ts] {16-21}
export const useAppStore = defineStore("app", {
  state: () => {
    return {
      count: 0,
      userInfo: {},
    };
  },
  getters: {},
  actions: {
    // 并不需要显式指定类型，会自动类型推导
    randomizeCount() {
      this.count = Math.round(100 * Math.random());
      return this.count;
    },
    // 异步案例
    async login(username: string, password: string) {
      const { code, data } = await api.post(username, password);
      if (code === 200) {
        this.userInfo = data;
      }
    },
  },
});
```

```vue [index.vue] {3,12}
<template>
  <div>{{ appStore.count }}</div>
  <button @click="appStore.randomizeCount()">按钮</button>
</template>

<script lang="ts" setup>
  import { useAppStore } from "@/stores/app.ts";

  const appStore = useAppStore();

  // 像普通函数一样使用
  appStore.randomizeCount();
</script>
```

:::



## 访问其他 store 的 action

想要使用另一个 store 的话，直接在 action 中调用就好了。

```typescript {14,15}
import { useCounterStore } from "@/stores/counter.ts";

export const useAppStore = defineStore("app", {
  state: () => {
    return {
      count: 0,
      userInfo: {},
    };
  },
  getters: {},
  actions: {
    randomizeCount() {
      // 调用其他 store 的 action 方法
      const counterStore = useCounterStore();
      counterStore.increment();

      this.count = Math.round(100 * Math.random());
      return this.count;
    },
  },
});
```



## 订阅 action

可以通过 `store.$onAction()` 来监听 action 和它们的结果。其中：

- 传递给它的回调函数会在 action 本身之前执行；
- `after` 表示在 promise 解决之后，允许你在 action 解决后执行的一个回调函数；
- `onError` 允许在 action 抛出错误或 `reject` 时执行一个回调函数。

::: code-group

```vue [index.vue] {30}
<script lang="ts" setup>
  import { useAppStore } from "@/stores/app.ts";

  const appStore = useAppStore();

  const unsubscribe = appStore.$onAction(
    ({
      name,  /* action方法名称 */
      store, /* Store对象 */
      args,  /* action方法的参数值 */
      after, /* 在action方法执行完成后触发 */
      onError, /* 在action方法执行失败时触发 */
    }) => {
      console.log(`action执行前触发~`);
      console.log(name);  // setCount
      console.log(store); // Store对象
      console.log(args.join(", ")); // 555, 布布一二

      // result 表示 action 函数的返回值，没有返回值就是 undefined
      after((result) => {
        console.log(`action执行后触发~`, result);
      });

      onError((error) => {
        console.warn(`action错误时触发~`, error);
      });
    });
  
  // 手动删除监听器
	unsubscribe()

  // 触发 action 函数
  appStore.setCount(555, "布布一二");
</script>
```

```typescript [useAppStore.ts]
export const useAppStore = defineStore("app", {
  state: () => {
    return {
      count: 0,
    };
  },
  getters: {},
  actions: {
    setCount(count: number, name: string) {
      this.count = count;
      return "ok";
    },
  },
});
```

:::

默认情况下，action 订阅器会被绑定到添加它的组件上。这意味着，**当该组件被卸载时，它将会被自动删除**。如果你想在组件卸载后依旧保留它们，需要设置第二个参数为 `true`。

```vue {7}
<script setup>
  import { useAppStore } from "@/stores/app.ts";

  const appStore = useAppStore();
  
  // 此订阅器即便在组件卸载之后仍会被保留
  appStore.$onAction(callback, true)
</script>
```
