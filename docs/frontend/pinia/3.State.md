# State

大多数情况下，`state` 是 store 的核心，它存储了全局共享，可响应的数据源。



## 类型推导

```typescript {13}
interface UserInfo {
  name: string;
  age: number;
}

interface State {
  count: number;
  userInfo: Partial<UserInfo>;
}

export const useAppStore = defineStore("app", {
  // 为了完整类型推理，推荐使用箭头函数
  state: (): State => {
    return {
      count: 0,
      userInfo: {},
    };
  },
  getters: {},
  actions: {},
});
```



## 重置 State

使用选项式 API 时，可以通过调用 store 的 `$reset()` 方法将 state 重置为初始值。

::: code-group

```vue [index.vue] {15}
<script lang="ts" setup>
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();

  appStore.setCount(100);
  appStore.setUserInfo({
    name: "王一博",
    age: 25,
  });
  console.log(appStore.count);    // 100
  console.log(appStore.userInfo); // { name: "王一博", age: 25 }

  // 选项式写法中，自带了 $reset() 函数，而在组合式写法中，需要自定义
  appStore.$reset();
  console.log(appStore.count);    // 0
  console.log(appStore.userInfo); // {}
</script>
```

```typescript [useAppStore.ts]
export const useAppStore = defineStore("app", {
  state: (): State => {
    return {
      count: 0,
      userInfo: {},
    };
  },
  getters: {},
  actions: {
    setCount(count: number) {
      this.count = count;
    },
    setUserInfo(userInfo: UserInfo) {
      this.userInfo = userInfo;
    },
  },
});
```

:::



## 变更 State

选项式 API 时，你可以通过调用 store 的 `$patch` 方法更新 state 中定义的属性值（不需要像上面那样在 `actions` 中写函数了，当然有自定义逻辑时除外）。

::: code-group

```vue [index.vue（推荐使用）] {14-18}
<script lang="ts" setup>
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();

  appStore.setCount(100);
  appStore.setUserInfo({
    name: "王一博",
    age: 25,
  });
  console.log(appStore.count);    // 100
  console.log(appStore.userInfo); // { name: "王一博", age: 25 }

  appStore.$patch((state) => {
    state.count = 200;
    state.userInfo.name = "陈伟霆";
    state.userInfo.age = 35;
  });
  console.log(appStore.count);    // 200
  console.log(appStore.userInfo); // { name: "陈伟霆", age: 35 }
</script>
```

```vue [index.vue] {14-20}
<script lang="ts" setup>
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();

  appStore.setCount(100);
  appStore.setUserInfo({
    name: "王一博",
    age: 25,
  });
  console.log(appStore.count);    // 100
  console.log(appStore.userInfo); // { name: "王一博", age: 25 }

  appStore.$patch({
    count: 200,
    userInfo: {
      // 允许只更新 userInfo 内部的个别属性
      name: "陈伟霆",
    },
  });
  console.log(appStore.count);    // 200
  console.log(appStore.userInfo); // { name: "陈伟霆", age: 25 }
</script>
```

:::



## 订阅 State

使用选项式 API 中，可以通过 store 的 `$subscribe` 方法侦听 state 及其变化。

> [!NOTE] 注意
>
> 在底层实现上，`$subscribe` 也使用了 Vue 的 `watch` 函数，但 `$subscribe` 的好处是只在 patch 后 **触发一次**！

::: code-group

```vue [Parent.vue] {13-16}
<template>
	<child/>
</template>

<script lang="ts" setup>
  import Child from "@/components/Child.vue";
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();

  setTimeout(() => {
    // 触发更新
    appStore.$patch((state) => {
      state.count = 200;
      state.userInfo.name = "王一博";
    });
  }, 3000);
</script>
```

```vue [Child.vue] {7-10}
<script setup lang="ts">
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();

  // 订阅更新
  appStore.$subscribe((_, state) => {
    console.log(state.count);
    console.log(state.userInfo.name);
  }, { flush: "sync" /* 立即触发一次 */ });
</script>
```

:::



### 取消订阅

默认情况下，*state subscription* 会被绑定到它们的组件上（如果 store 在组件的 `setup()` 函数中）。

这意味着，**当该组件被卸载时，state 订阅将会被自动删除**。如果想要在组件卸载后依旧保留他们，需要设置 `{ detached: true }` 作为第二个参数。

```vue {10}
<script setup lang="ts">
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();

  // 订阅更新
  appStore.$subscribe((_, state) => {
    console.log(state.count);
    console.log(state.userInfo.name);
  }, { flush: "sync", detached: true });
</script>
```
