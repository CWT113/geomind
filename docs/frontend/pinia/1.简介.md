# 简介

Pinia 是 Vue 的专属状态管理库，它允许你跨组件或页面共享状态。

## 安装

使用包管理器安装 pinia（[查看当前版本](https://www.npmjs.com/package/pinia)）：

``` bash
pnpm install pinia
```

在 `main.ts` 中，创建 pinia 实例，并将其注册为插件：

```typescript [main.ts] {2,7,9}
import { createApp } from "vue";
import { createPinia } from "pinia";

import App from "./App.vue";
import router from "./router";

const app = createApp(App);

app.use(createPinia());
app.use(router);

app.mount("#app");
```
