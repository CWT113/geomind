# 定义 Store

## 什么是 Store？

Pinia 中 Store 本质就是一个 **集中管理状态的容器**，但它比 Vuex 更轻量、更灵活、使用负担更低。

> [!NOTE] Store 是独立的状态容器
> 每个 Store 就像是一个单独的“数据仓”。可以按功能点把不同的状态拆分为多个 Store，如：
> - 用户模块（userStore）
> - 地图模块（mapStore）
> - 权限模块（authStore）
>
> 每个 Store 之间互不影响，彼此独立。

Store 包含三个核心内容：

|   核心    | 描述                    | 对标 Vue   |
|:-------:|:----------------------|:---------|
|  state  | 定义响应式变量               | data     |
| getters | 对 state 的派生数据，具备缓存特性  | computed |
| actions | 处理异步、修改 state 的唯一逻辑入口 | methods  |

## Store 命名

Store 通过 `defineStore()` 定义，其中：

- 第一个参数要求是一个 **独一无二** 的名字，也被用作 id，Pinia 将它用来连接 Store 和 devtools；
- 第二个参数接受两类值：setup 函数或 option 对象；
- 同时，约定俗成，它的返回值使用 `useXxx` 开头的风格进行命名；

``` typescript
import { defineStore } from "pinia";

export const useAppStore = defineStore("app", () => {
  // 其他配置...
});
```

## 选项式 Store

选项式 Store 和 Vue2 的使用方式很相似，它将 state 的定义和操作进行明确的区分，更容易上手。

> [!CAUTION] 注意
>
> `state` 中定义的响应式变量，习惯上将其认定为是 **只读** 的，外界不要直接修改变量的值，而是通过 `actions` 中定义的方法进行更改！

```typescript [useAppStore.ts]
export const useAppStore = defineStore("app", {
  // state 中定义的变量，可以读取，但不推荐直接修改
  state: () => ({
    name: "sunny",
    info: {
      age: 25,
      hobbies: ["篮球", "足球"],
    },
  }),
  getters: {
    // getters 中定义的变量，默认就是只读的
    getName: (state) => state.name,
    getInfo: (state) => state.info,
  },
  actions: {
    setName(name: string) {
      this.name = name;
    },
    setInfo(info: Partial<typeof this.info>) {
      if (!info || Object.keys(info).length == 0) {
        return;
      }
      Object.assign(this.info, info);
    },
  },
});
```

## 组合式 Store

组合式 Store 则和 Vue3 的使用方式很相似，它比 选项式 Store 更加灵活，因为可以在内部声明 `watch`、`onMounted` 等组合式函数。

> [!CAUTION] 注意
>
> 使用组合式 Store 时，内部定义的响应式变量，也推荐使用 `readonly` 进行包括，将其变为 **只读** 变量，外界通过方法进行修改值！

``` typescript [useAppStore.ts] {20,21}
export const useAppStore = defineStore("app", () => {
  const name = ref("sunny");
  const info = reactive({
    age: 25,
    hobbies: ["篮球", "足球"],
  });

  function setName(value: string) {
    name.value = value;
  }

  function setInfo(value?: Partial<typeof info>) {
    if (!value || Object.keys(value).length == 0) {
      return;
    }
    Object.assign(info, value);
  }

  return {
    name: readonly(name),
    info: computed(() => readonly(info)), // info及其内部属性都变为只读的
    setName,
    setInfo,
  };
});
```

## 使用 Store

> [!CAUTION] 注意
>
> `store` 是一个用 `reactive` 包装的对象，这意味着不需要在 `getters` 后面写 `.value`，并且也 **不能对其内部的属性进行解构，否则会失去响应式**！

```vue

<script lang="ts" setup>
  import { useAppStore } from "@/stores/counter.ts";

  const appStore = useAppStore();
  console.log(appStore.name); // ✅
  console.log(appStore.info); // ✅

  // 不能解构属性，会失去响应式
  const { name, info } = useAppStore(); // [!code --]
  // 当然，解构方法是被允许的
  const { setName, setInfo } = useAppStore(); // [!code ++]
</script>
```

如果真的想从 Store 中解构属性，并且保持其响应式状态，此时需要使用 `storeToRefs()` 。它将会把每一个响应式属性自动包装为 `Ref` 类型。

```vue

<script lang="ts" setup>
  import { storeToRefs } from "pinia";
  import { useAppStore } from "@/stores/counter.ts";

  // storeToRefs() 将其包装为 Ref 类型后，还会自动将其内部属性变为 只读属性
  const { name, info } = storeToRefs(useAppStore()); // [!code ++]
</script>
```
