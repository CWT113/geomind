# h 函数

`h()` 函数是一个用于手动创建虚拟 DOM 节点（VNode）的工具函数。

平时在 `.vue` 文件中写的 `<template>` 模板语法，在底层会被编译成由 `h()` 函数组成的渲染函数。

`h()` 函数最多接受三个参数：
$$
h(type, props, children)
$$

|   参数   |             类型             | 是否必填 | 作用                                                     |
| :------: | :--------------------------: | -------- | :------------------------------------------------------- |
|   type   | String \| Object \| Function | 是       | HTML标签名、Vue组件、或异步组件                          |
|  props   |            Object            | 否       | 传给标签或组件的属性                                     |
| children |  String \| Array \| Object   | 否       | 子节点，可以是文本字符串、由`h()` 组成的数组、或插槽对象 |
