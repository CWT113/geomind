# 侦听器

在 Vue3 中，可以使用 `watch` 、`watchEffect` 等 API 来监测响应式属性的变化，并在属性发生改变时执行特定的操作。



## 侦听数据源类型

`watch` 的第一个参数需要写入待监测的数据源，它可以是一个 **ref（包括计算属性）、一个响应式对象、一个 getter 函数、或多个数据源组成的数组**。

```vue {8,13,18}
<script setup lang="ts">
  import { ref, watch } from "vue";

  const x = ref(0);
  const y = ref(0);

  // 侦听单个ref值
  watch(x, (newX, oldX) => {
    console.log(`旧值是：${oldX}，新值是：${newX}`);
  });

  // 侦听getter函数
  watch(() => y.value, (newY, oldY) => {
    console.log(`旧值是：${oldY}，新值是：${newY}`);
  });

  // 侦听多个数据源组成的数组
  watch([x, () => y.value], ([newX, newY]) => {
    console.log(`X的新值是：${newX}，Y的新值是：${newY}`);
  });
</script>
```

> [!WARNING] 注意
>
> 不能使用 `watch` 侦听响应式对象的某个属性值，例如：
>
> ```vue {7,12}
> <script setup lang="ts">
>   import { reactive, watch } from "vue";
> 
>   const obj = reactive({ count: 10 });
> 
>   // 报错：watch的第一个参数不能传入 `obj.count` 这样的普通值
>   watch(obj.count, (newVal) => { // [!code --]
>     console.log(`新值是：${newVal}`);
>   });
> 
>   // 使用getter函数，watch在初始化时会自动执行一次，Vue内部会自动收集依赖
>   watch(() => obj.count, (newVal) => { // [!code ++]
>     console.log(`新值是：${newVal}`);
>   });
> </script>
> ```



## 深层侦听器

直接向 `watch` 传入一个响应式对象，内部会隐式地创建一个深层侦听器，即该回调函数在任何嵌套属性变更时都会被触发。

```vue {10}
<script setup lang="ts">
  import { reactive, watch } from "vue";

  const obj = reactive({
    name: "tom",
    count: 10,
  });

  // 侦听一个响应式对象时，obj内部的任何一个属性发生变化，都会触发侦听器
  watch(obj, (newVal, oldVal) => {
    // 嵌套的属性发生变化后，newVal和oldVal是相等的
    console.log(newVal === oldVal);
  });

  function handleChange() {
    obj.count++;
  }
</script>
```

当将一个完整的响应式对象通过 getter 函数侦听时，只有在整个对象发生变化时，才会被触发。在这种情况下，如果仍需要侦听对象属性的变化，可以显式的加上 `deep` 选项，强制转为深层侦听器。

> [!WARNING] 注意
>
> 强制开启深度侦听时，内部需要遍历被侦听对象中的所有嵌套属性，当对象属于大型数据结构时，开销很大。

```vue {14,10}
<script setup lang="ts">
  import { reactive, watch } from "vue";

  const obj = reactive({
    name: "tom",
    count: 10,
  });

  // 使用getter函数侦听响应式对象时，只有obj整个对象发生变化时，才会触发侦听器
  watch(() => obj, (newVal, oldVal) => {
    console.log(newVal);
    console.log(oldVal);
  }, {
    deep: true,
  });

  function handleChange() {
    obj.count++;
  }
</script>
```



## 立即触发侦听器

`watch` 侦听器默认是懒执行的，只有当数据源发生变化时，才会执行回调。如果希望在创建侦听器时，立即执行一次回调，则需要配置 `immediate` 选项。

```vue {10}
<script setup lang="ts">
  import { ref, watch } from "vue";

  const x = ref(0);

  watch(x, (newX, oldX) => {
    // 初始化时默认会触发一次
    console.log(`旧值是：${oldX}，新值是：${newX}`);
  }, {
    immediate: true,
  });
</script>
```



## 一次性侦听器

`watch` 侦听器默认是当数据源发生变化时，侦听器回调就会被触发。如果希望回调只在数据源发生变化时触发一次，则需要配置 `once` 选项。

```vue {10}
<script setup lang="ts">
  import { ref, watch } from "vue";

  const x = ref(0);

  watch(x, (newX, oldX) => {
    // 初始化时默认会触发一次
    console.log(`旧值是：${oldX}，新值是：${newX}`);
  }, {
    once: true,
  });

  function handleChange() {
    x.value++;
  }
</script>
```



## watchEffect

`watchEffect` 用于简化 `watch` 侦听器的写法，它会自动追踪响应式数据的变化，而不需要指定具体的数据源。

> [!NOTE] watch 和 wathEffect 的区别？
>
> 

```vue {7,15}
<script setup lang="ts">
  import { ref, watch, watchEffect } from "vue";

  const todoId = ref(1);
  const data = ref("");

  watch(todoId, async () => {
    const response = await fetch(`https://jsonplaceholder.typicode.com/todos/${todoId.value}`);
    data.value = await response.json();
  }, {
    immediate: true,
  });

  // watchEffect内部自动追踪响应式变量 todoId，并且默认开启了immediate: true
  watchEffect(async () => {
    const response = await fetch(`https://jsonplaceholder.typicode.com/todos/${todoId.value}`);
    data.value = await response.json();
  });

  function handleChange() {
    todoId.value++;
  }
</script>
```



## 停止侦听器

在 `setup()` 或 `<script setup>` 中 **同步创建的侦听器**，会自动绑定到组件实例上，并随着组件的卸载而停止。因此，在绝大多数情况下，无需关心如何停止一个侦听器。

但是，如果使用 **异步创建的侦听器**，它并不会绑定到组件上，此时必须在组件卸载时手动将其停止，以防止内存泄漏。

```vue
<script setup lang="ts">
  import { watchEffect } from "vue";

  // 挂载到组件实例上，随组件销毁而结束
  watchEffect(() => {});

  // 这样写则不会挂载到组件实例上，组件销毁也不会停止
  setTimeout(() => {
    watchEffect(() => {});
  }, 100);
</script>
```

要停止一个侦听器，需要调用 `watch` 或 `watchEffect` 返回的函数。

```vue {7}
<script setup lang="ts">
  import { onUnmounted, ref, watchEffect } from "vue";

  const x = ref(0);

  onUnmounted(() => {
    unwatch();
  });

  const unwatch = watchEffect(() => {
  });
</script>
```
