# 异步组件

异步组件（Async Components）是一种允许我们只在需要时才从服务器加载组件的技术，而不是在应用首次启动时把所有组件一次性全部下载下来。

在传统开发模式中，所有的组件都会被打包到一个巨大的 JS 文件中。而异步组件会触发代码分割（Code Splitting），将组件单独打包成一个小文件（Chunk）。只当该组件需要在屏幕上渲染时，浏览器才会去下载这个小文件。

> [!NOTE] 异步组件优势
>
> - **显著提升页面首次加载速度**：使用异步组件后，首页只下载首屏需要的代码，其他页面和复杂组件按需加载，大大缩短了用户的等待时间；
> - **减少非必要的网络带宽和资源消耗**：有些组件用户的点击频率较低，对应的组件只在用户点击时加载，帮用户节省流量，同时也减轻服务器压力；



## 基本用法

```vue {8}
<template>
	<async-child/>
</template>

<script setup lang="ts">
  import { defineAsyncComponent } from "vue";

  const AsyncChild = defineAsyncComponent(() => import("@/components/Child.vue"));
</script>
```

与普通组件一样，异步组件也可以使用 `app.component()` 全局注册：

```ts
app.component("MyChild", defineAsyncComponent(() => 
	import("@/components/Child.vue"))
);
```



## 加载与错误状态

异步操作不可避免地会涉及到加载和错误状态，因此 `defineAsyncComponent()` 也支持在高级选项中处理这些状态。

```vue
<template>
	<async-child/>
</template>

<script setup lang="ts">
  import { defineAsyncComponent } from "vue";
  import ErrorComponent from "@/components/Error/index.vue";
  import LoadingComponent from "@/components/Loading/index.vue";

  const AsyncChild = defineAsyncComponent({
    loader: () => import("@/components/Child.vue"), // [!code ++]
    // 模拟加载超时的效果
    loader: () => {
      return new Promise((resolve) => {
        setTimeout(() => {
          resolve(import("@/components/Child.vue"));
        }, 4000);
      });
    },
    // 加载异步组件期间展示的组件
    loadingComponent: LoadingComponent,
    // 展示加载组件的延迟时间
    delay: 200,
    // 加载失败时展示的组件
    errorComponent: ErrorComponent,
    // 加载超过了该时间，则展示加载失败组件（默认：Infinity）
    timeout: 3000,
  });
</script>
```
