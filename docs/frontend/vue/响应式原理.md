# 响应式原理

Vue 的响应式机制是 Vue 框架最核心的部分之一。一句话概括：

- **Vue2**：主要通过 `Object.defineProperty()` 劫持对象已有属性的 `get` 和 `set`；
- **Vue3**：主要通过 `Proxy` 代理整个对象，结合 `Reflect` 完成属性操作。`ref` 还会通过自身的 `getter` 或 `setter` 实现依赖追踪；

|    对比项    |          Vue2           |           Vue3           |
| :----------: | :---------------------: | :----------------------: |
|   核心技术   | Object.defineProperty() |     Proxy + Reflect      |
|   监听范围   |    已定义的对象属性     | 对代理对象执行的多种操作 |
| 新增对象属性 |    通常需要 Vue.set()    |         直接赋值         |
| 删除对象属性 |  通常需要 Vue.delete()   |        直接 delete        |
| 数组索引赋值 | 无法可靠触发更新 | 可以触发更新 |
| 修改数组长度 | 无法可靠触发更新 | 可以触发更新 |
| 深层对象处理 | 初始化时递归观测 | 按访问需求创建嵌套代理 |
| 依赖收集 | Dep + Watcher | track() + ReactiveEffect |





## Vue2

Vue2 中的 Object.defineProperty 是如何实现响应式的呢？假设我们有一个普通 JavaScript 对象：

```typescript {8,12,17}
const user = {
  name: '张三',
};

// 保存原来的属性值
let value = user.name;

Object.defineProperty(user, 'name', {
  enumerable: true,
  configurable: true,
  // 当读取 user.name 时执行
  get() {
    console.log('读取了 name 属性');
    return value;
  },
  // 当修改 user.name 时执行
  set(newValue) {
    console.log('修改了 name 属性');
    value = newValue;
  },
});

// 触发 get()
console.log(user.name);
// 触发 set()
user.name = '李四';
```

这样，我们就成功监听到了属性的读取和修改。但是，上面的方式 **只能监听已经通过 Object.defineProperty 定义了访问器的属性**。例如：

```typescript
user.age = 20;
```

由于 `age` 是后面添加的，没有提前设置 `getter` 和 `setter`，因此不会触发上面的监听逻辑。



## Vue3

Vue3 使用 `Proxy` 来完成响应式，它的作用是 **创建一个对象的代理，在操作对象时，自动拦截读取、赋值、删除等操作**。

```typescript {6,10,15,20}
const user = {
  name: '张三',
  age: 20,
};

const proxyUser = new Proxy(user, {
  // 读取属性时触发
  get(target, key, receiver) {
    console.log(`读取属性：${String(key)}`);
    return Reflect.get(target, key, receiver);
  },
  // 修改或新增属性时触发
  set(target, key, value, receiver) {
    console.log(`修改属性：${String(key)}，新值：${value}`);
    return Reflect.set(target, key, value, receiver);
  },
  // 删除属性时触发
  deleteProperty(target, key) {
    console.log(`删除属性：${String(key)}`);
    return Reflect.deleteProperty(target, key);
  },
});

console.log(proxyUser.name);

proxyUser.name = '李四';
proxyUser.age = 25;

delete proxyUser.age;
```



### track 和 trigger

前面仅仅使用 Proxy，还不能称为完整的响应式系统。还需要添加两个核心模块：

- `track`：读取响应式属性时，收集依赖；
- `trigger`：修改响应式属性时，通知对应依赖执行；

考虑下面的 Vue3 代码：

```typescript
import { reactive, watchEffect } from 'vue';

const user = reactive({
  name: '张三',
  age: 20,
});

watchEffect(() => {
  console.log('姓名：', user.name);
});

// 自动触发 watchEffect
user.name = '李四';
```

`watchEffect` 函数执行时读取了 `user.name`，此时就进行了依赖收集的功能。简单来说：就是这个函数依赖于 `user.name`，当其变化时，它就应该重新执行。

我们把这个需要自动重新运行的函数称为 **副作用函数**（Effect）。



### 手写响应式系统

下面通过 TypeScript，实现 `reactive()`、`track()`、`trigger()` 和 `effect()`。

::: code-group

```typescript [effect.ts]
/**
 * 响应式副作用函数类型
 */
type EffectRunner = (() => void) & {
  // deps 用来记录当前 Effect 被添加到了哪些依赖集合，后续可清理依赖
  deps: Set<EffectRunner>[];
};

// Proxy 的 getter 被触发时，我们必须知道是哪个函数在读取这个属性，因此该变量就是用来记录当前正在执行的副作用函数
let activeEffect: EffectRunner | undefined;
// 全局依赖存储结构
const targetMap = new WeakMap<object, Map<PropertyKey, Set<EffectRunner>>>();
// 缓存已经创建过的代理，避免重复创建
const reactiveMap = new WeakMap<object, object>();

/**
 * 清理副作用函数前面收集的依赖
 * @param runner 需要清理的副作用函数
 */
function cleanup(runner: EffectRunner) {
  for (const dep of runner.deps) {
    dep.delete(runner);
  }
  runner.deps.length = 0;
}

/**
 * 注册并执行副作用函数
 * @param fn 需要自动追踪依赖的函数
 */
export function effect(fn: () => void) {
  const runner = (() => {
    // 收集之前，先清理之前的副作用函数
    cleanup(runner);
    // 保存外层正在执行的 Effect
    const previous = activeEffect;
    // 标记正在执行的 Effect
    activeEffect = runner;
    try {
      // 执行时读取的响应式属性会收集 runner
      fn();
    } finally {
      activeEffect = previous;
    }
  }) as EffectRunner;
  runner.deps = [];
  // 首次执行，创建依赖关系
  runner();
}

/**
 * 收集响应式依赖属性
 * @param target 被代理的原始对象
 * @param key 当前读取的属性名
 */
function track(target: object, key: PropertyKey) {
  // 没有正在执行的 Effect，无需收集
  if (!activeEffect) return;
  // 获取对象的依赖表
  let depsMap = targetMap.get(target);
  if (!depsMap) {
    depsMap = new Map();
    targetMap.set(target, depsMap);
  }
  // 获取当前属性的依赖集合
  let deps = depsMap.get(key);
  if (!deps) {
    deps = new Set();
    depsMap.set(key, deps);
  }
  // 避免重复收集依赖
  if (!deps.has(activeEffect)) {
    deps.add(activeEffect);
    // 记录反向关联，方便清理旧依赖
    activeEffect.deps.push(deps);
  }
}

/**
 * 触发属性对象的副作用函数
 * @param target 被代理的原始对象
 * @param key 发生变化的属性名
 */
function trigger(target: object, key: PropertyKey) {
  // 找到当前对象的依赖表
  const depsMap = targetMap.get(target);
  if (!depsMap) return;
  // 当前当前属性对应的依赖集合
  const deps = depsMap.get(key);
  if (!deps) return;
  // 复制依赖集合，避免执行过程中清理依赖
  const effectsToRun = new Set(deps);
  effectsToRun.forEach((runner) => {
    if (runner !== activeEffect) {
      runner();
    }
  });
}

/**
 * 创建响应式代理对象
 * @param target 需要代理的原始对象
 */
export function reactive<T extends object>(target: T): T {
  // 如果已经存在代理，直接返回
  const existingProxy = reactiveMap.get(target);
  if (existingProxy) {
    return existingProxy as T;
  }

  const proxy = new Proxy(target, {
    get(target, key, receiver) {
      // 收集依赖
      track(target, key);
      // 读取属性的真实值
      const result = Reflect.get(target, key, receiver);
      if (result !== null && typeof result === 'object') {
        return reactive(result);
      }
      return result;
    },
    set(target, key, value, receiver) {
      // 保存旧的值
      const oldValue = Reflect.get(target, key, receiver);
      // 执行实际赋值操作
      const success = Reflect.set(target, key, value, receiver);
      // 当新旧值不同时，触发更新
      if (success && !Object.is(oldValue, value)) {
        trigger(target, key);
      }
      return success;
    },
  });
  reactiveMap.set(target, proxy);
  return proxy;
}
```

```typescript [测试响应式]
import { effect, reactive } from '@/test/index.ts';

const user = reactive({
  name: '张三',
  age: 25,
});

effect(() => {
  console.log('name更新：' + user.name);
});

user.name = '李四';
```

### ref 为什么要 .value？

在 Vue3 中，官方推荐的是 `reactive()` 用来代理对象类型，而 `ref()` 用来代理基本数据类型。

```typescript
const user = reactive({
  name: '张三',
});

const count = ref(0);
```

这是因为这里的 `0` 是一个基本数据类型，它不能直接通过 Proxy 代理。因此 Vue3 想了一个办法，把 **基本数据类型包装到一个具有 `.value` 属性的对象中**。

```typescript
const count = {
  value: 0,
};
```

然后就能使用 Proxy 进行代理，并且通过 `getter` 或 `setter` 拦截 `.value` 的访问和修改了。



简单的 `ref` 实现：

::: code-group

```typescript [effect.ts]
/**
 * 创建 ref 响应式对象
 * @param initialValue 初始值
 */
export function ref<T>(initialValue: T) {
  let value = initialValue;
  const refObject = {
    get value(): T {
      track(refObject, 'value');
      return value;
    },
    set value(newValue: T) {
      if (Object.is(value, newValue)) return;
      value = newValue;
      trigger(refObject, 'value');
    },
  };
  return refObject;
}
```

```typescript [测试响应式]
const count = ref(0);

effect(() => {
  console.log('count值：' + count.value);
});

count.value++;
count.value++;
```
