# 插槽

插槽（Slot）是组件的一种内容分发机制。简单来说，插槽就像是子组件在自己的模板中挖了一个“坑”，而父组件在使用子组件时，可以往这个“坑”里填入任意内容。



## 默认插槽

默认插槽是最基础的插槽，子组件通过 `<solt>` 标签占位，如果父组件不传内容，还可以写上默认内容。

::: code-group

```vue [Parent.vue] 
<template>
  <child>
    <p>这是父组件传递的插槽内容</p>
  </child>
</template>

<script setup lang="ts">
  import Child from "@/components/Child.vue";
</script>
```

```vue [Child.vue] {3} 
<template>
  <header>
    <slot>这是插槽的默认内容</slot>
  </header>
</template>
```

:::



## 具名插槽 

当一个组件里需要有多个插槽占位时，就需要给每个插槽进行命名，这就是具名插槽。没有起名字的插槽默认叫 `default`。

::: code-group

```vue [Parent.vue] {11}
<template>
  <child>
    <template #header>
      这是往 Header 插入的内容
    </template>
	
    <template #default>
      这是往 Default 插入的内容
    </template>
    <!-- 没有通过 # 指定插槽的元素，自动插入默认插槽 -->
    <p>这也会直接插入 Default 插槽</p>
	
    <template #footer>
      这是往 Footer 插入的内容
    </template>
  </child>
</template>

<script setup lang="ts">
 import Child from "@/components/Child.vue";
</script>
```

```vue [Child.vue]
<template>
  <header>
  	<slot name="header"></slot>
  </header>

  <main>
  	<slot name="default"></slot>
  </main>

  <footer>
  	<slot name="footer"></slot>
  </footer>
</template>
```

:::



## 条件插槽

如果需要根据内容是否被传入了插槽来渲染某些内容，就可以结合 `$slots` 和 `v-if` 来实现。

```vue
<template>
  <header v-if="$slots.header">
    <slot name="header"></slot>
  </header>

  <main v-if="$slots.default">
    <slot name="default"></slot>
  </main>

  <footer v-if="$slots.footer">
    <slot name="footer"></slot>
  </footer>
</template>
```



## 作用域插槽

在某些场景下，父组件的插槽想要使用子组件作用域内的数据。此时就需要通过作用域插槽将子组件的数据提供给父组件。

::: code-group

```vue [Parent.vue] {4-6}
<template>
  <child>
    <!-- 作用域插槽：获取子组件通过插槽传递的参数 -->
    <template #header="slotProps">
    	{{ slotProps.username }} - {{ slotProps.age }}
    </template>
  </child>
</template>

<script setup lang="ts">
  import Child from "@/components/Child.vue";
</script>
```

```vue [Child.vue] {4}
<template>
  <header>
    <!-- 注意：name 是保留关键字，不能用于传值 -->
    <slot name="header" :username="username" :age="age"></slot>
  </header>

  <main>
  	<slot name="default"></slot>
  </main>
</template>

<script setup lang="ts">
  import { ref } from "vue";

  const username = ref("tom");
  const age = ref(0);
</script>
```

:::
