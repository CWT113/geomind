# 动态组件

动态组件是 Vue3 提供的一种在同一个位置上，根据响应式数据动态切换不同组件的机制。

它主要通过 Vue 的 `<component>` 内置的特殊元素和 `:is` 属性实现。



## 为什么需要动态组件？

::: info

假设后台管理系统中，设备管理页面有两个展示模式：

- 列表模式：使用 `DeviceTable.vue` 展示设备数据；
- 地图模式：使用 `DeviceMap.vue` 展示 Cesium 三维场景；

用户点击不同的按钮，页面显示不同的组件。

:::

如果不使用动态组件，通常这样写：

```vue
<template>
  <DeviceTable v-if="activeTab === 'table'" />

  <DeviceMap v-else-if="activeTab === 'map'" />
</template>
```

使用动态组件，只需要修改 `activeComponent` 的值，就能自动切换对应组件：

```vue {2}
<template>
	<component :is="activeComponent" />

  <button @click="activeTab = 'table'">
    列表模式
  </button>
  <button @click="activeTab = 'map'">
    地图模式
  </button>
</template>

<script setup lang="ts">
  import { ref, computed } from 'vue';
  import DeviceMap from './components/DeviceMap.vue';
  import DeviceTable from './components/DeviceTable.vue';

  const activeTab = ref<ViewMode>('table');

  const activeComponent = computed(() => {
    return activeTab.value === 'table'
      ? DeviceTable
    : DeviceMap;
  });
</script>
```

需要注意的是，**动态组件切换后，原来的组件会被销毁**。如果想要保持状态需要借助 `KeepAlive`。



## KeepAlive

`<KeepAlive>` 是 Vue3 提供的内置组件，能够缓存动态组件实例，避免每次切换都重新创建。

```vue
<template>
  <KeepAlive>
    <component :is="activeComponent" />
  </KeepAlive>
</template>
```



使用 `<KeepAlive>` 后，还需要了解两个生命周期钩子：

```typescript {14,19}
import {
  onMounted,
  onUnmounted,
  onActivated,
  onDeactivated,
} from 'vue';

// 首次挂载执行
onMounted(() => {
  console.log('组件已挂载');
});

// 被 KeepAlive 激活时执行
onActivated(() => {
  console.log('组件被激活');
});

// 被 KeepAlive 停用时执行
onDeactivated(() => {
  console.log('组件被停用');
});

// 真正卸载时执行
onUnmounted(() => {
  console.log('组件被卸载');
});
```

在 Cesium 开发时，就可以借助动态组件。例如被缓存的地图组件停用后，可能需要暂停某些实时更新逻辑，而在激活时恢复。
