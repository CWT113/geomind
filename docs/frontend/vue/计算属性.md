# 计算属性

计算属性（computed）用于根据其他数据的变化 **动态计算衍生出来的属性值**，而且 **具有缓存机制**，只有相关依赖发生变化时才会重新计算。

> [!WARNING] 注意
>
> - 计算属性的 getter 内部应该只做计算，而不做其他的事情，如改变其他状态、异步请求或更改 DOM 等；
> - 计算属性返回的是一个派生值，可以把它看作一个“临时快照”，每当数据源发生变化时，都会创建一个新的快照，因此修改计算属性的返回值是没有意义的。



## 基础示例

`<template>` 中的模板表达式一般只用来写简单的操作，如果在模板中写太多的逻辑，会让模板变得臃肿，难以维护。

> [!TIP] 提示
>
> 计算属性会自动追踪内部使用到的响应式依赖。当检测到响应式依赖发生变化时，计算属性也会立马重新计算。

```vue {14-16}
<template>
  <!-- 不建议在模板中写复杂的代码逻辑，难以维护 -->
  <div>{{ message.split("").reverse().join("") }}</div>

  <div>{{ messageComp }}</div>
</template>

<script setup lang="ts">
  import { computed, ref } from "vue";

	const message = ref("hello");

  // 使用计算属性将结果算好，然后在模板中使用
  const messageComp = computed(() => {
    return message.value.split("").reverse().join("");
  });
</script>
```



## 计算属性 vs 方法

在大多数情况下，计算属性能完成的功能，使用方法都可以完成。但是，不同点在于 **计算属性会基于其响应式依赖而进行数据缓存**，而方法不会。

这意味着只要 `message` 不发生改变，无论访问多少次 `messageComp` 都会立即返回之前计算好的结果，而不会重复执行 getter 函数。而方法则会在每次访问时，都重新执行一次内部逻辑，当内部逻辑比较复杂时，会影响性能。

```vue {17,22}
<template>
  <div>{{ messageComp }}</div>
  <div>{{ messageComp }}</div>
  <div>{{ messageComp }}</div>

  <div>{{ reverseMsg() }}</div>
  <div>{{ reverseMsg() }}</div>
  <div>{{ reverseMsg() }}</div>
</template>

<script setup lang="ts">
  import { computed, ref } from "vue";

  const message = ref("hello");

  const messageComp = computed(() => {
    console.log("computed"); // 模板中调用了3次，但是打印只会触发一次，后续都使用缓存值
    return message.value.split("").reverse().join("");
  });

  function reverseMsg() {
    console.log("method"); // 模板中调用了3次，就会打印3次，每次都重新计算
    return message.value.split("").reverse().join("");
  }
</script>
```



## 可写计算属性

计算属性默认是只读的，当尝试修改一个计算属性时，会报警告。如果需要用到可写计算属性，需要提供 getter 和 setter 函数：

```vue
<script setup lang="ts">
  import { computed, ref } from "vue";

  const firstName = ref("liu");
  const lastName = ref("xu");

  const fullName = computed({
    get() {
      return firstName.value + " " + lastName.value;
    },
    // 当设置 fullName 的值时，就会触发 setter 函数
    set(newVal: string) {
      [firstName.value, lastName.value] = newVal.split(" ");
    },
  });
</script>
```



## 获取上一个值

通过计算属性 getter 的第一个参数可以获取计算属性返回的上一个值。

::: code-group

```vue {7} [只读计算属性]
<script setup lang="ts">
  import { computed, ref } from "vue";

  const count = ref(2);

  // 当 count 的值大于3时，会一直返回上一个值，也就是3
  const alwaysSmall = computed((previous) => {
    if (count.value <= 3) {
      return count.value;
    }
    return previous;
  });
</script>
```

```vue [可写计算属性]
<script setup>
  import { ref, computed } from 'vue';

  const count = ref(2);

  const alwaysSmall = computed({
    get(previous) {
      if (count.value <= 3) {
        return count.value;
      }
      return previous;
    },
    set(newValue) {
      count.value = newValue * 2;
    }
  });
</script>
```

:::
