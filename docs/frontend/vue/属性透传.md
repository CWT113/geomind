# 属性透传

在 Vue3 中，属性透传是指当你想向一个组件传递属性（Props）或事件监听器（Emit），但该组件并没有在自己的 props 或 emits 中声明它们时，这些属性会自动传递给该组件的根元素。



## 属性继承

当一个组件以单个元素作为根渲染时，透传的 attribute 会自动被添加到根元素上。

> [!NOTE] 提示
>
> - 属性继承时，如果子组件的根元素已经有了 `class` 或 `style` 属性，它会和父组件上继承的值合并；
> - `@click` 等事件也可以用作属性透传；

::: code-group

```vue [Parent.vue]
<template>
  <child class="large-btn" id="submit-btn" @click="handleClick"/>
</template>

<script setup lang="ts">
  import Child from "@/components/Child.vue";

  function handleClick() {
    console.log("clicked");
  }
</script>
```

```vue [Child.vue]
<template>
  <!-- 父组件的 class 和 id 被透传到 button 上，并且会自动合并 -->
  <button class="btn">点击我</button>
</template>
```

:::



## 多根节点透传

Vue3 支持多根节点组件，但 **多根节点组件不会自动进行属性透传**，因为此时 Vue 不知道要把属性透传到哪一个根节点上。

如果明确要透传到某个节点上时，需要适用内置的 **变量 `$attrs` 来显示绑定**。

```vue {4}
<template>
  <header>头部</header>
  <!-- 使用 $attrs 指明要把父组件的属性透传到该元素上 -->
  <button v-bind="$attrs" class="btn">点击我</button>
  <footer>底部</footer>
</template>
```



## 禁用透传

有时候如果不希望把属性自动透传到组件的根元素上，而是透传到根元素内部的某个节点上。此时需要通过 `inheritAttrs` 属性来禁用默认的属性透传。

```vue {5,13}
<template>
  <div class="container">
    <header>头部</header>
    <!-- 使用 $attrs 指明要把父组件的属性透传到该元素上 -->
    <button v-bind="$attrs" class="btn">点击我</button>
    <footer>底部</footer>
  </div>
</template>

<script setup lang="ts">
  defineOptions({
    // 禁用默认的属性透传
    inheritAttrs: false,
  });
</script>
```



## 在 script 中访问透传属性

除了在模板中使用 `$attrs`，也可以在 `<script setup>` 中通过 `useAttrs()` 来获取透传的属性。

```vue {18}
<template>
  <div class="container">
    <header>头部</header>
    <!-- 使用 $attrs 指明要把父组件的属性透传到该元素上 -->
    <button v-bind="$attrs" class="btn">点击我</button>
    <footer>底部</footer>
  </div>
</template>

<script setup lang="ts">
  import { useAttrs } from "vue";

  defineOptions({
    // 禁用默认的属性透传
    inheritAttrs: false,
  });

  const attrs = useAttrs();

  console.log(attrs.class); // large-btn
  console.log(attrs.id); // submit-btn
</script>

```
