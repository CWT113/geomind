# 枚举

枚举（Enum）是 TS 中一种特殊的数据类型，它允许你定义一组命名的常量。



## 数字枚举

默认情况下，枚举属性值从 0 开始编号。

```ts
enum Direction {
  Up, // 0
  Down, // 1
  Left, // 2
  Right // 3
}

const dir: Direction = Direction.Up;
// 或者
const dir1: Direction = Direction["Up"];

console.log(dir); // 0
```



## 手动赋值

可以手动为枚举成员指定值。

::: code-group

```ts [数字值]
enum Status {
  Success = 200,
  Error = 500,
  NotFound = 404
}

console.log("状态：" + Status.Success); // "状态：200"
```

```ts [字符串值]
enum Direction {
  Up = "Up",
  Down = "Down",
  Left = "Left",
  Right = "Right"
}

console.log("方向：" + Direction.Down); // "方向：Down" 
```

:::



## 常量枚举

使用 const 修饰的枚举会在编译时内联，生成更优化的代码。

::: code-group

```ts [原始代码]
const enum Color {
  Red = "RED",
  Green = "GREEN",
  Blue = "BLUE"
}

const c: Color = Color.Red;
console.log("颜色：" + c); // "颜色：RED"
```

```ts [编译后]
"use strict";
const c = "RED" /* Color.Red */;
console.log("颜色：" + c); // "颜色：RED"
```

:::



## 枚举合并

多个同名的 Enum 结构，会自动合并。

> [!WARNING] 注意
>
> - 多个 Enume 合并时，只允许其中一个成员省略初始值，其他成员必须显式赋值；
> - 合并时不能存在同名成员，否则报错；

```ts
enum Status {
  Success
}

enum Status {
  // 枚举合并时，只允许其中一个成员忽略初始值
  Error = 500
}

enum Status {
  Error = 404 // 语法报错：不能存在同名成员 // [!code --]
}

// 等同于
enum Status {
  Success,
  Error = 500,
  NotFound = 404
}
```
