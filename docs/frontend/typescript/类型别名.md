# 类型别名

类型别名（Type Aliases）用于为复杂类型定义一个简洁的名字，让代码更易读、更易维护。



## 基础类型与联合类型

当需要让代码更具语义化，或者一个变量可以接受多种类型时，就可以使用类型别名。

```ts
// 基础类型别名（增强语义）
type Point = number;
const x: Point = 10;

// 联合类型别名（限制取值范围）
type Status = "pending" | "approved" | "rejected";
const s: Status = "pending";
```



## 复杂对象结构

用来统一定义数据的骨架，让代码在多处复用时保持整洁。

```ts
type User = {
  id: number;
  name: string;
  isAdmin?: boolean; // 可选属性
}

const u: User = {
  id: 1,
  name: "tom",
  isAdmin: false
}
```



## 函数签名

如果需要将函数作为参数传递（回调函数），用类型别名可以让参数列表更加简洁。

```ts
// 定义回调函数类型
type Callback = (result: string) => string;

// 定义运算函数类型
type MathOperation = (a: number, b: number) => number;
// 使用函数类型别名
const add: MathOperation = (a, b) => a + b;
add(1, 2);
```



## 类型别名与泛型

类型别名可以配合泛型使用，创建可复用的类型定义。

```ts
type Result<T> = {
  success: boolean;
  data?: T;
  error?: string;
}

type Pair<K, V> = {
  key: K;
  value: V;
}

const r: Result<string> = {
  success: true,
  data: "hello,world"
}
const p: Pair<string, number> = {
  key: "name",
  value: 123
}
```



## 类型别名与映射

类型别名可以与映射类型结合，创建强大的类型转换。

```ts
// 遍历所有属性，并将其变为只读
type MyReadonly<T> = { readonly [P in keyof T]: T[P] };

// 遍历所有属性，并将其变为可选
type MyPartial<T> = { [P in keyof T]?: T[P] };

interface User {
  name: string;
  age: number;
}

const readonlyUser: MyReadonly<User> = {
  name: "tom",
  age: 20
}
readonlyUser.name = "bob"; // 类型报错：name属性是只读的 // [!code --]

const partialUser: MyPartial<User> = {
  name: "alice",
  // age: 20
}
```
