# 类型映射

映射类型（Mapped Types）是 TS 中一种 **基于已有类型创建新类型** 的强大特性。

它允许开发者批量修改属性的特性，如将所有属性变为可选、将所有属性变为只读等。

> [!TIP] 提示
>
> 映射类型使用 `keyof` 和 `in` 关键字遍历已有类型的所有键，然后对每个键应用相同的类型转换。



## 属性修饰符

属性修饰符可以组合使用，常见的属性修饰符有：

|  修饰符   | 描述                 |
| :-------: | -------------------- |
|     ?     | 将属性设为可选       |
|    -?     | 将可选属性变为不可选 |
| readonly  | 将属性设为只读       |
| -readonly | 将只读属性变为不只读 |

```ts {14,9}
interface User {
  id: number;
  name: string;
  email: string;
}

// 将 T 中的属性变为可选
type MyPartial<T> = {
  [P in keyof T]?: T[P];
}

// 将 T 中的属性变为只读
type MyReadonly<T> = {
  readonly [P in keyof T]: T[P];
}
```



## 键名映射

映射类型还可以使用 `as` 关键字来重映射键名。

```ts {10}
interface User {
  id: number;
  name: string;
  email: string;
}

// 为所有键添加前缀
type WithPrefix<T, Prefix extends string> = {
  // 使用 as 关键字重映射键名，Capitalize 将首字母大写
  [P in keyof T as `${Prefix}${Capitalize<string & P>}`]: T[P];
}

type PrefixedUser = WithPrefix<User, "user">;
// 转换后的类型：
// { userId: number; userName: string; userEmail: string; }
```



## 键过滤

通过条件类型和映射类型的组合，可以实现键的过滤。

```ts {8,10}
interface User {
  id: number;
  name: string;
  email: string;
}

// 使用条件类型过滤指定键
type MyOmit<T, K extends keyof T> = {
  // 如果 P 可以赋值给 K（即在排除列表中），返回 never（不包含）
  [P in keyof T as P extends K ? never : P]: T[P];
}

type UserWithoutEmail = MyOmit<User, "email">;
// 转换后的类型：
// { id: number; name: string; }
```

> [!TIP] 提示
>
> 在映射类型中，使用 `never` 作为属性类型，该属性会被完全移除。



## 内置映射类型

TS 内置了许多基于映射类型实现的工具类型。

```ts {2,6,10,14,18}
// Partial - 将所有属性变为可选
type P1 = Partial<{ a: string; b: number }>;
// 结果：{ a?: string; b?: number; }

// Required - 将可选属性变为必填
type R1 = Required<{ a?: string; b?: number }>;
// 结果：{ a: string; b: number }

// Readonly - 将所有属性变为只读
type R2 = Readonly<{ a: string; b: number }>;
// 结果：{ readonly a: string; readonly b: number }

// Pick - 选择指定的属性
type P2 = Pick<{ a: string; b: number }, "a">;
// 结果：{ a: string }

// Omit - 排除指定的属性
type O1 = Omit<{ a: string; b: number }, "a">;
// 结果：{ b: number }
```
