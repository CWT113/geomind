# 数组与元组

## 数组

数组（Array）类型用于确保数组中所有的数据都是同一类型。

::: code-group

```ts [方括号形式]
// 纯数字类型
const numbers: number[] = [1, 2, 3];
// 纯字符串类型
const strings: string[] = ['tom', 'bob'];
// 混合类型
const minxed: (number | string)[] = [1, 2, 'tom'];
```

```ts [泛型形式]
// 纯数字类型
const numbers: Array<number> = [1, 2, 3];
// 纯字符串类型
const strings: Array<string> = ['tom', 'bob'];
// 混合类型
const minxed: Array<number | string> = [1, 2, 'tom'];
```

:::



### 类型推断

如果数组变量没有声明类型，TS 会自动推断数组成员的类型。如果数组的初始值是空数组，此时会被推断为类型为 `any[]`。

```ts {5,8}
// 类型推断为 any[]
const arr = [];

arr.push(1);
arr // 被推断为 number[]

arr.push("bob");
arr // 被推断为 (string | number)[]
```

注意，类型推断的自动更新只发生在初始值为空数组的情况。如果初始值不是空数组，类型推断就不会更新。

```ts
const arr: number[] = [1, 2, 3];

arr.push("123"); // 类型报错：'string'类型赋值给'number'类型
```



### 只读数组

TS 允许声明只读数组，只需要在数组类型前面加上 `readonly` 关键字即可。

```ts
const arr: readonly number[] = [1, 2, 3];

arr[0] = 10; // 类型报错
arr.push(10); // 类型报错
delete arr[2]; // 类型报错
```

> [!WARNING] 注意
>
> - `readonly` 关键字不能与数组的泛型写法一起使用；
>
>   ```ts
>   const arr: readonly Array<number> = [1, 2, 3]; // 语法报错
>   ```
>
> - `readonly number[]` 与 `number[]` 在 TS 中是两种不同的类型，**后者是前者的子类型**。这意味着：`number[]` 可以赋值给父类型 `readonly number[]`，反过来则不行。
>
>   ```ts
>   function getSum(arr: number[]) { }
>     
>   const readonlyArr: readonly number[] = [1, 2, 3];
>     
>   getSum(readonlyArr); // 类型报错：readonly number[] 不能赋值给 number[]
>   ```



实际上，在 TS 中也专门提供了两个泛型，用来生成只读数组类型。

```ts
// ReadonlyArray<T> 的泛型是 number 类型
const arr1: ReadonlyArray<number> = [1, 2, 3];
// Readonly<T[]> 的泛型是 number[] 类型
const arr2: Readonly<number[]> = [1, 2, 3];
```

只读数组还有另一种声明方法，就是使用 `const` 断言。

```ts
const arr = [1, 2, 3] as const;

arr.push(1); // 类型报错：arr为只读数组
```



### 多维数组

TS 中使用 `T[][]` 的形式，表示二维数组。

```ts
const arr: number[][] = [
  [1, 2, 3],
  [4, 5, 6],
];
```



## 元组

> 数组中元素的数据类型都是相同的（`any[]` 除外），如果想存储的元素数据类型不同，就需要使用元组。

元组（Tuple）是一种特殊类型的数组，它允许 **在数组中存储不同类型的元素，并且每个元素都有明确的类型和位置**。

```ts
// 数组
const a: number[] = [1];
// 元组
const t: [number] = [1];

// 元组成员的类型可以添加问号后缀(?)，表示该成员可选
// 注意：可选成员必须位于元组尾部
const arr: [string, number, boolean?] = ["tom", 1, true];
```



### 可扩展元组

元组中的成员在限制类型时长度就已固定，如果对长度外的成员赋值，就会报错。

```ts
const arr: [number, number] = [1, 2];

arr[2] = 3; // 类型报错：arr[2]为undefined
```

但是，使用扩展运算符（`...`），可以表示不限成员数量的元组。

```ts {1}
type Names = [string, ...number[]];

const a: Names = ["A", 1, 2];
const b: Names = ["B", 1, 2, 3];

// 扩展运算符可以用在元组的任意位置，但后面必须跟一个数组
type t1 = [...boolean[], string, number];
type t2 = [string, ...boolean[], number];
type t3 = [string, number, ...boolean[]];
```



### 只读元组

元组也是可以只读的，不允许进行修改。

```ts
// 方括号写法
type t = readonly [number, number];

// 泛型写法
type t = Readonly<[number, number]>;

// 类型断言，此时会将其转换为 readonly [1, 2]
const arr = [1, 2] as const;
```



### 推断元组长度

TS 会根据元素内部的成员数量，来推断出元组的长度。

```ts
function f1(p: [number, number]) {
  if (p.length === 2) { // ok
  }
  if (p.length === 3) { // 类型报错：长度不可能为3 // [!code --]
  }
}

function f2(p: [number, number?]) {
  if (p.length === 1 || p.length === 2) { // ok
  }
  if (p.length === 3) { // 类型报错：长度不可能为3  // [!code --]
  }
}

const arr: [...number[]] = [1, 2, 3];
if (arr.length === 4) { // ok，使用扩展运算符后，就无法推断成员数量了  // [!code --]
}
```
