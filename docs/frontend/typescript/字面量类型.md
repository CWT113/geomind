# 字面量类型

字面量类型（Literal Types）是 TypeScript 中一种 **表示特定值** 而不是通用类型的特性。

## 字符串字面量

字符串字面量类型用于将变量的取值限制为特定的字符串。

```ts
let direction: "up" | "left" | "down" | "right" = "up";
direction = "down";
direction = "upup"; // 编译错误：upup 不在四种类型之内 // [!code --]

// 定义状态类型只能是这三个固定值
type Status = "pending" | "active" | "completed";
const currentStatus: Status = "pending";
```

## 数字字面量

数字字面量类型将变量的取值限制为特定的数字。

> [!TIP] 提示
>
> 数字字面量可以替代简单的枚举（enum）使用，尤其是只需要几个固定数值时。

```ts
type Weekday = 1 | 2 | 3 | 4 | 5 | 6 | 7;
const today: Weekday = 1;
```

## 对象字面量

对象字面量类型可以定义对象的结构，并可以使用 `readonly` 修饰符将属性设为只读。

> [!TIP] 提示
>
> 只读对象常用于定义配置对象、常量对象等不希望被修改的数据。

::: code-group

```ts [对象字面量]
type Point = {
  x: number;
  y: number;
};

const p: Point = {
  x: 100,
  y: 200,
};
```

```ts {2,3} [只读对象字面量]
type Point = {
  readonly x: number;
  readonly y: number;
};

const p: Point = {
  x: 100,
  y: 200,
};

p.x = 50; // 编译错误：p.x是只读的 // [!code --]
```

:::

## 模板字面量

模板字面量类型使用 JavaScript 模板字符串的语法来创建新的类型。它允许我们动态地生成字符串类型。

```ts
type EventName = `on${string}`;

const event1: EventName = "onClick";
const event2: EventName = "submit"; // 编译报错：不是以 on 开头 // [!code --]

// Capitalize 用于将字符串首字母大写
type Handler = `handle${Capitalize<string>}`;

const handler1: Handler = "handleSubmit";
const handler2: Handler = "handlesubmit"; // 编译报错：第二个字符串没有以 首字母大写 开头 // [!code --]
```
