# 基本类型

TypeScript 是由微软开发的开源编程语言，在 JavaScript 的基础上增加了 **静态类型检查** 的超集。

> [!WARNING] 注意
>
> TypeScript 中的类型 **均为小写字母**，首字母大写的 `Number`、`String`、`Boolean` 等是 JavaScript 中的内置对象，而不是类型名称。



## string 类型

`string` 类型包含所有的字符串。

```ts
const x: string = "hello";
const y: string = `world`;
const z: string = `hello, ${name}`;
```



## number 类型

`number` 类型包含所有整数、浮点数、十进制数和十六进制数。

```ts
const x: number = 10;
const y: number = 3.14;
const z: number = 0xf00d;
const m: number = 0b1010;
```



## boolean 类型

`boolean` 类型只包含 true 和 false 两个布尔值。

```ts
const x: boolean = true;
const y: boolean = false;
```



## bigint 类型 <Badge type="tip" text="ES2020+" />

`bigint` 类型包含所有的大整数。

> [!WARNING] 注意
>
> bigint 类型与 number 类型不兼容，把 number 类型的值强制赋值给 bigint 类型会类型报错。

```ts
const x: bigint = 10n;
const y: bigint = 0xffffn;

const m: bigint = 10; // 报错 // [!code --]
const n: bigint = 0xffff; // 报错  // [!code --]
```



## symbol 类型

symbol 类型包含了所有的 Symbol 值。

```ts
const x: symbol = Symbol();
```



## object 类型

根据 JavaScript 的设计，`object` 类型包含了所有 **对象、数组和函数**。

```ts
const x: object = { name: "zs" };
const y: object = [1, 2, 3];
const z: object = (n: number) => n + 1;
```



## undefined 类型

`undefined` 类型只包含一个值 undefined，表示 **未定义（还未给出定义，以后可能会有定义）**。

```ts
const x: undefined = undefined;
```



## null 类型

null 类型也只包含一个值 null，表示为 **空（即此处没有值 ）**。

```ts
const x: null = null;
```



## any 类型

`any` 表示任意类型，适合不确定数据类型的情况。但使用时需要谨慎，因为 any 类型会绕过类型检查。

```ts
let x: any = "hello";
x = 100; // 允许
x = false; // 允许

const arrayList: any = [1, "hello", true];
arrayList[1] = "10"; // 允许
```



## void 类型

`void` 类型用于没有返回值的函数。

```ts
function logMessage(msg: string): void {
  console.log(msg);
}
```



## never 类型

never 类型表示不会有返回值，通常用于抛出错误或进入无限循环的函数，表示该函数用于不会正常结束。

```ts
// 返回 never 的函数必须存在无法达到的终点
function error(message: string): never {
  throw new Error(message);
}

// 推断的返回值类型为 never
function infiniteLoop(): never {
  while (true) {
  }
}
```
