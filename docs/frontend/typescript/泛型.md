# 泛型

泛型是一种编程语言特性，允许再定义函数、类、接口时使用 **占位符来表示类型**，而不是具体的类型。



## 泛型标识符

在泛型中，通常使用一些约定俗成的标识符：

| 标识符 | 描述                                     |
| :----: | ---------------------------------------- |
|   T    | 代表 Type，是最常见的泛型类型参数名      |
| K 和 V | 表示键（Key）和值（Value）的泛型参数类型 |
|   E    | 表示数组元素的泛型类型参数               |
|   R    | 表示函数返回值的泛型类型参数             |
| U 和 V | 表示第二、第三个泛型类型参数             |

::: code-group

```ts [T]
function getName<T>(name: T): T {
  return name;
}
```

```ts [K和V]
interface KeyValuePair<K, V> {
  key: K,
  value: V
}
```

```ts [E]
function printArray<E>(arr: E[]) {
  arr.forEach((item: E) => {
    console.log(item);
  })
}
```

```ts [R]
function getResult<R>(value: R): R {
  return value;
}
```

```ts [U和V]
function combine<U, V>(first: U, second: V): string {
  return `${first} ${second}`;
}
```

:::



## 泛型函数

使用泛型来创建一个可以处理不同类型的函数：

```ts {1}
function identity<T>(arg: T): T {
  return arg;
}

const res1 = identity<string>("hello");
console.log(res1); // 'hello'

const res2 = identity<number>(100);
console.log(res2); // 100
```



## 泛型接口

使用泛型来定义接口，使接口的成员能够使用任意类型：

```ts {1}
interface Pair<T, U> {
  first: T,
  second: U
}

const p: Pair<string, number> = {
  first: "tom",
  second: 100
}
console.log(p); // { first: 'tom', second: 100 }
```



## 泛型类

泛型也可以应用于类的实例变量和方法：

```ts
class Box<T> {
  private value: T;

  constructor(value: T) {
    this.value = value;
  }

  getValue(): T {
    return this.value;
  }
}

const box = new Box<string>("hello");
console.log(box.getValue()); // 'hello'
```



## 泛型约束

泛型约束可以用来显式泛型的类型范围：

```ts {5}
interface Length {
  length: number
}

function logLength<T extends Length>(arg: T) {
  console.log(arg.length);
}

logLength("hello"); // 5

logLength(100); // 类型报错：数字没有 length 属性
```



## 泛型默认值

泛型默认值用于在不指定类型参数时能够使用默认类型：

```ts {1}
function defaultValue<T = string>(arg: T) {
  console.log(arg);
}

defaultValue("hello"); // 推断为 string 类型
defaultValue(100); // 推断为 number 类型
defaultValue<number>(100); // 显式设置为 number 类型
```
