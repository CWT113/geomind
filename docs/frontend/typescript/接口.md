# 接口

接口（interface）主要用于定义 **对象** 必须包含哪些属性和方法，但不关心这些方法具体的实现。

接口和类型别名的对比：

|   比较维度   | 接口                           | 类型别名                                     |
| :----------: | :----------------------------- | :------------------------------------------- |
|   适用范围   | 仅限对象和函数                 | 任何类型（基础类型、联合类型、元组、对象等） |
|   扩展方式   | 使用 `extends` 关键字          | 使用交叉类型 `&`                             |
|   声明合并   | 支持（同名接口会自动合并）     | 不支持（同名 type 会报错）                   |
| 高级类型操作 | 不支持（如映射类型、条件类型） | 支持                                         |



## 声明方式

### 基本属性

```ts
interface User {
  username: string;
  // 可选属性
  age?: number;
  // 只读属性
  readonly sex: boolean;
  // 函数声明
  sayHi: (m: string) => string;
}
```



### 属性索引

属性索引共有 string、number 和 symcol 三种类型。

> [!WARNING] 注意
>
> 一个接口中，最多只能定义一个属性索引。该属性索引会自动约束该类型中其他的属性。

```ts {11,6}
interface User {
  age: number; // 类型报错
  sex: boolean; // 类型报错

  // 字符串索引限制了该类型中所有字段名称必须为 string，且类型也必须为 string
  [prop: string]: string;
}

interface MyArr {
  // 数值索引，其实就是指定了数组的类型
  [prop: number]: string;
}
const arr: MyArr = ['a', 'b', 'c'];
```



### 对象中的方法

当我们想在对象中声明一个方法的类型时，可以这样写：

::: code-group

```ts [基本使用] {3,8,13-15}
// 方法一（函数重载时使用）
interface User {
  sayHi(x: boolean): string;
}

// 方法二（常用）
interface User {
  sayHi: (x: boolean) => string;
}

// 方法三
interface User {
  sayHi: {
    (x: boolean): string
  }
}

const user: User = {
  sayHi(x: boolean) {
    return x ? "通过" : "拒绝";
  }
}

console.log(user.sayHi(true));
```

```ts [函数重载]
interface User {
  // 只能使用方法一的方式声明
  sayHi(): number;
  sayHi(x: boolean): boolean;
  sayHi(x: string, y: string): string;
}

// 单独给出函数方法的实现
function MyFunc(): number;
function MyFunc(x: boolean): boolean;
function MyFunc(x: string, y: string): string;
function MyFunc(x?: string | boolean, y?: string): number | boolean | string {
  if (x === undefined && y === undefined) return 1;

  if (typeof x === 'boolean' && y === undefined) return true;

  if (typeof x === 'string' && typeof y === 'string') return '1';

  throw new Error("parameters error");
}


const user: User = {
  sayHi: MyFunc
}

console.log(user.sayHi()); // 1
console.log(user.sayHi(true)); // true
console.log(user.sayHi("1", "2")); // '1'
```

:::



### 函数

接口也可以用来声明独立的函数。

```ts
interface Add {
  (x: number, y: number): number;
}

const myAdd: Add = (x, y) => x + y;
```



## 接口继承

### 继承 interface

接口可以使用 `extends` 关键字，继承其他接口。

```ts {10}
interface Shape {
  name: string;
}

interface Style {
  color: string;
}

// 同时继承多个接口，Circle 已同时拥有了 Shape 和 Style 中的属性
interface Circle extends Shape, Style {
  radius: number;
}
```

> [!WARNING] 注意
>
> 多重继承时，如果多个父接口中存在同名属性，那么这些同名属性的类型必须一致，否则报错。

```ts
interface Shape {
  id: string;
}

interface Style {
  id: number;
}

interface Circle extends Shape, Style { // 类型报错：继承属性 'id' 在 Shape 和 Style 中的类型不一致 // [!code --]
}
```



### 继承 Type

接口也可以继承 `type` 别名定义的 **对象类型**。

```ts
// type 定义的类型必须是对象才能被继承
type Country = {
  name: string;
  capital: string;
}

interface China extends Country {
  population: number;
}
```



### 继承 Class

接口还可以继承 `Class`，即继承该类的所有成员。

```ts {9}
class User {
  name: string = "";

  sayHi(): boolean {
    return true;
  }
}

interface P extends User {
  hobbies: string | string[]
}

// 实现类中就必须实现所有属性
const person: P = {
  name: "张三",
  hobbies: ["篮球", "足球"],
  sayHi: () => {
    return true;
  }
}
```
