# 闭包

闭包（Closure）是指 **函数能够访问其外部作用域中变量的特性**，即使这个外部函数已经返回或执行完毕。

合理使用闭包可以实现数据封装、状态管理和模块化，但需要特别注意避免内存泄漏的问题。



> [!TIP] 💡 闭包的工作原理
>
> 当一个函数定义在另一个函数内部时，内部函数会形成一个闭包。这个闭包会：
>
> 1. 捕获外部函数的变量和参数；
> 2. 即使外部函数执行完毕，这些变量仍然保持在内存中；
> 3. 内部函数可以继续访问和修改这些变量；

> [!NOTE] 🎖️ 优点
>
> - 数据封装：可以创建私有变量，防止外部访问；
> - 延长变量生命周期：保持变量在内存中，实现状态持久化；
> - 模块化：创建独立的作用域，避免命名冲突；
> - 函数工厂：动态生成函数，提高代码复用性；

> [!CAUTION] ⚠️ 缺点
>
> - 内存泄漏：如果闭包引用的变量过大或过多，可能导致内存占用增加；
> - 性能影响：闭包会比普通函数占用更多的内存；
> - 代码复杂度：过度使用闭包可能使代码难以理解和维护；

```js
function outer() {
  let count = 0;
  
  function inner() {
	count++;
	console.log(count);
  }
  
  // 返回内部函数
  return inner;
}

const counter = outer();
counter(); // 1
counter(); // 2
counter(); // 3
```



## 闭包使用场景

### 数据封装和私有变量

JavaScript 中没有 private 私有变量的说法，但可以通过闭包实现私有变量的效果。

```js
function outer() {
  // 外部无法访问到 count 变量
  let count = 0;
  
  return {
	increment() {
	  count++;
	  return count;
	},
	decrement() {
	  count--;
	  return count;
	},
	getCount() {
	  return count;
	}
  }
}

const counter = outer();
console.log(counter.increment()); // 1
console.log(counter.increment()); // 2
console.log(counter.decrement()); // 1
console.log(counter.getCount());  // 1
```



### 函数工厂

```js
function createGreeting(greeting) {
  return function (name) {
	return `${greeting}, ${name}!`;
  };
}

const sayHello = createGreeting("Hello");
console.log(sayHello("Alice")); // "Hello, Alice!"

const sayHi = createGreeting("Hi");
console.log(sayHi("Bob")); // "Hi, Bob!"
```



### 事件处理

```js {22}
// 避免内存泄漏的写法（提供清理函数）
function setupEventListeners() {
  let count = 0;
  
  const button = document.getElementById("btn");
  
  function handler() {
	count++;
	console.log("按钮被点击了 " + count + " 次");
  }
  
  button.addEventListener("click", handler);
  
  // 返回清理函数
  return function () {
	button.removeEventListener("click", handler);
  };
}

const cleanup = setupEventListeners();
```
