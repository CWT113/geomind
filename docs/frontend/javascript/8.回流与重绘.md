# 回流与重绘

回流（Reflow）和重绘（Repaint）是浏览器渲染页面时的两个重要过程。

它们的核心区别是：

- **回流**：元素的几何属性发生变化，浏览器需要重新计算布局；
- **重绘**：元素的颜色等外观属性发生变化，不影响布局，浏览器只需要更新绘制结果；

重点理解：**回流通常会引起重绘，但重绘不一定引起回流**。



## 回流

当 DOM 元素的尺寸、位置或者页面布局发生变化时，浏览器需要重新计算元素的几何信息，这个过程就是回流。

> [!NOTE] 场景的回流操作
>
> - 修改元素的 `width`、`height`、`margin`、`padding` 等布局属性；
> - 添加、删除影响布局的 DOM 元素；
> - 改变字体大小、文字内容导致元素尺寸变化；
> - 改变浏览器窗口大小；

```javascript
const box = document.querySelector(".box");

// 修改宽度，触发回流
box.style.width = "300px";
// 修改高度，触发回流
box.style.height = "200px";
// 修改内边距，可能触发回流
box.style.padding = "20px";
```



## 重绘

当元素的外观发生变化，但不影响元素的大小和位置时，浏览器不需要重新计算布局，只需要重新绘制相关内容，这个过程叫重绘。

```javascript
const box = document.querySelector(".box");

// 修改背景颜色，触发重绘
box.style.backgroundColor = "red";
// 修改文字颜色，触发重绘
box.style.color = "white";
// 修改边框颜色，触发重绘
box.style.borderColor = "blue";
```

> [!CAUTION] 注意
>
> `border-color` 通常只需要重绘，但修改 `border-width` 可能会影响布局，引发回流。



## 如何减少回流和重绘？

### 避免频繁修改布局属性

不推荐：

```javascript
for (let i = 0; i < 100; i++) {
  box.style.width = `${100 + i}px`;
}
```

这里发生了 100 次样式修改，但不代表浏览器一定执行 100 次回流，因为浏览器可能会批量处理。



### 避免布局抖动

不推荐：

```javascript
for (let i = 0; i < 100; i++) {
  // 先修改布局
  box.style.width = `${100 + i}px`;
  // 再读取布局信息
  console.log(box.offsetWidth);
}
```

每次修改后立即读取布局信息，容易引起强制同步布局，性能开销很大。



### 动画优先使用 transform

不推荐：

```javascript
// 改变 left，可能触发回流
box.style.left = "200px";
```

推荐：

```javascript
// transform 通常不触发回流
box.style.transform = "translateX(200px)";
```

对于动画，优先使用 `transform` 和 `opacity`，通常可以获得更好的渲染性能。
