# 嫌隙小记

## 对象判空

``` typescript
function isEmpty(obj: object) {
  return obj && typeof obj === "object" && Reflect.ownKeys(obj).length === 0;
  // 常规对象判空完全够用，但有特殊情况会存在误判（详见误判案例）
  // return obj && typeof obj === "object" && Object.keys(obj).length === 0;
}

console.log(isEmpty({})); // true
console.log(isEmpty({ a: 1 })); // false
console.log(isEmpty({ a: null })); // false
console.log(isEmpty({ a: undefined })); // false
```

> [!NOTE] `Reflect.ownKeys()` 详解
>
> `Reflect.ownKeys()` 是 ES6 `Reflect` API 中的一个方法，用来获取 **对象所有的自有属性键**，包括：
> - 字符串键
> - Symbol键
> - 可枚举和不可枚举属性
>
> 这使得它比 `Object.keys()` 更加全面。

:::details 特殊误判案例
`Object.keys(obj).length === 0` 可以判断常规的对象，但是以下几种特殊情况却会误判。

:::code-group

``` typescript [属性值不可枚举]
const obj1 = {};
Object.defineProperty(obj1, "a", {
  value: 1,
  enumerable: false, // 不可枚举
});
console.log(obj1); // { a: 1 }
console.log(isEmpty(obj1)); // true
```

``` typescript [Symbol类型为键]
// Object.keys() 不返回 Symbol 类型的键
const obj2 = {
  [Symbol("a")]: 1,
};
console.log(obj2); // { a: 1 }
console.log(isEmpty(obj2)); // true
```

``` typescript [无原型对象]
// 虽然是空对象，但是它没有 原型链、toString 等方法
const obj = Object.create(null);
console.log(obj); // {}
console.log(isEmpty(obj)); // true
```

``` typescript [Proxy做代理]
// 😂😂 如果用 Proxy 做了代理，两种方法都无法判断
const obj = new Proxy({ a: 1 }, {
  ownKeys() {
    return [];
  },
});
console.log(obj); // { a: 1 }
console.log(isEmpty(obj)); // true
```

:::

## 页面可见性API

`Page Visibility API` （页面可见性 API） 专门用于 **检测浏览器当前页面是否被隐藏或显示**，非常适合处理用户切换标签页、最小化窗口等场景。

> [!NOTE] 使用场景
>
> - 暂停 / 播放视频或音频；
> - 停止 / 启动动画或轮播图；
> - 暂停轮询服务器请求，在页面恢复可见时再继续；

```javascript
document.addEventListener("visibilitychange", () => {
  if (document.hidden) {
	console.log("用户离开了当前页面（切换标签页或最小化）~~")
  } else {
	console.log("用户回到了当前页面~~")
  }
})
```
