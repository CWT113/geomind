# 防抖与节流

防抖（Debounce）和节流（Throttle）都是用于控制函数执行频率的技术，常用于优化高频出发的事件。

它们的核心区别是：

- **防抖**：连续触发事件时不断重置定时器，只有停止触发达到指定时间后才执行，常用于 搜索框输入；
- **节流**：在规定时间间隔内最多执行一次函数，通常通过时间戳或定时器实现，常用于滚动监听、鼠标移动等；

简单来说，防抖关注最后一次触发，节流关注执行频率。



## 防抖

```javascript
function debounce(fn, delay = 300) {
  let timer = null;

  return function (...args) {
    // 清理上一次的定时器
    clearTimeout(timer);

    timer = setTimeout(() => {
      fn.apply(this, ...args);
    }, delay);
  };
}

// 使用方式
const search = debounce((value) => {
  console.log("搜索内容：", value);
});

// 如果下面的四个调用都发生在 500ms 内，最终只输出 Vue3
search("v");
search("vu");
search("vue");
search("vue3");
```





## 节流

```javascript
function throttle(fn, delay = 1000) {
  let lastTime = 0;

  return function (...args) {
    const now = Date.now();
    if (now - lastTime > delay) {
      lastTime = now;
      fn.apply(this, args);
    }
  };
}

// 使用方式
const handleScroll = throttle(() => {
  console.log("滚动事件执行");
});

window.addEventListener("scroll", handleScroll);
```
