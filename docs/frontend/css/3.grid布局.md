# Grid 布局

Flex 布局是 **轴线布局**，只能指定“项目”针对轴线的位置，可以看作是一维布局。而 Grid 布局则是 **将容器划分为“行”和“列”**，产生单元格，然后指定“项目”所在的单元格，可以看作是二维布局。



## 基本概念

采用网格布局的区域，称为“容器”（container）。容器内采用网格定位的子元素，称为“项目”（item）。

容器里面的水平区域称为“行”（row），垂直区域称为“列”（column）。

## 容器的属性

### grid-template-columns

此属性用于定义每一列的列宽。

```css
.container {
  display: grid;
  /* 使用具体像素布局 */
  grid-template-columns: 100px 100px 100px;
  /* 使用百分比布局 */
  grid-template-columns: 33.33% 33.33% 33.33%;
  /* 使用 auto 自动布局 */
  grid-template-columns: auto auto auto;
}
```



### grid-template-rows

此属性用于定义每一行的行高。

```css
.container {
  display: grid;
  /* 使用具体像素布局 */
  grid-template-rows: 100px 100px 100px;
  /* 使用百分比布局 */
  grid-template-rows: 33.33% 33.33% 33.33%;
  /* 使用 auto 自动布局 */
  grid-template-rows: auto auto auto;
}
```



#### repeat 函数

`repeat` 函数用于简化重复的值。

```css
.container {
  display: grid;
  /* grid-template-columns: 100px 100px 100px; */
  /* grid-template-rows: 100px 100px 100px; */

  /* 使用 repeat() 简化后 */
  grid-template-columns: repeat(3, 100px); /* 重复3个100px */
  grid-template-rows: repeat(3, 100px);
}
```



#### minmax 函数

`minmax` 函数 **产生一个长度范围**，表示长度就在这个范围之中。

```css
.container {
  display: grid;
  /* 第三列最小100px，最大1fr */
  grid-template-columns: 1fr 1fr minmax(100px, 1fr);
}
```



#### fr 关键字

为了方便表示 **比例关系**，网格布局提供了 `fr` 关键字。如果两列的宽度分别为 `1fr` 和 `2fr`，就表示后者是前者的两倍。

```css
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  /* 搭配具体的 px 像素值使用 */
  grid-template-columns: 100px 2fr 1fr;
}
```

上面的代码表示第一列 100px，中间一列的宽度是第三列的两倍。



#### auto 关键字

`auto` 关键字表示由浏览器自己决定长度。

```css
.container {
  display: grid;
  grid-template-rows: auto auto auto;
  grid-template-columns: auto auto auto;
}
```



#### auto-fill 关键字

有时，单元格的大小是固定的，但是容器的大小不确定。如果希望每一行（或每一列）容器容纳尽可能多的单元格，就可以使用 `auto-fill` 关键字表示 **自动填充**。

```css
.container {
  display: grid;
  grid-template-columns: repeat(auto-fill, 100px);
}
```

上面的代码表示每列的宽度为 100px，然后自动填充，直到容器不能放置更多的列（缩放浏览器宽度查看效果）。



### row-gap

> [!NOTE]
>
> 旧属性名 `grid-row-gap` 已被废弃，CSS 把 Grid 和 Flex 的间距属性统一了，不再只服务于 Grid，所以去掉了 `grid-` 前缀。

此属性用于设置行与行的间距（行间距）。

```css
.container {
  display: grid;
  row-gap: 10px;
}
```



### column-gap

此属性用于设置列与列的间距（列间距）。

```css
.container {
  display: grid;
  column-gap: 20px;
}
```



### gap

此属性是 `grid-row-gap` 和 `grid-column-gap` 的合并简写形式。

```css
.container {
  display: grid;
  column-gap: 10px 20px;
}
```
