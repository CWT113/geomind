# 工程配置

新建一个 Maven 工程，要求如下：

- JDK：Java17+（Spring6 要求 SDK 最低版本是 Java17）
- Maven：3.6+
- Spring：6.2.19



## 基础示例

第一步：在 `pom.xml` 中引入 `Spring-context` 和 `junit-jupiter-api` 核心依赖。

::: code-group

```xml [pom.xml]
<dependencies>
  <!-- 引入 SpringContext 依赖，表示将 Spring 的基础依赖引入了 -->
  <dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-context</artifactId>
    <version>6.2.19</version>
  </dependency>
  <!-- 引入 Junit5 单元测试依赖 -->
  <dependency>
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter-api</artifactId>
    <version>5.14.4</version>
    <scope>test</scope>
  </dependency>
</dependencies>
```

:::

第二步：创建 `HelloWorld` 类，并与 `java` 目录平级新建 `resources` 文件夹，新增 `application.xml`，通过 XML 的方式管理 Bean。

::: code-group

```xml {11} [application.xml]
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
    <!--
        配置 HelloWorld 所对应的 Bean，意为将 HelloWorld 对象交给 Spring 的容器管理。
        属性详解：
          - id：设置 Bean 的唯一标识，采用小驼峰命名方式
          - class：设置 Bean 所对应类型的全类名
     -->
    <bean id="helloWorld" class="com.example.beans.HelloWorld"/>
</beans>
```

```java [HelloWorld]
public class HelloWorld {
  public void sayHello() {
    System.out.println("Hello World!");
  }
}
```

:::

第三步：创建 `HelloWorldTest` 测试类，测试 `HelloWorld` 类是否被成功注册。

```java {7,9} [HelloWorldTest]
public class HelloWorldTest {
  @Test
  @DisplayName("通过XML配置读取并获取Bean")
  void testHelloWorld() {
    // 根据 application.xml 创建并初始化 IoC 容器
    // Spring 会解析该 XML 文件，读取其中配置的 Bean 依赖关系，并实例化这些对象
    ClassPathXmlApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
    // 从 Spring 容器中提取 id 为 helloWorld 的 Bean 实例
    HelloWorld helloWorld = (HelloWorld) context.getBean("helloWorld");
    // 调用实例方法
    helloWorld.sayHello();
  }
}
```





## 原理分析

>💡 问题 1：底层是如何创建类的，为什么能够调用类的方法？

修改 `HelloWorld` 类，为其新增无参构造方法：

```java
public class HelloWorld {
  public HelloWorld() {
    System.out.println("无参构造函数");
  }

  public void sayHello() {
    System.out.println("Hello World!");
  }
}
```

运行单元测试之后查看控制台，发现输出了 “无参构造函数”，因此可知它底层本质是通过反射机制调用了无参构造函数创建类的。



>💡 问题 2：Spring 是如何创建对象的呢，底层原理是什么？

```java
// 解析 application.xml 文件，从中获取 class 属性值，类的全类名
// 通过反射机制调用无参数构造方法创建对象
Class clazz = Class.forName("com.example.beans.HelloWorld");
Object object = clazz.getDeclaredConstructor().newInstance();
```



>💡 问题 3：Spring 底层把创建好的对象存储到一个什么样的数据结构中了呢？

```java
private final Map<String, BeanDefinition> BeanDefinitionMap = new ConcurrentHashMap<>(256);
```

Spring 容器加载到 Bean 时，会把这个类的描述信息，以包名加类名的方式存到 `BeanDefinitionMap` 中。

`Map<String, BeanDefinition>` 其中 String 是 Key，默认是类名首字母小写，BeanDefinition 是 Bean 的定义对象。



## 配置 Log4j2 日志

Log4j2 是一个开源的日志组件，可以用来记录系统行为的时间、等级、详情信息等相关内容。

Log4j2 的日志信息优先级如下：

| 日志等级（从低到高） | 描述                                           |
| :------------------: | ---------------------------------------------- |
|        TRACE         | 追踪信息，最低的日志级别，相当于追踪程序的执行 |
|        DEBUG         | 调试信息                                       |
|         INFO         | 基本信息                                       |
|         WARN         | 警告信息                                       |
|        ERROR         | 错误信息                                       |
|        FATAL         | 严重错误信息                                   |



需要注意的是，级别高的会自动屏蔽级别低的日志，即设置了 ERROR 的日志，INFO、WARN 级别的日志不会显示。



### 引入依赖

在 `pom.xml` 中引入 `log4j-core` 和 `log4j-slf4j2-impl` 依赖：

```xml
<dependencies>
  <!-- 引入 log4j 依赖 -->
  <dependency>
    <groupId>org.apache.logging.log4j</groupId>
    <artifactId>log4j-core</artifactId>
    <version>2.26.1</version>
  </dependency>
  <dependency>
    <groupId>org.apache.logging.log4j</groupId>
    <artifactId>log4j-slf4j2-impl</artifactId>
    <version>2.26.1</version>
  </dependency>
</dependencies>
```





### 添加配置文件

在 `resources` 文件夹下新建 `log4j2.xml` 配置文件：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Configuration status="WARN"
               xmlns="https://logging.apache.org/xml/ns"
               xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
               xsi:schemaLocation="https://logging.apache.org/xml/ns
                                   https://logging.apache.org/xml/ns/log4j-config-2.xsd">
  <Appenders>
    <!-- 1.输出日志信息到控制台 -->
    <Console name="Console" target="SYSTEM_OUT">
      <!-- <PatternLayout pattern="%d{yyyy-MM-dd HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n"/> -->
      <PatternLayout
                     pattern="%style{%d{yyyy-MM-dd HH:mm:ss.SSS}}{cyan} %style{[%t]}{green} %style{%-5level}{blue} %style{%logger{36}}{magenta} - %msg%n"/>
    </Console>

    <!-- 2.输出日志到单个文件 -->
    <!--
        参数解释：
          - fileName：日志文件的保存路径及文件名
          - append：是否将日志追加至文件内，true：追加写入，false：重启应用时清空重写
     -->
    <File name="SingleFile" fileName="logs/app.log" append="true">
      <PatternLayout pattern="%d{yyyy-MM-dd HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n"/>
    </File>

    <!-- 3.滚动输出日志到多个文件 -->
    <RollingFile name="RollingFile" fileName="logs/app.log" filePattern="logs/app-%d{yyyy-MM-dd}-%i.log.gz">
      <PatternLayout pattern="%d{yyyy-MM-dd HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n"/>

      <!-- 历史日志清理策略 -->
      <DefaultRolloverStrategy max="30"> <!-- max="30" 表示同一天/同一个周期内最多保留 30 个序号的文件（%i从1到30） -->
        <!-- 自动删除超过 30 天的历史日志文件 -->
        <Delete basePath="logs" maxDepth="1">
          <IfFileName glob="app-*.log.gz"/>
          <IfLastModified age="30d"/>
        </Delete>
      </DefaultRolloverStrategy>

      <!-- 触发滚动策略 -->
      <Policies>
        <!-- 基于时间的滚动策略：interval="1" 表示按照 filePattern 中的最小单位递增 1 触发（此处是每天递增） -->
        <TimeBasedTriggeringPolicy interval="1" modulate="true"/>
        <!-- 基于文件大小的滚动策略：size="10 MB" 表示单文件达到10MB后触发滚动 -->
        <SizeBasedTriggeringPolicy size="1KB"/>
      </Policies>
    </RollingFile>
  </Appenders>

  <Loggers>
    <!-- 全局日志级别 -->
    <Root level="DEBUG">
      <AppenderRef ref="Console"/>
      <AppenderRef ref="SingleFile"/>
      <AppenderRef ref="RollingFile"/>
    </Root>
  </Loggers>
</Configuration>
```



### 使用日志

```java
public class HelloWorldTest {
  private Logger logger = LoggerFactory.getLogger(HelloWorldTest.class);

  @Test
  @DisplayName("通过XML配置读取并获取Bean")
  void testHelloWorld() {
    // 根据 application.xml 创建并初始化 IoC 容器
    // Spring 会解析该 XML 文件，读取其中配置的 Bean 依赖关系，并实例化这些对象
    ClassPathXmlApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
    // 从 Spring 容器中提取 id 为 helloWorld 的 Bean 实例
    HelloWorld helloWorld = (HelloWorld) context.getBean("helloWorld");
    // 调用实例方法
    helloWorld.sayHello();

    logger.info("单元测试成功！");
    logger.warn("单元测试异常！");
    logger.error("单元测试错误！");
  }
}
```
