# Junit

在之前的测试方法中，几乎都能看到下面的两行代码：

```java
// XML方式获取
ApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
HelloWorld helloWorld = (HelloWorld) context.getBean("helloWorld");

// 注解方式获取
ApplicationContext context = new AnnotationConfigApplicationContext(AppConfig.class);
Calculator calculator = context.getBean(HelloWorld.class);
```

这两行代码的主要作用是创建 Spring 容器，然后获取容器内管理的对象，但是每次测试都需要重复编写。

针对这个问题，Spring 集成了 Junit 测试，可以通过配置来实现容器创建。



## 引入依赖

```xml
<dependencies>
  <!-- 引入 spring-test 依赖 -->
  <dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-test</artifactId>
    <version>${spring.version}</version>
  </dependency>
  <!-- 引入 junit6 依赖 -->
  <dependency>
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter-api</artifactId>
    <version>6.1.3</version>
    <scope>test</scope>
  </dependency>
</dependencies>
```



## 添加配置文件

```java [AppConfig]
@Configuration
@ComponentScan("com.example")
public class AppConfig {
}
```





## 创建 service

```java
public interface Calculator {
  int add(int a, int b);
}

@Service
public class CalculatorImpl implements Calculator {
  @Override
  public int add(int a, int b) {
    return a + b;
  }
}
```



## 单元测试

使用组合注解 `@SpringJUnitConfig` 指定配置类 `AppConfig.class`，在测试属性上直接使用 `@Autowired` 注入目标组件：

```java {1,2,7}
@ExtendWith(SpringExtension.class)
@ContextConfiguration(classes = AppConfig.class)
// 等价于上面两行
@SpringJUnitConfig(AppConfig.class) // [!code ++]
public class CalculatorTest {
  @Autowired
  private Calculator calculator; // 直接注入 Spring 容器管理的 Bean

  @Test
  void testCalculator() {
    int added = calculator.add(1, 3);
    Assertions.assertEquals(4, added);
  }
}
```
