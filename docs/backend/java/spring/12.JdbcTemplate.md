# JdbcTemplate

JdbcTemplate 是 Spring 框架（Spring-jdbc 模块）提供的一个核心类，用于简化传统的 JDBC 数据库操作。

它采用模板方法设计模式，封装了繁琐且重复的底层数据库样板代码，让开发者只需专注于编写 SQL 语句和处理业务数据。

> [!NOTE] 核心作用
>
> - **自动化资源管理**：自动获取和释放数据库连接、语句及结果集，防止连接泄露；
> - **异常体系转换**：将底层的检查型异常 SQLException 转换为 Spring 统一的非检查型异常（DataAccessException），无需强制 try-catch；
> - **便捷的对象映射**：配合 `RowMapper` 或 `BeanPropertyRowMapper`，可一行代码将结果自动转为 Java Bean；
> - **无缝整合事务**：与 Spring 的声明式事务（如 `@Transactional`）天然兼容；

```sql
CREATE DATABASE `demo`;
```

## 创建 Druid 配置类

创建 Druid 和 JdbcTemplate 配置类：

::: code-group

```java {2,18,29} [SpringConfig]
@Configuration
@PropertySource("classpath:db.properties") // 注入 db.properties 配置文件
public class SpringConfig {
  @Value("${jdbc.url}")
  private String url;

  @Value("${jdbc.driver}")
  private String driverClassName;

  @Value("${jdbc.username}")
  private String username;

  @Value("${jdbc.password}")
  private String password;

  @Bean
  public DataSource druidDataSource() {
    DruidDataSource dataSource = new DruidDataSource();
    dataSource.setUrl(url);
    dataSource.setDriverClassName(driverClassName);
    dataSource.setUsername(username);
    dataSource.setPassword(password);
    return dataSource;
  }

  // Spring会自动将上面定义的 druidDataSource 注入到参数中
  @Bean
  public JdbcTemplate jdbcTemplate(DataSource dataSource) {
    return new JdbcTemplate(dataSource);
  }
}
```

```java [AppConfig]
@Configuration
@ComponentScan("com.example")
public class AppConfig {
}
```

```properties [db.properties]
jdbc.username=root
jdbc.password=1234
jdbc.url=jdbc:mysql://localhost:3306/demo
jdbc.driver=com.mysql.cj.jdbc.Driver
```

:::





## 增删改操作

```java {4,10,18,26}
@SpringJUnitConfig(AppConfig.class)
public class JdbcTemplateTest {
  @Autowired
  private JdbcTemplate jdbcTemplate; // 注入JdbcTemplate对象

  // 增
  @Test
  void testInsert() {
    String sql = "insert into t_emp values(null, ?, ?, ?)";
    int affectRows = jdbcTemplate.update(sql, "张凌赫", 29, "男");
    Assertions.assertEquals(1, affectRows);
  }

  // 删
  @Test
  void testDelete() {
    String sql = "delete from t_emp where id = ?";
    int affectRows = jdbcTemplate.update(sql, 6);
    Assertions.assertEquals(1, affectRows);
  }

  // 改
  @Test
  void testUpdate() {
    String sql = "update t_emp set name = ? where id = ?";
    int affectRows = jdbcTemplate.update(sql, "童锦程789", 2);
    Assertions.assertEquals(1, affectRows);
  }
}
```





## 查询单个对象

::: code-group

```java [JdbcTemplateTest] {9}
@SpringJUnitConfig(AppConfig.class)
public class JdbcTemplateTest {
  @Autowired
  private JdbcTemplate jdbcTemplate; // 注入JdbcTemplate对象

  @Test
  void testQuerySingleRow() {
    String sql = "select * from t_emp where id = ?";
    Employee employee = jdbcTemplate.queryForObject(sql, new BeanPropertyRowMapper<>(Employee.class), 1);
    System.out.println(employee);
  }
}
```

```java [Employee]
@Data
@NoArgsConstructor
@AllArgsConstructor
public class Employee {
  private Integer id;

  private String name;

  private String age;

  private String sex;
}
```
