# 手写容器

手写简易版 Spring 容器主要依赖于两个核心 Java 特性：**自定义注解**（Annotations）和 **反射机制**（Reflection）。

> [!NOTE] 核心思路
>
> 扫描标记了自定义注解的类，通过反射实例化它们存入一个 Map（Bean 容器），然后再遍历这些实例，把带有注入注解的属性通过反射赋值。



## 自定义注解

创建两个注解，一个用来标记类让容器管理（类似 `@Component`），另一个用来标记需要注入的属性（类似 `@Autowired`）。

::: code-group

```java [MyComponent]
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
public @interface MyComponent {
}
```

```java [MyAutowired]
@Target({ElementType.FIELD})
@Retention(RetentionPolicy.RUNTIME)
public @interface MyAutowired {
}
```

:::



## 创建业务测试类

创建 `UserService` 和 `UserDao` 两个服务类，然后通过自定义的注解将其加入容器并注入依赖。

::: code-group

```java [UserService] {5,7,8}
public interface UserService {
  void save();
}

@MyComponent // 告诉容器自动进行管理
public class UserServiceImpl implements UserService {
  @MyAutowired // 使用自定义注解将其注入依赖
  private UserDao userDao;

  @Override
  public void save() {
    this.userDao.save();
    System.out.println("UserServiceImpl执行结束");
  }
}

```

```java [UserDao] {5}
public interface UserDao {
  void save();
}

@MyComponent
public class UserDaoImpl implements UserDao {
  @Override
  public void save() {
    System.out.println("UserDaoImpl执行结束");
  }
}
```

## 实现IoC容器

容器初始化分为两步：实例化 Bean 和 依赖注入。

::: code-group

```java
public class AnnotationApplicationContext implements ApplicationContext {
  // 存放所有 Bean 的容器
  private final Map<Class<?>, Object> beanFactory = new HashMap<>();

  private static String rootPath;

  /**
   * 获取 Bean 对象
   *
   * @param clazz Bean.Class
   */
  @Override
  public Object getBean(Class<?> clazz) {
    return beanFactory.get(clazz);
  }

  /**
   * 根据包路径扫描加载 Bean
   *
   * @param basePackage 包路径
   */
  public AnnotationApplicationContext(String basePackage) {
    try {
      // 把 com.example.service 格式的包路径，修改为 com/example/service 格式的文件夹路径
      String packageDirName = basePackage.replace('.', '/');
      // 获取包在类路径（ClassPath）中的实际URL
      Enumeration<URL> dirs = Thread.currentThread().getContextClassLoader().getResources(packageDirName);
      while (dirs.hasMoreElements()) {
        URL url = dirs.nextElement();
        // 对 URL 进行 UTF-8 编码，解决空格或中文乱码问题
        String filePath = URLDecoder.decode(url.getFile(), StandardCharsets.UTF_8);
        // 拿到ClassPath根路径
        rootPath = filePath.substring(0, filePath.length() - packageDirName.length());
        loadBean(new File(filePath));
      }
    } catch (IOException e) {
      throw new RuntimeException(e);
    }

    loadDI();
  }

  /**
   * 加载 Bean 到容器中
   *
   * @param fileParent 扫描的包路径
   */
  private void loadBean(File fileParent) {
    if (fileParent.isDirectory()) {
      File[] childrenFiles = fileParent.listFiles();
      if (childrenFiles == null || childrenFiles.length == 0) {
        return;
      }

      for (File child : childrenFiles) {
        if (child.isDirectory()) {
          loadBean(child);
        } else {
          // 如果是文件，裁剪掉前面的根路径，只保留包路径部分
          String pathWithClass = child.getAbsolutePath().substring(rootPath.length() - 1);
          // 检查文件后缀是否为 Java 编译后的字节码文件
          if (pathWithClass.contains(".class")) {
            // 把路径分隔符 \ 替换为包名分隔符 .，并去掉 .class 后缀，还原成全类名，如 com.example.service.UserService
            String fullName = pathWithClass.replaceAll("\\\\", ".").replace(".class", "");
            try {
              // 使用反射根据全类名加载 Class 对象到 JVM 中
              Class<?> aClass = Class.forName(fullName);
              if (!aClass.isInterface()) {
                // 获取该类上标注的 @MyComponent 自定义注解
                MyComponent annotation = aClass.getAnnotation(MyComponent.class);
                if (annotation != null) {
                  // 通过反射调用无参构造函数创建该类的实例
                  Object instance = aClass.getDeclaredConstructor().newInstance();
                  if (aClass.getInterfaces().length > 0) {
                    System.out.println("正在加载【" + aClass.getInterfaces()[0] + "】，实例对象是：" + instance.getClass().getName());
                    // 如果有接口，把接口的 class 当作 key，实例对象当成 value
                    beanFactory.put(aClass.getInterfaces()[0], instance);
                  } else {
                    System.out.println("正在加载【" + aClass.getName() + "】，实例对象是：" + instance.getClass().getName());
                    // 如果没有接口，就把自己的 class 当作 key，实例对象当成 value
                    beanFactory.put(aClass, instance);
                  }
                }
              }
            } catch (Exception e) {
              throw new RuntimeException(e);
            }
          }
        }
      }
    }
  }

  /**
   * 实现依赖注入
   */
  private void loadDI() {
    // 遍历容器beanFactory中存放的所有 Bean 实体键值对
    for (Map.Entry<Class<?>, Object> entry : beanFactory.entrySet()) {
      // 获取当前遍历到的对象实例
      Object obj = entry.getValue();
      // 获取该对象实例的 Class 类型
      Class<?> aClass = obj.getClass();
      // 获取该类中声明的所有属性字段
      Field[] declaredFields = aClass.getDeclaredFields();
      for (Field field : declaredFields) {
        MyAutowired annotation = field.getAnnotation(MyAutowired.class);
        if (annotation != null) {
          field.setAccessible(true);
          try {
            /**
			 			 * 核心注入逻辑：
			       * - field.getType()：获取属性的类型（如 UserService）
			       * - beanFactory.get(field.getType())：从容器中根据类型拿出对应的依赖实例对象
			       * - field.set()：将拿到的依赖实例对象，赋值给当前的属性字段
			       */
            field.set(obj, beanFactory.get(field.getType()));
          } catch (IllegalAccessException e) {
            throw new RuntimeException(e);
          }
        }
      }
    }
  }
}
```

```java [ApplicationContext]
  Object getBean(Class<?> clazz);
}
```

## 测试运行

自动扫描包路径下的所有类，实现依赖注入。

```java
@Test
void testSpring() {
  ApplicationContext context = new AnnotationApplicationContext("com.example");
  UserService userService = (UserService) context.getBean(UserService.class);
  userService.save();
  System.out.println(userService);
}
```
