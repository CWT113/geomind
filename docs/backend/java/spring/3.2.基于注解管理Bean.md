# 基于注解管理 Bean

Spring 从 2.5 版本开始，提供了通过注解管理 Bean 的方式，简化 XML 的配置。Spring 提供了多个注解，注解可以直接标注在 Java 类上，将它们定义成 Spring Bean。

|    注解     | 说明                                                         |
| :---------: | ------------------------------------------------------------ |
| @Controller | 用在 Controller 控制层，将控制层的类标记为 Bean，其功能与 @Component 相同 |
|  @Service   | 用在 Service 业务层，将业务层的类标记为 Bean，其功能与 @Component 相同 |
| @Repository | 用在 Dao 数据访问层，将访问层的类标记为 Bean，其功能与 @Component 相同 |
| @Component  | 该注解是通用注解，可以用在任意层，仅表示被标注的类是一个 Bean |



## 开启组件扫描

Spring 默认不使用注解装配 Bean，因此需要 **手动开启组件扫描** 功能。开启此功能后，Spring 会 **自动扫描指定的包及其子包下的所有类**，如果类上使用了 `@Component` 注解，该类就会被装配到容器中。

```java {3,6,9,10,13,14,15}
@Configuration
// 基础配置
@ComponentScan("com.example")

// 扫描特定包下的文件
@ComponentScan({"com.example.controller", "com.example.service"})

// 排除特定的组件
@ComponentScan(basePackages = "com.example",
               excludeFilters = @ComponentScan.Filter(type = FilterType.ANNOTATION, classes = Service.class)) // 排除所有 @Service 注解标注的类

// 仅包含特定的组件
@ComponentScan(basePackages = "com.example",
               useDefaultFilters = false, // 关闭默认的全量扫描规则
               includeFilters = @ComponentScan.Filter(type = FilterType.ANNOTATION, classes = Controller.class)) // 仅扫描 @Controller 注解标注的类
public class Application {
  public static void main(String[] args) {
    ApplicationContext context = new AnnotationConfigApplicationContext(Application.class);
    UserController userController = context.getBean(UserController.class);
    System.out.println(userController);
    UserService userService = context.getBean(UserService.class);
    System.out.println(userService);
  }
}
```





## `@Autowired` 注入

`@Autowired` 是用于实现依赖注入的核心注解。它的作用是让 Spring 容器 **自动将所需的对象装配到当前类中**，而无需手动编写 `new` 语句来创建对象。

```java
@Target({ElementType.CONSTRUCTOR, ElementType.METHOD, ElementType.PARAMETER, ElementType.FIELD, ElementType.ANNOTATION_TYPE}) // 指定可以标注的位置
@Retention(RetentionPolicy.RUNTIME) // 指定生命周期
@Documented // 生成文档
public @interface Autowired {
  // 注入时是否要求被注入的 Bean 必须存在，不存在则报错，默认true
  boolean required() default true;
}
```



### 属性注入

属性注入是直接标注在成员变量上，代码简洁，但不利于脱离 Spring 容器单独进行单元测试。

::: code-group

```java [UserControllerTest] {1,2,6}

@ComponentScan("com.example") // 扫描 com.example 包下的所有类
public class UserControllerTest {
  @Test
  void testUserController() {
    ApplicationContext context = new AnnotationConfigApplicationContext(UserControllerTest.class);
    UserController userController = context.getBean(UserController.class);
    userController.addUser();
  }
}
```

```java [UserController] {1,3,4}

  private UserService userService;
```

### 构造器注入

>
> 当有参构造函数只有一个时，`@Autowired` 注解可以省略。但是有多个构造函数时不能省略，否则报错！

### 联合 `@Qualifier` 注解

当 Spring 容器中存在多个相同类型的 Bean 时，仅靠 `@Autowired`（默认按类型查找）会导致 Spring 无法确定使用哪一个，从而抛出 `NoUniqueBeanDefinitionException` 异常。这时就需要配合 `@Qualifier` 指定唯一的 Bean 名称。

::: code-group

```java [UserController] {4}
@Controller
public class UserController {
  @Autowired
  @Qualifier("userServiceImpl") // 通过 byName 的方式，指定要注入的 UserService 子类
  private UserService userService;

  public void addUser() {
    this.userService.addUser();
    System.out.println("Controller层已执行");
  }
}
```

```java [UserServiceImpl] {1}
@Service("userServiceImpl")
public class UserServiceImpl implements UserService {
  @Autowired
  private UserDao userDao;

  @Override
  public void addUser() {
    this.userDao.addUser();
    System.out.println("Service层已执行");
  }
}
```

```java [UserService2Impl] {1}
@Service("userService2Impl")
public class UserService2Impl implements UserService {
  @Autowired
  private UserDao userDao;

  @Override
  public void addUser() {
    this.userDao.addUser();
    System.out.println("Service2层已执行");
  }
}
```

## `@Resource` 注入

`@Resource` 注解是 Jakarta EE 标准规范提供的注解，Spring 框架对其提供了完全支持，同样也可以用来实现依赖注入。

`@Resource`  和 `@Autowired` 的区别：

|    对比维度    |        @Resource         |           @Autowired           |
| :------------: | :----------------------: | :----------------------------: |
|      来源      |     Jakarta EE 提供      |        Spring 原生提供         |
|  默认装配规则  | 优先按名称（byName）查找 |    优先按类型（byType）查找    |
|  指定名称方式  |      使用 name 属性      |    需搭配 `@Qualifier` 注解    |
| 支持的注入位置 |    字段、Setter 方法     | 构造器、字段、Setter 方法、参数 |





### 已知 name 注入

::: code-group

```java [UserController] {3}
@Controller
public class UserController {

  public void addUser() {

  }
}
```
