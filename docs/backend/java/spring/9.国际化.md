# 国际化

## Java 国际化

在 Java 中实现国际化的核心依赖有两个类：`java.util.Locale`（定义地区与语言）和 `java.util.ResourceBundle`（管理资源属性文件）。



### 准备属性文件

在项目的资源目录（resources）下创建不同语言的 `.properties` 文件：

> [!IMPORTANT] 命名规则
>
> 配置文件名称必须按照 `basename_language_country.properties` 来命名。
>

::: code-group

```properties [messages.properties]
welcome.message=Hello, Guest!
greeting.message=Good Morning, {0}!
```

```properties [messages_en_US.properties]
welcome.message=Hello, Guest!
greeting.message=Good Morning, {0}!
```

```properties [messages_zh_CN.properties]
welcome.message=你好，访客!
greeting.message=早上好, {0}!
```

:::



### 获取国际化属性

```java
public class I18nTest {
  @Test
  void test() {
    // 指定目标 Locale
    Locale zhCN = new Locale("zh", "CN");
    Locale enUS = new Locale("en", "US");
    // 加载基础名为 messages 的资源包
    ResourceBundle bundleZh = ResourceBundle.getBundle("messages", zhCN);
    ResourceBundle bundleEn = ResourceBundle.getBundle("messages", enUS);

    // 读取简单文本
    System.out.println("中文：" + bundleZh.getString("welcome.message"));
    System.out.println("英文：" + bundleEn.getString("welcome.message"));

    // 处理带动态参数的文本
    String templateZh = bundleZh.getString("greeting.message");
    String formattedZh = MessageFormat.format(templateZh, "张三");
    System.out.println(formattedZh);
    String templateEn = bundleEn.getString("greeting.message");
    String formattedEn = MessageFormat.format(templateEn, "zhangsan");
    System.out.println(formattedEn);
  }
}
```
