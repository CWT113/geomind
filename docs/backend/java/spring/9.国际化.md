# 国际化

## Java 国际化

在 Java 中实现国际化的核心依赖有两个类：`java.util.Locale`（定义地区与语言）和 `java.util.ResourceBundle`（管理资源属性文件）。



### 准备资源文件

在项目的资源目录（resources）下创建不同语言的 `.properties` 文件：

> [!IMPORTANT] 命名规则
>
> 配置文件名称必须按照 `basename_language_country.properties` 来命名。
>

> [!NOTE]
>
> 查找资源包时遵循从具体到通用的顺序，例如当请求 zh_CN 时：
>
> - messages_zh_CN.properties
> - messages_zh.properties
> - 系统默认 Locale 对应的文件
> - messages.properties

::: code-group

```properties [messages.properties]
welcome.message=Hello, Guest!
greeting.message=Good Morning, {0}!
```

```properties [messages_en_US.properties]
welcome.message=Hello, Guest!
greeting.message=Good Morning, {0}!
```

```properties [messages_zh_CN.properties]
welcome.message=你好，访客!
greeting.message=早上好, {0}!
```

:::



### 获取国际化属性

```java
public class I18nTest {
  @Test
  void testI18n() {
    // 指定目标 Locale
    Locale zhCN = new Locale("zh", "CN");
    Locale enUS = new Locale("en", "US");
    // 加载基础名为 messages 的资源包
    ResourceBundle bundleZh = ResourceBundle.getBundle("messages", zhCN);
    ResourceBundle bundleEn = ResourceBundle.getBundle("messages", enUS);

    // 读取简单文本
    System.out.println("中文：" + bundleZh.getString("welcome.message"));
    System.out.println("英文：" + bundleEn.getString("welcome.message"));

    // 处理带动态参数的文本
    String templateZh = bundleZh.getString("greeting.message");
    String formattedZh = MessageFormat.format(templateZh, "张三");
    System.out.println(formattedZh);
    String templateEn = bundleEn.getString("greeting.message");
    String formattedEn = MessageFormat.format(templateEn, "zhangsan");
    System.out.println(formattedEn);
  }
}
```



### 日期和数字本地化

除了文本，不同地区的数字、货币与日期格式也有所不同：

```java
public class I18nTest {
  @Test
  void testCurrencyAndDate() {
    Locale us = Locale.US;
    Locale cn = Locale.CHINA;

    // 货币格式化
    NumberFormat currencyUS = NumberFormat.getCurrencyInstance(us);
    NumberFormat currencyCN = NumberFormat.getCurrencyInstance(cn);
    System.out.println(currencyUS.format(12345.57)); // $12,345.57
    System.out.println(currencyCN.format(12345.57)); // ¥12,345.57

    // 日期格式化
    LocalDate today = LocalDate.now();
    DateTimeFormatter dfUS = DateTimeFormatter.ofLocalizedDate(FormatStyle.FULL).withLocale(us);
    DateTimeFormatter dfCN = DateTimeFormatter.ofLocalizedDate(FormatStyle.FULL).withLocale(cn);
    System.out.println(dfUS.format(today)); // Wednesday, September 2, 2026
    System.out.println(dfCN.format(today)); // 2026年9月2日星期三
  }
}
```



## Spring 国际化

Spring 中国际化是通过 `MessageSource` 这个接口来支持的，它有 3 个实现类：

- `ResourceBundleMessageSource`：是 Java 中 `ResourceBundle` 基础类实现，允许仅通过资源名加载国际化资源；
- `ReloadableResourceBundleMessageSource`：这个功能和第一个类功能类似，多了定时刷新功能，允许在不重启系统的情况下，更新资源的信息；
- `StaticMessageSource`：允许通过编程的方式提供国际化信息；



### 创建国际化配置文件

```java
@Configuration
public class I18nConfig  {
  @Bean
  public MessageSource messageSource() {
    ReloadableResourceBundleMessageSource messageSource = new ReloadableResourceBundleMessageSource();
    // 对应 resources/messages*.properties
    messageSource.setBasename("classpath:messages");
    messageSource.setDefaultEncoding("UTF-8");
    messageSource.setFallbackToSystemLocale(false);
    return messageSource;
  }
}
```





### 测试国际化

```java {8,9,16,17}
@SpringJUnitConfig(AppConfig.class)
public class I18nTest {
  @Autowired
  private MessageSource messageSource;

  @Test
  void testGetMessages() {
    String messageCN = messageSource.getMessage("welcome.message", null, Locale.CHINA);
    String messageUS = messageSource.getMessage("welcome.message", null, Locale.US);
    System.out.println(messageCN);
    System.out.println(messageUS);
  }

  @Test
  void testSetMessages() {
    String messageCN = messageSource.getMessage("greeting.message", new Object[]{"王一博"}, Locale.CHINA);
    String messageUS = messageSource.getMessage("greeting.message", new Object[]{"YiBo Wang"}, Locale.US);
    System.out.println(messageCN);
    System.out.println(messageUS);
  }
}
```
