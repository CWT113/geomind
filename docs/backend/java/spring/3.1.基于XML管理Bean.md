# 基于 XML 管理 Bean

在 Spring6 中，基于 XML 配置文件管理（配置和获取）Bean 是 Spring 的经典使用方式。



## 获取 Bean 对象

### 根据 id 获取

> [!CAUTION] 注意
>
> 根据 id 获取 Bean 时，XML 中 Bean 的 id 属性 **必须唯一**，不能重名，否则报错。

::: code-group

```java [HelloWorldTest] {6}
@Test
void testHelloWorld() {
  // 根据 application.xml 创建并初始化 IoC 容器
  ApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
  // 根据 id 获取，但是需要强转为对应的类
  HelloWorld helloWorld = (HelloWorld) context.getBean("helloWorld");
  helloWorld.sayHello();
}
```

```xml [applicatiom.xml] {5}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
  <bean id="helloWorld" class="com.example.beans.HelloWorld"/>
</beans>
```

:::



### 根据 类型 获取

> [!CAUTION] 注意
>
> 根据 类型 获取 Bean 时，XML 中 Bean 的 class 属性 **必须唯一**，不能重复，否则报错。

```java [HelloWorldTest] {6}
@Test
void testHelloWorld() {
  // 根据 application.xml 创建并初始化 IoC 容器
  ApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
  // 根据 类型 获取，不需要强转为对应的类
  HelloWorld helloWorld = context.getBean(HelloWorld.class);
  helloWorld.sayHello();
}
```



### 根据 id 和类型获取

```java [HelloWorldTest] {6}
@Test
void testHelloWorld() {
  // 根据 application.xml 创建并初始化 IoC 容器
  ApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
  // 根据 id和类型 共同获取，二者都不能写错，否则报错
  HelloWorld helloWorld = context.getBean("helloWorld", HelloWorld.class);
  helloWorld.sayHello();
}
```



## 依赖注入

依赖注入（DI）是控制反转（IoC）思想的具体实现方式，指由外部容器自动将所需的依赖传递到对象内部，而不是由对象自己内部 `new` 出来。



### 通过 setter 注入

通过 setter 注入，类对象中必须实现 `getter` 和 `setter` 方法。

::: code-group

```xml {7} [applicatiom.xml]
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
  <bean id="student" class="com.example.beans.Student">
    <!-- 通过调用对象的 setter 给属性赋值 -->
    <property name="id" value="1"/>
    <property name="name" value="tom"/>
    <property name="age" value="25"/>
  </bean>
</beans>
```

```java [StudentTest] {5}
@Test
void testStudent() {
  // 根据 application.xml 创建并初始化 IoC 容器
  ApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
  Student student = context.getBean("student", Student.class);
  System.out.println(student);
}
```

```java [Student]
@Data
@NoArgsConstructor
public class Student {
  private Integer id;

  private String name;

  private Integer age;
}
```

:::



### 通过 构造器 注入

通过 构造器 注入，类对象中必须实现全参构造方法。

::: code-group

```xml {7} [applicatiom.xml]
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
```

## 特殊值处理

### 字面量赋值

基本数据类型就属于字面量，字符串就会赋值给 `String`，数字会赋值给 `Integer`。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
  <bean id="student" class="com.example.beans.Student">
    <!-- 赋值给 id 时，是数字 1 -->
    <constructor-arg name="id" value="1"/>
    <!-- 赋值给 name 时，是字符串 tom -->
    <constructor-arg name="name" value="tom"/>
  </bean>
</beans>
```



### null 值

想要赋值 `null` 值时，必须使用 `<null />` 标签，而不能直接 `value="null"`。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
  <bean id="student" class="com.example.beans.Student">
    <constructor-arg name="name"> <!-- [!code ++] -->
      <null/> <!-- [!code ++] -->
    </constructor-arg> <!-- [!code ++] -->
    
    <!-- ❌ 表示给 name 赋值为字符串 'null' -->
    <constructor-arg name="name" value="null"/>
  </bean>
</beans>
```



### xml 实体

在 XML 配置中，因为 `<` 是 XML 语言的保留字符，直接写 `value="a < b"` 会导致 XML 解析语法错误。因此必须使用实体字符 `&lt;` 来替代 `<`。

| 原始符号 | XML 转义字符 |
| :------: | :---------: |
|    <     |   `&lt;`    |
|    >     |   `&gt;`    |
|    &     |   `&amp;`   |
|    “     |  `&quot;`   |
|    ‘     |   `&apos`   |



```xml {9}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
  <bean id="student" class="com.example.beans.Student">
    <property name="id" value="1"/>

    <!-- 这种方式会把 'a < b' 当成一个字符串赋值，因此没有错误 -->
    <property name="name" value="a < b"/>

    <property name="name">
      <!-- ❌ 当使用 <value> 标签赋值的时候，就会引发 xml 语法报错 -->
      <!-- <value>a < b</value> -->

      <!-- 此时使用 &lt; 就不会报语法错误了 -->
      <value>a &lt; b</value> <!-- [!code ++] -->
    </property>
  </bean>
</beans>
```



### CDATA 节

CDATA 中的 C 表示 Character 文本、字符的含义，因此 CDATA 就表示纯文本数据。

```xml {9}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans.xsd">
  <bean id="student" class="com.example.beans.Student">
    <property name="id" value="1"/>
    <property name="name">
      <!-- 使用 CDATA 节，直接转义 -->
      <value><![CDATA[a < b]]></value>
    </property>
    <property name="age" value="25"/>
  </bean>
</beans>
```

### 引用外部 Bean

```xml {10}
<?xml version="1.0" encoding="UTF-8"?>

    <property name="name" value="tom"/>

    <property name="clazz" ref="clazz"/>
  </bean>

  <bean id="clazz" class="com.example.beans.Clazz">
    <property name="clazzId" value="1001"/>
    <property name="clazzName" value="一年级"/>
  </bean>
```

## 引入外部属性文件

在 `pom.xml` 中引入依赖：

```xml
<dependencies>
  <!-- 引入 mysql 数据库依赖 -->
  <dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <version>9.7.0</version>
  </dependency>
  <!-- 引入 druid 连接池依赖 -->
  <dependency>
    <groupId>com.alibaba</groupId>
    <artifactId>druid</artifactId>
    <version>1.2.20</version>
  </dependency>
</dependencies>
```

在 `main/resources` 目录下新建 `db.properties` 文件：

```properties
jdbc.driver=com.mysql.cj.jdbc.Driver
jdbc.url=jdbc:mysql://localhost:3306/demo
jdbc.username=root
jdbc.password=1234
```

通过 XML 引入外部文件属性时，推荐使用 `context` 命名空间简化配置：

::: code-group

```xml [application.xml] {4,7,8,10,14}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd
                           http://www.springframework.org/schema/context
                           http://www.springframework.org/schema/context/spring-context.xsd">
  <!-- 引入外部属性文件 -->
  <context:property-placeholder location="classpath:db.properites"/>

  <!-- 通过 ${key} 引用属性文件中的值 -->
  <bean id="dataSource" class="com.alibaba.druid.pool.DruidDataSource">
    <property name="driverClassName" value="${jdbc.driver}"/>
    <property name="url" value="${jdbc.url}" />
    <property name="username" value="${jdbc.username}" />
    <property name="password" value="${jdbc.password}" />
  </bean>
</beans>
```

## Bean 的作用域

Spring 容器在创建 Bean 时，通过定义作用域（Scope）来决定 Bean 的生命周期和创建策略。

Spring6 中一共提供了 6 种作用域，其中前 2 种为通用作用域，后 4 种仅在 Web 应用程序（如 Spring MVC）中生效。

|      作用域       | 适用环境 | 描述                                                         |
| :---------------: | :------: | ------------------------------------------------------------ |
| singleton（默认） | 所有环境 | **单例模式**，在整个 Spring 容器中，该 Bean 只有一个实例。容器初始化时即创建（除非配置懒加载）。 |
|     prototype     | 所有环境 | **多例模式**，每次向容器请求时，容器都会创建一个全新的实例   |
|      request      | Web 环境  | 请求作用域，每个 HTTP 请求都会创建一个独立的 Bean 实例，仅在当前 HTTP 请求内有效 |
| session | Web 环境 | 会话作用域，在同一个 HTTP Session 生命周期内共享一个 Bean 实例 |
| application | Web 环境 | 应用作用域，在整个 `ServletContext` 生命周期内共享一个 Bean 实例（类似于全局单例） |
| websocket | Web 环境 | WebSocket 作用域，在同一个 WebSocket 的生命周期内共享一个 Bean 实例 |



::: code-group

```xml [application.xml] {7}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd">
  <!-- 设置 User 类的作用域为 prototype，即可以拥有多个实例，默认是 singleton -->
  <bean id="user" class="com.example.beans.User" scope="prototype"/>
</beans>
```

```java [User]
@Data
@NoArgsConstructor
@AllArgsConstructor
public class User {
  private Integer id;

  private String username;

  private String password;
}
```

```java [UserTest]
@Test
void testUser() {
  ApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
  // 可以获取多个实例，每次获取都会重新创建实例
  User user1 = context.getBean(User.class);
  User user2 = context.getBean(User.class);
  System.out.println(user1 == user2); // false
}
```

## Bean 的生命周期

> [!NOTE]
>
> 第一步：Bean 对象创建（调用无参构造函数）
>
> 第二步：给 Bean 对象设置属性
>
> 第三步：Bean 的前置处理器（初始化之前）
>
> 第四步：Bean 对象初始化
>
> 第五步：Bean 的后置处理器（初始化之后）
>
> 第六步：Bean 对象创建完成，可在应用中使用
>
> 第七步：Bean 对象销毁
>
> 第八步：XML 容器关闭



::: code-group

```xml [application.xml] {7}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd">
  <!-- 初始化和销毁方法需要手动设置 -->
  <bean id="user" class="com.example.beans.User" init-method="initMethod" destroy-method="destroyMethod">
    <property name="id" value="1"/>
    <property name="username" value="tom"/>
    <property name="password" value="1234"/>
  </bean>
</beans>
```

```java [User] {53,58}
public class User {
  private Integer id;

  private String username;

  private String password;

  public User() {
    System.out.println("第一步：Bean 对象创建");
  }

  public User(Integer id, String username, String password) {
    this.id = id;
    this.username = username;
    this.password = password;
  }

  public Integer getId() {
    return id;
  }

  public void setId(Integer id) {
    System.out.println("第二步：给 Bean 对象设置属性");
    this.id = id;
  }

  public String getUsername() {
    return username;
  }

  public void setUsername(String username) {
    this.username = username;
  }

  public String getPassword() {
    return password;
  }

  public void setPassword(String password) {
    this.password = password;
  }

  @Override
  public String toString() {
    return "User{" +
      "id=" + id +
      ", username='" + username + '\'' +
      ", password='" + password + '\'' +
      '}';
  }

  // 手动声明初始化方法
  public void initMethod() {
    System.out.println("第四步：Bean 对象初始化");
  }

  // 手动声明销毁方法
  public void destroyMethod() {
    System.out.println("第七步：Bean 对象销毁");
  }
}
```

```java [UserTest] {7}
@Test
void testUser() {
  ClassPathXmlApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
  User user = context.getBean(User.class);
  System.out.println("第六步：Bean 对象创建完成，可在应用中使用");
  System.out.println(user);
  context.close();
}
```

Bean 的前置/后置处理器会在生命周期初始化前后添加额外的操作，需要实现 `BeanPostProcessor` 接口，且必须配置到 XML 容器中才能生效。

> [!CAUTION] 注意
>
> 后置处理器并不是正对某一个 Bean 生效，而是对 XML 容器中的所有 Bean 都会生效。

::: code-group

```xml [application.xml] {7}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd">
  <!-- Bean的后置处理器必须要放入 XML 容器中才生效 -->
  <bean id="beanProcessor" class="com.example.processor.BeanProcessor"/>

  <!-- 初始化和销毁方法需要手动设置 -->
  <bean id="user" class="com.example.beans.User" init-method="initMethod" destroy-method="destroyMethod">
    <property name="id" value="1"/>
    <property name="username" value="tom"/>
    <property name="password" value="1234"/>
  </bean>
</beans>
```

```java [BeanProcessor]
public class BeanProcessor implements BeanPostProcessor {
  @Nullable
  @Override
  public Object postProcessBeforeInitialization(Object bean, String beanName) throws BeansException {
    System.out.println("第三步：Bean 的前置处理器");
    System.out.println(beanName + " = " + bean);
    return bean;
  }

  @Nullable
  @Override
  public Object postProcessAfterInitialization(Object bean, String beanName) throws BeansException {
    System.out.println("第五步：Bean 的后置处理器");
    System.out.println(beanName + " = " + bean);
    return bean;
  }
}
```

## FactoryBean

FactoryBean 是 Spring 提供的一个接口，俗称工厂 Bean，是用来帮助开发者将复杂对象的创建逻辑封装起来。

实现 FactoryBean 接口后，Spring 会将该接口的 `getObject()` 方法返回的对象注册到容器中，而不是注册 FactoryBean 本身。

- **普通 Bean**：直接由 Spring 反射 `new` 出来；
- **FactoryBean**：一个生产 Bean 的工厂，Spring 容器调用它的 `getObject()` 来获取实际的 Bean 对象。



::: code-group

```java [UserFactoryBean]
public class UserFactoryBean implements FactoryBean<User> {
  // 返回由工厂创建的真实 Bean 实例
  @Nullable
  @Override
  public User getObject() throws Exception {
    User user = new User();
    // 可以编写复杂的对象组装逻辑
    user.setId(1);
    user.setUsername("tom");
    user.setPassword("123456");
    return user;
  }

  // 返回创建的 Bean 的类型
  @Nullable
  @Override
  public Class<?> getObjectType() {
    return User.class;
  }

  // 是否为单例模式
  @Override
  public boolean isSingleton() {
    return true;
  }
}
```

```xml [application.xml] {7}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd">
  <!-- 将 UserFactoryBean 注入到容器中，但拿到的对象是 User -->
  <bean id="user" class="com.example.beans.UserFactoryBean"/>
</beans>
```

```java [UserTest] {9}
@Test
void testUser() {
  ClassPathXmlApplicationContext context = new ClassPathXmlApplicationContext("application.xml");
  // 获取由 FactoryBean 产出的 User 对象
  User user = context.getBean("user", User.class);
  System.out.println(user); // User(id=1, username=tom, password=123456)

  // 如果要获取 FactoryBean 工厂本身，需要在 id 前加上 & 符
  Object factoryBean = context.getBean("&user");
  System.out.println(factoryBean.getClass().getName()); // com.example.beans.UserFactoryBean
}
```

## 基于 XML 自动装配

自动装配（Autowiring）是指 Spring 容器根据特定的规则，隐式地为 Bean 注入依赖项，而无需手动编写 `<property>` 或 `<constructor-arg>` 标签。

自动装配的  5 种模式：

|     模式     | 描述                                                         |
| :----------: | ------------------------------------------------------------ |
| no / default | 默认值。不使用自动装配，必须通过 `<property>` 或 `<constructor-arg>` 显式指定依赖 |
|    byName    | **根据属性名自动装配**，Spring  会查找与 Bean 的 setter 方法属性名完全一致的 Bean ID 进行注入 |
|    byType    | **根据属性类型自动装配**，Spring 会查找与属性类型相匹配的 Bean 进行注入（若匹配到多个相同类型的 Bean 会抛出异常） |
| constructor  | **根据构造函数参数类型自动装配**，类似于 byType，但应用于构造函数的参数 |

::: code-group

```xml [application.xml]
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd">
  <!-- 根据 byType 方式进行注入 -->
  <bean id="userController" class="com.example.controller.UserController" autowire="byType"/>
  <!-- 注意：Bean 的 id 必须与 Controller 中 setUserService 方法去掉 set 后的属性名一致 -->
  <bean id="userService" class="com.example.service.impl.UserServiceImpl" autowire="byType"/>
  <!-- 注意：Bean 的 id 必须与 Service 中 setUserDao 方法去掉 set 后的属性名一致 -->
  <bean id="userDao" class="com.example.dao.impl.UserDaoImpl"/>

  <!-- 根据 byName 方式进行注入 -->
  <bean id="userController" class="com.example.controller.UserController" autowire="byName"/>
  <!-- 注意：Bean 的 id 必须与 Controller 中 setUserService 方法去掉 set 后的属性名一致 -->
  <bean id="userService" class="com.example.service.impl.UserServiceImpl" autowire="byName"/>
  <!-- 注意：Bean 的 id 必须与 Service 中 setUserDao 方法去掉 set 后的属性名一致 -->
  <bean id="userDao" class="com.example.dao.impl.UserDaoImpl"/>
</beans>
```

```java [UserController] {5}
public class UserController {
  private UserService userService;

  // 必须提供 setter 方法，供 Spring 自动装配使用
  public void setUserService(UserService userService) {
    this.userService = userService;
  }

  public void saveUser() {
    this.userService.saveUser();
  }
}
```

```java [UserServiceImpl] {9}
public interface UserService {
  void saveUser();
}

public class UserServiceImpl implements UserService {
  private UserDao userDao;

  // 必须提供 setter 方法，供 Spring 自动装配使用
  public void setUserDao(UserDao userDao) {
    this.userDao = userDao;
  }

  @Override
  public void saveUser() {
    this.userDao.saveUser();
  }
}
```

```java [UserDaoImpl]
public interface UserDao {
  void saveUser();
}

public class UserDaoImpl implements UserDao {
  @Override
  public void saveUser() {
    System.out.println("保存成功！");
  }
}
```
