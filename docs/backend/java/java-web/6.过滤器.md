# 过滤器

过滤器（Filter）是运行在 Servlet 容器中的一种组件，用于在请求到达 Servlet 之类，或响应离开 Servlet 之后，**对请求和响应进行拦截和预处理**。

::: info 常见的过滤器

- 身份验证过滤器：检查用户受否登录，未登录则拦截并重定向到登录页；
- 字符编码过滤器：防止出现中文乱码情况，统一将请求编码设置为 UTF-8；
- 日志记录过滤器：记录请求的 IP、访问路径或请求处理时间；
- 敏感词过滤器：对用户输入的文本进行过滤或替换；

:::



## 生命周期

过滤器是一个实现了 `jakarta.servlet.Filter` 中 `Filter` 接口的 Java 类，它的生命周期由 Servlet 容器管理，主要包含三个方法：

| 生命周期                                               | 描述                                                       |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| init(FilterConfig config)                              | 容器启动并创建 Filter 后调用，用于初始化资源（仅执行一次） |
| doFilter(ServletRequest, ServletResponse, FilterChain) | 编写具体的过滤操作                                         |
| destroy()                                              | 容器关闭或销毁 Filter 时调用，用于释放资源（仅执行一次）   |

```java {17}
@WebFilter("/*")
public class EncodingFilter implements Filter {
  @Override
  public void init(FilterConfig config) throws ServletException {
    // TODO：获取初始化参数，做一些初始操作
    String username = config.getInitParameter("username");
    System.out.println("Username: " + username);
  }

  @Override
  public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain) throws IOException, ServletException {
    // TODO：在请求到达 Servlet 之前做一些处理
    // 设置请求编码和响应类型
    request.setCharacterEncoding("UTF-8");
    response.setContentType("text/html;charset=UTF-8");
    // 放行请求，传递给下一个过滤器或 Servlet 目标
    chain.doFilter(request, response);
  }

  @Override
  public void destroy() {
  }
}
```

> [!NOTE] 提示
>
> 在 `doFilter` 方法中，调用 `chain.doFilter(request, response)` 的意义：
>
> - 如果调用了，请求会继续传递给下一个过滤器或 Servlet；
> - 如果不调用，请求将被拦截在此处，后面的 Servlet 将不会被执行（常用于权限未通过时的直接中断）；



## 过滤器链

如果有多个过滤器作用于同一个请求，它们会形成一个过滤器链（Filter Chain），并按照指定的顺序依次执行。

> [!NOTE] 过滤器执行顺序
>
> - **传统的 `web.xml` 方式（推荐）**：过滤器的执行顺序由它们在 `web.xml` 中的 `<filter-mapping>` 的声明先后顺序决定。
> - **Spring Boot 方式**：如果使用 Spring 框架，可以使用 `@Order()` 注解或 `FilterRegistrationBean` 显式指定顺序；
> - **`@WebFilter` 注解**：此方式无法显式指定执行顺序（通常按类名首字母或扫描顺序），因此要保证严格的执行顺序，建议在 `web.xml` 中配置映射；

 ::: code-group

```xml {9,14,19} [web.xml]
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="http://xmlns.jcp.org/xml/ns/javaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd"
         version="4.0">
  <!-- 定义自定义的过滤器，并指定其对应的 Java 类 -->
  <filter>
    <!-- 第一个执行 -->
    <filter-name>LoggingFilter</filter-name>
    <filter-class>com.demo.Filters.LoggingFilter</filter-class>
  </filter>
  <filter>
    <!-- 第二个执行 -->
    <filter-name>EncodingFilter</filter-name>
    <filter-class>com.demo.Filters.EncodingFilter</filter-class>
  </filter>
  <filter>
    <!-- 最后一个执行 -->
    <filter-name>AuthenticationFilter</filter-name>
    <filter-class>com.demo.Filters.AuthenticationFilter</filter-class>
  </filter>
  
  <!-- 创建自定义过滤器的 路径过滤规则 -->
  <filter-mapping>
    <filter-name>LoggingFilter</filter-name>
    <url-pattern>/*</url-pattern>
  </filter-mapping>
  <filter-mapping>
    <filter-name>EncodingFilter</filter-name>
    <url-pattern>/*</url-pattern>
  </filter-mapping>
  <filter-mapping>
    <filter-name>AuthenticationFilter</filter-name>
    <url-pattern>/*</url-pattern>
  </filter-mapping>
</web-app>
```

```java [LoggingFilter]
public class LoggingFilter implements Filter {
  private static final DateTimeFormatter DATE_TIME_FORMATTER = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss.SSS");

  @Override
  public void init(FilterConfig filterConfig) throws ServletException {
  }

  @Override
  public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain) throws IOException, ServletException {
    long start = System.currentTimeMillis();

    HttpServletRequest httpRequest = (HttpServletRequest) request;
    HttpServletResponse httpResponse = (HttpServletResponse) response;

    // 获取请求时间
    String requestTime = LocalDateTime.now().format(DATE_TIME_FORMATTER);
    // 获取请求方式
    String requestMethod = httpRequest.getMethod();
    // 获取请求 URL 地址
    String requestURL = httpRequest.getRequestURL().toString();
    // 获取请求 URI 路径
    String requestURI = httpRequest.getRequestURI();
    // 获取请求 IP，这里只是简单演示，真实获取 IP 需要考虑多种情况
    String clientIp = httpRequest.getHeader("X-Forwarded-For");
    // 获取 GET 请求的 Params 参数
    String requestParams = getRequestParams(httpRequest);
    // 获取用户信息及部门信息
    HttpSession session = httpRequest.getSession(false);
    String username = "Unknown Username";
    String department = "Unknown Department";
    if (session != null) {
      username = session.getAttribute("username").toString();
      department = session.getAttribute("department").toString();
    }
    // 获取响应状态
    int status = httpResponse.getStatus();
    // TODO: 请求信息入库等操作！
    long end = System.currentTimeMillis();
    System.out.println("=====================[LOG START]=======================");
    System.out.println("[Log] Request Time: " + requestTime);
    System.out.println("[Log] Request Method: " + requestMethod);
    System.out.println("[Log] Request URL: " + requestURL);
    System.out.println("[Log] Request URI: " + requestURI);
    System.out.println("[Log] Request ClientIP: " + clientIp);
    System.out.println("[Log] Request Params: " + requestParams);
    System.out.println("[Log] Request Username: " + username);
    System.out.println("[Log] Request Department: " + department);
    System.out.println("[Log] Response Status: " + status);
    System.out.println("[Log] Request Completed: " + (end - start) + "ms");
    System.out.println("=====================[LOG EDN]========================");
    // 传递到下一个过滤器
    chain.doFilter(httpRequest, response);
  }

  @Override
  public void destroy() {
  }

  /**
   * 简单获取请求参数
   * @param request HttpServletRequest对象
   * @return 拼接后的请求参数字符串
   */
  private String getRequestParams(HttpServletRequest request) {
    Map<String, String[]> paramsMap = request.getParameterMap();
    if (paramsMap.isEmpty()) {
      return "{}";
    }
    StringBuilder sb = new StringBuilder("{");
    paramsMap.forEach((key, values) -> {
      sb.append(key)
        .append("=")
        .append(values.length == 1 ? values[0] : Arrays.toString(values))
        .append(", ");
    });
    if (sb.length() > 1) {
      // 移除最后末尾多余的逗号和空格
      sb.deleteCharAt(sb.length() - 2);
    }
    sb.append("}");
    return sb.toString();
  }
}
```

```java [AuthenticationFilter]
public class AuthenticationFilter implements Filter {
  @Override
  public void init(FilterConfig filterConfig) throws ServletException {
  }

  @Override
  public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain) throws IOException, ServletException {
    HttpServletRequest httpRequest = (HttpServletRequest) request;
    HttpServletResponse httpResponse = (HttpServletResponse) response;

    String requestURI = httpRequest.getRequestURI();
    HttpSession session = httpRequest.getSession(false);

    // 排除无需登录即可访问的页面
    boolean isLoginPage = requestURI.endsWith("/login") || requestURI.endsWith("/register");
    boolean isLoggedIn = session != null && session.getAttribute("user") != null;

    System.out.println("=====================[Auth START]======================");
    System.out.println("[Auth] Auth Success: " + requestURI);
    System.out.println("=====================[Auth EDN]========================");

    if (isLoginPage || isLoggedIn) {
      chain.doFilter(request, response);
    } else {
      System.out.println("[Auth] Auth Failed: " + requestURI);
      httpResponse.sendRedirect(httpRequest.getContextPath() + "/login");
    }
  }

  @Override
  public void destroy() {
  }
}
```
