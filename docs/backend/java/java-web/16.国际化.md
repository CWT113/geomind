# 国际化

Servlet 可以根据请求者的区域设置拾取相应版本的网站，并根据当地的语言、文化和需求提供响应的网站版本。



## 检测区域设置

| 方法                 | 描述                           |
| -------------------- | ------------------------------ |
| getCountry()         | 获取该区域的国家/地区代码      |
| getDisplayCountry()  | 获取当前区域国家/地区名称      |
| getLanguage()        | 获取当前区域的语言代码         |
| getDisplayLanguage() | 获取当前区域的语言名称         |
| getISO3Country()     | 获取当前国家的三个字母缩写     |
| getISO3Language()    | 获取当前国家语言的三个字母缩写 |

```java
@WebServlet("/getLocal")
public class GetLocale extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    Locale locale = req.getLocale();
    // 获取国家代码和名称
    String country = locale.getCountry();
    String displayCountry = locale.getDisplayCountry();
    // 获取区域语言代码和名称
    String language = locale.getLanguage();
    String displayLanguage = locale.getDisplayLanguage();
  }
```





## 语言设置

Servlet 可以输出以西欧语言（如英语、西班牙语、德语、法语、意大利语、荷兰语等）编写的页面。

```java
@WebServlet("/getLocal")
public class GetLocale extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 设置西班牙语言代码
    resp.setHeader("Content-Language", "es");
  }
}
```



## 特定区域设置日期

使用 `java.text.DateFormat` 类及其静态方法 `getDateTimeInstance()` 来格式化特定于区域设置的日期和时间。

```java {9-12}
@WebServlet("/getLocal")
public class GetLocale extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();
    
    // 获取客户端的区域设置
    Locale locale = req.getLocale();
    String date = DateFormat
      .getDateTimeInstance(DateFormat.FULL, DateFormat.SHORT, locale)
      .format(new Date());
    
    String title = "特定于区域设置的日期";
    String docType = "<!DOCTYPE html> \n";
    writer.println(docType +
                   "<html>\n" +
                   "<head><title>" + title + "</title></head>\n" +
                   "<body bgcolor=\"#f0f0f0\">\n" +
                   "<h1 align=\"center\">" + date + "</h1>\n" +
                   "</body></html>");
  }
}
```



## 特定区域设置货币

使用 `java.text.NumberFormat` 类及其静态方法 `getCurrencyInstance()` 来格式化数字为特定于区域设置的货币。

```java {9-11}
@WebServlet("/getLocal")
public class GetLocale extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();
    
    // 获取客户端的区域设置
    Locale locale = req.getLocale();
    NumberFormat nft = NumberFormat.getCurrencyInstance(locale);
    String formattedCurr = nft.format(1000000);

    String title = "特定于区域设置的货币";
    String docType = "<!DOCTYPE html> \n";
    writer.println(docType +
                   "<html>\n" +
                   "<head><title>" + title + "</title></head>\n" +
                   "<body bgcolor=\"#f0f0f0\">\n" +
                   "<h1 align=\"center\">" + formattedCurr + "</h1>\n" +
                   "</body></html>");
  }
}
```



## 特定区域设置百分比

使用 `java.text.NumberFormat` 类及其静态方法 `getPercentInstance()` 来格式化特定于区域设置的百分比。

```java {9-11}
@WebServlet("/getLocal")
public class GetLocale extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();

    // 获取客户端的区域设置
    Locale locale = req.getLocale();
    NumberFormat nft = NumberFormat.getPercentInstance(locale);
    String formattedPerc = nft.format(0.51);

    String title = "特定于区域设置的百分比";
    String docType = "<!DOCTYPE html> \n";
    writer.println(docType +
                   "<html>\n" +
                   "<head><title>" + title + "</title></head>\n" +
                   "<body bgcolor=\"#f0f0f0\">\n" +
                   "<h1 align=\"center\">" + formattedPerc + "</h1>\n" +
                   "</body></html>");
  }
}
```
