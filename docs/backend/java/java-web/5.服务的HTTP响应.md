# 服务端 HTTP 响应

当浏览器向服务端发送请求后，服务端需要向浏览器返回响应数据，这个响应数据一般包含状态行、响应报头、空行及文档。



## 响应头信息

下面是服务端返回到浏览器的 HTTP 1.1 响应报头：

| 响应头信息          | 描述                                                         |
| :------------------ | ------------------------------------------------------------ |
| Allow               | 指定服务器支持的请求方法                                     |
| Cache-Control       | 指定响应文档在何种情况下可以安全地缓存，如 public、private 或 no-cache 等 |
| Connection          | 指定浏览器是否使用持久 HTTP 连接，如 Keep-Alive 表示持久连接，close 表示不使用持久连接 |
| Content-Disposition | 指定浏览器按照该响应头把文件保存到本地                       |
| Content-Encoding    | 指定页面的编码方式                                           |
| Content-Language    | 指定文档编写所使用的语言，如 en、en-us 等                    |
| Content-Length      | 指定响应中的字节数                                           |
| Content-Type        | 指定响应文档的 MIME 类型                                     |
| Expires             | 响应头内容的过期时间                                         |
| Refresh             | 指定浏览器刷新页面的秒数                                     |
| Retry-After         | 该响应头可与 503 响应配合使用，告诉客户端多久重复一次请求    |
| Set-Cookie          | 指定一个与页面关联的 Cookie                                  |



## 设置 HTTP 响应头

下面的方法可用于在 Servlet 中设置 HTTP 响应头，这些方法通过 `HttpServletResponse` 对象调用。

| 方法                                 | 描述                                                 |
| ------------------------------------ | ---------------------------------------------------- |
| setStatus(int sc)                    | 设置响应状态码                                       |
| containsHeader(String name)          | 检查是否已经设置同名的响应头                         |
| addHeader(String name, String value) | 添加带有给定的名称和值的响应头                       |
| setHeader(String name, String value) | 设置带有给定的名称和值的响应头                       |
| setIntHeader(String name, int value) | 设置带有给定的名称和整数值的响应头                   |
| setContentType(String type)          | 如果客户端没有设置，则服务端设置响应的内容 MIME 类型 |
| addCookie(Cookie cookie)             | 把指定的 Cookie 添加到响应头                         |
| sendRedirect(String location)        | 使用指定的重定向 URL，发送临时重定向响应到客户端     |
| setCharacterEncoding(String charset) | 设置被发送到客户端的响应的字符编码，如 UTF-8         |
| sendError(int code, String message)  | 发送状态码和状态信息到客户端                         |

::: code-group

```java [基础响应头] {6,8,10,12}
@WebServlet("/HelloForm")
public class HelloForm extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 设置自动刷新时间为 5 秒
    resp.setIntHeader("Refresh", 5);
    // 设置响应内容类型
    resp.setContentType("text/html;charset=utf-8");
    // 添加自定义 Cookie
    resp.addCookie(new Cookie("cookie", "HelloWorld"));
    // 设置字符编码
    resp.setCharacterEncoding("UTF-8");

    PrintWriter writer = resp.getWriter();
    writer.println("<h1>Hello,World</h1>");
  }

  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 这里的处理逻辑简单，直接调用 doGet 方法返回内容
    doGet(req, resp);
  }
}
```

```java [发送失败状态码] {5}
@WebServlet("/HelloForm")
public class HelloForm extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    resp.sendError(HttpServletResponse.SC_UNAUTHORIZED, "Unauthorized!!!");
  }

  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 这里的处理逻辑简单，直接调用 doGet 方法返回内容
    doGet(req, resp);
  }
}
```
