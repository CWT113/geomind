# 客户端 HTTP 请求

当浏览器请求网页时，它会向服务端发送特定的信息，这些信息不能被直接读取，因为这些信息是作为 HTTP 请求头的一部分进行传输的。



## 请求头信息

下面是来自浏览器端常见的请求头，可以在发起请求时携带：

| 请求头信息      | 描述                                                         |
| :-------------- | ------------------------------------------------------------ |
| Accept          | 指定浏览器可以处理的 MIME 类型，如 image/png 或 image/jpeg 等 |
| Accept-Charset  | 指定浏览器显示信息的字符集，如 ISO-8859-1                    |
| Accept-Encoding | 指定浏览器该如何处理的编码类型，如 gzip                      |
| Accept-Language | 指定浏览器的首选语言，如 en、en-us 等                        |
| Authorization   | 指定客户端携带的 Token 等身份验证信息                        |
| Connection      | 指示客户端是否可以处理持久 HTTP 连接，如 Keep-Alive 指使用了持久连接 |
| Content-Length  | 该头只适用于 POST 请求，并给出 POST 数据的大小               |
| Cookie          | 该头用于把之前发送到浏览器的 cookies 返回到服务端            |
| Host            | 指定原始的 URL 中的主机和端口                                |
| Referer         | 指定指向的 Web 页的 URL，如在网页 1 点击链接跳转到网页 2，浏览器在请求网页 2 时，Referer 就是网页 1 的 URL |
| User-Agent      | 该头用于识别发出请求的浏览器，并可以向不同类型的浏览器返回不同的内容 |



## 读取 HTTP 请求头

下面的方法可以在 Servlet 程序中读取 HTTP 请求头。这些方法通过 `HttpServletRequest` 对象调用。

| 方法                            | 描述                                                         |
| ------------------------------- | ------------------------------------------------------------ |
| getHeaderNames()                | 返回一个枚举，包含在该请求中包含的所有的请求头名             |
| getHeader(String name)          | 以字符串形式返回指定的请求头的值                             |
| getAttributeNames()             | 返回一个枚举，包含提供给该请求可用的属性名称                 |
| getAttribute(String name)       | 以对象形式返回已命名属性的值，如果没有给定名称的属性存在，则返回 null |
| getParameterNames()             | 返回一个 String 对象的枚举，包含在该请求中包含的参数的名称   |
| getParameterValues(String name) | 返回一个 **字符串对象的数组**，包含所有给定的请求参数的值，如果参数不存在则返回 null |
| getParameterMap()               | 将参数封装成 Map 类型                                        |
| getCookies()                    | 返回一个数组，包含客户端发送该请求的所有的 Cookie 对象       |
| getSession()                    | 返回与该请求关联的当前 session 会话，或者如果请求没有 session 会话，则创建一个 |
| getMethod()                     | 返回请求的 HTTP 方法的名称                                   |
| getServerPort()                 | 返回接收到这个请求的端口号                                   |
| getQueryString()                | 返回包含在路径后的请求 URL 中的查询字符串                    |
| getContentType()                | 返回请求主体的 MIME 类型，如果不知道类型则返回 null          |
| getInputStream()                | 使用 ServletInputStream，以二进制数据形式检索请求的主体      |
| getCharacterEncoding()          | 返回请求主体中使用的字符编码的名称                           |

```java {10,12,17-22,26,27,28,30}
@WebServlet("/HelloForm")
public class HelloForm extends HttpServlet {
  // 处理客户端的 GET 请求
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 明确指定请求参数的字符编码格式
    req.setCharacterEncoding("UTF-8");

    // 查看请求方式
    System.out.println("Request Method: " + req.getMethod());
    // 查看请求携带的 Cookies
    Cookie[] cookies = req.getCookies();
    System.out.println("Request Cookies: " + Arrays.toString(cookies));

    // 查询 Headers 请求头信息
    System.out.println("============== Request Headers =============");
    Enumeration<String> headerNames = req.getHeaderNames();
    while (headerNames.hasMoreElements()) {
      String headerName = headerNames.nextElement();
      String headerValue = req.getHeader(headerName);
      System.out.println(headerName + ": " + headerValue);
    }

    // 查询 Params 请求体信息
    System.out.println("============== Request Params =============");
    Enumeration<String> paramNames = req.getParameterNames();
    while (paramNames.hasMoreElements()) {
      String paramName = paramNames.nextElement();
      // 只能获取单个值，如果有复选框值的时候，会截断只获取第一个
      // String paramValue = req.getParameter(paramName);
      // √ 推荐：使用 getParameterValues() 方法获取所有的属性值
      String[] paramValue = req.getParameterValues(paramName); // [!code ++]
      if (paramValue.length == 1) {
        System.out.println(paramName + ": " + paramValue[0]);
      } else {
        System.out.println(paramName + ": " + Arrays.toString(paramValue));
      }
    }
  }

  // 处理客户端的 POST 请求
  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 这里的处理逻辑简单，直接调用 doGet 方法返回内容
    doGet(req, resp);
  }
}
```
