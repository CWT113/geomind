# 自动刷新页面

假设有一个网页，它是显示现场比赛成绩、股票市场状况或货币兑换率，这些网页需要实时更新数据，那么就可以使用 Servlet 提供的机制，使网页在给定的时间间隔自动刷新。

刷新网页最简单的方式就是使用响应对象的 `setIntHeader()`：

```java
public void setIntHeader(String header, int headerValue);
```

此方法把头信息 `Refresh` 连同一个表示时间间隔的整数值（单位：秒）发送回浏览器。
