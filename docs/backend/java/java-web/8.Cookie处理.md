# Cookie 处理

Cookie 是存储在客户端计算机上的文本文件，并保留了各种可用于追踪的信息。

其中识别返回用户包括三个步骤：

- 服务器向浏览器发送一组 Cookie，例如：姓名、年龄或识别号码；
- 浏览器将这些信息存储在本地计算机上，以备将来使用；
- 当下一次浏览器向服务器发送任何请求时，浏览器都会把这些 Cookie 信息发送到服务器，服务器将使用这些信息来识别用户；

| 常用方法            | 描述                                                         |
| ------------------- | ------------------------------------------------------------ |
| setDomain(pattern)  | 设置 cookie 适用的域                                         |
| getDomain()         | 获取 cookie 适用的域                                         |
| setMaxAge(expiry)   | 设置 cookie 过期的时间，单位：秒（不设置则长期有效）         |
| getMaxAge()         | 获取 cookie 的最大生存周期，单位：秒（-1 表示 cookie 持续有效，直到浏览器关闭） |
| getName()           | 获取 cookie 名称，名称在创建后不能改变                       |
| setValue(newValue)  | 设置与 cookie 关联的值                                       |
| getValue()          | 获取 cookie 关联的值                                         |
| setPath(uri)        | 设置 cookie 适用的路径，若不指定，则与当前页面相同目录下的所有 URL 都会返回 cookie |
| getPath()           | 获取 cookie 适用的路径                                       |
| setSecure(flag)     | 设置 cookie 是否应该只在加密的（即 SSL）连接上发送           |
| setComment(purpose) | 设置 cookie 的注释                                           |
| getComment()        | 获取 cookie 的注释                                           |



## Servlet 设置 Cookie

> [!WARNING] 注意
>
> 设置 Cookie 时，无论是名称还是值，都 **不能包含空格** 和以下的任何字符：
>
> ```tex
> [] () = , " ? / @ : ;
> ```

```java {6,8,10,11,13,14}
@WebServlet("/helloForm")
public class HelloForm extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 从请求中获取 name 参数
    Cookie name = new Cookie("name", URLEncoder.encode(req.getParameter("name"), StandardCharsets.UTF_8));
    // 从请求中获取 url 参数
    Cookie url = new Cookie("url", req.getParameter("url"));
    // 为 Cookie 设置过期时间为 24 小时
    name.setMaxAge(60 * 60 * 24);
    url.setMaxAge(60 * 60 * 24);
    // 在响应头中添加两个 Cookie
    resp.addCookie(name);
    resp.addCookie(url);

    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();
    writer.println("<h1>Cookie添加成功！</h1>");
  }

  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    doGet(req, resp);
  }
}
```



## Servlet 读取 Cookie

要读取 Cookie 需要通过调用 `getCookies()` 方法获取到 Cookie 数组，然后循环遍历数组获取每一个值。

```java {6,11,14}
@WebServlet("/helloForm")
public class HelloForm extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 获取请求头中的 Cookie
    Cookie[] cookies = req.getCookies();

    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();
    for (Cookie cookie : cookies) {
      String name = cookie.getName();
      // 如果是 name 属性，需要进行一下编码
      if ("name".equals(name)) {
        String value = URLDecoder.decode(cookie.getValue(), StandardCharsets.UTF_8);
        writer.println("<h1>" + name + ": " + value + "</h1>");
      } else {
        writer.println("<h1>" + name + ": " + cookie.getValue() + "</h1>");
      }
    }
  }

  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    doGet(req, resp);
  }
}
```



## Servlet 删除 Cookie

删除 Cookie 并没有直接的方法可以执行，但可以通过下面的步骤将其设置为立即过期来完成：

- 读取现有的 Cookie，并把它存储在 Cookie 对象中；
- 使用 `setMaxAge()` 方法设置 Cookie 的 Age 为 0 来删除现有的 Cookie；
- 最后再将这个 Cookie 添加到响应头中；

```java {6,21,22}
@WebServlet("/helloForm")
public class HelloForm extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 获取请求头中的 Cookie，当 Cookie 失效时，值为 null
    Cookie[] cookies = req.getCookies();

    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();

    if (cookies != null && cookies.length > 0) {
      for (Cookie cookie : cookies) {
        String name = cookie.getName();
        // 如果是 name 属性，需要进行一下编码
        if ("name".equals(name)) {
          String value = URLDecoder.decode(cookie.getValue(), StandardCharsets.UTF_8);
          writer.println("<h1>" + name + ": " + value + "</h1>");
        } else {
          writer.println("<h1>" + name + ": " + cookie.getValue() + "</h1>");
        }
        cookie.setMaxAge(0);
        resp.addCookie(cookie);
      }
    } else {
      writer.println("<h1>Cookie已失效！</h1>");
    }
  }

  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    doGet(req, resp);
  }
}
```
