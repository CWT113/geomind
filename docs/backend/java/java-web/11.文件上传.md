# 文件上传

Servlet 可以与 HTML Form 表单一起使用，来允许用户上传文件到服务器。

::: code-group

```java [UploadServlet] {3,4,5,20,21,24,33}
@WebServlet("/uploadFile")
@MultipartConfig(
  fileSizeThreshold = 1024 * 1024 * 3, // 内存临界值，3MB
  maxFileSize = 1024 * 1024 * 40, // 单个文件最大限制，40MB
  maxRequestSize = 1024 * 1024 * 50 // 单次请求总大小限制，50MB
)
public class UploadFile extends HttpServlet {
  private static final String UPLOAD_DIRECTORY = "upload";

  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 构造临时路径来存储上传的文件
    String uploadPath = req.getServletContext().getRealPath("./") + File.separator + UPLOAD_DIRECTORY;
    File uploadDir = new File(uploadPath);
    if (!uploadDir.exists()) {
      uploadDir.mkdirs();
    }

    try {
      for (Part part : req.getParts()) {
        String fileName = part.getSubmittedFileName();
        if (fileName != null && !fileName.isEmpty()) {
          String filePath = uploadPath + File.separator + fileName;
          part.write(filePath);
        }
      }
      req.setAttribute("message", "文件上传成功！");
    } catch (Exception e) {
      req.setAttribute("message", "错误信息：" + e.getMessage());
    }

    // 上传成功后，跳转到 message.jsp 页面
    req.getServletContext().getRequestDispatcher("/html/message.jsp").forward(req, resp);
  }
}
```

```html [upload.jsp]
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<html>
  <head>
	<title>文件上传实例</title>
  </head>
  <body>
	<h1>文件上传实例</h1>
	<form method="post" action="/uploadFile" enctype="multipart/form-data">
	  选择一个文件:
	  <input type="file" name="uploadFile"/>
	  <br/><br/>
	  <input type="submit" value="上传"/>
	</form>
  </body>

```

```html [message.jsp]
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<html>
  <head>
	<title>文件上传结果</title>
  </head>
  <body>
	<center>
	  <%-- req.setAttribute("message", "文件上传成功！") 的值会被写入到此处 --%>
	  <h2>${message}</h2>
	</center>
  </body>
</html>
```

:::

> [!NOTE] 参数配置
>
> 在 Servlet 3.0+ 之后，推荐使用原生的 `@MultipartConfig` 注解和 `HttpServletRequest.getPart()` 方法来实现文件上传，其中注解有以下
> 3 个关键参数：
>
> - `fileSizeThreshold`：内存临界值，当上传的文件大小 小于等于 3MB 时，文件数据会直接保存在服务器的内存中，处理速度最快；一旦上传的文件大小超过
    3MB，系统会自动把超出部分写入服务器的临时磁盘文件中，避免大文件占用过多内存导致服务器崩溃；
> - `maxFileSize`：单个文件最大显示，用于限制任意单个允许上传的文件的最大体积。如果用户尝试上传一个超过 40MB 的文件，Servlet
    会直接抛出异常并拒绝接收该文件；
> - `maxRequestSize`：单次请求总大小限制，用于限制整个 HTTP 请求的最大体积。如果用户在同一次请求中同时上传多个文件，所有文件体积加上表单数据的总和不能超过
    50MB；
