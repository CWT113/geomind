# 异常处理

Servlet 异常处理是 JavaWeb 应用程序中的一种防御性机制。当 Servlet 内部抛出未捕获的运行时异常，或业务逻辑触发特定的 HTTP 错误代码时，Servlet 容器会捕获这些异常，并**自动转发至预先定义好的错误处理页面**，避免将系统堆栈直接暴漏给终端用户。



## web.xml 配置

在 web.xml 中，通过 `<error-page>` 标签可以统一 **映射 HTTP 状态码** 或 **Java 异常类型**。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="http://xmlns.jcp.org/xml/ns/javaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd"
         version="4.0">
  <!-- 通过 error-code 映射：当出现 403、404 错误，映射到对应的 jsp 页面 -->
  <error-page>
    <error-code>403</error-code>
    <location>/error/403.jsp</location>
  </error-page>
  <error-page>
    <error-code>404</error-code>
    <location>/error/404.jsp</location>
  </error-page>

  <!-- 通过 exception-type 映射：当出现 ServletException 等异常时，统一映射到 errorHandler 去处理 -->
  <error-page>
    <exception-type>jakarta.servlet.ServletException</exception-type>
    <location>/errorHandler</location>
  </error-page>
  <error-page>
    <exception-type>java.lang.ArithmeticException</exception-type>
    <location>/errorHandler</location>
  </error-page>
</web-app>
```



## 异常属性读取

当 Servlet 出现异常时，容器会将错误上下文推入请求域，并使用以下固定的方法和属性名提取信息：

| 方法                   | 描述         |
| ---------------------- | ------------ |
| request.getAttribute() | 读取异常内容 |

| 属性名                               | 返回类型  | 描述                   |
| ------------------------------------ | :-------: | ---------------------- |
| jakarta.servlet.error.status_code    |  Integer  | HTTP 状态码            |
| jakarta.servlet.error.message        |  String   | 错误描述信息           |
| jakarta.servlet.error.request_uri    |  String   | 触发错误的请求资源 URI |
| jakarta.servlet.error.exception_type | Class<?>  | 抛出异常的 Class 类型  |
| jakarta.servlet.error.exception      | Throwable | 实际抛出的异常对象     |

::: code-group

```java [ErrorHandler] {6,8,10,12,14}
@WebServlet("/errorHandler")
public class ErrorHandler extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 获取 HTTP 状态码
    Integer statusCode = (Integer) req.getAttribute("jakarta.servlet.error.status_code");
    // 获取异常错误内容
    String message = (String) req.getAttribute("jakarta.servlet.error.message");
    // 获取异常错误发生的 URI
    String requestUri = (String) req.getAttribute("jakarta.servlet.error.request_uri");
    // 获取异常错误类型
    Class<?> exceptionType = (Class<?>) req.getAttribute("jakarta.servlet.error.exception_type");
    // 获取异常信息堆栈
    Throwable exception = (Throwable) req.getAttribute("jakarta.servlet.error.exception");

    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();
    writer.println("<h3>requestURI: " + requestUri + "</h3>");
    writer.println("<h3>statusCode: " + statusCode + "</h3>");
    writer.println("<h3>message: " + message + "</h3>");
    writer.println("<h3>exceptionType: " + exceptionType.getName() + "</h3>");
    writer.println("<h3>exception: " + exception.getClass().getName() + "</h3>");
  }

  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    doGet(req, resp);
  }
}
```

```java [HelloForm] {8}
@WebServlet("/helloForm")
public class HelloForm extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    // 手动制造 java.lang.ArithmeticException 异常
    int a = 100;
    int b = 0;
    int res = a / b; // 发生异常，会自动映射到 /errorHandler 内部
    resp.setContentType("text/html");
    PrintWriter writer = resp.getWriter();
    writer.println("<h1>结果是：" + res + "</h1>");
  }

  @Override
  protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    doGet(req, resp);
  }
}
```
