# 处理时间

使用 Servlet 最重要的优势之一是可以使用 Java 种的绝大多数可用的方法，如 `java.util` 包中的 `Date` 类。

| 方法            | 描述                                                         |
| --------------- | ------------------------------------------------------------ |
| after(date)     | 调用的 Date 对象种包含的日期在 date 之后，返回 true          |
| before(date)    | 调用的 Date 对象种包含的日期在 date 之前，返回 true          |
| equals(date)    | 判断调用的 Date 对象种包含的日期、时间是否和 date 相同，相同返回 true |
| compareTo(date) | 比较两个 date 值，若值相等返回 0；若调用对象在 date 之前，返回负值；若调用对象在 date 之后，则返回正值 |
| clone()         | 克隆 Date 对象                                               |
| getTime()       | 返回毫秒数                                                   |
| setTime(time)   | 设置 time 指定的时间和日期，表示从 1970 年 1 月 1 日开始的毫秒数 |



## 获取日期时间

```java {7}
@WebServlet("/currentDate")
public class CurrentDate extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();
    Date date = new Date();

    String title = "显示当前的日期和时间";
    String docType = "<!DOCTYPE html> \n";
    writer.println(docType +
                   "<html>\n" +
                   "<head><title>" + title + "</title></head>\n" +
                   "<body bgcolor=\"#f0f0f0\">\n" +
                   "<h1 align=\"center\">" + title + "</h1>\n" +
                   "<h2 align=\"center\">" + date + "</h2>\n" +
                   "</body></html>");
  }
}
```



## 格式化日期

`SimpleDateFormat` 是一个以语言环境敏感的方式来格式化和解析日期的具体类。

```java {8,17}
@WebServlet("/currentDate")
public class CurrentDate extends HttpServlet {
  @Override
  protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
    resp.setContentType("text/html;charset=UTF-8");
    PrintWriter writer = resp.getWriter();
    Date date = new Date();
    SimpleDateFormat sf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");

    String title = "显示当前的日期和时间";
    String docType = "<!DOCTYPE html> \n";
    writer.println(docType +
                   "<html>\n" +
                   "<head><title>" + title + "</title></head>\n" +
                   "<body bgcolor=\"#f0f0f0\">\n" +
                   "<h1 align=\"center\">" + title + "</h1>\n" +
                   "<h2 align=\"center\">" + sf.format(date) + "</h2>\n" +
                   "</body></html>");
  }
}
```
