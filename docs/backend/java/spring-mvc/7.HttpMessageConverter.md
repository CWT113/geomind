# HttpMessageConverter

`HttpMessageConverter` 是 SpringMVC 提供的一个核心策略接口，负责在 **HTTP 请求/响应体（二进制流/文本）与 Java 对象** 之间进行双向的序列化与反序列化。



当客户端发起请求或服务端返回响应时，网络传输的数据是基于文本或字节流的（如 JSON、XML、表单字符串），而 Java 代码操作的是强类型对象。`HttpMessageConverter` 就是连接二者的桥梁。



## 配置 Jackson 转换

首先在项目中引入 Jackson 相关依赖：

```xml
<dependencies>
  <!-- 引入 Jackson 核心数据绑定依赖 -->
  <dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.22.2</version>
  </dependency>
</dependencies>
```

基于纯 Java 配置类的项目中，需要实现 `WebMvcConfigurer`接口，并重写 `extendMessageConerters` 方法。

::: code-group

```java {8} [WebConfig]
@Configuration
@EnableWebMvc // 如果是 SpringBoot 项目，去掉此注解，避免覆盖 Boot 自动装配
@ComponentScan("com.example")
public class WebConfig implements WebMvcConfigurer {
  @Bean
  public void extendMessageConverters(List<HttpMessageConverter<?>> converters) {
    // 允许使用 Jackson 把 HTTP 请求里的 JSON 转换为 Java 对象
    converters.add(new MappingJackson2HttpMessageConverter());
  }
}
```

```xml [web.xml] {19}
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="https://jakarta.ee/xml/ns/jakartaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="https://jakarta.ee/xml/ns/jakartaee https://jakarta.ee/xml/ns/jakartaee/web-app_6_1.xsd"
         version="6.1">
  <!-- 配置 SpringMVC 前端控制器 -->
  <servlet>
    <servlet-name>springMVC</servlet-name>
    <servlet-class>org.springframework.web.servlet.DispatcherServlet</servlet-class>

    <!-- 指定容器类型为注解配置容器 -->
    <init-param>
      <param-name>contextClass</param-name>
      <param-value>org.springframework.web.context.support.AnnotationConfigWebApplicationContext</param-value>
    </init-param>
    <!-- 指定配置类全名称，让Spring容器去加载指定的配置类 -->
    <init-param>
      <param-name>contextConfigLocation</param-name>
      <param-value>com.example.config.WebConfig</param-value>
    </init-param>
  </servlet>

  <servlet-mapping>
    <servlet-name>springMVC</servlet-name>
    <url-pattern>/</url-pattern>
  </servlet-mapping>
</web-app>
```

:::

如果使用纯xml配置文件的方式，需要新建一个 `springMVC-servlet.xml` 文件：

::: code-group

```xml {19} [springMVC-servlet.xml]
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xmlns:mvc="http://www.springframework.org/schema/mvc"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd
                           http://www.springframework.org/schema/context
                           https://www.springframework.org/schema/context/spring-context.xsd
                           http://www.springframework.org/schema/mvc
                           https://www.springframework.org/schema/mvc/spring-mvc.xsd">
  <!-- 配置组件扫描 -->
  <context:component-scan base-package="com.example.controller"/>

  <!-- 启用注解式 MVC -->
  <mvc:annotation-driven>
    <!-- 允许使用 Jackson 把 HTTP 请求里的 JSON 转换为 Java 对象 -->
    <mvc:message-converters>
      <bean class="org.springframework.http.converter.json.MappingJackson2HttpMessageConverter"/>
    </mvc:message-converters>
  </mvc:annotation-driven>
</beans>
```

```xml [web.xml]
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="https://jakarta.ee/xml/ns/jakartaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="https://jakarta.ee/xml/ns/jakartaee https://jakarta.ee/xml/ns/jakartaee/web-app_6_1.xsd"
         version="6.1">
  <!-- 配置 SpringMVC 前端控制器 -->
  <servlet>
    <servlet-name>springMVC</servlet-name>
    <servlet-class>org.springframework.web.servlet.DispatcherServlet</servlet-class>
    <!-- 无需手动配置，Spring会自动查找 /WEB-INF/springMVC-servlet.xml 文件 -->
  </servlet>

  <servlet-mapping>
    <servlet-name>springMVC</servlet-name>
    <url-pattern>/</url-pattern>
  </servlet-mapping>
</web-app>
```
