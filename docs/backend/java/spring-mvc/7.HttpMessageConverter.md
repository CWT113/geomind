# HttpMessageConverter

`HttpMessageConverter` 是 SpringMVC 提供的一个核心策略接口，负责在 **HTTP 请求/响应体（二进制流/文本）与 Java 对象** 之间进行双向的序列化与反序列化。



当客户端发起请求或服务端返回响应时，网络传输的数据是基于文本或字节流的（如 JSON、XML、表单字符串），而 Java 代码操作的是强类型对象。`HttpMessageConverter` 就是连接二者的桥梁。



## 配置 Jackson 转换

首先在项目中引入 Jackson 相关依赖：

```xml
<dependencies>
  <!-- 引入 Jackson 核心数据绑定依赖 -->
  <dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.22.2</version>
  </dependency>
</dependencies>
```

基于纯 Java 配置类的项目中，需要实现 `WebMvcConfigurer` 接口，并重写 `extendMessageConerters` 方法。

::: code-group

```java {8} [WebConfig]
@Configuration
@EnableWebMvc // 如果是 SpringBoot 项目，去掉此注解，避免覆盖 Boot 自动装配
@ComponentScan("com.example")
public class WebConfig implements WebMvcConfigurer {
  @Override
  public void extendMessageConverters(List<HttpMessageConverter<?>> converters) {
    // 允许使用 Jackson 把 HTTP 请求里的 JSON 转换为 Java 对象
    converters.add(new MappingJackson2HttpMessageConverter());
  }
}
```

## 配置 fastjson2 转换

首先在项目中引入 fastjson2 相关依赖，需要注意的是 spring6 和 spirng5 使用的版本有区别：

```xml
<dependencies>
  <!-- 引入 fastjson2 依赖 -->
  <dependency>
    <groupId>com.alibaba.fastjson2</groupId>
    <artifactId>fastjson2</artifactId>
    <version>2.0.65</version>
  </dependency>
  <!-- 引入 fastjson2-extension-spring6 依赖 -->
  <dependency>
    <groupId>com.alibaba.fastjson2</groupId>
    <artifactId>fastjson2-extension-spring6</artifactId>
    <version>2.0.65</version>
  </dependency>
</dependencies>
```

基于纯 Java 配置类的项目中，需要实现 `WebMvcConfigurer` 接口，并重写 `extendMessageConerters` 方法。

::: code-group

```java {8}
@Configuration
@EnableWebMvc
@ComponentScan("com.example")
public class WebConfig implements WebMvcConfigurer {
  @Override
  public void extendMessageConverters(List<HttpMessageConverter<?>> converters) {
    // 允许使用 Jackson 把 HTTP 请求里的 JSON 转换为 Java 对象
    converters.add(new FastJsonHttpMessageConverter());
  }
}
```

```xml [web.xml]

<web-app xmlns="https://jakarta.ee/xml/ns/jakartaee"
```

## 请求输入注解

### @RequestBody

`@RequestBody` 注解用于提取请求体（Body），通过 `HttpMessageConverter` 反序列化为 Java 对象。

```java
@PostMapping("/users")
public String createUser(@RequestBody UserDto userDto) {
  return "Created: " + userDto.getUsername();
}
```



### RequestEntity

`RequestEntity<T>` 泛型容器类，不仅包含反序列化后的 Body，还完整的封装了请求头（Headers）、HTTP 方法（HttpMethod）和请求 URI。

```java 
@PostMapping("/orders")
public String processOrder(RequestEntity<OrderDto> request) {
  HttpHeaders headers = request.getHeaders();
  String traceId = headers.getFirst("X-Trace-Id");
  OrderDto body = request.getBody();

  return "Order processed with traceId: " + traceId;
}
```



## 请求输出注解

### @ResponseBody

`@ResponseBody` 注解用于告知 Spring 跳过视图解析，不再渲染 JSP/Thymeleaf 模板，直接将方法的返回值作为 HTTP 响应体，由匹配的 `HttpMessageConverter` 序列化输出。

```java {4}
@Controller
public class LegacyController {
  @GetMapping("/data")
  @ResponseBody // 返回字符串 index，而不是寻找名为 "index.html" 的视图
  public String getData() {
    return "index";
  }
}
```



### @RestController

`@RestController` 是一个复合注解，它组合了 `@Controller` 和 `@ResponseBody`，表示将该类中的所有方法均默认应用 `@ResponseBody`，全部返回 JSON，而非视图。

```java
@RestController
public class LegacyController {
  @GetMapping("/data")
  public String getData() {
    return "index";
  }
}
```



### ResponseEntity

`ResponseEntity<T>` 泛型响应容器类，用于全面控制 HTTP 响应的三大要素：HTTP 状态码、响应头以及响应体。

```java
@GetMapping("/users/{id}")
public ResponseEntity<UserDto> getUser(@PathVariable Long id) {
  UserDto user = userService.findById(id);
  if (user == null) {
    return ResponseEntity.notFound().build(); // 404
  }

  return ResponseEntity.ok() // 200 OK
    .header("X-Server-Time", String.valueOf(System.currentTimeMillis()))
    .body(user);
}
```
