# @RequestMapping 注解

`@RequestMapping` 是 SpringMVC 中用于 **建立 HTTP 请求路径与控制器方法之间隐射关系** 的核心注解。它可以标注在 **类** 或 **方法** 上，告诉 Spring 框架当某个特定的 URL 被访问时，应该由哪个方法来处理请求。

> [!NOTE] 标注的地方
>
> - **标注在类上**：定义该控制器下所有处理方法的通用根路径，起到模块化和命名空间的作用；
> - **标注在方法上**：定义具体的接口子路径，最终的访问路径为 `根路径 + 方法路径`。若类上未标注，则直接映射方法上的路径；

```java {2,5}
@Controller
@RequestMapping("/user")
public class UserController {
  // 最终的访问路径是 /users/list
  @RequestMapping("/list")
  public String getAllUsers() {
    return "User Profile";
  }
}
```



## 常用属性

| 属性         | 说明                                   | 示例                            |
| :----------: | :------------------------------------- | ------------------------------- |
| value / path | 映射的请求 URL，支持多个路径或 Ant 风格通配符 | path = “/list”                  |
| method       | 限制 HTTP 的请求方法                     | method = RequestMethod.POST     |
| params       | 限制请求中必须包含特定参数或参数值     | params = “type = admin”           |
| headers      | 限制请求头中必须包含特定字段或属性值   | headers = “context-type = text/*” |
| consumes     | 限制请求提交的媒体类型（Content-Type） | consumes =“application/json”     |
| produces | 指定返回的内容类型，通常结合 `@ResponseBody` 设置编码格式 | produces = “application/json; charset = UTF-8” |





### value 属性

> [!NOTE] Ant 风格
>
> value 属性是可以用来匹配路径的，路径支持模糊匹配，我们把这种模糊匹配称之为 Ant 风格。关于路径中的通配符包括：
>
> - `?`：代表一个字符；
> - `*`：代表 0 ~ n 个任意字符；
> - `**`：代表 0 ~ n 个任意字符，并且路径中可以出现路径分割符。但注意：`**` 通配符使用时，左右不能出现字符，只能是 `/`；

::: code-group

```java [基本使用] {3,10}
@Controller
public class UserController {
  @RequestMapping("/list") // 如果只写了一个 value 属性，可以省略 value
  @RequestMapping(value = "/list") // 如果只有一个接口，可以省略 {}
  @RequestMapping(value = {"/list", "/getAllUser"}) // 可以是一个数组，无论请求哪一个都执行该接口
  public String getAllUsers() {
    return "all users";
  }

  @RequestMapping(path = "/list") // path 属性和 value 属性的功能完全一样
  public String getDetail() {
    return "user detail";
  }
}
```

```java [Ant风格] {3,8,13}
@Controller
public class UserController {
  @RequestMapping(value = "/a?z/list") // 只要是任意的字符都能请求成功，如：aaz，abz，acz
  public String getAllUsers() {
    return "all users";
  }

  @RequestMapping(path = "/a*z/detail") // 任意的 0 ~ n 个字符都能请求成功，如：aaz，abcz，aabcdz
  public String getDetail() {
    return "user detail";
  }

  @RequestMapping(path = "/**/addUser") // 任意的前缀都能请求成功，如：a/addUser，abc/addUser
  public String addUser() {
    return "user detail";
  }
}
```

:::



### method 属性

正常情况下，如果不指定 method 属性，该接口将默认接收所有类型的 HTTP 请求（包括 GET、POST、PUT、DELTE 等）。

```java {3,8,14,19}
@Controller
public class UserController {
  @RequestMapping(value = "/detail", method = RequestMethod.GET)
  public String getDetail() {
    return "user detail";
  }

  @RequestMapping(value = "/addUser", method = RequestMethod.POST)
  public String addUser() {
    return "add user";
  }

  // 表示 POST 或 PUT 请求都可以执行该接口
  @RequestMapping(value = "/editUser", method = {RequestMethod.POST, RequestMethod.PUT})
  public String editUser() {
    return "edit user";
  }

  @RequestMapping(value = "/deleteUser", method = RequestMethod.DELETE)
  public String deleteUser() {
    return "delete user";
  }
}
```

为了简化代码，Spring 专门引入了 `@RequestMapping` 的衍生注解，其底层本质都是对 method 的封装。

|        衍生注解         | 等价于                                                       |
| :---------------------: | ------------------------------------------------------------ |
|  @GetMapping(“/path”)   | @RequestMapping(value = "/path", method = RequestMethod.GET) |
|  @PostMapping("/path")  | @RequestMapping(value = "/path", method = RequestMethod.POST) |
|  @PutMapping("/path")   | @RequestMapping(value = "/path", method = RequestMethod.PUT) |
| @DeleteMapping("/path") | @RequestMapping(value = "/path", method = RequestMethod.DELETE) |

```java {4,10,16,22}
@Controller
public class UserController {
  // @RequestMapping(value = "/detail", method = RequestMethod.GET)
  @GetMapping("/detail")
  public String getDetail() {
    return "user detail";
  }

  // @RequestMapping(value = "/addUser", method = RequestMethod.POST)
  @PostMapping("/addUser")
  public String addUser() {
    return "add user";
  }

  // @RequestMapping(value = "/editUser", method = {RequestMethod.POST, RequestMethod.PUT})
  @PutMapping("/editUser") // 衍生注解是单一的注解，因此无法完成两种请求都执行同一个方法，但可以再写一个方法，用 PostMapping 标注
  public String editUser() {
    return "edit user";
  }

  // @RequestMapping(value = "/deleteUser", method = RequestMethod.DELETE)
  @DeleteMapping("deleteUser")
  public String deleteUser() {
    return "delete user";
  }
}
```



### params 属性

只有当请求种携带的参数完全满足 `params` 指定的表达式条件时，SpringMVC 才会将请求分发给该方法。

核心表达式语法：

|      语法       | 描述                                                     |
| :-------------: | -------------------------------------------------------- |
|     “name”      | 请求中必须包含名为 name 的参数，值不限                   |
|     “!name”     | 请求中严禁包含名为 name 的参数                           |
| “name=admin” | 请求中必须包含名为 name 的参数，且值必须等于 admin       |
| “name!=admin” | 请求中不能包含名为 name 的参数，或包含但值不能等于 admin |

```java {4,11,18,25}
@Controller
public class UserController {
  // 必须携带 name 参数，如: /user?name=tom
  @GetMapping(value = "/user", params = "name")
  @ResponseBody
  public String getUserById(@RequestParam String name) {
    return "User: " + name;
  }

  // 不能携带 name 参数
  @GetMapping(value = "/user2", params = {"!name"})
  @ResponseBody
  public String getUserById2() {
    return "user2";
  }

  // 必须携带 name 参数，且值必须是 tom
  @GetMapping(value = "/user3", params = {"name=tom"})
  @ResponseBody
  public String getUserById3(@RequestParam String name) {
    return "user2: " + name;
  }

  // 不能携带 name 参数，或者包含 name 参数但值不能为 tom
  @GetMapping(value = "/user4", params = {"name!=tom"})
  @ResponseBody
  public String getUserById4() {
    return "user4";
  }
}
```



### headers 属性

只有当客户端请求携带的 Header 完全符合 headers 属性中声明的规则时，该请求才会被分发到对应的方法进行处理。

核心表达式语法：

|        语法         | 描述                                                         |
| :-----------------: | ------------------------------------------------------------ |
|    “headerName”     | 请求中必须包含名为 headerName 的请求头，值不限               |
|    “!headerName”    | 请求中严禁包含名为 headerName 的请求头                       |
| “headerName=value”  | 请求中必须包含名为 headerName 的请求头，且值必须等于 value   |
| “headerName!=value” | 请求中不能包含名为 headerName 的请求头，或包含但值不能等于 value |

```java {4,11,18,25}
@Controller
public class UserController {
  // 请求头中必须携带 Authorization
  @GetMapping(value = "/user", headers = "Authorization")
  @ResponseBody
  public String getUserById() {
    return "OK";
  }

  // 请求头中不能携带 Debug-Mode
  @GetMapping(value = "/user2", headers = "!Debug-Mode")
  @ResponseBody
  public String getUserById2() {
    return "OK";
  }

  // 请求头中必须携带 Authorization，且值必须是 Bearer123
  @GetMapping(value = "/user3", headers = {"Authorization=Bearer123"})
  @ResponseBody
  public String getUserById3() {
    return "OK";
  }

  // 请求头中不能包含 Debug-Mode，或者包含 Debug-Mode 参数但值不能为 development
  @GetMapping(value = "/user4", headers = {"Debug-Mode!=development"})
  @ResponseBody
  public String getUserById4() {
    return "OK";
  }
}
```
