# RESTful 架构风格

RESTful 架构风格是一种基于 HTTP 协议的网络 API 设计规范。其核心理念是将网络服务视作“资源”的管理，通过 URL 定位资源，使用标准 HTTP 动词操作资源，并利用 HTTP 状态码反映操作结果。

> [!NOTE] 核心要素
>
> - **资源定位**：URI 仅用于标识资源，只能使用名词，避免动词，通常采用名词复数形式（如：`/users`、`/articles`）；
> - **操作动词**：动作统一由标准的 HTTP 请求方法定义（如：GET、POST）；
> - **无状态性**：服务端不保存客户端的交互上下文，每次请求必须携带身份认证及处理所需的全部参数（如：JWT）；
> - **语义化状态码**：不再用统一的 200，而是使用更加标准的 HTTP 状态码（如：201、204、400、404）；

```java [RESTful风格] {10,21,32,43,54,65,66}
@RestController
@RequestMapping("/user")
public class UserController {
  /**
   * 查询所有
   * GET /user
   * @param userDto 查询条件
   */
  @GetMapping
  public String getAllUsers(UserDto userDto) {
    System.out.println(userDto);
    return "OK";
  }

  /**
   * 查询详情
   * GET /user/1
   * @param userId 用户Id
   */
  @GetMapping("/{userId}")
  public String getUserById(@PathVariable Long userId) {
    System.out.println(userId);
    return "OK";
  }

  /**
   * 新增用户
   * POST /user
   * @param userDto 用户信息
   */
  @PostMapping
  public String createUser(@RequestBody UserDto userDto) {
    System.out.println(userDto);
    return "OK";
  }

  /**
   * 更新用户
   * PUT /user
   * @param userDto 用户信息
   */
  @PutMapping
  public String updateUser(@RequestBody UserDto userDto) {
    System.out.println(userDto);
    return "OK";
  }

  /**
   * 删除用户
   * DELETE /user/1
   * @param userId 用户Id
   */
  @DeleteMapping("/{userId}")
  public String deleteUserById(@PathVariable Long userId) {
    System.out.println(userId);
    return "OK";
  }

  /**
   * 批量删除用户
   * DELETE /user?ids=1,2,3
   * @param userIds 用户Id集合
   */
  @DeleteMapping
  public String deleteUsers(@RequestParam("ids") List<Long> userIds) { // 名称不同，手动把请求参数 ids 映射到形参 userIds 上
    // public String deleteUsers(Long[] ids) { // 名称相同，自动映射到 ids 上
    System.out.println(userIds);
    return "OK";
  }
}
```
