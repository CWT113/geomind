# 获取请求参数

## 获取请求参数

### 默认形参匹配

当请求参数名与 Controller 方法的形参名称一致时，SpringMVC 会自动将参数值转换为对应类型并注入。

- **适用场景：** 简单的 GET 或 POST 表单提交

```java {6}
@RestController
@RequestMapping("/user")
public class UserController {
  // 请求地址：/user/getUserById?userId=1
  @GetMapping("/getUserById")
  public String getUserById(Integer userId) { // 不需要写 @RequestParam，形参名与请求参数名完全一致即可自动绑定
    return "OK，UserId: " + userId;
  }
}
```



::: info 解决报错问题

如果上面的接口在请求时报错，内容如下：

```tex
Request processing failed: java.lang.IllegalArgumentException: Name for argument of type [java.lang.String] not specified, and parameter name information not available via reflection. Ensure that the compiler uses the '-parameters' flag.
```

此时需要在 `pom.xml` 中配置 **开启参数名称保留**。因为默认在编译打包时，会把 `String name` 打包成类似于 `arg0` 之类的参数，开启后则会原样打包。

```xml {8}
<build>
  <plugins>
    <plugin>
      <groupId>org.apache.maven.plugins</groupId>
      <artifactId>maven-compiler-plugin</artifactId>
      <configuration>
        <!-- 开启参数名保留 -->
        <parameters>true</parameters>
      </configuration>
    </plugin>
  </plugins>
</build>
```

> [!TIP] 提示
>
> 配置完成后，记得执行 `mvn clean` 命令清理后，再进行打包！

:::



### Pojo 对象绑定

当参数较多时，可以直接使用一个 Java 对象接收，SpringMVC 会 **通过反射自动匹配对象中的属性名** 和 setter 方法。

- **适用场景**：表单提交、多条件筛选查询；

::: code-group

```java {6} [UserController]
@RestController
@RequestMapping("/user")
public class UserController {
  // 请求路径：/user/register?username=tom&password=12345&address.city=xian
  @PostMapping("/register")
  public String register(UserDto user) {
    return user.toString();
  }
}
```

```java [UserDto]
@Data
public class UserDto {
  private String username;

  private String password;

  // 支持 address.city 级联赋值操作
  private Address address;
}

@Data
class Address {
  private String city;
}
```

:::



### @RequestParam

用于显式指定参数名、设置是否必填（`required`）以及提供默认值（`defaultValue`）。

- **适用场景**：参数名与方法形参不同名、参数必填校验或需设定默认值；

```java {7,8}
@RestController
@RequestMapping("/user")
public class UserController {
  // 请求路径：/user/list?username=admin
  @GetMapping("/list")
  public String list(
    @RequestParam("username") String name, // 把请求参数中的 username 映射到 name 形参上
    @RequestParam(value = "password", required = false, defaultValue = "1234") String password
  ) {
    return "OK，Username = " + name + "，Password = " + password;
  }
}
```



### @PathVariable

`@PathVariable` 适合在 RESTful 风格的接口中，通过 URL 模板映射把路径片段作为参数提取出来。

```java {5,6,11,12}
@RestController
@RequestMapping("/user")
public class UserController {
  // 请求路径：/user/deleteUser/1001
  @GetMapping("/deleteUser/{userId}")
  public String deleteUser(@PathVariable Integer userId) { // @PathVariable 不写参数时，{userId} 与 userId 名称必须一致
    return "OK，UserId = " + userId;
  }

  // 请求路径：/user/deleteUser/1001
  @GetMapping("/deleteUser2/{id}")
  public String deleteUser2(@PathVariable("id") Integer userId) { // @PathVariable 写参数时，表示把 {id} 映射到 userId 形参上
    return "OK，UserId = " + userId;
  }
}
```



### @RequestBody

利用 `HttpMessageConverter` （如 Jackson）将 **请求体中的 JSON 序列化并绑定到实体对象** 上。

- **适用场景**：前后端分离开发中的 POST/PUT JSON 数据交互；

- **请求示例**：请求头中包含 `Content-Type: application/json`，Body 内容为 `{ "name": "tom", "age": 25 }`；



使用 `@RequestBody` 获取 JSON 请求体时，需要先配置 Jackson，允许让 Jackson 把 HTTP 请求中的 JSON 数据转换为对应的 Java 类：

::: code-group

```java {6} [UserController]
@RestController
@RequestMapping("/user")
public class UserController {
  // 请求路径：/user/createUser，请求体为 { "username": "admin", "password": "123456" }
  @PostMapping("/createUser")
  public String createUser(@RequestBody UserDto userDto) { // 请求体中的 JSON 数据，会自动映射到 dto 中对应的字段上
    return "OK，UserDto = " + userDto.toString();
  }
}
```

```java [UserDto]
@Data
public class UserDto {
  private String username;

  private String password;
}
```

```xml [web.xml] {18-20}
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
```

### 原生 ServletAPI 注入

SpringMVC 支持直接将 `HttpServletRequest`、`HttpSession` 作为形参注入。

- **适用场景**：需要底层 Servlet 能力、灵活动态遍历参数或读取原始输入流；

```java
@RestController
@RequestMapping("/user")
public class UserController {
  // 请求路径：/user/getUser?customParam=superAdmin
  @GetMapping("/getUser")
  public String getUser(HttpServletRequest request) {
    String userAgent = request.getHeader("User-Agent");
    String ipAddress = request.getRemoteAddr();
    String customParam = request.getParameter("customParam");
    return "IP: " + ipAddress + ", UA: " + userAgent + ", Param: " + customParam;
    // 输出："IP: 127.0.0.1, UA: PostmanRuntime/2.5.0, Param: superAdmin"
  }
}
```



### 集合与数组绑定

用于接收同一个参数名的多值传递（如复选框选中项或批量 ID）。

- **数组**：直接声明数组类型即可；
- **List 集合**：必须使用 `@RequestParam` 注解，否则 Spring 默认会将其当成 JavaBean 处理，并抛出实例化异常；

```java
@RestController
@RequestMapping("/user")
public class UserController {
  // 请求路径：/user/getUser1?ids=1&ids=2&ids=3
  @GetMapping("/getUser1")
  public String getUser1(Long[] ids) {
    return "Array Ids: " + Arrays.toString(ids);
  }

  // 请求路径：/user/getUser2?ids=1&ids=2&ids=3
  @GetMapping("/getUser2")
  public String getUser2(@RequestParam("ids") List<Long> ids) {
    return "List Ids: " + ids.toString();
  }
}
```



## 获取请求头参数

### @RequestHeader

`@RequestHeader` 的用法和 `@RequestParam` 的用法一样，只不过它是专门用来获取请求头中参数的信息。

```java {6,7}
@RestController
@RequestMapping("/user")
public class UserController {
  @GetMapping("/list")
  public String list(
    @RequestHeader("User-Agent") String userAgent,
    @RequestHeader(value = "Host", required = false, defaultValue = "") String host
  ) {
    return "OK，UserAgent = " + userAgent + "，Host = " + host;
  }
}
```



## 获取 Cookie 值

### @CookieValue

`@CookieValue` 的用法也和 `@RequestParam` 的用法一样，只不过它是专门用来获取请求头中 Cookie 值的信息。

```java {6}
@RestController
@RequestMapping("/user")
public class UserController {
  @GetMapping("/list")
  public String list(
    @RequestHeader(value = "Cookie", required = false, defaultValue = "") String cookie
  ) {
    return "OK，Cookie = " + cookie;
  }
}
```
