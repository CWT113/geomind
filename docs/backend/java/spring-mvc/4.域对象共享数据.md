# 域对象共享数据

SpringMVC 沿用并封装了 JavaWeb 中 Servlet 的域对象，核心主要有 Request 域（请求域）、Session 域（会话域）、Application 域（应用域）。

|     域对象     |   对应的 Servlet   | 生命周期                                                                                    |
|:--------------:|:------------------:|:--------------------------------------------------------------------------------------------|
|   Request 域   | HttpServletRequest | 单次 HTTP 请求内有效。请求转发（Forward）可共享，重定向（Redirect）失效                     |
|   Session 域   |    HttpSession     | 一次会话内有效。同一客户端多次请求间共享，直到会话超时、浏览器会话关闭或调用 `invalidate()` |
| Application 域 |   ServletContext   | 整个 Web 应用运行期间全局有效。所有用户、所有会话均可共享，随服务启动创建，随服务关闭销毁   |



## Request 域

在 SpringMVC 中，向 Request 域传递数据主要有 6 种常见的实现方式。

虽然使用语法各有不同，但除原生 ServletAPI 之外，其余方式底层均依托于同一个模型对象（`BindingAwareModelMap`），在视图渲染阶段由框架统一调用 `request.setAttribute()` 将键值对存入 Request 域。



### 原生 ServletAPI

直接在控制器方法的形参中声明 `HttpServletRequest` ，通过标准的 Servlet API 存入数据。

> [!NOTE] 特点
>
> 简单直观，但与 Servlet API 强耦合，不利于单元测试，现代 Spring 开发中通常不作为首选。

```java
@RestController
@RequestMapping("/user")
public class UserController {
  @GetMapping("/list")
  public String list(HttpServletRequest request) {
    request.setAttribute("userId", 1001);
    request.setAttribute("username", "admin");
    return "OK";
  }
}
```



### Model 接口（推荐）

SpringMVC 提供的轻量级模型接口，专门用于承载试图所需的数据。

> [!NOTE] 特点
>
> 代码与 Servlet API 规范解耦，只负责提供数据容器，是 Controller 开发中最推荐、最常用的方式。

```java
@RestController
@RequestMapping("/user")
public class UserController {
  @GetMapping("/list")
  public String list(Model model) {
    // 存入键值对
    model.addAttribute("userId", 1001);
    model.addAttribute("username", "admin");
    // 存入值是一个对象
    model.addAttribute("user", new User("admin", 123456));
    // 如果没有写 attributeName 的话，默认名称是类名首字母小写
    model.addAttribute(new User("admin", 123456));

    return "OK";
  }
}
```



### Map 接口

在方法入参中声明 `java.util.Map`，SpringMVC 会自动为其注入底层模型上下文的引用。

```java
@RestController
@RequestMapping("/user")
public class UserController {
  @GetMapping("/list")
  public String list(Map<String, Object> map) {
    // 完全按照 Map 的键值对方式赋值
    map.put("username", "admin");
    map.put("password", 123456);
    return "OK";
  }
}
```



### ModelMap 类

`ModelMap` 继承自 `LinkedHashMap<String, Object>`，同时提供了链式调用的便捷方法。

```java
@RestController
@RequestMapping("/user")
public class UserController {
  @GetMapping("/list")
  public String list(ModelMap modelMap) {
    // 既可以使用 addAttribute，也可以像 Map 一样使用 put 方法
    modelMap.addAttribute("username", "admin")
            .addAttribute("password", 123456);
    return "OK";
  }
}
```



### ModelAndView 类

将 **模型数据** 与 **视图名称** 统一打包为一个对象作为方法的返回值，不再依赖方法的 String 返回值指定视图。

```java
@RestController
@RequestMapping("/user")
public class UserController {
  @GetMapping("/list")
  public String list(Map<String, Object> map) {
    ModelAndView modelAndView = new ModelAndView();
    // 添加模型数据
    modelAndView.addObject("username", "admin");
    modelAndView.addObject("password", 123456);
    // 指定视图名称
    modelAndView.setViewName("index");
    return "OK";
  }
}
```



### @ModelAttribute

`@ModelAttribute` 可应用于 **方法** 或 **方法入参** 上，自动将数据放置在 `Request` 域中。

```java {5,11}
@RestController
@RequestMapping("/user")
public class UserController {
  // 每次请求都会将公共数据放入 Request 域中，key=userId，value=1001
  @ModelAttribute("userId")
  public Integer setUserId() {
    return 1001;
  }

  @GetMapping("/list")
  public String list(@ModelAttribute("userId") Integer userId) { // 在入参处通过注解获取到公共数据
    return "OK: UserId = " + userId;
  }
}

```



## Session 域

### 原生 ServletAPI

在控制器方法的形参中直接声明 `HttpSession` 或 `HttpServletRequest`，Spring MVC 会在调用该方法时自动将当前会话的 Session 实例注入进来。

```java {6,7,15,18}
@RestController
public class LoginController {
  @PostMapping("/login")
  public String login(String username, String password, HttpSession session) {
    // 存入 Session 域
    session.setAttribute("username", username);
    session.setAttribute("password", password);
    return "Login Success: Username = " + username + " Password = " + password;
  }

  @GetMapping("/logout")
  public String logout(HttpSession session) {
    System.out.println(session.getAttribute("username"));
    // 清除指定属性
    session.removeAttribute("username");
    session.removeAttribute("password");
    // 手动使整个会话失效
    session.invalidate();
    return "Logout Success";
  }
}
```



### @SessionAttributes

在 Controller 类上声明 `@SessionAttributes`，指定哪些属性需要同步到 Session。当该 Controller 中的方法向 `Model` 添加同名属性时，SpringMVC 会自动将其同步备份到 Session 域中。

```java {19,3,8,9,14,15}
@RestController
// 当 Controller 中的 Model 中出现名为 username、password 的属性时，SpringMVC 会将这些属性同步到当前会话的 Session 中
@SessionAttributes({"username", "password"})
public class LoginController {
  // 写入 Model，Spring 会自动同步到 Session
  @PostMapping("/login")
  public String login(String username, String password, Model model) {
    model.addAttribute("username", username);
    model.addAttribute("password", password);
    return "Login Success: Username = " + username + " Password = " + password;
  }

  @GetMapping("/logout")
  public String logout(@SessionAttribute(value = "username", required = false) String username,
                       @SessionAttribute(value = "password", required = false) String password,
                       SessionStatus status
                      ) {
    // 当前 Controller 中由 @SessionAttributes 管理的 Session 属性处理完成，可以清理掉
    status.setComplete();
    return "Logout Success，Username = " + username + " Password = " + password;
  }
}

```





## Application 域

### 原生 ServletAPI

在控制器方法中注入 `HttpServletRequest` 或 `HttpSession`，通过 `getServletContext()` 方法获取底层的 `ServletContext` 实例进行操作。

```java {8,16,18,9}
@RestController
public class LoginController {
  @PostMapping("/login")
  public String login(String username, String password, HttpServletRequest request) {
    ServletContext application = request.getServletContext();
    application.setAttribute("username", username);
    application.setAttribute("password", password);
    return "Login Success: Username = " + username + " Password = " + password;
  }

  @GetMapping("/logout")
  public String logout(HttpSession session) {
    ServletContext context = session.getServletContext();
    // 读取全局共享数据
    String username = (String) context.getAttribute("username");
    String password = (String) context.getAttribute("password");
    return "Logout Success: Username = " + username + " Password = " + password;
  }
}
```



### 注入 ServletContext

SpringWeb 容器在启动时会自动将当前的 `ServletContext` 实例注入到容器中。可以在任何由 Spring 管理的组件（Controller、Service、Component）中直接注入该对象。

```java {3,4}
@RestController
public class LoginController {
  @Autowired
  private ServletContext servletContext;

  @PostMapping("/login")
  public String login(String username, String password) {
    servletContext.setAttribute("username", username);
    servletContext.setAttribute("password", password);
    return "Login Success: Username = " + username + " Password = " + password;
  }

  @GetMapping("/logout")
  public String logout(HttpSession session) {
    ServletContext context = session.getServletContext();
    // 读取全局共享数据
    String username = (String) servletContext.getAttribute("username");
    String password = (String) servletContext.getAttribute("password");
    return "Logout Success: Username = " + username + " Password = " + password;
  }
}
```
