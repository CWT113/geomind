# AVL 树

**平衡二叉搜索树**（Balanced Binary Tree，BBT）是一种结构平衡的二叉搜索树，即 **叶子节点的高度差不超过 1**，并且左右两个子树都是一棵平衡二叉树。

它能在 $O(log_2n)$ 内完成插入、查找和删除操作，最早被发明的平衡二叉搜索树就是 AVL 树。

常见的平衡二叉搜索树有：AVL 树、红黑树和 Treap（树堆）。
