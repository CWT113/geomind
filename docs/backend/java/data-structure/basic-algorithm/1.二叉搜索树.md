# 二叉搜索树

**二叉搜索树**（Binary Search Tree，BST），又称二叉查找树、有序二叉树或排序二叉树，是一种特殊的二叉树结构。

> [!NOTE] 二叉搜索树的性质
>
> - 对于任意节点，如果其左子树非空，则左子树所有节点的值均 **小于** 该节点的值；
> - 对于任意节点，如果其右子树非空，则右子树所有节点的值均 **大于** 该节点的值；
> - 任意节点的左右子树也都分别是二叉搜索树（递归定义）；

![二叉搜索树](https://qcdn.itcharge.cn/images/20240511171406.png)

二叉搜索树的核心特性：**左子树所有节点值 < 根节点值 < 右子树所有节点值**。



## 查找

> 二叉搜索树查找：即在二叉搜索树中定位 key 对于的值。

二叉搜索树的查找过程和二分查找的思路很相似，通过对比当前节点的 key 与 待查找的 key，每次高效的缩小一半的范围。

查找算法复杂度分析：

|    指标    |   复杂度    | 说明                                                      |
| :--------: | :---------: | --------------------------------------------------------- |
|  最优时间  | $O(log_2n)$ | 树接近完全平衡，高度为 $h = log_2n$，每次查找缩小一半范围 |
|  最坏时间  |   $O(n)$    | 树退化为单链表，需要遍历所有节点                          |
|  平均时间  | $O(log_2n)$ | 随机插入的情况下，平均查找时长为 $long_2n$                |
| 空间复杂度 |   $O(1)$    | 递归实现时为 $O(h)$，迭代实现为 $O(1)$，$h$ 为树高        |

::: code-group

```java [迭代实现] {8,10,12}
public class BSTTree1 {
  public BSTNode root;

  public Object get(int key) {
    BSTNode node = root;
    while (node != null) {
      if (key < node.key) {
        node = node.left;  // 向左查找
      } else if (key > node.key) {
        node = node.right; // 向右查找
      } else {
        return node.value; // 找到了
      }
    }
    return null;
  }
}
```

```java [递归实现] {13,15,17}
public class BSTTree1 {
  public BSTNode root;

  public Object get(int key) {
    return doGet(root, key);
  }

  private Object doGet(BSTNode node, int key) {
    if (node == null) {
      return null;
    }
    if (key < node.key) {
      return doGet(node.left, key); // 向左查找
    } else if (key > node.key) {
      return doGet(node.right, key); // 向右查找
    } else {
      return node.value;
    }
  }
}
```

```java [BSTNode]
/**
 * 二叉搜索树节点类

static class BSTNode {
  int key;
  Object value;
  BSTNode left;
  BSTNode right;

  public BSTNode(int key) {
    this.key = key;
  }

  public BSTNode(int key, Object value) {
    this.key = key;
    this.value = value;
  }

  public BSTNode(int key, Object value, BSTNode left, BSTNode right) {
    this.key = key;
    this.value = value;
    this.left = left;
    this.right = right;
  }
}
```

## 最小左子树

::: code-group

```java [迭代版本] {12-15}
public class BSTTree1 {
  public BSTNode root;

  public Object min() {
    return min(root);
  }

  private Object min(BSTNode node) {
    if (node == null) {
      return null;
    }
    BSTNode p = node;
    while (p.left != null) {
      p = p.left;
    }
    return p.value;
  }
}
```

```java [递归版本] {21}
public class BSTTree1 {
  public BSTNode root;

  public Object min() {
    return doMin(root);
  }

  /**
   * 递归查找最小左子树
   * @param node 节点
   * @return 最小左子树值
   */
  private Object doMin(BSTNode node) {
    if (node == null) {
      return null;
    }
    // 没有左子节点时，表示已找到最小子节点
    if (node.left == null) {
      return node.value;
    }
    return doMin(node.left);
  }
}
```

## 插入

二叉搜索树插入时不允许出现重复的节点，因此如果 值 已存在于树中，则更新，否则插入。

```java {15,22,28,30}
public class BSTTree1 {
  public BSTNode root;

  public void put(int key, Object value) {
    BSTNode node = root;
    BSTNode parent = null; // 记录父节点
    while (node != null) {
      parent = node;
      if (key < node.key) {
        node = node.left;
      } else if (key > node.key) {
        node = node.right;
      } else {
        // 更新
        node.value = value;
        return;
      }
    }

    // 如果 parent 为空，表示树为空，则将当前节点作为根节点
    if (parent == null) {
      root = new BSTNode(key, value);
      return;
    }

    // 新增：如果 parent 不为空，则判断插入左子树还是右子树
    if (key < parent.key) {
      parent.left = new BSTNode(key, value);
    } else {
      parent.right = new BSTNode(key, value);
    }
  }
}
```





## 查找前驱

> [!TIP] 查找思路
>
> 1. **先找节点**：沿查找路径遍历，查看当前节点是否存在，并同时记录“自左而来的祖先”；
> 2. **两种情况处理**：
>    - 节点有左子树：则查找 **左子树最大的节点**，就是前驱节点；
>    - 节点无左子树：则最近的 **自左而来的祖先节点**，就是前驱节点；
>
> 注：“自左而来的祖先”表示在查找路径上，最后一个需要你 **往右走** 的节点，这个节点比目标小，可能是前驱。

```java {29,31}
public class BSTTree1 {
  public BSTNode root;

  public Object successor(int key) {
    BSTNode node = root;
    BSTNode ancestorFromLeft = null; // 自左而来的祖先节点
    while (node != null) {
      if (key < node.key) {
        node = node.left;
      } else if (key > node.key) {
        ancestorFromLeft = node;
        node = node.right;
      } else {
        // 找到了当前节点，不做任何处理
        break;
      }
    }
    // 如果没有找到对应的节点，表示树里面没有该节点
    if (node == null) {
      return null;
    }

    /**
     * 找到节点：
     * 情况1：当前节点有左子树，则左子树的最大右子树就是前驱节点
     * 情况2：当前节点没有左子树，则离它最近的、自左而来的祖先就是前驱节点
     */
    if (node.left != null) {
      return max(node.left);
    }
    return ancestorFromLeft != null ? ancestorFromLeft.value : null;
  }
}
```



## 查找后继

>[!TIP] 查找思路
>
>1. **先找节点**：沿查找路径遍历，查看当前节点是否存在，并同时记录“自右而来的祖先”；
>2. **两种情况处理**：
>   - 节点有右子树：则查找 **右子树最小的节点**，就是后继节点；
>   - 节点无右子树：则最近的 **自右而来的祖先节点**，就是后继节点；
>
>注：“自右而来的祖先节点”表示在查找路径上，最后一个需要你 **往左走** 的节点，这个节点比目标小，可能是前驱。

```java {22,24}
public class BSTTree1 {
  public BSTNode root;

  public Object predecessor(int key) {
    BSTNode node = root;
    BSTNode ancestorFromRight = null; // 自右而来的祖先节点
    while (node != null) {
      if (key < node.key) {
        ancestorFromRight = node;
        node = node.left;
      } else if (key > node.key) {
        node = node.right;
      } else {
        break;
      }
    }
    // 如果没有找到对应的节点，表示树里面没有该节点
    if (node == null) {
      return null;
    }
    if (node.right != null) {
      return min(node.right);
    }
    return ancestorFromRight != null ? ancestorFromRight.value : null;
  }
}
```



## 删除

二叉搜索树最大的缺点就是 在经过多次插入和删除操作后，树可能退化为链表。这种情况下，所有的操作时间复杂度都将从 $O(log_2n)$ 劣化为 $O(n)$。

![AVL 树在删除节点后发生退化](https://www.hello-algo.com/chapter_tree/avl_tree.assets/avltree_degradation_from_removing_node.png)

```java
public class BSTTree1 {
  public BSTNode root;

  public Object delete(int key) {
    BSTNode node = root;
    BSTNode parent = null;
    while (node != null) {
      if (key < node.key) {
        parent = node;
        node = node.left;
      } else if (key > node.key) {
        parent = node;
        node = node.right;
      } else {
        break;
      }
    }
    // 没有找到节点
    if (node == null) {
      return null;
    }

    if (node.left == null) { // 有右孩子，没左孩子
      shift(parent, node, node.right);
    } else if (node.right == null) { // 有左孩子，没有右孩子
      shift(parent, node, node.left);
    } else {
      BSTNode s = node.right;
      BSTNode sParent = node; // 后继节点的父节点
      while (s.left != null) {
        sParent = s;
        s = s.left;
      }

      if (sParent != node) { // 待删除节点和后继节点不相邻
        shift(sParent, node, node.right);
        s.right = node.right;
      }
      shift(parent, node, s);
      s.left = node.left;
    }

    return node.value;
  }
}
```



## 范围查询

::: code-group

```java [比key小的值] {18-23}
/**
 * 查找比 key 小的值
 * @param key 待查找值
 * @return 比 key 小的值
 */
public List<Object> less(int key) {
  ArrayList<Object> result = new ArrayList<>();
  // 中序遍历
  BSTNode p = root;
  LinkedList<BSTNode> stack = new LinkedList<>();
  while (p != null || !stack.isEmpty()) {
    if (p != null) {
      stack.push(p);
      p = p.left;
    } else {
      BSTNode pop = stack.pop();
      // 处理值
      if (pop.key < key) {
        result.add(pop.value);
      } else {
        // 如果当前的节点的 key，比要查找的 key 大了，则可以退出循环了
        break;
      }
      p = pop.right;
    }
  }
  return result;
}
```

```java [比key大的值] {18-22}
/**
 * 查找比 key 大的值
 * @param key 待查找值
 * @return 比 key 大的值
 */
public List<Object> greater(int key) {
  ArrayList<Object> result = new ArrayList<>();
  // 逆中序遍历
  BSTNode p = root;
  LinkedList<BSTNode> stack = new LinkedList<>();
  while (p != null || !stack.isEmpty()) {
    if (p != null) {
      stack.push(p);
      p = p.right;
    } else {
      BSTNode pop = stack.pop();
      // 处理值
      if (pop.key > key) {
        result.add(pop.value);
      } else {
        break;
      }
      p = pop.left;
    }
  }
  return result;
}

```

```java [介于key1和key2之间的值] {18-22}
/**
 * 查找比 key1 大，比 key2 小的值
 * @param key1 待查找值1
 * @param key2 待查找值2
 * @return 比 key1 大，比 key2 小的值
 */
public List<Object> between(int key1, int key2) {
  ArrayList<Object> result = new ArrayList<>();
  BSTNode p = root;
  LinkedList<BSTNode> stack = new LinkedList<>();
  while (p != null || !stack.isEmpty()) {
    if (p != null) {
      stack.push(p);
      p = p.left;
    } else {
      BSTNode pop = stack.pop();
      // 处理值
      if (pop.key >= key1 && pop.key <= key2) {
        result.add(pop.value);
      } else if (pop.key > key2) {
        break;
      }
      p = pop.right;
    }
  }
  return result;
}
```
