# 二叉搜索树

**二叉搜索树**（Binary Search Tree，BST），又称二叉查找树、有序二叉树或排序二叉树，是一种特殊的二叉树结构。

> [!NOTE] 二叉搜索树的性质
>
> - 对于任意节点，如果其左子树非空，则左子树所有节点的值均 **小于** 该节点的值；
> - 对于任意节点，如果其右子树非空，则右子树所有节点的值均 **大于** 该节点的值；
> - 任意节点的左右子树也都分别是二叉搜索树（递归定义）；

![二叉搜索树](https://qcdn.itcharge.cn/images/20240511171406.png)

二叉搜索树的核心特性：**左子树所有节点值 < 根节点值 < 右子树所有节点值**。



## 查找

> 二叉搜索树查找：即在二叉搜索树中定位 key 对于的值。

二叉搜索树的查找过程和二分查找的思路很相似，通过对比当前节点的 key 与 待查找的 key，每次高效的缩小一半的范围。

::: code-group

```java [非递归实现] {8,10,12}
public class BSTTree1 {
  public BSTNode root;

  public Object get(int key) {
    BSTNode node = root;
    while (node != null) {
      if (key < node.key) {
        node = node.left;  // 向左查找
      } else if (key > node.key) {
        node = node.right; // 向右查找
      } else {
        return node.value; // 找到了
      }
    }
    return null;
  }
}
```

```java [递归实现] {13,15,17}
public class BSTTree1 {
  public BSTNode root;

  public Object get(int key) {
    return doGet(root, key);
  }

  private Object doGet(BSTNode node, int key) {
    if (node == null) {
      return null;
    }
    if (key < node.key) {
      return doGet(node.left, key); // 向左查找
    } else if (key > node.key) {
      return doGet(node.right, key); // 向右查找
    } else {
      return node.value;
    }
  }
}
```

```java [单元测试]
private static BSTTree1 createTree() {
  BSTTree1.BSTNode n1 = new BSTTree1.BSTNode(1, "阆涴");
  BSTTree1.BSTNode n3 = new BSTTree1.BSTNode(3, "公孙嬿");
  BSTTree1.BSTNode n2 = new BSTTree1.BSTNode(2, "灵毓秀", n1, n3);
  BSTTree1.BSTNode n5 = new BSTTree1.BSTNode(5, "虞渊初云");
  BSTTree1.BSTNode n7 = new BSTTree1.BSTNode(7, "炎晶晶");
  BSTTree1.BSTNode n6 = new BSTTree1.BSTNode(6, "白璩儿", n5, n7);

  BSTTree1.BSTNode root = new BSTTree1.BSTNode(4, "秦牧", n2, n6);

  BSTTree1 tree = new BSTTree1();
  tree.root = root;
  return tree;
}

@Test
@DisplayName("测试二叉搜索树-Get方法")
void testGet() {
  BSTTree1 tree = createTree();

  assertEquals("阆涴", tree.get(1));
  assertEquals("灵毓秀", tree.get(2));
  assertEquals("公孙嬿", tree.get(3));
  assertEquals("秦牧", tree.get(4));
  assertEquals("虞渊初云", tree.get(5));
  assertEquals("白璩儿", tree.get(6));
  assertEquals("炎晶晶", tree.get(7));

  assertNull(tree.get(8));
}
```

```java [BSTNode]
/**
 * 二叉搜索树节点类
 */
static class BSTNode {
  int key;
  Object value;
  BSTNode left;
  BSTNode right;

  public BSTNode(int key) {
    this.key = key;
  }

  public BSTNode(int key, Object value) {
    this.key = key;
    this.value = value;
  }

  public BSTNode(int key, Object value, BSTNode left, BSTNode right) {
    this.key = key;
    this.value = value;
    this.left = left;
    this.right = right;
  }
}
```
