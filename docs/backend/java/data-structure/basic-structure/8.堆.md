# 堆

堆（Heap）是一种特殊的 **树形数据结构**，通常指 **二叉堆**（Binary Heap）。它是一棵 **完全二叉树**，并且满足一个关键特性：

- 大顶堆（Max Heap）：任意节点的值 ≥ 子节点的值；
- 小顶堆（Min Heap）：任意节点的值 ≤ 子节点的值；

换句话说，堆保证了 **堆顶元素永远是最大值或最小值**。

>可以把它想象成“层级严格、位置紧凑的树”，但重点是：堆不是用来查找任意元素的，而是用来快速得到最大/最小值的结构。

> [!NOTE] 堆的优势
>
> - **获取最值非常快**：最大值/最小值用于在堆顶，直接取即可，因此时间复杂度为 $O(1)$；
> - **插入和删除很快**：插入时，把元素加到最后，然后上浮，删除时把最后一个元素提到堆顶，再下沉，因此时间复杂度为 $O(logn)$；
> - **占用空间紧凑**：二叉堆通常用数组实现，不需要指针，内存连续、存储效率高；

## 建堆

建堆（Heapify）是指将无序数组调整为满足堆特性（最大堆或最小堆）的过程。

> [!NOTE] Floyd 建堆算法
>
> Floyd 建堆算法是构建二叉堆的高效方法，时间复杂度为 $O(n)$。思路如下：
>
> 1. 将无序数组视为完全二叉树；
> 2. 从 **最后一个非叶子节点**（$size / 2 - 1$） 开始，**自底向上、从右到左** 对每个节点进行 **下潜** 操作；
> 3. 逐渐将子树调整为堆，最终整个数组成为堆；
>
> ```tex
> 原始数组: [1, 2, 3, 4, 5, 6, 7]
> 视为完全二叉树:
>         1(0)
>        /     \
>      2(1)     3(2)
>      /  \     /  \
>    4(3) 5(4) 6(5) 7(6)
> 
> 叶子节点 (4, 5, 6, 7) 没有子节点，不需要参与下潜操作。
> 只需处理非叶子节点: 索引 2 → 1 → 0
> ```

```java {28-33,35-39}
public class MaxHeap {
  private final int[] array;
  private int size;

  public MaxHeap(int capacity) {
    this.array = new int[capacity];
  }

  /**
   * 建堆
   */
  private void heapify() {
    // 找到最后一个非叶子节点（公式：size / 2 - 1）
    for (int i = size / 2 - 1; i >= 0; i--) {
      // 执行下潜操作
      down(i);
    }
  }

  /**
   * 元素下潜
   * @param parent 索引
   */
  private void down(int parent) {
    int left = parent * 2 + 1;
    int right = left + 1;
    int max = parent;
    if (left < size && array[left] > array[max]) {
      max = left;
    }
    if (right < size && array[right] > array[max]) {
      max = right;
    }
    // 表示找到了子元素比 parent 大，需要交换变量
    if (max != parent) {
      swap(max, parent);
      // 递归判断
      down(max);
    }
  }

  /**
   * 交换两个变量
   * @param i 索引i
   * @param j 索引j
   */
  private void swap(int i, int j) {
    int temp = array[i];
    array[i] = array[j];
    array[j] = temp;
  }
}
```





## 完整堆实现

> [!TIP] 建议
>
> 关于堆的实现，其中 建堆（`heapify`）、上浮（`up`）、下潜（`down`）三个方法是关键，须牢记！

```java {12,24,35,53,70,80}
public class MaxHeap {
  private final int[] array;
  private int size;

  public MaxHeap(int capacity) {
    this.array = new int[capacity];
  }

  /**
   * 建堆
   */
  public void heapify() {
    // 找到最后一个非叶子节点（公式：size / 2 - 1）
    for (int i = size / 2 - 1; i >= 0; i--) {
      // 执行下潜操作
      down(i);
    }
  }

  /**
   * 获取堆顶元素（不删除）
   * @return 堆顶元素
   */
  public int peek() {
    if (size == 0) {
      throw new IndexOutOfBoundsException("索引越界");
    }
    return array[0];
  }

  /**
   * 获取堆顶元素（带删除）
   * @return 堆顶元素
   */
  public int poll() {
    if (size == 0) {
      throw new IndexOutOfBoundsException("索引越界");
    }
    int top = array[0];
    // 将顶部元素和尾部元素交换，然后size--
    swap(0, size - 1);
    size--;
    // 此时堆顶元素再次下潜
    down(0);
    return top;
  }

  /**
   * 获取索引位置处的元素（带删除）
   * @param index 索引
   * @return 索引位置处的元素
   */
  public int poll(int index) {
    if (size == 0 || index < 0 || index > size) {
      throw new IndexOutOfBoundsException("索引越界");
    }
    int deleted = array[index];
    // 将顶部元素和尾部元素交换，然后size--
    swap(index, size - 1);
    size--;
    // 此时堆顶元素再次下潜
    down(index);
    return deleted;
  }

  /**
   * 替换堆顶元素
   * @param replaced 待替换的值
   */
  public void replace(int replaced) {
    array[0] = replaced;
    down(0);
  }

  /**
   * 堆尾插入元素
   * @param offered 待插入值
   * @return true：插入成功；false：插入失败
   */
  public boolean offer(int offered) {
    if (size == array.length) {
      return false;
    }
    up(offered);
    size++;
    return true;
  }

  /**
   * 元素上浮
   * @param offered 待插入值
   */
  private void up(int offered) { // [!code ++]
    int child = size;// [!code ++]
    while (child > 0) {// [!code ++]
      int parent = (child - 1) / 2;// [!code ++]
      if (offered > array[child]) {// [!code ++]
        array[child] = array[parent];// [!code ++]
      } else {// [!code ++]
        break;// [!code ++]
      }// [!code ++]
      child = parent;// [!code ++]
    }// [!code ++]
    array[child] = offered;// [!code ++]
  }// [!code ++]

  /**
   * 元素下潜
   * @param parent 索引
   */
  private void down(int parent) { // [!code ++]
    int left = parent * 2 + 1;// [!code ++]
    int right = left + 1;// [!code ++]
    int max = parent;// [!code ++]
    if (left < size && array[left] > array[max]) {// [!code ++]
      max = left;// [!code ++]
    }// [!code ++]
    if (right < size && array[right] > array[max]) {// [!code ++]
      max = right;// [!code ++]
    }// [!code ++]
    // 表示找到了子元素比 parent 大，需要交换变量 // [!code ++]
    if (max != parent) {// [!code ++]
      swap(max, parent);// [!code ++]
      // 递归判断 // [!code ++]
      down(max);// [!code ++]
    }// [!code ++]
  }// [!code ++]

  /**
   * 交换两个变量
   * @param i 索引i
   * @param j 索引j
   */
  private void swap(int i, int j) {
    int temp = array[i];
    array[i] = array[j];
    array[j] = temp;
  }
}
```
