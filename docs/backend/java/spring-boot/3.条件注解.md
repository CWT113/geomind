# 条件注解

在 SpringBoot 中，条件注解主要用于 **根据某些条件决定一个 Bean/配置类是否生效**。它们是 SpringBoot 自动配置的核心机制。

主要的条件注解可以分为两大类：

- Spring Framework 原生条件注解：`@Conditional`

- Spring Boot 提供的常用条件注解：

  | 条件注解                   | 描述                            |
  | -------------------------- | ------------------------------- |
  | @ConditionalOnClass        | classpath 有某个类时成立        |
  | @ConditionalOnMissingClass | classpath 没有某个类时成立      |
  | @ConditionalOnBean         | IoC 容器中有某个 Bean 时成立 |
  | @ConditionalOnMissingBean  | IoC 容器中没有某个 Bean 时成立 |
  | @ConditionalOnProperty | 根据配置文件中的配置项决定 Bean 是否创建 |
  | @ConditionalOnExpression | 根据 SpEL 表达式来判断 Bean 是否被创建 |
  | @ConditionalOnResource     | 判断 classpath 中是否存在某个资源文件，存在时，配置才生效 |
  
  



## @Conditional

`@Conditional` 是所有条件注解的基础。它表示 **只有条件满足，这个 Bean 或配置类才会生效**。

::: code-group

```java [MyConfig] {4}
@Configuration
public class MyConfig {
  @Bean // Bean默认的名字就是方法名
  @Conditional(MyCondition.class) // 当 MyCondition 的 matches() 返回 true 时创建 Bean
  public MyService myService() {
    return new MyService();
  }
}
```

```java [MyCondition] {7,3}
import org.springframework.context.annotation.Condition;

public class MyCondition implements Condition {
  @Override
  public boolean matches(ConditionContext context, AnnotatedTypeMetadata metadata) {
    // 返回 true 表示条件成立
    return true;
  }
}
```

```java [MainAppApplication中测试] {7}
@SpringBootApplication
public class MainAppApplication {
  public static void main(String[] args) {
    ConfigurableApplicationContext context = SpringApplication.run(MainAppApplication.class, args);

    // 获取名称为 myService 的 Bean
    Object myService = context.getBean("myService");
    System.out.println(myService);

    context.close();
  }
}
```

```java [单元测试] {4}
@SpringBootTest
class ApplicationTests {
  @Autowired
  private MyService myService; // 不存在该 Bean 时直接报错

  @Test
  void contextLoads() {
    System.out.println(myService);
  }
}
```

:::

不过实际开发中，我们很少自己直接写 `Condition`，因为 SpringBoot 已经提供了大量现成的条件注解。



## @ConditionalOnClass

`@ConditionalOnClass` 表示当 **某个类存在于 classpath 中时，配置才生效**。

::: code-group

```java [RedisConfig] {2}
@Configuration
@ConditionalOnClass(RedisTemplate.class) // 当项目存在 Redis 依赖时，才创建 RedisService 这个 Bean
public class RedisConfig {
  @Bean
  public RedisService redisService() {
    return new RedisService();
  }
}
```

```java [MainAppApplication] {7}
@SpringBootApplication
public class MainAppApplication {
  public static void main(String[] args) {
    ConfigurableApplicationContext context = SpringApplication.run(MainAppApplication.class, args);

    // 获取 Bean
    Object bean = context.getBean("redisService");
    System.out.println(bean);

    context.close();
  }
}
```

:::

::: info 提示

在使用 `RedisTemplate.class` 时出现爆红，需要在 `pom.xml` 中引入 Redis 依赖：

```xml
<!-- 引入 redis 依赖 -->
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

:::



## @ConditionalOnMissingClass

`@ConditionalOnMissingClass` 与 `@ConditionalOnClass` 正好相反，**当某个类不存在时，配置才生效**。

::: code-group

```java [MyConfig] {2}
@Configuration
@ConditionalOnMissingClass("com.example.MyClass") // 当 MyClass 不存在时，才创建 MyService 这个 Bean
public class MyConfig {
  @Bean
  public MyService myService() {
    return new MyService();
  }
}
```

```java [MainAppApplication]
@SpringBootApplication
public class MainAppApplication {
  public static void main(String[] args) {
	ConfigurableApplicationContext context = SpringApplication.run(MainAppApplication.class, args);

	// 获取 Bean
	Object bean = context.getBean("myService");
	System.out.println(bean);

	context.close();
  }
}
```

:::



## @ConditionalOnBean

`@ConditionalOnBean` 表示 **容器中已经存在指定 Bean 时，当前配置才生效**。

::: code-group

```java [MyConfig] {9}
@Configuration
public class MyConfig {
  @Bean
  public A a() {
    return new A();
  }

  @Bean
  @ConditionalOnBean(A.class) // 当容器中存在 A Bean 时，B 才会创建
  public B b() {
    return new B();
  }
}
```

```java [MainAppApplication]
@SpringBootApplication
public class MainAppApplication {
  public static void main(String[] args) {
    ConfigurableApplicationContext context = SpringApplication.run(MainAppApplication.class, args);

    // 获取 Bean
    Object bean = context.getBean("a");
    Object bean1 = context.getBean("b");
    System.out.println(bean);
    System.out.println(bean1);

    context.close();
  }
}
```

:::



## @ConditionalOnMissingBean

`@ConditionalOnMissingBean` 与 `@ConditionalOnBean` 正好相反，**当容器中不存在指定 Bean 时，当前配置才生效**。

::: code-group

```java [MyConfig] {4}
@Configuration
public class MyConfig {
  @Bean
  @ConditionalOnMissingBean(A.class) // 当容器中不存在 A Bean时，B 才被创建
  public B b() {
    return new B();
  }
}
```

```java [MainAppApplication]
@SpringBootApplication
public class MainAppApplication {
  public static void main(String[] args) {
    ConfigurableApplicationContext context = SpringApplication.run(MainAppApplication.class, args);

    // 获取 Bean
    Object bean = context.getBean("b");
    System.out.println(bean);

    context.close();
  }
}
```

:::



## @ConditionalOnProperty

`@ConditionalOnProperty` 表示 **根据配置文件中的配置项决定 Bean 是否创建**。

::: code-group

```java [MyConfig] {3,4,5,6}
@Configuration
// 当配置文件中 my.service.enabled 为 true 时，才创建 Bean
@ConditionalOnProperty(
  name = "my.service.enabled",
  havingValue = "true",
  matchIfMissing = true) // 如果 my.service.enabled 没有配置时，默认开启
public class MyConfig {
  @Bean
  public MyService myService() {
    return new MyService();
  }
}
```

```yaml [application.yaml]
my:
  service:
    enabled: false
```

:::



## @ConditionalOnExpression

`@ConditionalOnExpression` 表示 **根据 SpEL 表达式来判断 Bean 是否被创建**。

::: code-group

```java [MyConfig] {3}
@Configuration
// 当表达式中的条件均成立时，才创建 Bean
@ConditionalOnExpression("${my.service.enabled:true} and ${my.service.port:8088} > 1000")
public class MyConfig {
  @Bean
  public MyService myService() {
    return new MyService();
  }
}
```

```yaml [application.yaml]
my:
  service:
    enabled: true
    port: 8088
```

:::

> [!TIP] 💡 提示
>
> 在实际开发中，更推荐使用 `@ConditionalOnProperty` 注解，因为它更简单、更清晰。



## @ConditionalOnResource

`@ConditionalOnResource` 表示 **判断 classpath 中是否存在某个资源文件，存在时，配置才生效**。

```java {3}
@Configuration
// 当存在 my-config.yaml 文件时，配置才生效
@ConditionalOnResource(resources = "classpath:my-config.yaml")
public class MyConfig {
  @Bean
  public MyService myService() {
    return new MyService();
  }
}
```
