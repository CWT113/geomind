# 日志框架

## 日志框架

Java 的日志体系分为两层：**抽象层**（门面）和 **实现层**。

### 抽象的日志框架

抽象的日志框架也叫做 “门面”，它只 **提供统一的日志接口 API**，不提供具体的实现。

- 优势：**实现解耦**，如果底层想从 Logback 切换到 Log4j2，业务代码不需要修改；
- 常见代表：SLF4J、Apache Commons Logging



### 具体的日志框架

具体的日志框架负责 **真正的实现日志记录**、格式化、输出日志到文件或控制台等底层操作。

- 常见代表：Logback、Log4j、Log4j2

SpringBoot 默认默认使用的是 SLF4J + Logback 的组合。



## Logback

### 核心配置组件

Logback 的配置核心由 3 个组件构成：Logger（日志记录器）、Appender（输出目的地）、Encoder（日志格式）。



##### Logger

Logger 负责定义 **哪些类/包的日志需要被处理**，并指定处理级别。

> [!NOTE] 核心属性
>
> - `name`：指定包或类的全限定名称（如 `com.example.demo`）；
> - `level`：日志级别，仅输出“级别 ≥ 当前设置” 的日志；
> - `additivity`：是否向上级 Logger（如 `root`）传递日志（默认 `true`，可能会导致重复输出，需要按需关闭）；



##### Appender

Appender 定义 **日志的输出位置**（如控制台、文件），常用实现类：

|    Appender 类型    |                   作用                   |       适用场景       |
| :-----------------: | :--------------------------------------: | :------------------: |
|   ConsoleAppender   |               输出到控制台               |     开发环境调试     |
|    FileAppender     |              输出到指定文件              |     简单文件记录     |
| RollingFileAppender | 按规则滚动输出到多个文件（防止文件过大） | 生产环境长期日志存储 |



##### Encoder

Encoder 定义 **日志的输出格式**，常用 `<property>` 属性自定义格式。

> [!NOTE] 常用占位符
>
> - `%d{yyyy-MM-dd HH:mm:ss.SSS}`：日志时间（精确到毫秒）
> - `%thread`：当前线程名称
> - `%-5level`：日志级别（左对齐，如 `INFO `）
> - `%logger{36}`：Logger 名称（通常是类名，最长 36 个字符，超出省略）
> - `%msg`：日志消息
> - `%n`：换行符



### 日志级别

日志级别从低到高依次为：`TRACE < DEBUG < INFO < WARN < ERROR`。

| 日志级别 | 日志名称 | 描述                                                   |
| :------: | :------: | :----------------------------------------------------- |
|  TRACE   | 追踪级别 | 记录程序运行的极详细内部日志                           |
|  DEBUG   | 调试级别 | 记录详细的开发调试日志                                 |
|   INFO   | 信息级别 | **默认日志级别**，记录系统正常运行的关键生命周期等信息 |
|   WARN   | 警告级别 | 程序运行存在潜在风险或非预期情况的日志                 |
|  ERROR   | 错误级别 | 程序发生了严重错误导致功能执行失败的日志               |

> [!WARNING] ⚠️ 警告
>
> 生产环境中严谨全局开启 `DEBUG` 或 `TRACE` 级别，因为这会产生海量的日志文件，不仅占用磁盘空间，还会由于频繁的磁盘 IO 操作严重拖慢系统性能。



### 基础配置

在 `src/main/resources` 下，新建 `logback-spring.xml` 文件（文件名以 `*-spring.xml` 结尾，可以与 Spring 的特性结合）。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
  <!-- 日志目录，当前模块叫 common-utils -->
  <property name="LOG_PATH" value="logs/common-utils"/>
  <!-- 日志文件名 -->
  <property name="LOG_NAME" value="app"/>
  <!-- 文件日志输出格式 -->
  <property name="FILE_PATTERN" value="%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n"/>
  <!-- 控制台日志输出格式（带颜色） -->
  <property name="CONSOLE_LOG_PATTERN"
            value="%cyan(%d{yyyy-MM-dd HH:mm:ss.SSS}) %green([%thread]) %highlight(%-5level) %boldMagenta(%logger{36}) - %msg%n"/>

  <!-- 输出到控制台 -->
  <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
    <encoder>
      <pattern>${CONSOLE_LOG_PATTERN}</pattern>
      <charset>UTF-8</charset>
    </encoder>
  </appender>

  <!-- 输出到文件 -->
  <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
    <file>${LOG_PATH}/${LOG_NAME}.log</file>

    <!-- 按日期+文件大小滚动 -->
    <rollingPolicy class="ch.qos.logback.core.rolling.SizeAndTimeBasedRollingPolicy">
      <fileNamePattern>${LOG_PATH}/%d{yyyy-MM-dd}/${LOG_NAME}.%i.log.gz</fileNamePattern>
      <!-- 单个文件最大10MB -->
      <maxFileSize>10MB</maxFileSize>
      <!-- 保留7天的归档日志 -->
      <maxHistory>7</maxHistory>
      <!-- 所有日志总大小不超过1GB -->
      <totalSizeCap>1GB</totalSizeCap>
      <!-- 最长保留30天 -->
      <maxHistory>30</maxHistory>
    </rollingPolicy>

    <encoder>
      <pattern>${FILE_PATTERN}</pattern>
      <charset>UTF-8</charset>
    </encoder>
  </appender>

  <!-- 配置全局日志 -->
  <root level="INFO">
    <appender-ref ref="CONSOLE"/>
    <appender-ref ref="FILE"/>
  </root>

  <!-- 配置指定包的日志，additivity 为 false 表示不传递到 root 全局 -->
  <logger name="com.example.controller" level="ERROR" additivity="false">
    <appender-ref ref="FILE"/>
  </logger>
</configuration>
```



### 高级配置

#### 按环境区分配置

通过 `springProfile` 标签，可针对不同环境（如 dev / prod）配置不同的策略。

::: code-group

```xml [logback-spring.xml] {11,25}
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
  <property name="LOG_PATH" value="logs/common-utils"/>
  <property name="LOG_NAME" value="app"/>

  <property name="FILE_PATTERN" value="%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n"/>
  <property name="CONSOLE_LOG_PATTERN"
            value="%cyan(%d{yyyy-MM-dd HH:mm:ss.SSS}) %green([%thread]) %highlight(%-5level) %boldMagenta(%logger{36}) - %msg%n"/>

  <!-- 开发环境：输出控制台，但不输出文件 -->
  <springProfile name="dev">
    <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
      <encoder>
        <pattern>${CONSOLE_LOG_PATTERN}</pattern>
        <charset>UTF-8</charset>
      </encoder>
    </appender>

    <root level="INFO">
      <appender-ref ref="CONSOLE"/>
    </root>
  </springProfile>

  <!-- 生产环境：输出到文件，控制台不输出 -->
  <springProfile name="prod">
    <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
      <file>${LOG_PATH}/${LOG_NAME}.log</file>

      <rollingPolicy class="ch.qos.logback.core.rolling.SizeAndTimeBasedRollingPolicy">
        <fileNamePattern>${LOG_PATH}/%d{yyyy-MM-dd}/${LOG_NAME}.%i.log.gz</fileNamePattern>
        <maxFileSize>10MB</maxFileSize>
        <maxHistory>7</maxHistory>
        <totalSizeCap>1GB</totalSizeCap>
      </rollingPolicy>

      <encoder>
        <pattern>${FILE_PATTERN}</pattern>
        <charset>UTF-8</charset>
      </encoder>
    </appender>

    <root level="INFO">
      <appender-ref ref="FILE"/>
    </root>
  </springProfile>
</configuration>
```

```yaml [application.yaml] {6}
spring:
  application:
    name: springboot-01
  profiles:
    # 当前环境
    active: prod
```

:::



#### 异步输出

通过 `AsyncAppender` 包装其他 `Appender`，可避免日志输出阻塞主线程（适合高并发场景）。

```xml {7,16}
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
  <!-- ...其余配置 -->
  
  <appender name="ASYNC_FILE" class="ch.qos.logback.classic.AsyncAppender">
    <!-- 关联之前定义的 FILE appender -->
    <appender-ref ref="FILE"/>
    <!-- 缓冲区大小（默认256） -->
    <queueSize>1024</queueSize>
    <!-- 不丢弃日志（默认当队列满80%时丢弃TRACE/DEBUG级） -->
    <discardingThreshold>0</discardingThreshold>
  </appender>

  <root level="INFO">
    <appender-ref ref="CONSOLE"/>
    <appender-ref ref="ASYNC_FILE"/>
  </root>
</configuration>
```



#### 日志过滤

通过 `ThresholdFilter` 过滤特定级别以下的日志。

```xml {6-9}
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
  <!-- ...其余配置 -->

  <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
    <filter class="ch.qos.logback.classic.filter.ThresholdFilter">
      <!-- 只输出 WARN 异常的级别 -->
      <level>WARN</level>
    </filter>
    <encoder>
      <pattern>${CONSOLE_LOG_PATTERN}</pattern>
      <charset>UTF-8</charset>
    </encoder>
  </appender>
</configuration>
```



## Logback 搭配 Spring

在 SpringBoot 中，Logback 可以通过 `springProperty` 等扩展标签与 Spring 环境深度集成，实现日志配置与 Spring 配置的联动。这种方式让日志配置更灵活，尤其适合需要动态调整或外部化配置的场景。



### springProperty 标签

`springProperty` 是 Spring 对 Logback 的扩展标签，用于在 Logback 配置文件（**仅 `logback-spring.xml` 支持**）中 **引用 Spring 环境中的属性**。

标签属性说明：

|    属性名    | 作用                                                         | 示例                  |
| :----------: | ------------------------------------------------------------ | :-------------------- |
|    scope     | 变量作用域（通常为 context，表示 Logback 上下文级别，全局可访问） | scope =“context”       |
|     name     | 在 Logback 配置中使用的变量名（后续通过 `${name}` 引用）      | name =“LOG_PATH”       |
|    source    | 对应 Spring 环境中的属性名（如 `application.yaml` 中的 `logging.path`） | source =“logging.path” |
| defaultValue | 当 source 对应的属性不存在时，使用的默认值                   | defaultValue =“logs/”  |



### 基础配置

::: code-group

```xml [logback-spring.xml] {4,6}
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
  <!-- 日志根目录：优先取配置文件中的 logging.path，默认为 logs/common-utils -->
  <springProperty scope="context" name="LOG_PATH" source="logging.path" defaultValue="logs/common-utils"/>
  <!-- 日志文件名：优先取配置文件中的 logging.file.name，默认为 app  -->
  <springProperty scope="context" name="LOG_NAME" source="logging.file.name" defaultValue="app"/>

  <property name="FILE_PATTERN" value="%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n"/>
  <property name="CONSOLE_LOG_PATTERN"
            value="%cyan(%d{yyyy-MM-dd HH:mm:ss.SSS}) %green([%thread]) %highlight(%-5level) %boldMagenta(%logger{36}) - %msg%n"/>

  <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
    <encoder>
      <pattern>${CONSOLE_LOG_PATTERN}</pattern>
      <charset>UTF-8</charset>
    </encoder>
  </appender>

  <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">
    <file>${LOG_PATH}/${LOG_NAME}.log</file>

    <rollingPolicy class="ch.qos.logback.core.rolling.SizeAndTimeBasedRollingPolicy">
      <fileNamePattern>${LOG_PATH}/%d{yyyy-MM-dd}/${LOG_NAME}.%i.log.gz</fileNamePattern>
      <maxFileSize>10MB</maxFileSize>
      <maxHistory>7</maxHistory>
      <totalSizeCap>1GB</totalSizeCap>
      <!-- 最长保留30天 -->
      <maxHistory>30</maxHistory>
    </rollingPolicy>

    <encoder>
      <pattern>${FILE_PATTERN}</pattern>
      <charset>UTF-8</charset>
    </encoder>
  </appender>

  <root level="INFO">
    <appender-ref ref="CONSOLE"/>
    <appender-ref ref="FILE"/>
  </root>
</configuration>
```

```yaml [application.yaml] {11,13}
server:
  port: 8080

spring:
  application:
    name: springboot-01

logging:
  file:
    # 输出的日志名称
    name: common-utils
    # 输出的日志路径
    path: logs/my-common-utils
```

:::
