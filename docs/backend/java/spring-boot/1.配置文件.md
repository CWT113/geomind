# 配置文件

在 SpringBoot 中，外部配置文件指独立于已打包的可执行文件（如 `.jar` 包）之外的配置文件，常见的方式有 `application.properties` 或 `application.yaml`。

它允许在不重新编译或重新打包应用代码的前提下，为不同部署环境（开发、测试、生产）动态调整数据库连接、端口号等运行参数。



## properties 配置

`application.properties` 是 SpringBoot 最基础配置文件格式，采用标准的 **键值对（Key-Value）** 结构。

```properties
# 服务基础配置
server.port=8080

# 数据源配置
spring.datasource.url=jdbc:mysql://localhost:3306/mydb?useSSL=false
spring.datasource.username=root
spring.datasource.password=1234

# 自定义属性与引用
app.name=OrderService
app.description=${app.name} is running on port ${server.port}
```

**核心特点：** 格式简单直观，但层级关系需要用“点号”前缀表达，重复书写较多。



## yaml 配置

`application.yaml` 是一种以数据为中心、注重可读性的层次化配置格式。通过 **缩进** 表达对象层级，减少了键名前缀的重复。

```yaml
server:
  port: 8080
spring:
  application:
    name: myApp
  # 数据源配置
  datasource:
    url: jdbc:mysql://localhost:3306/mydb?useSSL=false
    username: root
    password: 1234
# 自定义属性与引用
app:
  name: OrderService
  # 属性引用
  description: ${app.name} is running on port ${server.port}
  # 数组或列表（方式一）
  allowed-origins:
    - https://example.com
    - https://test.com
  # 数组或列表（方式二）
  ports: [8001, 8002, 8003]
  # 字符串转数组
  roles: superAdmin,admin,guest
  # 绑定到嵌套属性
  addr:
    province: Shanxi
    city: Xi'an
```



### 读取配置

#### @Value

用于注入 **单个属性**，适合少量配置的场景。数组或列表需要逐个索引引用或配合 SpEL 表达式。

::: code-group

```java [AppConfig] {3,6,9,21,22}
@Configuration
public class AppConfig {
  @Value("${spring.datasource.username}")
  private String username;

  @Value("${spring.datasource.password}")
  private String password;

  @Value("${app.description}")
  private String description;

  // @Value("${app.allowed-origins}") // 数组或列表方式不能直接获取，而是多次注入 // [!code --]
  @Value("${app.allowed-origins[0]},${app.allowed-origins[1]}") // [!code ++]
  private List<String> allowedOrigins;
  // private String[] allowedOrigins;

  @Value("${app.ports[0]},${app.ports[1]},${app.ports[2]}") // [!code ++]
  private List<Integer> ports;
  // private String[] ports;

  @Value("${app.roles}")
  // @Value("#{'${app.roles}'.split(',')}") // SpEL表达式
  private List<String> roles;

  public void printfInfo() {
    System.out.println("username = " + username);
    System.out.println("password = " + password);
    System.out.println("description = " + description);
    System.out.println("allowedOrigins = " + Arrays.toString(allowedOrigins));
    System.out.println("ports = " + Arrays.toString(ports));
    System.out.println("roles = " + roles);
  }
}

```

```java [单元测试]
@SpringBootTest
class ApplicationTests {
  @Autowired
  private AppConfig appConfig;

  @Test
  void test01() {
    appConfig.printfInfo();
  }
}
```

:::



#### @ConfigurationProperties

用于 **批量绑定** 指定前缀下的所有属性到 Java 类中，类内字段名需与配置属性名匹配，且必须提供 setter 方法。

```java [AppConfig] {1,3,23}
@Setter
@Configuration
@ConfigurationProperties(prefix = "app") // 使用时，类内必须有 setter 函数
public class AppConfig {
  @Value("${spring.datasource.username}")
  private String username;

  @Value("${spring.datasource.password}")
  private String password;

  private String description;

  // private List<String> allowedOrigins; // 名称相同，即可自动隐射到该属性上
  private String[] allowedOrigins;

  // private List<Integer> ports;
  private String[] ports;

  // private List<String> roles;
  private String[] roles;

  // 嵌套属性
  private Address addr;

  public void printfInfo() {
    System.out.println("username = " + username);
    System.out.println("password = " + password);
    System.out.println("description = " + description);
    System.out.println("allowedOrigins = " + Arrays.toString(allowedOrigins));
    System.out.println("ports = " + Arrays.toString(ports));
    System.out.println("roles = " + Arrays.toString(roles));
    System.out.println("addr = " + addr);
  }
}
```



### 绑定第三方类属性

当需要绑定第三方库提供的类时，可通过 `@ConfigurationProperties` 注解在 `@Bean` 方法上实现。

::: code-group

```yaml [application.yaml]
server:
  port: 8080
spring:
  application:
    name: myApp
app:
  name: OrderService
  # 绑定到第三方的数据
  addr:
    province: Shanxi
    city: xi'an
```

```java [AppConfig]
@Configuration
public class AppConfig {
  @Bean // 纳入 IoC 容器管理
  @ConfigurationProperties(prefix = "app.addr")
  public Address address() {
    return new Address(); // 假设 Address 是第三方库提供的类
  }
}
```

```java [Address]
@Setter
@ToString
public class Address {
  private String province;

  private String city;
}
```

```java [单元测试]
@SpringBootTest
class Springboot01ApplicationTests {
  @Autowired
  private AppConfig appConfig;

  @Test
  void test01() {
    Address address = appConfig.address();
    System.out.println(address);
  }
}

```

:::



### 自定义数据来源

通过 `@PropertySource` 注解引入额外的 properties 文件，扩展配置来源。

> [!WARNING] 注意
>
> `@PropertySource` 只支持 `.properties` 文件，不支持 `.yaml` 文件。

::: code-group

```properties [other.properties]
app.name=UserService
app.version=1.0.0
app.port=9000
```

```java [AppConfig] {3,4}
@Setter
@Configuration
@ConfigurationProperties(prefix = "app")
@PropertySource("classpath:/custom/other.properties") // 注意：@PropertySource 只能用于 properties 文件
public class AppConfig {
  private String name;

  private String version;

  private Integer port;

  public void printfInfo() {
    System.out.println("name = " + name);
    System.out.println("version = " + version);
    System.out.println("port = " + port);
  }
}
```

:::



### 配置合并

使用 YAML 的 `import` 指令，可将不同功能的配置拆分为独立文件，由主配置文件统一导入。

::: code-group

```yaml [application.yaml]
spring:
  application:
    name: myApp
  config:
    # 通过 import 导入拆分的配置文件
    import:
      - classpath:application-mysql.yaml
      - classpath:application-redis.yaml
```

```yaml [application-mysql.yaml]
spring:
  datasource:
    # 数据库配置
    url: jdbc:mysql://localhost:3306/mydb?useSSL=false
    username: root
    password: 1234
```

```yaml [application-redis.yaml]
spring:
  data:
    # redis配置
    redis:
      host: localhost
      port: 6379
```

```java [单元测试]
@Configuration
public class AppConfig {
  @Value("${spring.datasource.url}")
  private String mysqlName;

  @Value("${spring.datasource.password}")
  private String mysqlPassword;

  @Value("${spring.data.redis.host}")
  private String redisHost;

  @Value("${spring.data.redis.port}")
  private String redisPort;

  public void printfInfo() {
    System.out.println("mysqlName = " + mysqlName);
    System.out.println("mysqlPassword = " + mysqlPassword);
    System.out.println("redisHost = " + redisHost);
    System.out.println("redisPort = " + redisPort);
  }
}
```

:::



### 多环境配置

通过 `profiles.active` 指定当前激活的环境，SpringBoot 会自动加载对应的 `application-{环境名}.yaml` 文件。

::: code-group

```yaml {6} [application.yaml]
spring:
  application:
    name: myApp
  profiles:
    # 指定启动环境
    active: dev
```

```yaml [application-dev.yaml]
spring:
  datasource:
    # 数据库配置
    url: jdbc:mysql://localhost:3306/mydb?useSSL=false
    username: root
    password: 1234
  data:
    # redis配置
    redis:
      host: localhost
      port: 6379
```

```yaml [application-prod.yaml]
spring:
  datasource:
    # 数据库配置
    url: jdbc:mysql://221.195.20.98:13306/mydb?useSSL=false
    username: root
    password: 1234
  data:
    # redis配置
    redis:
      host: 221.195.20.98
      port: 16379
```

:::
