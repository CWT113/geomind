# 增删改查

基础入门中使用 `Statement` 进行查询会发生 SQL 注入的问题，因此后续的增删改查操作建议都使用 `PreparedStatement` 来完成。



## 查询

### 单行单列

查询单行单列比较经典的场景就是统计表中数据的个数。

```java
@Test
@DisplayName("查询单行单列")
void testQuerySingleRowAndCol() throws SQLException {
  // 1.获取连接对象
  Connection connection = DriverManager
    .getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");
  // 2.创建 PreparedStatement，并初始化 SQL 语句
  PreparedStatement preparedStatement = connection.prepareStatement("select count(*) as count from t_emp");
  // 3.执行查询
  ResultSet resultSet = preparedStatement.executeQuery();

  // 4.获取查询结果，只有一行因此没有必要遍历
  if (resultSet.next()) {
    int count = resultSet.getInt("count");
    System.out.println(count);
  }

  // 5.释放资源
  resultSet.close();
  preparedStatement.close();
  connection.close();
}
```



### 单行多列

```java {9}
@Test
@DisplayName("查询单行多列")
void testQuerySingleRow() throws SQLException {
  // 1.获取连接对象
  Connection connection = DriverManager
    .getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");
  // 2.创建 PreparedStatement，并初始化 SQL 语句
  PreparedStatement preparedStatement = connection.prepareStatement("select * from t_emp where emp_id = ?");
  // 3.为占位符赋值，并执行查询
  preparedStatement.setInt(1, 3);
  ResultSet resultSet = preparedStatement.executeQuery();

  // 4.获取查询结果，只有一行因此没有必要遍历
  while (resultSet.next()) {
    int empId = resultSet.getInt("emp_id");
    String empName = resultSet.getString("emp_name");
    String empSalary = resultSet.getString("emp_salary");
    int empAge = resultSet.getInt("emp_age");
    System.out.println(empId + "\t" + empName + "\t" + empSalary + "\t" + empAge);
  }

  // 5.释放资源
  resultSet.close();
  preparedStatement.close();
  connection.close();
}
```

## 新增

```java {13}
@Test
@DisplayName("新增单行")
void testInsert() throws SQLException {
  // 1.获取连接对象
  Connection connection = DriverManager
    .getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");
  // 2.创建 PreparedStatement，并初始化 SQL 语句
  PreparedStatement preparedStatement = connection.prepareStatement("insert into t_emp (emp_name,emp_salary,emp_age) values (?,?,?)");
  // 3.为占位符赋值，并执行插入操作
  preparedStatement.setString(1, "王一博");
  preparedStatement.setInt(2, 11000);
  preparedStatement.setInt(3, 25);
  int result = preparedStatement.executeUpdate();

  System.out.println(result > 0 ? "新增成功！" : "新增失败！");

  // 5.释放资源
  preparedStatement.close();
  connection.close();
}
```
