# 批量操作

向数据库插入多条数据时，一条一条插入时非常消耗性能的，而批量插入可以解决这个问题。

::: code-group

```java [批量插入] {4,5,17}
@Test
@DisplayName("测试名称")
void testBatch() throws SQLException {
  Connection connection = DriverManager
    .getConnection("jdbc:mysql://localhost:3306/jdbc?rewriteBatchedStatements=true", "root", "1234");

  String sql = "insert into t_emp (emp_name, emp_salary, emp_age) values (?,?,?)";
  // 传入第二个参数，表示需要返回主键ID
  PreparedStatement preparedStatement = connection.prepareStatement(sql);

  long start = System.currentTimeMillis();
  for (int i = 0; i < 10000; i++) {
    preparedStatement.setString(1, "tom" + i);
    preparedStatement.setDouble(2, 100.0 + i);
    preparedStatement.setInt(3, 1 + i);
    // 执行批量插入操作
    preparedStatement.addBatch();
  }
  long end = System.currentTimeMillis();
  System.out.println("总耗时：" + (end - start) + "ms"); // 51ms

  preparedStatement.close();
  connection.close();
}
```

```java [一条条插入]
@Test
@DisplayName("测试名称")
void testInsertMany() throws SQLException {
  Connection connection = DriverManager // ?rewriteBatchedStatements=true
    .getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");

  String sql = "insert into t_emp (emp_name, emp_salary, emp_age) values (?,?,?)";
  // 传入第二个参数，表示需要返回主键ID
  PreparedStatement preparedStatement = connection.prepareStatement(sql);

  long start = System.currentTimeMillis();
  for (int i = 0; i < 10000; i++) {
    preparedStatement.setString(1, "tom" + i);
    preparedStatement.setDouble(2, 100.0 + i);
    preparedStatement.setInt(3, 1 + i);
    // 本质是一条一条数据的插入
    preparedStatement.executeUpdate();
  }
  long end = System.currentTimeMillis();
  System.out.println("总耗时：" + (end - start) + "ms"); // 27000ms

  preparedStatement.close();
  connection.close();
}
```
