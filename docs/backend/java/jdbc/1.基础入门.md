# 基础入门

JDBC（Java Database Connectivity，Java 数据库连接）是 Java 语言中用来规范客户端程序如何访问数据库的应用程序 API。

> [!NOTE] 核心作用
>
> - 统一访问标准：只需要些一套代码，就能连接并操作各种不同的数据库；
> - 发送 SQL 语句：支持向数据库发送增、删、改、查等指令；
> - 处理查询结果：将数据库返回的数据结构转换为 Java 对象（如 ResultSet）；



## 项目搭建

> [!NOTE] JDBC 项目搭建
>
> 1. 准备数据库；
>

>

>
> 4. 选中 lib 文件夹右键，点击“添加为库”，与项目集成；

### 基础实现

```java
public static void main(String[] args) throws Exception {
  // 1.注册驱动（JDK6之后可以忽略不写）
  // Class.forName("com.mysql.cj.jdbc.Driver");

  // 2.获取连接对象
  String url = "jdbc:mysql://localhost:3306/jdbc";
  String username = "root";
  String password = "1234";
  Connection connection = DriverManager.getConnection(url, username, password);

  // 3.获取执行SQL语句的对象
  Statement statement = connection.createStatement();

  // 4.编写SQL语句，并执行，拿到返回的结果集
  String sql = "select * from t_emp";
  ResultSet resultSet = statement.executeQuery(sql);

  // 5.处理结果，遍历 resultSet 结果集
  while (resultSet.next()) {
    int empId = resultSet.getInt("emp_id");
    String empName = resultSet.getString("emp_name");
    double empSalary = resultSet.getDouble("emp_salary");
    int empAge = resultSet.getInt("emp_age");
    System.out.println(empId + "\t" + empName + "\t" + empSalary + "\t" + empAge);
  }

  // 6.释放资源
  resultSet.close();
  statement.close();
  connection.close();
}
```



## 核心 API 详解

### 注册驱动

```java
Class.forName("com.mysql.cj.jdbc.Driver");
```

在使用 JDBC 连接数据库时，需要加载对应数据库的驱动程序，以便与数据库进行通信。

但其实从 JDK6 开始，不再需要显式的调用 `Class.forName()` 来加载 JDBC 驱动程序了，只要在类路径中集成了对应的 jar 包，会自动在初始化时注册驱动程序。



### Connection

`Connection` 接口是 JDBC API 中的重要接口，用于建立与数据库的通信通道。在建立连接时，需要指定数据库 URL、用户名和密码：

```java
  String url = "jdbc:mysql://localhost:3306/jdbc";
  String username = "root";
  String password = "1234";
  Connection connection = DriverManager.getConnection(url, username, password);
```

除此之外，Connection 接口还负责 **管理事务**，接口提供了 `commit` 和 `rollback` 方法，用于提交事务和回滚事务。

在使用 JDBC 技术时，必须要先获取 Connection 对象，在使用完毕后，要释放资源，避免资源占用浪费和泄露。



### Statement

`Statement` 接口用于执行 SQL 语句并与数据库进行交互，返回的结果可以是一个或多个对象：

- **增、删、改**：返回受影响行数（单个结果）
- **查**：单行单列、多行单列、单行多列（多个结果）

```java
Statement statement = connection.createStatement();

String sql = "select * from t_emp";
ResultSet resultSet = statement.executeQuery(sql);
```

> [!CAUTION] SQL 注入问题
>
> 当使用 Statement 执行 **动态构建的 SQL 查询时**，往往需要将查询条件与 SQL 语句拼接在一起，此时就会出现特殊情况导致 SQL 注入问题发生。

::: details 演示 SQL 注入问题

```java
public static void main(String[] args) throws Exception {
  // 获取连接对象
  Connection connection = DriverManager.getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");

  // 获取执行SQL语句的对象
  Statement statement = connection.createStatement();

  // 从控制台让用户输入用户名进行动态查询
  System.out.println("请输入用户名：");
  Scanner scanner = new Scanner(System.in);
  String name = scanner.nextLine(); // 此时如果输入 abc' or '1' = '1 就会发生SQL注入问题 // [!code --]

  // 编写SQL语句，并执行，拿到返回的结果集
  String sql = "select * from t_emp where emp_name = '" + name + "'"; // [!code --]
  ResultSet resultSet = statement.executeQuery(sql);

  // 处理结果，遍历 resultSet 结果集
  while (resultSet.next()) {
    int empId = resultSet.getInt("emp_id");
    String empName = resultSet.getString("emp_name");
    double empSalary = resultSet.getDouble("emp_salary");
    int empAge = resultSet.getInt("emp_age");
    System.out.println(empId + "\t" + empName + "\t" + empSalary + "\t" + empAge);
  }

  // 释放资源
  resultSet.close();
  statement.close();
  connection.close();
}
```

:::



### PreparedStatement

`PreparedStatement` 是 `Statement` 接口的子接口，用于执行 **预编译** 的 SQL 查询。

> [!NOTE] 优势
>
> - **预编译 SQL 语句**：在创建 PreparedStatement 时，就会预编译 SQL 语句，此时 SQL 已经固定；
> - **防止 SQL 注入**：PreparedStatement 支持参数化查询，将数据作为参数传递到 SQL 中，采用 `?` 占位符的方式，将传入的参数用一对单引号包裹起来，并且单引号内部如果再出现单引号，会将其 `\'` 进行转译，有效防止 SQL 注入问题；
> - **性能提升**：PreparedStatement是预编译SQL语句，因此同一SQL语句多次执行的情况下，可以复用，不必每次重新编译和解析；

::: details 解决 SQL 注入问题

```java
public static void main(String[] args) throws Exception {
  // 获取连接对象
  Connection connection = DriverManager.getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");

  // 获取执行SQL语句的对象
  PreparedStatement preparedStatement = connection.prepareStatement("select * from t_emp where emp_name = ?"); // [!code ++]

  // 从控制台让用户输入用户名进行动态查询
  System.out.println("请输入用户名：");
  Scanner scanner = new Scanner(System.in);
  String name = scanner.nextLine();

  // 把输入的值，填充到 ? 占位符的位置
  preparedStatement.setString(1, name); // [!code ++]
  ResultSet resultSet = preparedStatement.executeQuery(); // [!code ++]

  // 处理结果，遍历 resultSet 结果集
  while (resultSet.next()) {
    int empId = resultSet.getInt("emp_id");
    String empName = resultSet.getString("emp_name");
    double empSalary = resultSet.getDouble("emp_salary");
    int empAge = resultSet.getInt("emp_age");
    System.out.println(empId + "\t" + empName + "\t" + empSalary + "\t" + empAge);
  }

  // 释放资源
  resultSet.close();
  preparedStatement.close();
  connection.close();
}
```

:::



### ResultSet

`ResultSet` 用于表示从数据库中执行查询语句所返回的结果集。它提供了用于遍历和访问查询结果的方式：

- **遍历结果**：使用 `next()` 方法将游标移动到结果集的下一行，逐行遍历数据库查询的结果，其结果返回 true 时表示有下一行；
- **获取单列结果**：通过 `getXxx()` 的方法获取单列的数据，该方法为重载方法，支持索引和列名进行获取；

```java
while (resultSet.next()) {
  int empId = resultSet.getInt("emp_id");
  String empName = resultSet.getString("emp_name");
  double empSalary = resultSet.getDouble("emp_salary");
  int empAge = resultSet.getInt("emp_age");
  System.out.println(empId + "\t" + empName + "\t" + empSalary + "\t" + empAge);
}
```
