# 连接池

连接池就是 **数据库连接对象的缓冲区**，通过配置，由连接池负责创建连接、管理连接、释放连接等操作。

预先创建数据库连接放入连接池，用户在请求时，通过池直接获取连接，使用完毕后，将连接放回池中，避免了频繁的创建和销毁，同时解决了创建的效率。

当池中无连接可用，且未达到上限时，连接池会新建连接；当池中连接达到上限，用户请求会等待，但可以设置超时时间。



## Druid 连接池

Druid（德鲁伊）是阿里巴巴开源的高性能数据库连接池，不仅代替了传统德 DBCP、C3P0 等连接池，还集成了监控、统计、防 SQL 注入、加密等核心功能，目前是 Java 生态中最主流的数据库连接池之一。

```java {5}
@Test
@DisplayName("Druid连接池")
void testDruidDatasource() throws SQLException {
  // 1.创建 DruidDatasource 连接池对象
  DruidDataSource druidDataSource = new DruidDataSource();
  // 2.设置连接池配置信息
  druidDataSource.setDriverClassName("com.mysql.cj.jdbc.Driver");
  druidDataSource.setUrl("jdbc:mysql://localhost:3306/jdbc");
  druidDataSource.setUsername("root");
  druidDataSource.setPassword("1234");
  // 设置初始化时创建的连接池个数
  druidDataSource.setInitialSize(10);
  // 设置最大的连接池个数，当有第11个连接进来时，就会接着创建，但最多不超过20个
  druidDataSource.setMaxActive(20);

  // 3.通过连接池对象获取连接对象
  Connection connection = druidDataSource.getConnection();
  // 4.基于connection进行增删改查

  // 5.回收连接
  connection.close();
}
```

 



## HikariCP 连接池

HikariCP 是一个高性能的 JDBC 连接池组件，号称性能最好的后起之秀，它基于 BoneCP 做了不少的改进和优化，Spring Boot2.x 及更高版本默认使用它作为数据库连接池。

```java {5}
@Test
@DisplayName("HikariCP连接池")
void testHikariCP() throws SQLException {
  // 1.创建 HikariDataSource 连接池对象
  HikariDataSource hikariDataSource = new HikariDataSource();
  // 2.设置连接池的配置信息
  hikariDataSource.setDriverClassName("com.mysql.cj.jdbc.Driver");
  hikariDataSource.setJdbcUrl("jdbc:mysql://localhost:3306/jdbc");
  hikariDataSource.setUsername("root");
  hikariDataSource.setPassword("1234");
  // 设置初始化连接池数量
  hikariDataSource.setMinimumIdle(10);
  // 设置最大的连接池数量
  hikariDataSource.setMaximumPoolSize(20);

  // 3.通过连接池获取连接对象
  Connection connection = hikariDataSource.getConnection();
  System.out.println(connection);

  // 4.使用连接池进行增删改查

  // 5.回收连接
  connection.close();
}
```
