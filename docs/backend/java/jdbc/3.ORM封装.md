# ORM 封装

ORM（对象关系映射）主要有三部分组成：

- **Object**：Java 中的对象/实体类，如 `Employee`；
- **Relational**：关系型数据库中的表和数据，如表 `t_emp`；
- **Mapping**：建立对象与数据库表之间的对应关系；

简单来说，ORM 是一种思想，它的目的是让你像操作 Java 对象一样去操作数据库，而不需要手动写大量繁琐的 JDBC 代码和 SQL 拼接。



## 实体类搭建

**实体类** 就是一个普通的 Java 类（通常是 pojo 或 JavaBean），它的属性和数据库中的某张表的字段 **一一对应**。它的主要作用是在代码中 **承载和传输数据**。

|   表字段   |  类型   |   描述   |
| :--------: | :-----: | :------: |
|   emp_id   |   int   |  员工ID  |
|  emp_name  | varchar | 员工姓名 |
| emp_salary | double  | 员工薪资 |
|  emp_age   |   int   | 员工年龄 |

::: details 表对应的实体类

```java
public class Employee {
  // 表字段是下划线命名，而实体类中需要写为小驼峰命名
  private Integer empId;
  private String empName;
  private Double empSalary;
  private Integer empAge;

  public Employee() {
  }

  public Employee(Integer empId, String empName, Double empSalary, Integer empAge) {
    this.empId = empId;
    this.empName = empName;
    this.empSalary = empSalary;
    this.empAge = empAge;
  }

  public Integer getEmpId() {
    return empId;
  }

  public void setEmpId(Integer empId) {
    this.empId = empId;
  }

  public String getEmpName() {
    return empName;
  }

  public void setEmpName(String empName) {
    this.empName = empName;
  }

  public Double getEmpSalary() {
    return empSalary;
  }

  public void setEmpSalary(Double empSalary) {
    this.empSalary = empSalary;
  }

  public Integer getEmpAge() {
    return empAge;
  }

  public void setEmpAge(Integer empAge) {
    this.empAge = empAge;
  }

  @Override
  public String toString() {
    return "Employee{" +
      "empId=" + empId +
      ", empName='" + empName + '\'' +
      ", empSalary=" + empSalary +
      ", empAge=" + empAge +
      '}';
  }
}
```

## 封装单个对象

```java {13,20-24}
@Test
@DisplayName("ORM封装单个对象")
void testSingleObject() throws SQLException {
  Connection connection = DriverManager
    .getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");

  PreparedStatement preparedStatement = connection.prepareStatement("select * from t_emp where emp_id = ?");
  preparedStatement.setInt(1, 2);

  ResultSet resultSet = preparedStatement.executeQuery();

  // 构建一个空对象，只有查询成功之后才进行赋值
  Employee employee = null;

  while (resultSet.next()) {
    int empId = resultSet.getInt("emp_id");
    String empName = resultSet.getString("emp_name");
    double empSalary = resultSet.getDouble("emp_salary");
    int empAge = resultSet.getInt("emp_age");
    employee = new Employee();
    employee.setEmpId(empId);
    employee.setEmpName(empName);
    employee.setEmpSalary(empSalary);
    employee.setEmpAge(empAge);
  }

  System.out.println(employee);

  resultSet.close();
  preparedStatement.close();
  connection.close();
}
```



## 封装集合

```java {11,19,20}
@Test
@DisplayName("测试名称")
void testMaryObject() throws SQLException {
  Connection connection = DriverManager
    .getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");

  PreparedStatement preparedStatement = connection.prepareStatement("select * from t_emp");
  ResultSet resultSet = preparedStatement.executeQuery();

  // 使用集合来接收
  List<Employee> employees = new ArrayList<>();

  while (resultSet.next()) {
    int empId = resultSet.getInt("emp_id");
    String empName = resultSet.getString("emp_name");
    double empSalary = resultSet.getDouble("emp_salary");
    int empAge = resultSet.getInt("emp_age");
    // 使用构造函数构建单个对象
    Employee employee = new Employee(empId, empName, empSalary, empAge);
    employees.add(employee);
  }

  for (Employee employee : employees) {
    System.out.println(employee);
  }

  resultSet.close();
  preparedStatement.close();
  connection.close();
}
```
