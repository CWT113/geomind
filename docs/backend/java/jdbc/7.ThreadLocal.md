# ThreadLocal

## 工具类封装 1.0 版本

::: info

在项目更目录下，新建 `resources` 文件夹，并将其标记为 “资源根目录”，然后新建 `db.properties` 文件编写连接池对象的初始化参数。

:::

::: code-group

```java [JDBCUtil] {7,9,11,13}
public class JDBCUtil {
  // 使用 DataSource 父接口，多态的体现
  private static DataSource dataSource;

  static {
    try {
      Properties properties = new Properties();
      // 从当前类的加载对象中获取 db.properties 配置文件
      InputStream inputStream = JDBCUtil.class.getClassLoader().getResourceAsStream("db.properties");
      // 将其加载到 properties 中
      properties.load(inputStream);
      // 创建 Druid 连接池对象
      dataSource = DruidDataSourceFactory.createDataSource(properties);
    } catch (Exception e) {
      throw new RuntimeException(e);
    }
  }

  public static Connection getConnection() {
    try {
      return dataSource.getConnection();
    } catch (SQLException e) {
      throw new RuntimeException(e);
    }
  }

  public static void release(Connection connection) {
    try {
      connection.close();
    } catch (SQLException e) {
      throw new RuntimeException(e);
    }
  }
}
```

```properties [db.properties]
driverClassName=com.mysql.cj.jdbc.Driver
url=jdbc:mysql://localhost:3306/jdbc
username=root
password=1234
initialSize=10
maxActive=20
```

:::

上面封装的代码有一个缺点是 **无法保证在同一个事务中使用的是同一个 Connection**，每次调用 `JDBCUtil.getConnection()` 得到的都是不一样的连接，这样频繁创建销毁会比较耗费资源。



## ThreadLocal

ThreadLocal 是 JDK1.2 版本中提供的类，主要用于解决多线程程序的并发问题提供的一种新的思路。

ThreadLocal 用于保存某个线程的共享变量，原因是在 Java 中，每一个线程对象中都有一个 `ThreadLocalMap<ThreadLocal, Object>`，其中 Key 是 ThreadLocal，而 Object 即为该线程的共享变量。

这个 Map 是通过 ThreadLocal 的 `get` 和 `set` 方法操作的，对于同一个 `static ThreadLocal`，不同线程只能从中 get、set 和 remove 自己的变量，而不会影响其他线程的变量。

常用的方法：

|   方法   | 描述                                      |
| :------: | ----------------------------------------- |
|  get()   | 获取 ThreadLocal 中当前线程的共享变量的值 |
|  set()   | 设置 ThreadLocal 中当前线程的共享变量的值 |
| remove() | 移除 ThreadLocal 中当前线程的共享变量的值 |





## 工具类封装 2.0 版本

为了解决 1.0 版本的缺点，可以通过 ThreadLocal 类，把得到的 Connection 存储到里面，后续都是用同一个 Connection 对象。

```java {5,23-27,36-40}
public class JDBCUtil {
  // 使用 DataSource 父接口，多态的体现
  private final static DataSource dataSource;
  // 存储创建的 Connection 对象
  private final static ThreadLocal<Connection> threadLocal = new ThreadLocal<>();

  static {
    try {
      Properties properties = new Properties();
      // 从当前类的加载对象中获取 db.properties 配置文件
      InputStream inputStream = JDBCUtil.class.getClassLoader().getResourceAsStream("db.properties");
      // 将其加载到 properties 中
      properties.load(inputStream);
      // 创建 Druid 连接池对象
      dataSource = DruidDataSourceFactory.createDataSource(properties);
    } catch (Exception e) {
      throw new RuntimeException(e);
    }
  }

  public static Connection getConnection() {
    try {
      Connection connection = threadLocal.get();
      if (connection == null) {
        connection = dataSource.getConnection();
        threadLocal.set(connection);
      }
      return connection;
    } catch (SQLException e) {
      throw new RuntimeException(e);
    }
  }

  public static void release() {
    try {
      Connection connection = threadLocal.get();
      if (connection != null) {
        threadLocal.remove();
        connection.close();
      }
    } catch (SQLException e) {
      throw new RuntimeException(e);
    }
  }
}
```
