# 主键回显

主键回显 是指在数据库中插入一条新纪录时，将由数据库自动生成的自增主键或序列的值，自动填充并返回到代码的对象实体中。

在没有主键回显时，执行插入操作后，数据库虽然生成了新的主键 ID，但在代码中的实体类对象该字段依然为 `null`。如果后续逻辑需要使用这个新生成的 ID，就必须再次查询数据库。主键回显省去了这步额外的查询。

```java {9,24,27}
@Test
@DisplayName("插入数据，并返回主键ID")
void testInsertReturnPK() throws SQLException {
  Connection connection = DriverManager
    .getConnection("jdbc:mysql://localhost:3306/jdbc", "root", "1234");

  String sql = "insert into t_emp (emp_name, emp_salary, emp_age) values (?,?,?)";
  // 传入第二个参数，表示需要返回主键ID
  PreparedStatement preparedStatement = connection.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS);

  // 创建员工对象
  Employee employee = new Employee(null, "王力宏", 8000.0, 40);
  preparedStatement.setString(1, employee.getEmpName());
  preparedStatement.setDouble(2, employee.getEmpSalary());
  preparedStatement.setInt(3, employee.getEmpAge());

  // 执行查询操作
  int result = preparedStatement.executeUpdate();

  ResultSet resultSet = null;
  if (result > 0) {
    System.out.println("新增成功！");
    // 新增成功后，获取返回的主键，结果是一个单行单列
    resultSet = preparedStatement.getGeneratedKeys();
    if (resultSet.next()) {
      // 单行单列的结果，因此直接获取索引为1的数据即可
      int empId = resultSet.getInt(1);
      employee.setEmpId(empId);
    }
    System.out.println(employee);
  } else {
    System.out.println("新增失败！");
  }

  if (resultSet != null) {
    resultSet.close();
  }
  preparedStatement.close();
  connection.close();
}
```
