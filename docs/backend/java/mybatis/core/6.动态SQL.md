# 动态 SQL

MyBatis 中的动态 SQL，指的是在 XML 文件中，通过一系列特定标签，根据传入参数的不同，动态地拼接出最终执行的 SQL 语句。

它的核心目的是解决手动用 JDBC 拼接 SQL 时容易出现的空格遗漏、多余逗号等问题。



## if 标签

`<if>` 标签表示 **条件包含**，用于根据条件决定是否将某段 SQL 拼接到语句中。`<if>` 的 `test` 属性用于编写判断表达式，常见的判断方式有：

|            判断表达式            | 含义                               |
| :------------------------------: | ---------------------------------- |
|           name != null           | 字符串名称不为 null                |
|   name != null and name != ‘’    | 字符串名称不为 null 且不是空字符串 |
|           age != null            | 数值类年龄不为 null                |
|           status == 1            | 布尔类状态等于 1                   |
| list != null and list.size() > 0 | 集合不为 null 且不为空             |

> [!WARNING] 注意
>
> - 如果参数是基本类型 `int`，它不能为 null，如果需要判断参数是否传入，通常需要使用 `Integer` 等包装类型；
> - `where 1 = 1` 是一种常见的查询全部的写法，方便后续统一拼接 `and` 条件，**也可以使用 `<where>` 标签替代**；

```xml {10,13}
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select * from sys_user
    where 1 = 1
    <if test="userId != null">
      and user_id = #{userId}
    </if>
    <if test="userName != null and userName != ''">
      and user_name = #{userName}
    </if>
  </select>

</mapper>
```



## where 标签

`<where>` 标签表示 **仅当内部标签有内容时，才插入 `where` 关键字**，并且会自动去除开头多余的 `and` 或 `or`。一般搭配 `<if>` 标签一起使用。

```xml {9}
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select * from sys_user
    <where>
      <if test="userId != null">
        user_id = #{userId}
      </if>
      <if test="userName != null and userName != ''">
        and user_name = #{userName}
      </if>
    </where>
  </select>

</mapper>
```



## set 标签

`<set>` 标签用于 `update` 语句，会动态插入 `set` 关键字，并自动去除末尾多余的逗号。

```xml {8}
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">
  <update id="updateUser">
    update sys_user
    <set>
      <if test="userName != null and userName != ''">
        user_name = #{userName}
      </if>
      <if test="password != null and password != ''">
        password = #{password}
      </if>
    </set>
    where user_id = #{userId}
  </update>

</mapper>
```



## trim 标签

`<trim>` 标签是更通用的定制标签，可以实现 `<where>` 或 `<set>` 的功能，通过 `prefix`、`suffix`、`prefixOverrides` 等属性自定义前后缀的添加与覆盖。

::: code-group

```xml [trim实现where效果] {9}
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select * from sys_user
    <trim prefix="where" prefixOverrides="and | or"> <!-- prefixOverrides 表示去掉多余的 and 或 or -->
      <if test="userId != null">
        and user_id = #{userId}
      </if>
      <if test="userName != null and userName != ''">
        and user_name = #{userName}
      </if>
    </trim>
  </select>

</mapper>
```

```xml {9} [trim实现set效果]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <update id="updateUser">
    update sys_user
    <trim prefix="set" prefixOverrides=",">
      <if test="userName != null and userName != ''">
        user_name = #{userName}
      </if>
      <if test="password != null and password != ''">
        password = #{password}
      </if>
    </trim>
    where user_id = #{userId}
  </update>

</mapper>
```

:::



## choose、when、otherwise 标签

这三个标签类似于 Java 中的 switch 语句。它按照顺序判断 `when` 中的条件，只拼接第一个满足条件的 SQL 片段，如果都不满足，则拼接 `otherwise` 中的内容。

```xml {12,16,20}
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select * from sys_user
    <where>
      <choose>
        <!-- 如果传入了 userId，优先按照 userId 查询 -->
        <when test="userId != null">
          user_id = #{userId}
        </when>
        <!-- 如果没有传入 userId，但传入了 userName，则按照 userName 查询 -->
        <when test="userName != null and userName != ''">
          and user_name = #{userName}
        </when>
        <!-- 如果前两者都没有传入，默认查询 del_flag = 0 的数据 -->
        <otherwise>
          and del_flag = 0
        </otherwise>
      </choose>
    </where>
  </select>

</mapper>
```



## foreach 标签

`<foreach>` 标签常用于构建 `in` 条件或批量插入语句。它可以遍历 List、Set、数组、Map 等集合。

> [!WARNING] 注意
>
> 如果集合为空，应该在业务层校验集合非空，或者在 SQL 中对空集合进行明确处理，不要直接执行 `in()` 查询或删除！

::: code-group

```xml {10} [SysUserMapper.xml]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select * from sys_user
    where user_id in
    <foreach collection="userIds" item="userId" open="(" separator="," close=")">
      #{userId}
    </foreach>
  </select>

</mapper>
```

```java [SysUserMapper]
public interface SysUserMapper {
  List<SysUser> selectAll(@Param("userIds") List<Long> userIds);
}
```

:::



## bind 标签

`<bind>` 标签用于在模糊查询时，动态拼接 `like` 参数。

```xml {8}
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">
  
  <select id="selectAll" resultType="com.example.pojo.SysUser">
    <bind name="keyword" value="'%' + username + '%'"/>
    select * from sys_user where user_name like #{keyword}
  </select>

</mapper>
```



## sql 和 include 标签

`<sql>` 标签用于将重复出现的 SQL 片段（如查询字段列表、公共 where 条件）抽取出来，并通过 `id` 属性给它一个唯一标识，方便后续引用。

```xml {6-8,13,20}
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">
  <sql id="sysUserColumns">
    user_id, user_name, nick_name, password, email, create_time, update_time
  </sql>

  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select
    <!-- 引用 sql 预定义的片段 -->
    <include refid="sysUserColumns"/>
    from sys_user
  </select>

  <select id="selectById" resultType="com.example.pojo.SysUser">
    select
    <include refid="sysUserColumns"/>
    from sys_user where user_id = #{userId}
  </select>
</mapper>
```
