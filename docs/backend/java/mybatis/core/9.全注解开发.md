# 全注解开发

在 MyBatis 中，全注解发开允许我们抛弃 XML 映射文件，直接在 Mapper 接口的方法上使用注解（如 `@Select`、`@Insert`、`@Results` 等）完成 SQL 编写、参数绑定与结果集映射。



## 基础 CRUD 注解

最基本的增删改查操作通过 `@Select`、`@Insert`、`@Update`、`@Delete` 四个注解实现。

::: code-group

```java {10} [SysUserMapper]
public interface SysUserMapper {
  @Select("select * from sys_user")
  List<SysUser> selectAll();

  @Select("select * from sys_user where user_id = #{userId}")
  SysUser selectById(Long userId);

  @Insert("insert into sys_user (user_id, user_name, nick_name, password, email, user_pic, create_time, update_time) " +
          "values (null, #{userName}, #{nickName}, #{password}, #{email}, null, now(), now())")
  @Options(useGeneratedKeys = true, keyProperty = "userId") // 要把数据库中插入主键赋值给类的哪个属性
  int addUser(SysUser sysUser);

  @Update("update sys_user set user_name = #{userName}, update_time = now() " +
          "where user_id = #{userId}")
  int updateUser(SysUser sysUser);

  @Delete("update sys_user set del_flag = 1 where user_id = #{userId}") // 逻辑删除
  int deleteById(Long userId);
}
```

```java [单元测试]
public class AppTest {
  @Test
  @DisplayName("查询所有用户")
  void testSelectAll() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession();
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    List<SysUser> sysUsers = mapper.selectAll();
    sysUsers.forEach(System.out::println);
  }

  @Test
  @DisplayName("根据Id查询用户")
  void testSelectById() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession();
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    SysUser sysUser = mapper.selectById(1L);
    System.out.println(sysUser);
  }

  @Test
  @DisplayName("新增用户")
  void testAddUser() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession(true);
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    SysUser sysUser = SysUser.builder()
      .userName("zsf")
      .nickName("张三丰222")
      .password("123456")
      .email("sanfeng@qq.com")
      .build();
    int affectRows = mapper.addUser(sysUser);
    System.out.println(affectRows);
    System.out.println(sysUser);
  }

  @Test
  @DisplayName("修改用户")
  void testUpdateUser() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession(true);
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    SysUser sysUser = SysUser.builder()
      .userId(8L)
      .userName("blongma")
      .build();
    int affectRows = mapper.updateUser(sysUser);
    System.out.println(affectRows); // userId自动赋值给了sysUser
  }

  @Test
  @DisplayName("删除用户")
  void testDeleteById() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession(true);
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    int affectRows = mapper.deleteById(8L);
    System.out.println(affectRows);
  }
}
```

## 结果集映射

当数据库列名与实体属性名不一致，或存在“一对一”、“一对多”级联查询时，使用 `@Results` 、`@Result` 代替 XML 中的 `<resultMap>`。

::: code-group

```java {3,15} [SysUserMapper]
public interface SysUserMapper {
  @Select("select * from sys_user where user_id = #{userId} and del_flag = 0")
  @Results(id = "userMap", value = { // 通过 id 指定唯一标识符，以便复用
    @Result(id = true, column = "user_id", property = "id"),
    @Result(column = "user_name", property = "username"),
    @Result(column = "nick_name", property = "nickname"),
    @Result(column = "password", property = "pwd"),
    @Result(column = "email", property = "email"),
    @Result(column = "create_time", property = "cTime"),
    @Result(column = "update_time", property = "uTime"),
  })
  User findDetailById(Long userId);

  @Select("select * from sys_user")
  @ResultMap("userMap") // 复用上面定义的映射规则
  List<User> listAllUsers();
}
```

```java [User]
@Data
public class User {
  private Long id;

  private String username;

  private String nickname;

  private String pwd;

  private String email;

  private LocalDateTime cTime;

  private LocalDateTime uTime;
}
```

```java [单元测试]
public class AppTest {
  @Test
  void testFindDetailById() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession();
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    User user = mapper.findDetailById(1L);
    System.out.println(user);
  }

  @Test
  void testListAllUsers() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession();
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    List<User> users = mapper.listAllUsers();
    users.forEach(System.out::println);
  }
}
```
