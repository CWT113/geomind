# 增删改查

MyBatis 是一款优秀的持久层框架，它支持自定义 SQL、存储过程以及高级映射。MyBatis 免除了几乎所有的 JDBC 代码以及设置参数和获取结果集的工作，通过简单的 XML 或注解来配置和映射原始类型、接口和 Java POJO 为数据库中的记录。



## 查询

### 单参数查询

> [!TIP]`#{}` 和 `${}` 的区别
>
> | 符号  |                         说明                         |         使用场景         |
> | :---: | :--------------------------------------------------: | :----------------------: |
> | `#{}` | 预编译占位符，填充到生成的 `?` 处，可以防止 SQL 注入 |     参数传递（推荐）     |
> | `${}` |     单纯的字符串拼接，直接替换，会存在 SQL 注入      | 动态表名、列名、排序字段 |
>
> ```xml
> <!-- 推荐 -->
> select * from user where username = #{username}
> 
> <!-- 排序字段必须用 ${}，但注意 SQL 注入风险 -->
> select * from user order by ${sortField}
> ```

::: code-group

```xml {13} [SysUserMapper.xml]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">
  <!-- 查询所有用户 -->
  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select * from sys_user
  </select>

  <!-- 根据用户Id查询 -->
  <select id="selectById" resultType="com.example.pojo.SysUser">
    select * from sys_user where user_id = #{userId}
  </select>
</mapper>
```

```java [SysUserMapper]
public interface SysUserMapper {
  List<SysUser> selectAll();

  SysUser selectById(Long userId);
}
```

```java [单元测试]
  @Test
  @DisplayName("查询所有用户")
  void testSelectAll() {
	SqlSession sqlSession = MyBatisUtils.getSqlSession();
	SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
	List<SysUser> sysUsers = mapper.selectAll();
	sysUsers.forEach(System.out::println);
  }

  @Test
  @DisplayName("根据Id查询用户")
  void testSelectById() {
	SqlSession sqlSession = MyBatisUtils.getSqlSession();
	SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
	SysUser sysUser = mapper.selectById(1L);
	System.out.println(sysUser);
  }
```

### 多参数查询

查询接口中有多个参数时，需要使用 `@Param` 注解为每个参数指定名称，以方便在 SQL 中进行使用，默认情况下参数使用 `param0`（或 `arg0`），`param1`（或 `arg1`）。

::: code-group

```xml {7} [SysUserMapper.xml]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">
  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select * from sys_user where user_id = #{userId} or user_name = #{username}
  </select>
</mapper>
```

```java {2,3} [SysUserMapper]
public interface SysUserMapper {
  List<SysUser> selectAll(@Param("userId") Long userId, // 使用 @Param 注解指定名称，然后在 XML 中使用
                          @Param("username") String username);
}
```

```java [单元测试]
@Test
@DisplayName("查询所有用户")
void testSelectAll() {
  SqlSession sqlSession = MyBatisUtils.getSqlSession();
  SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
  List<SysUser> sysUsers = mapper.selectAll(1L, "LiuXu");
  sysUsers.forEach(System.out::println);
}
```

### 对象参数查询

::: code-group

```xml {14} [SysUserMapper.xml]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">
  <select id="selectAll" resultType="com.example.pojo.SysUser">
    select * from sys_user
    where user_name = #{userName} or password = #{password}
  </select>

  <select id="selectByPage" resultType="com.example.pojo.SysUser">
    select * from sys_user
    where user_name = #{sysUser.userName} or password = #{sysUser.password}
    limit #{pageParam.offset}, #{pageParam.pageSize}
  </select>
</mapper>
```

```java [SysUserMapper]
public interface SysUserMapper {
  // 查询时只有一个对象
  List<SysUser> selectAll(SysUser sysUser);

  // 查询时也可以多个对象，字段只要相同，会自动映射到对象中的属性上
  List<SysUser> selectByPage(@Param("sysUser") SysUser sysUser,
                             @Param("pageParam") PageParam pageParam);
}
```

```java [单元测试]
public class AppTest {
  @Test
  @DisplayName("查询所有用户")
  void testSelectAll() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession();
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    SysUser sysUser = SysUser.builder()
      .userName("L")
      .password("9")
      .build();
    List<SysUser> sysUsers = mapper.selectAll(sysUser);
    sysUsers.forEach(System.out::println);
  }

  @Test
  @DisplayName("查询所有用户，并带分页")
  void testSelectByPage() {
    SqlSession sqlSession = MyBatisUtils.getSqlSession();
    SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
    SysUser sysUser = SysUser.builder()
      .userName("a")
      .password("123")
      .build();
    PageParam pageParam = new PageParam(0, 4);
    List<SysUser> sysUsers = mapper.selectByPage(sysUser, pageParam);
    sysUsers.forEach(System.out::println);
  }
}
```

```java [PageParam]
@Data
@AllArgsConstructor
public class PageParam {
  private Integer offset;

  private Integer pageSize;
}
```

### 结果映射

结果映射适合表中字段与实体类中字段名完全不同的情况。

> [!NOTE] 提示
>
> 如果表中是下划线命名，而实体类是驼峰命名，则开启驼峰命名自动映射即可。
>
> ```xml
> <settings>
>     <!-- 开启驼峰命名自动映射 -->
>     <setting name="mapUnderscoreToCamelCase" value="true"/>
> </settings>
> ```

::: code-group

```xml {7,17} [SysUserMapper.xml]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">
  <!-- 结果集映射，如果字段名称相同可以省略  -->
  <resultMap id="userResultMap" type="com.example.pojo.User">
    <id property="id" column="user_id"/>
    <result property="username" column="user_name"/>
    <result property="nickname" column="nick_name"/>
    <result property="pwd" column="password"/>
    <result property="email" column="email"/>
    <result property="cTime" column="create_time"/>
    <result property="uTime" column="update_time"/>
  </resultMap>

  <select id="selectAll" resultMap="userResultMap">
    select * from sys_user
  </select>
</mapper>
```

```java [SysUserMapper]
public interface SysUserMapper {
  List<User> selectAll();
}
```

## 新增

新增默认不会将新增后的主键返回，需要设置 `useGeneratedKeys` 为 `true`，并通过 `keyProperty` 指定回填的主键属性。

::: code-group

```xml {8} [SysUserMapper.xml]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <!-- 新增用户（返回主键Id） -->
  <insert id="addUser" useGeneratedKeys="true" keyProperty="userId">
    insert into sys_user (user_id, user_name, nick_name, password, email, user_pic, create_time, update_time)
    values (null, #{userName}, #{nickName}, #{password}, #{email}, null, now(), now())
  </insert>

</mapper>
```

```java [SysUserMapper]
public interface SysUserMapper {
  int addUser(SysUser sysUser);
}
```

```java [单元测试]
@Test
@DisplayName("新增用户")
void testAddUser() {
  SqlSession sqlSession = MyBatisUtils.getSqlSession(true); // 自动提交事务
  SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
  SysUser sysUser = SysUser.builder()
    .userName("whd")
    .nickName("王鹤棣")
    .password("999999")
    .email("whd@qq.com")
    .build();
  int affectRows = mapper.addUser(sysUser);
  System.out.println(affectRows);
  System.out.println(sysUser);
}
```

## 删除

::: code-group

```xml [SysUserMapper.xml]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <!-- 删除用户（逻辑删除） -->
  <delete id="deleteById">
    update sys_user set del_flag = 1 where user_id = #{userId}
  </delete>

  <!-- 删除用户（物理删除） -->
  <delete id="deleteById">
    delete from sys_user where user_id = #{userId}
  </delete>

</mapper>
```

```java [SysUserMapper]
public interface SysUserMapper {
  int deleteById(Long userId);
}
```

```java [单元测试]
@Test
@DisplayName("删除用户")
void testDeleteById() {
  SqlSession sqlSession = MyBatisUtils.getSqlSession(true); // 自动提交事务
  SysUserMapper mapper = sqlSession.getMapper(SysUserMapper.class);
  int affectRows = mapper.deleteById(10L);
  System.out.println(affectRows);
}
```
