# XML配置文件

MyBatis 的核心配置文件 `mybatis-config.xml` 用于配置全局行为、数据源、事务及映射器。

需要注意的是，MyBatis 对顶层标签的顺序有严格要求，如果不按照顺序编写，XML 解析会报错。

```xml {7,9,11,13,15,17,19}
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
  PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
  "https://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
  <!-- 外部属性引入 -->
  <properties resource="db.properties"/>
  <!-- 全局运行行为设置 -->
  <settings></settings>
  <!-- 类型别名配置 -->
  <typeAliases></typeAliases>
  <!-- 自定义类型处理器(可选) -->
  <typeHandlers></typeHandlers>
  <!-- 插件/拦截器 -->
  <plugins></plugins>
  <!-- 环境配置 -->
  <environments default="development"></environments>
  <!-- 映射器注册 -->
  <mappers></mappers>
</configuration>
```



## properties

用于 **引入外部键值对配置文件**（如 `db.properties`），或在 **内部自定义属性**，供后续标签使用 `${key}` 引用。

> [!NOTE] 提示
>
> - 如果外部 properties 文件和标签有相同字段，会优先使用外部 properties 文件；

::: code-group

```xml {7} [mybatis-config.xml]
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
        PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
  <!-- 引入外部配置文件 -->
  <properties resource="db.properties">
    <property name="author" value="tom"/> <!-- 或者自定义属性，其他地方通过 ${key} 引用 -->
  </properties>
</configuration>
```

```properties [db.properties]
jdbc.driver=com.mysql.cj.jdbc.Driver
jdbc.url=jdbc:mysql://localhost:3306/mybatis?useSSL=true&useUnicode=true&characterEncoding=UTF-8
jdbc.username=root
jdbc.password=1234
```

:::



## settings

指定 MyBatis 在运行期间的全局配置。

```xml {8}
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
        PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
  <settings>
    <!-- 开启驼峰命名自动映射 -->
    <setting name="mapUnderscoreToCamelCase" value="true"/>
    <!-- 超时时间（秒），决定驱动等待数据库响应的秒数 -->
    <setting name="defaultStatementTimeout" value="25"/>
  </settings>
</configuration>
```



## typeAliases

该配置是 MyBatis 的 **类型别名**，作用是给某个 Java 类起一个短名字，之后在 Mapper XML 里就不用写完整的类名了。

::: code-group

```xml [mybatis-config.xml]
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
        PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
  <typeAliases>
    <!-- 单独为某一个类设置别名 -->
    <typeAlias type="com.example.pojo.SysUser" alias="SysUser"/>
    <!-- 批量扫描包，自动将包下所有类的类名（首字母小写或原样）作为别名 -->
    <package name="com.example.pojo"/>
  </typeAliases>
</configuration>
```

```xml [SysUserMapper.xml]
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">

  <!-- <select id="selectAll" resultType="com.example.pojo.SysUser"> -->
  <select id="selectAll" resultType="SysUser"> <!-- 使用 typeAlias 写别名后，就不用写全类名了 -->
    select * from sys_user
  </select>

</mapper>
```

:::



## plugins

用于配置 MyBatis 的拦截器，如分页插件（PageHelper）、性能分析插件等。

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
        PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
  <plugins>
    <plugin interceptor="com.github.pagehelper.PageInterceptor">
      <!-- 指定数据库类型为 mysql -->
      <property name="helperDialect" value="mysql"/>
      <!-- 合理化分页，如 -1 页自动调整为第 1 页 -->
      <property name="reasonable" value="true"/>
    </plugin>
  </plugins>
</configuration>
```



## environments

用于定义数据库环境（如开发环境 `dev`、生产环境 `prod`）。虽然可以配置多个环境，但每个 `SqlSessionFactory` 实例只能选择一个生效。

> [!NOTE] 提示
>
> 在 SpringBoot 或 Spring 整合 MyBatis 时，通常由 Spring 管理数据源和事务，此标签会被 Spring 配置替代。

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
        PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
  <properties resource="db.properties"/>

  <environments default="development">
    <environment id="development">
      <!-- 使用 mybatis 默认的 JDBC 事务类型 -->
      <transactionManager type="JDBC"/>
      <!-- 连接数据源配置，POOLED 表示使用 mybatis 默认提供的连接池 -->
      <dataSource type="POOLED">
        <property name="driver" value="${jdbc.driver}"/>
        <property name="url" value="${jdbc.url}"/>
        <property name="username" value="${jdbc.username}"/>
        <property name="password" value="${jdbc.password}"/>
      </dataSource>
    </environment>
  </environments>
</configuration>
```



## mappers

用于告诉 MyBatis 去哪里找到你写的 Mapper 映射文件（XML）或 Mapper 接口，并把它们注册到 `SqlSessionFactory` 中。

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration
        PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
  <mappers>
    <!-- 使用相对 classpath 的资源引用 -->
    <mapper resource="mapper/SysUserMapper.xml"/>
    <!-- 使用完全限定接口名（要求 XML 和接口在同包同名，或接口使用纯注解） -->
    <mapper class="com.example.mapper.SysUserMapper"/>
    <!-- 包扫描注册（最常用，要求同包同名规则） -->
    <package name="com.example.mapper"/>
  </mappers>
</configuration>
```
