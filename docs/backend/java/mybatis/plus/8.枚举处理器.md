# 枚举处理器

MyBatis-Plus 中的枚举处理器（Enum TypeHandler），主要用于解决一个问题：
**Java 实体类中的枚举类型，如何与数据库中的整数或字符串进行自动转换**。

例如，我们希望：

- Java 中使用 `OrderStatus.PAID` 表示订单已支付；
- 数据库中存储数字 `1`，而不是字符串 `"PAID"`；
- 查询数据库时，自动将数字 `1` 转换回 `OrderStatus.PAID`；

MyBatis-Plus 提供了 `MyBatisEnumTypeHandler` 来完成这种转换。常见的有两种方式： **`@EnumValue` 注解（推荐）** 和 实现
`IEnum` 接口。



## @EnumValue 注解

首先，创建枚举类：

```java {11-13}
@Getter
@AllArgsConstructor
public enum OrderStatus {
  UNPAID(0, "未支付"),

  PAID(1, "未支付"),

  CANCELLED(2, "已取消");

  // 明确告诉 MyBatis-Plus，将枚举保存到数据库时，使用 code 的值，而不是枚举名称
  @EnumValue
  @JsonValue // Jackson的JSON序列化注解，它可以把 PAID 转为 1 返回给前端
  private final Integer code;

  private final String desc;
}
```

当增改查时，MyBatis-Plus 会自动根据 `@EnumValue` 注解进行转换：

```java {13,21}
@RestController
@RequestMapping("/order")
public class OrderController {
  @Autowired
  private OrderService orderService;

  @GetMapping
  public R<List<OrderVO>> queryAll(OrderDTO orderDTO) { // 查询时，orderStatus 需要填 PAID、UNPAID，会自动转为 code 的值
    Order order = BeanUtil.copyProperties(orderDTO, Order.class);
    List<Order> orders = orderService.lambdaQuery()
            .eq(order.getOrderId() != null, Order::getOrderId, order.getOrderId())
            .like(order.getOrderName() != null && !order.getOrderName().isBlank(), Order::getOrderName, order.getOrderName())
            .eq(order.getOrderStatus() != null, Order::getOrderStatus, order.getOrderStatus())
            .list();
    return R.ok(BeanUtil.copyToList(orders, OrderVO.class));
  }

  @PostMapping
  public R addOrder(@RequestBody OrderDTO orderDTO) {
    Order order = BeanUtil.copyProperties(orderDTO, Order.class);
    boolean saved = orderService.save(order); // 查询回来的值也是 PAID、UNPAID，并非 1、2、3
    return saved ? R.ok() : R.fail();
  }
}
```



## 实现 IEnum 接口

除了使用 `@EnumValue` 注解，还可以让枚举实现 MyBatis-Plus 提供的 `IEnum` 接口。

```java {3,15}
@Getter
@AllArgsConstructor
public enum OrderStatus implements IEnum<Integer> {
  UNPAID(0, "未支付"),

  PAID(1, "未支付"),

  CANCELLED(2, "已取消");

  private final Integer code;

  private final String desc;

  @Override
  public Integer getValue() { // 实现 IEnum 之后，会使用通过调用 getValue() 获取枚举值
    return code;
  }
}
```
