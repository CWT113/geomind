# 分页插件

MyBatis-Plus 的分页插件，主要用于实现数据库的物理分页，让我们不需要手动编写 `limit` 语句，就可以完成分页查询。



## 引入依赖

如果使用的 MyBatis-Plus 版本是 3.5.9 以上，分页插件需要单独引入 `mybatis-plus-jsqlparser`：

```xml

<dependency>
  <groupId>com.baomidou</groupId>
  <artifactId>mybatis-plus-jsqlparser</artifactId>
  <version>3.5.16</version>
</dependency>
```

这里的版本号需要和项目中的 MyBatis-Plus 版本号保持一致，低于 3.5.9 的版本通常不需要单独引入。



## 配置分页插件

```java {5,7}
@Configuration
public class MyBatisPlusConfig {
  @Bean
  public MybatisPlusInterceptor mybatisPlusInterceptor() {
    MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
    // 添加分页插件，并指定数据库为 MySQL
    interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
    return interceptor;
  }
}
```



这里涉及两个核心类：

|             类             | 作用                           |
| :------------------------: | ------------------------------ |
|   MybatisPlusInterceptor   | MyBatis-Plus 插件的统一管理入口 |
| PaginationInnerInterceptor | 真正执行分页逻辑的内部拦截器   |



如果配置了其他内部插件，官方建议 **把分页插件放在最后添加**，以减低 `COUNT` SQL 处理不正确的风险。



## 使用分页

最常用的是 `Page<T>` 类：

| 方法         | 含义             | 示例     |
| ------------ | ---------------- | -------- |
| getCurrent() | 当前页           | 1        |
| getSize()    | 每页记录数       | 10       |
| getTotal()   | 总记录数         | 100      |
| getPages()   | 总页数           | 10       |
| getRecords() | 当前页的数据集合 | 10条订单 |

::: code-group

```java [OrderController] {9}
@RestController
@RequestMapping("/order")
public class OrderController {
  @Autowired
  private OrderService orderService;

  @GetMapping("list")
  public RPage<OrderVo> list(PageQuery pageQuery) {
    return RPage.ok(orderService.queryPageList(pageQuery));
  }
}
```

```java [OrderService]
public interface OrderService extends IService<Order> {
  IPage<OrderVo> queryPageList(PageQuery pageQuery);
}
```

```java [OrderServiceImpl]
@Service
public class OrderServiceImpl extends ServiceImpl<OrderMapper, Order> implements OrderService {
  @Override
  public IPage<OrderVo> queryPageList(PageQuery pageQuery) {
    Page<Order> orderPage = baseMapper.selectPage(pageQuery.build(), null);
    // 利用 MyBatis-Plus 的 convert 将分页中的每条 Order 转换为 OrderVo
    return orderPage.convert(order -> {
      OrderVo orderVo = new OrderVo();
      BeanUtil.copyProperties(order, orderVo);
      return orderVo;
    });
  }
}

```

```java [PageQuery]
@Data
@NoArgsConstructor
public class PageQuery implements Serializable {
  @Serial
  private static final long serialVersionUID = 1L;

  private static final int DEFAULT_PAGE_NUM = 1;

  private static final int DEFAULT_PAGE_SIZE = Integer.MAX_VALUE;

  private Integer pageNum;

  private Integer pageSize;

  public <T> Page<T> build() {
    Integer num = ObjectUtil.defaultIfNull(this.getPageNum(), DEFAULT_PAGE_NUM);
    Integer size = ObjectUtil.defaultIfNull(this.getPageSize(), DEFAULT_PAGE_SIZE);
    if (num < 0) {
      num = DEFAULT_PAGE_NUM;
    }
    return new Page<>(num, size);
  }
}
```

```java [RPage]
@Data
@NoArgsConstructor
public class RPage<T> implements Serializable {
  @Serial
  private static final long serialVersionUID = 1L;

  private Integer code;

  private String message;

  private List<T> rows;

  private Long total;

  public static <T> RPage<T> ok(IPage<T> page) {
    RPage<T> rPage = new RPage<>();
    rPage.setCode(200);
    rPage.setMessage("操作成功");
    rPage.setRows(page.getRecords());
    rPage.setTotal(page.getTotal());
    return rPage;
  }

  public static <T> RPage<T> ok(List<T> list) {
    RPage<T> rPage = new RPage<>();
    rPage.setCode(200);
    rPage.setMessage("操作成功");
    rPage.setRows(list);
    rPage.setTotal((long) list.size());
    return rPage;
  }
}
```

```java [R]
@Data
@NoArgsConstructor
@AllArgsConstructor(access = AccessLevel.PRIVATE)
public class R<T> implements Serializable {
  @Serial
  private static final long serialVersionUID = 1L;

  private Integer code;

  private String message;

  private T data;

  public static <T> R<T> ok() {
    return restResult(200, "操作成功", null);
  }

  public static <T> R<T> ok(T data) {
    return restResult(200, "操作成功", data);
  }

  public static <T> R<T> ok(String message) {
    return restResult(200, message, null);
  }

  public static <T> R<T> ok(String message, T data) {
    return restResult(200, message, data);
  }

  public static <T> R<T> fail() {
    return restResult(500, "操作失败", null);
  }

  public static <T> R<T> fail(T data) {
    return restResult(500, "操作失败", data);
  }

  public static <T> R<T> fail(String message) {
    return restResult(500, message, null);
  }

  public static <T> R<T> fail(String message, T data) {
    return restResult(500, message, data);
  }

  public static <T> R<T> fail(Integer code, String message) {
    return restResult(code, message, null);
  }

  public static <T> R<T> restResult(Integer code, String message, T data) {
    return new R<>(code, message, data);
  }
}
```

底层执行 SQL 语句时，会先查询一次 `count(*)` ，然后再查询当前页的数据：

```sql
-- 查询总记录数
SELECT COUNT(*) FROM t_order;

-- 查询当前页数据
SELECT * FROM t_order LIMIT 0, 10;
```
