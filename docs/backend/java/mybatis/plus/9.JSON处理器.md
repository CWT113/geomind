# JSON 处理器

在 MyBatis-Plus 中，JSON 类型处理器（JSON TypeHandler）主要用于 **实现 Java 对象与数据库 JSON 字段之间的自动转换**。

MyBatis-Plus 内置了三种 TypeHandler，分别是：

- JacksonTypeHandler
- Fastjson2TypeHandler
- GsonTypeHandler

由于 SpringBoot 默认使用的就是 JacksonTypeHandler，因此这里也是用它作为 JSON 的处理器。



## 实体类配置

使用过程很简单，只需要修改实体类即可：

::: code-group

```java [SysUser] {14,3}
@Data
// 有JSON转实体类时，需要开启autoResultMap，自动开启结果映射
@TableName(value = "sys_user", autoResultMap = true)
public class SysUser {
  @TableId(value = "user_id", type = IdType.AUTO)
  private Long userId;

  private String userName;

  private String nickName;

  private String password;

  @TableField(typeHandler = JacksonTypeHandler.class) // 指定 JSON 格式的类型处理器
  private UserInfo info;

  private LocalDateTime createTime;

  private LocalDateTime updateTime;

  @TableField(value = "is_delete")
  private Integer isDelete;
}
```

```java {3} [UserInfo]
@Data
@NoArgsConstructor
@AllArgsConstructor(staticName = "of") // 可以直接使用 UserInfo.of() 创建对象
public class UserInfo {
  private Integer age;

  private String intro;

  private String gender;
}
```

:::

> [!TIP] 提示
>
> 这里有两个关键配置：
>
> - `@TableName(autoResultMap = true)`：让 MyBatis-Plus 自动构建结果映射，使查询时指定的 JSON 类型处理器能够生效；
> - `@TableField(typeHandler = JacksonTypeHandler.class)`：指定这个字段使用 Jackson 进行 JSON 转换；



## 单元测试

```java {23}
@SpringBootTest
class MainApplicationTests {
  @Autowired
  private SysUserService sysUserService;

  @Test
  @DisplayName("查询所有")
  void testQueryAll() {
    List<SysUser> sysUsers = sysUserService.list();
    sysUsers.forEach(System.out::println);
  }

  @Test
  @DisplayName("新增数据")
  void testInsert() {
    SysUser sysUser = new SysUser();
    sysUser.setUserName("Alice");
    sysUser.setNickName("Alice");
    sysUser.setPassword("Alice@123");
    sysUser.setCreateTime(LocalDateTime.now());
    sysUser.setUpdateTime(LocalDateTime.now());
    // 设置了 @AllArgsConstructor(staticName = "of") 就能这么用了
    sysUser.setInfo(UserInfo.of(25, "政治老师", "女"));
    boolean saved = sysUserService.save(sysUser);
    System.out.println(saved);
  }
}
```
