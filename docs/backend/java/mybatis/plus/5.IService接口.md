# IService 接口

`IService` 是 MyBatis-Plus 提供的一个 **通用业务层（Service）顶层接口**。

它进一步封装了单表常见的 CRUD 操作，提供了比底层的 `BaseMapper` 更高层、更丰富的业务方法（如链式查询、批量插入/更新、分页包装等）。

> [!NOTE]
>
> 与 BaseMapper 的关系：
>
> - `BaseMapper<T>`：位于 DAO/持久层，提供的是 SQL 级别的基本单表操作；
> - `IService<T>`：位于 Service/业务层，方法命名偏向于业务语义（如 `save` 代替 `insert`、`list` 代替 `selectList`），但底层本质上仍是调用对应的 Mapper；



## 基础用法

首先，创建 Mapper 接口，继承 `BaseMapper<T>`：

```java
@Mapper
public interface SysUserMapper extends BaseMapper<SysUser> {
  // 基础单表 CRUD 已内置，这里可以扩展复杂的多表关联 SQL
}
```

然后，自定义 Service 接口，继承 `IService<T>`：

```java
public interface SysUserService extends IService<SysUser> {
  // 可以添加自定义的特定业务方法
}
```

然后，`impl` 中的实现类需要同时满足两点：

- 继承 `ServiceImpl<M, T>`：`M` 为对应的 Mapper 接口，`T` 为实体类；
- 实现自定义的 Service 接口；

```java
@Service
public class SysUserServiceImpl extends ServiceImpl<SysUserMapper, SysUser> implements SysUserService {
  // ServiceImpl以及实现了 IService 中的所有方法
  // 在这里使用 baseMapper 或直接调用父类方法
}
```

直接调用 Service 层操作数据库，实现增删改查：

```java {9}
@SpringBootTest
class MainApplicationTests {
  @Autowired
  private SysUserService sysUserService;

  @Test
  @DisplayName("查询所有")
  void testListAll() {
    List<SysUser> sysUsers = sysUserService.list();
    sysUsers.forEach(System.out::println);
  }
}
```



## 开发基础业务接口

::: code-group

```java {9,15,22,27} [SysUserController]
@RestController
@RequestMapping("/sysUser")
public class SysUserController {
  @Autowired
  private SysUserService sysUserService; // [!code ++]

  @GetMapping("/{userId}")
  public SysUserVO queryUserById(@PathVariable("userId") Long userId) {
    SysUser sysUser = sysUserService.getById(userId);
    return BeanUtil.copyProperties(sysUser, SysUserVO.class);
  }

  @GetMapping
  public List<SysUserVO> queryUserByIds(@RequestParam("userIds") List<Long> userIds) {
    List<SysUser> sysUsers = sysUserService.listByIds(userIds);
    return BeanUtil.copyToList(sysUsers, SysUserVO.class);
  }

  @PostMapping
  public void addUser(@RequestBody SysUserDTO sysUserDTO) {
    SysUser sysUser = BeanUtil.copyProperties(sysUserDTO, SysUser.class);
    sysUserService.save(sysUser);
  }

  @DeleteMapping("/{userId}")
  public void deleteUserById(@PathVariable("userId") Long userId) {
    sysUserService.removeById(userId);
  }
}
```

## Lambda 条件查询

Lambda 条件查询主要可以分为 `lambdaQuery`（查询）和 `lambdaUpdate`（更新）两类，都适合做 **多条件的判断查询或更新**。

`lambdaQuery` 查询：

::: code-group

```java [SysUserController] {11}
@RestController
@RequestMapping("/sysUser")
public class SysUserController {
  @Autowired
  private SysUserService sysUserService;

  @GetMapping("/list")
  public List<SysUserVO> list(SysUserQuery userQuery) {
    // 调用自己在 Service 中定义的 queryUsers 方法
    List<SysUser> sysUsers = sysUserService
      .queryUsers(userQuery.getUserId(), userQuery.getUserName(), userQuery.getNickName());
    return BeanUtil.copyToList(sysUsers, SysUserVO.class);
  }
}
```

```java [SysUserServiceImpl]
@Service
public class SysUserServiceImpl extends ServiceImpl<SysUserMapper, SysUser> implements SysUserService {
  @Override
  public List<SysUser> queryUsers(Long userId, String userName, String nickName) {
    // 当前 Service 已经继承了 ServiceImpl，因此可以直接使用 this 调用 ServiceImpl 内置的方法
    return this.lambdaQuery() // [!code ++]
      .eq(userId != null, SysUser::getUserId, userId)
      .like(userName != null && !userName.isBlank(), SysUser::getUserName, userName)
      .like(nickName != null && !nickName.isBlank(), SysUser::getNickName, nickName)
      .list();
  }
}
```

```java [SysUserQuery]

  private String userName;

  private String password;

  private LocalDateTime createTime;

::: code-group

@RestController
@RequestMapping("/sysUser")
public class SysUserController {
  @Autowired
  private SysUserService sysUserService;

  @PutMapping
  public boolean updateUserById(@RequestBody SysUserDTO sysUserDTO) {
    // 调用自己在 Service 中定义的 updateUser 方法
    return sysUserService.updateUser(sysUserDTO.getUserId(),
                                     sysUserDTO.getUserName(),
                                     sysUserDTO.getNickName(),
                                     sysUserDTO.getPassword());
  }
}
```

```java {10} [SysUserServiceImpl]
@Service
public class SysUserServiceImpl extends ServiceImpl<SysUserMapper, SysUser> implements SysUserService {
  @Override
  public boolean updateUser(Long userId, String userName, String nickName, String password) {
    return this.lambdaUpdate() // [!code ++]
      .set(userName != null && !userName.isBlank(), SysUser::getUserName, userName)
      .set(nickName != null && !nickName.isBlank(), SysUser::getNickName, nickName)
      .set(password != null && !password.isBlank(), SysUser::getPassword, password)
      .eq(SysUser::getUserId, userId)
      .update(); // 调用 update() 才会真的执行更新操作
  }
}
```

## 批量新增

批量新增有两种效率高的方式：

- 使用 MyBatis 中的 `foreach` 标签批量生成 `VALUES ()`，这样最终只执行一次 SQL 插入语句，性能较高；
- 使用 MyBatis-Plus 中 `IService.saveBatch()` 方法，并搭配驱动连接中 `rewriteBatchedStatements=true` 配置；

::: code-group

```java [单元测试]
@SpringBootTest
class MainApplicationTests {
  @Autowired
  private SysUserService sysUserService;

  @Test
  @DisplayName("测试名称")
  void testInsertBatch() {
    long start = System.currentTimeMillis();
    List<SysUser> sysUsers = createSysUser(100000);
    sysUserService.saveBatch(sysUsers); // [!code ++]
    long end = System.currentTimeMillis();
    System.out.println("总耗时：" + (end - start));
  }

  private List<SysUser> createSysUser(int length) {
    List<SysUser> SysUsers = new ArrayList<>();
    for (int i = 0; i < length; i++) {
      SysUser sysUser = new SysUser();
      sysUser.setUserName("user_" + i);
      sysUser.setNickName("user_" + i);
      sysUser.setPassword("password_" + i);
      sysUser.setCreateTime(LocalDateTime.now());
      sysUser.setUpdateTime(LocalDateTime.now());
      SysUsers.add(sysUser);
    }
    return SysUsers;
  }
}
```
