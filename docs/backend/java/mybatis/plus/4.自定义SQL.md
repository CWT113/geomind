# 自定义 SQL

自定义 SQL 是指利用 MyBatis-Plus 的 Wrapper 来构建复杂的 `where` 条件，然后自己定义 SQL 中其余的部分。



>:beginner: 需求：将 user_id 在指定范围内的用户（如：1、2、3）的年龄统一都增加 1 岁。​



## 基础写法

借助 `LambdaUpdateWrapper` 的 `setsql()` 方法，来指定执行的 sql 语句：

```java {6}
@Test
void testByUpdateWrapper() {
  List<Long> userIds = List.of(1L, 2L, 3L);
  LambdaUpdateWrapper<SysUser> wrapper = new LambdaUpdateWrapper<SysUser>()
    .setSql("age = age + 1") // [!code ++]
    .in(SysUser::getUserId, userIds);
  int affectRows = sysUserMapper.update(null, wrapper);
  System.out.println(affectRows);
}
```

但是这样的写法并不规范，直接在 `setsql()` 中写死 `age = age + 1` 不利于维护。



## 自定义 SQL 写法

首先，基于 Wrapper 构建 `where` 条件：

```java [7]
@Test
void testByUpdateWrapper() {
  int addAge = 1;
  List<Long> userIds = List.of(1L, 2L, 3L);
  LambdaUpdateWrapper<SysUser> wrapper = new LambdaUpdateWrapper<SysUser>()
    .in(SysUser::getUserId, userIds);
  int affectRows = sysUserMapper.updateAgeByIds(wrapper, addAge);
  System.out.println(affectRows);
}
```

然后，在 Mapper 方法参数中，用 `@Param` 注解声明 Wrapper 变量名称：

> [!NOTE] 注意
>
> 自定义方法中的第一个参数，必须使用 `@Param("ew")` 这个名称，它必须叫 `ew`。

::: code-group

```java [XML写法] {3}
@Mapper
public interface SysUserMapper extends BaseMapper<SysUser> {
  int updateAgeByIds(@Param("ew") LambdaUpdateWrapper<SysUser> wrapper,
                     @Param("addAge") int addAge);
}
```

```java [全注解写法] {3}
@Mapper
public interface SysUserMapper extends BaseMapper<SysUser> {
  @Update("update sys_user set age = age + #{addAge} ${ew.customSqlSegment}")
  int updateAgeByIds(@Param("ew") LambdaUpdateWrapper<SysUser> wrapper,
                     @Param("addAge") int addAge);
}
```

:::

最后创建 `SysUserMapper.xml` 文件，自定义 SQL 语句，并使用已经构建好的 Wrapper 条件：

```xml {12,10}
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
  PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
  "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.SysUserMapper">
  <update id="updateAgeByIds">
    update
    	sys_user
    set
    	age = age + #{addAge}
    <!-- 拼接 mybatis-plus 生成的 where 条件 -->
    ${ew.customSqlSegment}
  </update>
</mapper>
```
