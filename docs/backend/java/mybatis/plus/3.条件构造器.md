# 条件构造器

条件构造器（Wrapper）就是用 Java 代码动态拼接 SQL 查询条件的工具。它可以帮我们构建 `where`、`order by`、`group by` 等 SQL 片段，而不必手动编写每一条 SQL 语句。



## QueryWrapper

`QueryWrapper` （普通查询构造器）是使用数据库字段名称字符串构造查询条件，例如 `eq("age", 18)`。

### 基础查询条件

|    方法     |    含义    | 示例                         |
| :---------: | :--------: | ---------------------------- |
|    `eq`     |    等于    | `eq("age", 18)`              |
|    `ne`     |   不等于   | `ne("age", 18)`              |
|    `gt`     |    大于    | `gt("age", 18)`              |
|    `ge`     |  大于等于  | `ge("age", 18)`              |
|    `lt`     |    小于    | `lt("age", 18)`              |
|    `le`     |  小于等于  | `le("age", 18)`              |
|  `between`  |  区间查询  | `between("age", 18, 30)`     |
|   `like`    |  模糊查询  | `like("user_name", "admin")` |
|    `in`     |  集合匹配  | `in("age", 18, 20, 22)`      |
|  `isNull`   |  字段为空  | `isNull("email")`            |
| `isNotNull` | 字段不为空 | `isNotNull("email")`         |



>:beginner:示例：查询名称中包含 `a`，且年龄大于等于 18 岁，且邮箱不为空的用户。

::: code-group

```java {3,4,5,6} [单元测试]
@Test
void testByQueryWrapper() {
  QueryWrapper<SysUser> wrapper = new QueryWrapper<SysUser>()
    .like("user_name", "a")
    .ge("age", 18)
    .isNotNull("email");
  List<SysUser> sysUsers = sysUserMapper.selectList(wrapper);
  sysUsers.forEach(System.out::println);
}
```

```sql [底层SQL]
SELECT 
	user_id,user_name,nick_name,age,password,email,create_time,update_time 
FROM 
	sys_user 
WHERE 
	(user_name LIKE ? AND age >= ? AND email IS NOT NULL)
```

:::



### 指定查询字段

如果只需要查询特定的几个字段，而不是所有字段，可以通过 `select` 指定：

::: code-group

```java [单元测试]
@Test
void testByQueryWrapper() {
  QueryWrapper<SysUser> wrapper = new QueryWrapper<SysUser>()
    .select("user_id", "user_name", "nick_name", "age") // [!code ++]
    .like("user_name", "a")
    .ge("age", 18)
    .isNotNull("email");
  List<SysUser> sysUsers = sysUserMapper.selectList(wrapper);
  sysUsers.forEach(System.out::println);
}
```

```sql [底层SQL]
SELECT 
	user_id,user_name,nick_name,age
FROM 
	sys_user 
WHERE 
	(user_name LIKE ? AND age >= ? AND email IS NOT NULL)
```

:::



### 排序

`orderByAsc` 表示升序排序，`orderByDesc` 表示降序排序。

::: code-group

```java [单元测试]
@Test
void testByQueryWrapper() {
  QueryWrapper<SysUser> wrapper = new QueryWrapper<SysUser>()
    .select("user_id", "user_name", "nick_name", "age")
    .orderByDesc("age"); // [!code ++]
  List<SysUser> sysUsers = sysUserMapper.selectList(wrapper);
  sysUsers.forEach(System.out::println);
}
```

```sql [底层SQL]
SELECT 
	user_id,user_name,nick_name,age 
FROM 
	sys_user 
ORDER BY 
	age DESC
```

:::



### 分组

分组使用 `groupBy` 字段。例如，统计每个年龄有多少名用户：

::: code-group

```java {4,5} [单元测试]
@Test
void testByQueryWrapper() {
  QueryWrapper<SysUser> wrapper = new QueryWrapper<SysUser>()
    .select("age", "count(*) as total") // 只查询 age 字段，并且将统计结果命名为 total
    .groupBy("age");
  List<Map<String, Object>> maps = sysUserMapper.selectMaps(wrapper);
  System.out.println(maps);
}
```

```sql [底层SQL]
SELECT 
	age,count(*) as total 
FROM 
	sys_user
GROUP BY 
	age
```

:::



### `or` 构造多条件

假设查询年龄大于 20 岁，或名称中有 `s` 的用户：

::: code-group

```java [单元测试]
@Test
void testByQueryWrapper() {
  QueryWrapper<SysUser> wrapper = new QueryWrapper<SysUser>()
    .select("user_id", "user_name", "nick_name", "age")
    .gt("age", 20)
    .or() // [!code ++]
    .like("user_name", "s");
  List<SysUser> sysUsers = sysUserMapper.selectList(wrapper);
  sysUsers.forEach(System.out::println);
}
```

```sql [底层SQL]
SELECT 
	user_id,user_name,nick_name,age 
FROM 
	sys_user 
WHERE 
	(age > ? OR user_name LIKE ?)
```

:::

如果要混合使用 `and`、`or`，需要特别注意括号。

::: code-group

```java [单元测试]
@Test
void testByQueryWrapper() {
  // 查询年龄大于等于 20 岁，或者名称中包含 s 并且 email 不为空的
  QueryWrapper<SysUser> wrapper = new QueryWrapper<SysUser>()
    .select("user_id", "user_name", "nick_name", "age")
    .ge("age", 20)
    .or(w -> w // [!code ++]
        .like("user_name", "s") // [!code ++]
        .isNotNull("email")); // [!code ++]
  List<SysUser> sysUsers = sysUserMapper.selectList(wrapper);
  sysUsers.forEach(System.out::println);
}
```

```sql [底层SQL]
SELECT 
	user_id,user_name,nick_name,age
FROM 
	sys_user
WHERE 
	(age >= ? OR (user_name LIKE ? AND email IS NOT NULL))
```

:::



## LambdaQueryWrapper

`LambdaQueryWrapper`（Lambda 查询构造器）是使用实体类方法引用，例如 `eq(SysUser::getAge, 18)`，**减少硬编码字段名**。日常查询优先推荐这个。

和 `QueryWrapper` 的功能基本相同，主要区别 **在于字段的指定方法**。



### 基础查询条件

查询用户名中包含 `s`、年龄大于 18 岁，并按照年龄降序排列：

::: code-group

```java {3-7} [单元测试]
@Test
void testByQueryWrapper() {
  LambdaQueryWrapper<SysUser> wrapper = new LambdaQueryWrapper<SysUser>()
    .select(SysUser::getUserId, SysUser::getUserName, SysUser::getNickName, SysUser::getAge)
    .like(SysUser::getUserName, "a")
    .ge(SysUser::getAge, 18)
    .orderByDesc(SysUser::getAge);
  List<SysUser> sysUsers = sysUserMapper.selectList(wrapper);
  sysUsers.forEach(System.out::println);
}
```

```sql [底层SQL]
SELECT 
	user_id,user_name,nick_name,age
FROM 
	sys_user
WHERE 
	(user_name LIKE ? AND age >= ?) ORDER BY age DESC
```

:::



### 动态查询

假设前端有一个用户查询表单：

- 用户名：可以不填
- 最小年龄：可以不填
- 最大年龄：可以不填

如果表单中填写了用户名，就按照用户名查询，如果填写了年龄，就增加年龄条件。

 ::: code-group

```java {9-11} [单元测试]
@Test
void testByQueryWrapper() {
  String username = null;
  Integer minAge = 10;
  Integer maxAge = 50;

  LambdaQueryWrapper<SysUser> wrapper = new LambdaQueryWrapper<SysUser>();
  // 如果 username 不为 null 且不为空字符串时，把表中的 user_name 字段和当前的 username 变量进行模糊查询
  wrapper.like(username != null && !username.isBlank(), SysUser::getUserName, username);
  wrapper.ge(minAge != null, SysUser::getAge, minAge);
  wrapper.le(maxAge != null, SysUser::getAge, maxAge);

  List<SysUser> sysUsers = sysUserMapper.selectList(wrapper);
  sysUsers.forEach(System.out::println);
}
```

```sql [底层SQL]
SELECT 
	user_id,user_name,nick_name,age,password,email,create_time,update_time 
FROM 
	sys_user
WHERE 
	(age >= ? AND age <= ?)
```

:::



## UpdateWrapper

`UpdateWrapper` （普通更新构造器）通过字段名称字符串指定更新内容和更新条件。



### 根据条件更新

例如，将设置用户 ID 为 3 的邮箱地址：

::: code-group

```java [单元测试]
@Test
void testByUpdateWrapper() {
  UpdateWrapper<SysUser> wrapper = new UpdateWrapper<SysUser>()
    .set("email", "lx779@gmail.com") // [!code ++]
    .eq("user_id", 3L); // [!code ++]
  // 参数 null 表示不通过实体对象更新字段，而是完全使用 wrapper 中 set() 更新字段
  int affectRows = sysUserMapper.update(null, wrapper);
  System.out.println(affectRows);
}
```

```sql [底层SQL]
UPDATE 
	sys_user 
SET 
	email=? 
WHERE 
	(user_id = ?)
```

:::



### 使用实体更新

如果需要修改的字段比较多，也可以通过实体对象传递更新值：

::: code-group

```java [单元测试]
@Test
void testByUpdateWrapper() {
  SysUser sysUser = SysUser.builder()
    .userName("WangYiBo")
    .nickName("王一博")
    .age(32)
    .build();
  UpdateWrapper<SysUser> wrapper = new UpdateWrapper<>();
  wrapper.eq("user_id", 3L);
  // 第一个参数指定实体类
  int affectRows = sysUserMapper.update(sysUser, wrapper); // [!code ++]
  System.out.println(affectRows);
}
```

```sql [底层SQL]
UPDATE 
	sys_user 
SET 
	user_name=?, nick_name=?, age=? 
WHERE 
	(user_id = ?)
```

:::



## LambdaUpdateWrapper

`LambdaUpdateWrapper`（Lambda 更新构造器）是通过实体类方法引用指定更新的字段和条件，避免手写字段名。

例如，将设置用户 ID 为 3 的邮箱地址：

::: code-group

```java [单元测试]
@Test
void testByUpdateWrapper() {
  LambdaUpdateWrapper<SysUser> wrapper = new LambdaUpdateWrapper<SysUser>()
    .set(SysUser::getAge, 35)
    .set(SysUser::getEmail, "l77922@gmail.com")
    .eq(SysUser::getUserId, 3L);
  int affectRows = sysUserMapper.update(null, wrapper);
  System.out.println(affectRows);
}
```

```sql [底层SQL]
UPDATE sys_user SET age=?,email=? WHERE (user_id = ?)
```

:::
