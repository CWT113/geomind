# 基础使用

MyBatis-Plus 是基于 MyBatis 增强的持久层框架，它提供了通用的 增删改查 方法，能够减少大量重复的 SQL 编写工作，同时也支持 XML、自定义 SQL、条件构造器和分页查询。



## 引入依赖

下面以 SpringBoot3.x 为主，使用 MyBatis-Plus 的 SpringBoot3 专用 starter。

```xml
<dependencies>
  <!-- 引入 mysql 驱动依赖 -->
  <dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
  </dependency>
  
  <!-- 引入 mybatis-plus 依赖 -->
  <dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
    <version>3.5.16</version>
  </dependency>
</dependencies>
```

> [!IMPORTANT] 提醒
>
> - Spring Boot 3.x 使用 `mybatis-plus-spring-boot3-starter` 依赖；
> - Spring Boot 2.x 使用 `mybatis-plus-boot-starter` 依赖；



## 配置数据库连接

在 `src/main/resources/application.yml` 中配置数据库：

```yaml
spring:
  application:
    name: demo-mp
  # 数据库配置
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/mybatis?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    username: root
    password: 1234
# mybatis-plus配置
mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
  mapper-locations:
    - classpath*:/mapper/**/*.xml
```

其中，`mapper-locations` 只要用于需要自定义编写 XML SQL 的场景，如果只使用 MyBatis-Plus 的通用 CRUD，可以暂时不配置。



## 创建数据库表

创建一张用户信息表：

```sql
CREATE TABLE `sys_user` (
  `user_id` bigint(64) unsigned NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `user_name` varchar(255) NOT NULL COMMENT '用户名称',
  `nick_name` varchar(255) NOT NULL COMMENT '用户昵称',
  `password` varchar(255) NOT NULL COMMENT '密码',
  `create_time` datetime NOT NULL COMMENT '创建时间',
  `update_time` datetime NOT NULL COMMENT '更新时间',
  PRIMARY KEY (`user_id`)
) ENGINE=InnoDB AUTO_INCREMENT=4 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

## 创建实体类

> [!NOTE] 提示
>
> - MyBatis-Plus 默认是 **开启了下划线转驼峰映射** 的，因此不需要额外配置；

```java {6}
@Data
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class SysUser {
  @TableId(value = "user_id", type = IdType.AUTO) // 指定主键，并使用数据库自增策略
  private Long userId;

  private String userName;

  private String nickName;

  private String password;

  private LocalDateTime createTime;

  private LocalDateTime updateTime;
}
```



## 创建 Mapper 接口

创建 Mapper 接口，并继承 `BaseMapper` 接口：

```java {2}
@Mapper
public interface SysUserMapper extends BaseMapper<SysUser> {
}
```

常用的增删改查方法：

|        方法         | 作用         |
| :-----------------: | ------------ |
| selectList(wrapper) | 条件查询     |
|   selectById(id)    | 根据主键查询 |
|   insert(entity)    | 新增数据     |
|   updateById(id)    | 根据主键更新 |
|   deleteById(id)    | 根据主键删除 |

```java {8,14,21,31,37}
@SpringBootTest
class MainApplicationTests {
  @Autowired
  private SysUserMapper sysUserMapper;

  @Test
  void testSelectAll() {
    List<SysUser> sysUsers = sysUserMapper.selectList(null);
    sysUsers.forEach(System.out::println);
  }

  @Test
  void testSelectById() {
    SysUser sysUsers = sysUserMapper.selectById(1L);
    System.out.println(sysUsers);
  }

  @Test
  void testInsert() {
    SysUser sysUser = new SysUser(null, "WangYb", "王一博", "123456", LocalDateTime.now(), LocalDateTime.now());
    int affectRows = sysUserMapper.insert(sysUser);
    System.out.println(affectRows);
  }

  @Test
  void testUpdateById() {
    SysUser sysUser = SysUser.builder()
      .userId(3L)
      .nickName("王一博886")
      .build();
    int affectRows = sysUserMapper.updateById(sysUser);
    System.out.println(affectRows);
  }

  @Test
  void testDeleteById() {
    int affectRows = sysUserMapper.deleteById(3L);
    System.out.println(affectRows);
  }
}
```
