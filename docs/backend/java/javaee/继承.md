# 继承

继承是面向对象编程（OOP）中的核心概念之一。它允许 **子类继承另一个类（称为父类或基类）的属性和方法**。

> [!NOTE] 继承的特性
>
> - 子类拥有父类中非 `private` 的属性、方法；
> - 子类可以拥有自己的属性和方法，即子类可以对父类进行扩展；
> - 子类可以用自己的方法覆盖父类中的同名方法；



## 继承关键字

### extends

在 Java 中，**类的继承是单一继承**（即一个子类只能拥有一个父类），所以 `extends` 关键字只能继承一个父类。

```java {15,21}
public class Animal {
  public String name;
  public int age;

  public Animal(String name, int age) {
    this.name = name;
    this.age = age;
  }

  public void eat() {
    System.out.println("动物可以吃饭！");
  }
}

class Dog extends Animal {
  public Dog(String name, int age) {
    super(name, age);
  }
}

class Cat extends Animal {
  public Cat(String name, int age) {
    super(name, age);
  }
}
```



### implements

使用 `implements` 关键字可以变相的使 Java 具有多继承的特性，使用范围为 **类继承接口** 的情况，可以同时继承多个接口。

```java {9}
interface Flyable {
  void fly();
}

interface Swimable {
  void swim();
}

class Duck implements Flyable, Swimable {
  @Override
  public void fly() {
    System.out.println("鸭子在低空飞行");
  }

  @Override
  public void swim() {
    System.out.println("鸭子在水中划水");
  }
}
```

`extends` 和 `implements` 区别：

|   特性   |             extends              |            implements            |
| :------: | :------------------------------: | :------------------------------: |
|   对象   |            类 继承 类            |           类 实现 接口           |
|   数量   |            只能单继承            |           可以多个实现           |
|   关系   |            A 是一种 B            |         A 具备 B 的功能          |
| 方法处理 | 子类可以使用父类方法，也可以重写 | 子类必须重写接口里的所有抽象方法 |



### this

`this` 关键字指向自己的引用，引用当前对象，即指向类内部的方法或成员变量。

```java {6,8}
class Cat {
  String name;

  public Cat(String name) {
    // 调用成员变量
    this.name = name;
    // 调用内部方法
    this.eat();
  }

  public void eat() {
    System.out.println(this.name);
  }
}

```



### super

`super` 关键字指向父类的引用，可以通过 `super.` 的方式调用父类中的方法或成员变量。

```java {19,21} 
class Person {
  String name;

  public Person(String name) {
    this.name = name;
  }

  public void eat() {
    System.out.println("吃饭ing");
  }
}

class Student extends Person {
  int score;

  public Student(String name, int score) {
    this.score = score;
    // super调用父类构造方法
    super(name);
    // super调用父类方法
    super.eat();
  }
}
```



### final

`final` 关键字用于修饰变量（包括类属性、对象属性、局部变量和形参）、方法和类。

> [!NOTE] 提示
>
> - 使用 `final` 修饰的类，表示该类为最终类，不能被继承；
> - 使用 `final` 修饰的方法，表示该方法不能被重写；
> - 使用 `final` 修饰的变量，表示该变量只能被赋值一次，之后再无法更改；

::: code-group

```java [修饰类]
final class Person {
}

class Student extends Person { // 报错：无法继承自 final 类 // [!code --]
}
```

```java [修饰方法]
class Person {
  public final void eat() {
  }
}

class Student extends Person {
  @Override
  public void eat() { // 报错：不能重写 final 修饰的方法 // [!code --]
    super.eat();
  }
}
```

```java [修饰变量]
class Student {
  final double PI = 3.14;
  // 声明静态常量
  final static double MAX_VALUE = 100;

  public void change() {
    PI = 3.1415; // 报错：不能给 final 修饰的变量赋值 // [!code --]
  }
}
```

:::
