# 抽象类

抽象类是使用 `abstract` 关键字修饰的类。它 **不能被实例化**（即通过 new 的方式获取实例），但它可以包含 **抽象方法**（只有声明，没有实现）和 **具体方法**（有实现）。

抽象类、普通类以及接口的对比：

|    特性    |               抽象类               |     普通类     |        接口（Java8+）        |
| :--------: | :--------------------------------: | :------------: | :--------------------------: |
|   实例化   |                不能                |       能       |             不能             |
|  构造方法  |               可以有               |     可以有     |            不能有            |
|  成员变量  | 可以各种类型（private、protected） |      同左      |      默认是 final 常量       |
|  普通方法  |           可以有具体实现           | 必须有具体实现 | 可以有 default / static 方法 |
|   多继承   |               单继承               |     单继承     |            多实现            |
| 访问修饰符 |               无限制               |     无限制     |       方法默认 public        |



## 定义抽象类

```java {9}
public abstract class Payment {
  protected double amount;

  public Payment(double amount) {
    this.amount = amount;
  }

  // 抽象方法：强制子类必须实现（支付渠道不同，逻辑不同）
  public abstract void pay();

  // 具体方法：子类直接复用（打印票据大家都一样）
  public void printReceipt() {
    System.out.println("打印支付凭证，金额：" + this.amount);
  }
}
```



## 继承抽象类

继承抽象类时，子类必须实现抽象类中定义的抽象方法。

::: code-group

```java [WechatPayment]
public class WechatPayment extends Payment {
  public WechatPayment(double amount) {
    super(amount);
  }

  @Override
  public void pay() {
    System.out.println("正在调用微信支付API，支付金额：" + amount);
  }
}
```

```java [Main]
public static void main(String[] args) {
  WechatPayment wechatPayment = new WechatPayment(200);
  // 调用内部实现的方法
  wechatPayment.pay();
  // 调用父级抽象类方法
  wechatPayment.printReceipt();
}
```

:::
