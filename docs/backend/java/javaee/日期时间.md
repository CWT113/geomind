# 日期时间

Java 中日期时间 API 经历了一次重大的演变。最初的 `java.util.Date` 和 `java.util.Calendar` 因为设计糟糕经常被吐槽。

为了彻底解决这个问题，Java8 引入了全新的 DateTime API（`java.time` 包）。这个新 API 是 **不可变且线程安全** 的，设计极其清晰。

核心日期时间类：

|        类         |       说明       | 示例值                                |
| :---------------: | :--------------: | ------------------------------------- |
|     LocalDate     | 日期（年-月-日） | 2026-06-17                            |
|     LocalTime     | 时间（时:分:秒.纳秒） | 13:37:36.927580800           |
|   LocalDateTime   |   日期 + 时间    | 2026-06-17 18:00:25                   |
|   ZonedDateTime   | 带时区的日期时间 | 2026-06-17T14:30+08:00 [Asia/Shanghai] |
|      Instant      |      时间戳      | 2026-06-17T06:30:45Z                  |
|     Duration      |     时间间隔     | PT10H30M                              |
|      Period       |     日期间隔     | P1Y2M3D                               |
| DateTimeFormatter |   格式化/解析    | yyyy-MM-dd HH:mm:ss                   |



## LocalDate

`LocalDate` 用于处理不需要时间的日期，格式为 `YYYY-MM-DD`。

```java {3,6,9-11,16-18}
public static void main(String[] args) {
  // 获取当前日期
  LocalDate today = LocalDate.now();
  System.out.println("今天日期：" + today); // 今天日期：2026-06-18
  // 创建指定日期
  LocalDate allday = LocalDate.of(2026, 3, 24);
  System.out.println("指定日期：" + allday); // 指定日期：2026-03-24
  // 日期计算
  LocalDate tomorrow = today.plusDays(1);
  LocalDate nextMonth = today.plusMonths(1);
  LocalDate lastYear = today.minusYears(1);
  System.out.println("明天：" + tomorrow); // 明天：2026-06-19
  System.out.println("下个月：" + nextMonth); // 下个月：2026-07-18
  System.out.println("去年今天：" + lastYear); // 去年今天：2025-06-18
  // 获取日期的详细信息
  int year = today.getYear();
  int month = today.getMonthValue();
  int day = today.getDayOfMonth();
  System.out.println(year + "年" + month + "月" + day + "号"); // 2026年6月18号
}
```



## LocalTime

`LocalTime` 用于处理不需要日期的时间，格式为 `HH:mm:ss.SSS`。

```java {2,6,9}
public static void main(String[] args) {
  LocalTime now = LocalTime.now();
  System.out.println("当前时间(含纳秒)：" + now); // 当前时间(含纳秒)：13:37:36.927580800
  System.out.println("当前时间(不含纳秒)：" + now.truncatedTo(ChronoUnit.SECONDS)); // 当前时间(不含纳秒)：13:37:36

  LocalTime badTime = LocalTime.of(23, 30, 30);
  System.out.println("睡觉时间：" + badTime); // 睡觉时间：23:30:30

  LocalTime inTwoHours = now.plusHours(2);
  System.out.println("两小时后：" + inTwoHours); // 两小时后：15:37:36.927580800
}
```



## LocalDateTime

`LocalDateTime` 是最常用的时间类，它组合了日期和时间，但不包含时区信息。

```java {2,5,8,9,13-18}
public static void main(String[] args) {
  LocalDateTime now = LocalDateTime.now();
  System.out.println("当前时间：" + now); // 当前时间：2026-06-18T13:42:39.301341400

  LocalDateTime appointment = LocalDateTime.of(2026, 3, 24, 12, 30, 30);
  System.out.println("预约时间：" + appointment); // 预约时间：2026-03-24T12:30:30

  LocalDate localDate = now.toLocalDate();
  LocalTime localTime = now.toLocalTime();
  System.out.println("获取日期：" + localDate); // 获取日期：2026-06-18
  System.out.println("获取时间：" + localTime); // 获取时间：13:44:22.829062700

  int year = now.getYear();
  int month = now.getMonthValue();
  int day = now.getDayOfMonth();
  int hour = now.getHour();
  int minute = now.getMinute();
  int second = now.getSecond();
  System.out.println(year + "年" + month + "月" + day + "号 " + hour + ":" + minute + ":" + second); // 2026年6月18号 13:48:12
}
```



## ZonedDateTime

`ZonedDateTime` 类是带时区的日期时间，如果需要严格考虑时区，就必须使用该类。

```java {2,5}
public static void main(String[] args) {
  ZonedDateTime now = ZonedDateTime.now();
  System.out.println("当前时区时间：" + now); // 当前时区时间：2026-06-18T13:53:22.129775+08:00[Asia/Shanghai]

  ZonedDateTime newYorkTime = ZonedDateTime.now(ZoneId.of("America/New_York"));
  System.out.println("纽约当前时间：" + newYorkTime); // 纽约当前时间：2026-06-18T01:53:22.131780500-04:00[America/New_York]
}
```



## Instant

`Instant` 时间戳，代表的是时间线上的一个瞬时点（UTC 时间），常用于机器识别和日志记录。

```java {2,5}
public static void main(String[] args) {
  long timestamp1 = Instant.now().toEpochMilli();
  System.out.println("当前毫秒数：" + timestamp1); // 当前毫秒数：1781762384872

  long timestamp2 = System.currentTimeMillis();
  System.out.println("当前毫秒数：" + timestamp2); // 当前毫秒数：1781762384877
}
```



## Duration 和 Period

`Duration` 用于计算 时间间隔，以秒为单位，适合 `LocalTime`、`Instant`；

`Period` 用于计算 日期间隔，以年、月、日为单位，适合 `LocalDate`；

::: code-group

```java {4}
public static void main(String[] args) {
  LocalDate startDate = LocalDate.of(2026, 3, 24);
  LocalDate endDate = LocalDate.of(2026, 4, 16);
  Period period = Period.between(startDate, endDate);
  int months = period.getMonths();
  int days = period.getDays();
  System.out.println("相差：" + months + "个月" + days + "天"); // 相差：0个月23天
}
```

```java {4}
public static void main(String[] args) {
  LocalTime startTime = LocalTime.of(8, 30);
  LocalTime endTime = LocalTime.of(12, 0);
  Duration duration = Duration.between(startTime, endTime);
  long hours = duration.toHours();
  long minutes = duration.toMinutes();
  System.out.println("相差：" + hours + "小时" + minutes + "分"); // 相差：3小时210分
}
```

:::



## DateTimeFormatter

`DateTimeFormatter` 用于将日期时间转换为我们想要的字符串格式，或者反过来将文本字符串解析为日期对象。它是线程安全的。

```java
public static void main(String[] args) {
  LocalDateTime now = LocalDateTime.now();
  DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

  String formatted = now.format(formatter);
  System.out.println("格式化后的字符串：" + formatted); // 2026-06-18 14:59:15

  String dateStr = "2026-06-18 14:59:15";
  LocalDateTime parsed = LocalDateTime.parse(dateStr, formatter);
  System.out.println("解析出的对象：" + parsed); // 2026-06-18T14:59:15
}
```
