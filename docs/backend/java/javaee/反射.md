# 反射

反射（Reflection）允许程序在运行期间查询、访问和修改类、接口、字段和方法的信息，它提供了动态操作类的能力。



## 获取 Class 对象

每个类在 JVM 中都有一个与之相关的 Class 对象。可以通过以下方式获取 Class 对象：

通过类字面量获取：

```java
Class<String> clazz = String.class;
```

通过对象实例：

```java
String str = "hello";
Class<? extends String> clazz = str.getClass();
```

通过 `Class.forName()` 方法：

```java
Class<?> clazz = Class.forName("java.lang.String");
```



## 创建对象

```java
Class<?> clazz = Class.forName("java.lang.String");
Object o = clazz.getDeclaredConstructor().newInstance();
```



## 访问字段

```java
public static void main(String[] args) throws Exception {
  Person person = new Person("王一博", 25);

  Class<Person> clazz = Person.class;
  Field field = clazz.getDeclaredField("name");
  // 如果字段是 private 修饰的，需要设置为可访问
  field.setAccessible(true);

  // 获取字段值
  String name = (String) field.get(person);
  System.out.println(name); // 王一博

  // 设置字段值
  field.set(person, "张凌赫");
  System.out.println(person.getName()); // 张凌赫
}
```



## 调用方法

```java
public static void main(String[] args) throws Exception {
  Person person = new Person("王一博", 25);

  Class<Person> clazz = Person.class;
  Method sayHello = clazz.getMethod("sayHello");
  sayHello.invoke(person); // hello

  Method greet = clazz.getMethod("greet", String.class);
  greet.invoke(person, "world");
}
```



## 获取构造函数

```java
public static void main(String[] args) throws Exception {
  Person person = new Person("王一博", 25);

  Class<Person> clazz = Person.class;
  Constructor<Person> constructor = clazz.getConstructor(String.class, Integer.class);
  Person person1 = constructor.newInstance("任嘉伦", 30);
  System.out.println(person1); // Person{name='任嘉伦', age=30}
}
```



## 获取接口和父类

```java
public static void main(String[] args) throws Exception {
  Person person = new Person("王一博", 25);
  Class<Person> clazz = Person.class;

  Class<?>[] interfaces = clazz.getInterfaces();
  for (Class<?> i : interfaces) {
    System.out.println("Interface：" + i.getSimpleName());
  }

  Class<?> superclass = clazz.getSuperclass();
  System.out.println("Superclass：" + superclass.getSimpleName());
}
```
