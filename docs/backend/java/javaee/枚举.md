# 枚举

在 Java 中，枚举（Enum）是一种特殊的数据类型，它用于定义一组固定的常量。

简单来说，当一个变量的取值是固定的一组值时，就应该使用枚举。例如：性别（男或女）、星期（周一到周日）、季节（春夏秋冬）等。



## 定义枚举

Java 枚举类使用 `enum` 关键字来定义，各个常量用全字母大写表示，使用逗号 `,` 分割。

::: code-group

```java [定义枚举]
enum Color {
  RED,
  GREEN,
  BLUE,
}
```

```java [使用枚举]
public static void main(String[] args) {
  Color red = Color.RED;
  System.out.println(red); // RED
}
```

:::



## 常用方法

`enum` 定义的枚举默认继承了 `java.lang.Enum` 类，并实现了 `java.lang.Serializable` 和 `java.lang.Comparable` 两个接口。

因此，枚举拥有以下几个方法：

|   方法    | 描述                              |
| :-------: | --------------------------------- |
| values()  | 获取枚举类中所有的值              |
| ordinal() | 找到每个枚举常量的索引，从 0 开始 |
| valueOf() | 获取指定字符串值得枚举常量        |

```java {3,6,10}
public static void main(String[] args) {
  // 获取所有的枚举值
  Color[] values = Color.values();
  for (Color value : values) {
    // 查看索引
    System.out.println(value + " 索引是 " + value.ordinal()); // RED 索引是 0
  }

  // 获取指定值的枚举常量
  Color red = Color.valueOf("RED");
  System.out.println(red); // RED
}
```



## 枚举类成员

枚举本质上是一个特殊的类，这意味枚举里面不仅可以写常量，还可以写 **属性、构造方法和普通方法**。

::: code-group

```java [Color]
public enum Color {
  RED(0, "红色"),
  GREEN(1, "绿色"),
  BLUE(2, "蓝色");

  private final Integer code;
  private final String description;

  Color(Integer code, String description) {
    this.code = code;
    this.description = description;
  }

  public Integer getCode() {
    return code;
  }

  public String getDescription() {
    return description;
  }
}
```

```java [Main]
public static void main(String[] args) {
  Color red = Color.RED;
  System.out.println(red.getCode());
  System.out.println(red.getDescription());
}
```

:::
