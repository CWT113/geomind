# 多线程

多线程是指在一个程序中同时运行多个“执行路径”（即线程）的技术。它允许程序将不同的任务拆分并发执行，从而充分利用 CPU 的多核性能，提高程序的响应速度和吞吐量。

> [!NOTE] 多线程优势
>
> - **提高 CPU 利用率**：在单线程下，如果程序在等待磁盘 IO 或网络请求，CPU 就会处于闲置状态，多线程可以在等待数据时切去执行其他任务；
>
> - **提高应用响应速度**：在 GUI 应用或 web 服务中，将耗时任务放入后台线程执行，主线程可以继续响应用户的点击或请求；

要理解多线程，首先需要区分 **进程（Process）** 和 **线程（Thread）**：

- **进程**：操作系统进行资源分配和调度的基本单元（如打开的浏览器或音乐播放器），每个进程拥有独立的内存空间；
- **线程**：进程内部的独立执行路径，是 CPU 调度的最小单位，**同一个进程内的多个线程** 会共享该进程的内存资源；



## 创建线程

### 继承 Thread 类

继承 Thread 类，并重写 `run()` 方法，调用 `start()` 启动线程。

```java {9}
public static void main(String[] args) {
  MyThread myThread1 = new MyThread();
  myThread1.start(); // 当前线程名称：Thread-0

  MyThread myThread2 = new MyThread();
  myThread2.start(); // 当前线程名称：Thread-1
}

public class MyThread extends Thread {
  @Override
  public void run() {
    String name = Thread.currentThread().getName();
    System.out.println("当前线程名称：" + name);
  }
}
```



### 实现 Runnable 接口

解耦任务与线程本身，避免了 Java 单继承的限制，推荐写法。

```java {6}
public static void main(String[] args) {
  Thread thread1 = new Thread(new MyRunnable());
  thread1.start(); // 当前线程名称：Thread-0
}

public class MyRunnable implements Runnable{
  @Override
  public void run() {
    String name = Thread.currentThread().getName();
    System.out.println("当前线程名称：" + name);
  }
}
```



### 实现 Callable 接口

与 Runnable 不同，Callable 允许线程 **带返回值** 并抛出受检异常。

```java {11,15}
public static void main(String[] args) throws Exception {
  Callable<Integer> task = () -> {
    int sum = 0;
    for (int i = 0; i < 100; i++) {
      sum += i;
    }
    return sum;
  };

  // 使用 FutureTask 创建任务载体
  FutureTask<Integer> futureTask = new FutureTask<>(task);
  new Thread(futureTask).start();

  // get()会阻塞直到获取线程计算的结果
  Integer result = futureTask.get();
  System.out.println("计算结果：" + result); // 计算结果：4950
}
```

::: info 关键解释

- task 是一个实现了 `Callable<Integer>` 接口的对象。它里面包含了你要在后台执行的具体逻辑，并且会返回一个 Integet 类型的结果；
- `FutureTask` 它是一个“桥梁”兼“容器”：
  - 充当桥梁：因为 Thread 类只认识 Runnable 接口，不认识 Callable。而 FutureTask 实现了 Runnable 接口，因此它可以被传递给 Thread；
  - 充当容器：它同时实现了 `Future` 接口，用来存储后台线程执行完 task 后返回的结果，或者捕获执行中抛出的异常；


:::
