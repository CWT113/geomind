# 数据类型

## 基本数据类型

Java 内置了 **8** 种基本数据类型，用于存储简单值。

| 数据类型 | 大小  | 取值范围 | 默认值 |
| :------: | :---: | :------: | :----: |
|   byte   | 1 字节 | $-128 \sim 127$ | 0 |
|  short   | 2 字节 | $-32768 \sim 32767$ | 0 |
|   int    | 4 字节 | $-2^{31} \sim 2^{31}-1$ | 0 |
|   long   | 8 字节 | $-2^{63} \sim 2^{63}-1$ | 0L |
|  float   | 4 字节 | 约 $±3.4 × 10^{38}$ | 0.0f |
|  double  | 8 字节 | 约 $±1.7 × 10^{308}$ | 0.0d |
|   char   | 2 字节 | - | \u0000 |
| boolean  | 1 字节 | $true / false$ | false |



## 引用数据类型

除了基本类型之外，Java 中其他的所有类型都属于引用类型。

|     引用类型      |        示例         | 描述                                            |
| :---------------: | :-----------------: | :---------------------------------------------- |
|    类（Class）    | `String`、`Scanner` | 最常见的引用类型，通过 `class` 定义             |
| 接口（Interface） | `List`、`Runnable`  | 通过 `interface` 定义，可以引用实现该接口的对象 |
|   数组（Array）   | `int[]`、`String[]` | 数组本身也是对象，属于引用类型                  |
|   枚举（Enum）    |     `DayOfWeek`     | 使用 `enum` 定义的特殊类                        |
| 注解（Annotaion） |     `@Override`     | 使用 `@interface` 定义的特殊接口                |



## 类型转换

### 自动类型转换

自动类型转换（也称隐式类型转换）是指 Java 编译器自动将一种基本数据类型转换为另一种基本数据类型的过程。

Java中数值类型的自动转换大小顺序如下：

$$
byte → short → int → long → float → double
$$

> [!NOTE] 转换规则
>
> - 转换过程中可能导致溢出或精度损失；
> - 在把大容量的类型转换为小容量的类型时，必须使用强制类型转换；
> - 不能对 boolean 类型进行类型转换，即 boolean 类型不能参与运算；
> - 特殊情况：如果两个操作数都是 byte、short 或 char，在计算时会被自动提升为 int；

```java {12}
void main() {
  // 小类型赋值给大类型，发生自动类型转换
  byte b = 1;
  short s = b;
  int i = s;
  float f = i;
  double d = f;

  byte b1 = 1;
  byte b2 = 2;
  // 两个 byte 类型运算时，必须使用 int 接收
  int res = b1 + b2;
}
```



### 强制类型转换

强制类型转换（也称显式类型转换）是指把大容量的类型强行塞进小容量的类型中。

> [!NOTE] 转换规则
>
> - 转换过程中可能导致溢出或精度损失；
> - 在浮点数转整数时，并不是四舍五入，而是直接将小数点后的数字截断；
> - 如果大类型数据值超出了小类型数据的最大表示范围，此时强转会导致数据溢出，得到错误的转换值；

::: code-group

```java [精度丢失]
void main() {
	double d = 3.1415;
	int i = (int) d;
	System.out.println(d); // 3.1415
	System.out.println(i); // 3
}
```

```java [数据溢出]
void main() {
  int i = 130;
  byte b = (byte) i; // byte的取值范围是 -128 ~ 127
  System.out.println(b); // -126
}
```

:::



## 常量

常量（Constant）是指在程序运行过程中，其值一旦被设定就不能再被改变的变量。

在 Java 中，使用 `final` 关键字来声明一个常量。为了让常量在整个类中都能使用，通常还会配合 `static` 关键字一起使用。

> [!NOTE] 命名规范
>
> - **字母全部大写**：常量中所有字母都必须大写；
> - **下划线分割**：如果有多个单词时，用下划线 `_` 连接；

```java
void main() {
  // 局部常量
  final double PI = 3.1415926;
}

class AppConfig {
  // 全局常量
  public static final double PI = 3.1415926;

  public static final String APP_NAME = "Java";
}
```
