# 数据类型

## 基本数据类型

Java 内置了 **8** 种基本数据类型，用于存储简单值。

| 数据类型 | 大小  | 取值范围 | 默认值 |
| :------: | :---: | :------: | :----: |
|   byte   | 1 字节 | $-128 \sim 127$ | 0 |
|  short   | 2 字节 | $-32768 \sim 32767$ | 0 |
|   int    | 4 字节 | $-2^{31} \sim 2^{31}-1$ | 0 |
|   long   | 8 字节 | $-2^{63} \sim 2^{63}-1$ | 0L |
|  float   | 4 字节 | 约 $±3.4 × 10^{38}$ | 0.0f |
|  double  | 8 字节 | 约 $±1.7 × 10^{308}$ | 0.0d |
|   char   | 2 字节 | - | \u0000 |
| boolean  | 1 字节 | $true / false$ | false |

## 引用数据类型

除了基本类型之外，Java中其他的所有类型都属于引用类型。

|     引用类型      |        示例         | 描述                                            |
| :---------------: | :-----------------: | :---------------------------------------------- |
|    类（Class）    | `String`、`Scanner` | 最常见的引用类型，通过 `class` 定义             |
| 接口（Interface） | `List`、`Runnable`  | 通过 `interface` 定义，可以引用实现该接口的对象 |
|   数组（Array）   | `int[]`、`String[]` | 数组本身也是对象，属于引用类型                  |
|   枚举（Enum）    |     `DayOfWeek`     | 使用 `enum` 定义的特殊类                        |
| 注解（Annotaion） |     `@Override`     | 使用 `@interface` 定义的特殊接口                |
