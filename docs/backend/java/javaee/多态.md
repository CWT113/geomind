# 多态

多态是同一个方法，在不同的对象上具有不同的表现形式。

要在 Java 中实现多态，必须同时满足 3 个必要条件：

- **要有继承（或实现）**：必须存在继承关系的父子类，或者实现关系的接口和实现类；
- **要有方法重写（Override）**：子类必须重写父类的方法，这样不同的子类才能有不同的表现；
- **父类引用指向子类对象（向上转型）**：这是多态的核心写法，用父类接受子类；



> [!NOTE] 多态中的成员访问特点
>
> 在使用多态 `Animal dog = new Dog();` 时，需要注意一个细节：
>
> - **成员方法**：**编译看左边**（父类必须有这个方法，否则报错），**运行看右边**（实际上执行的是子类重写后的方法）；
> - **成员变量**：编译和运行都看左边（多态不能改变变量的属性，访问的依然是父类的变量）；



## 基础使用

::: code-group

```java {7,14} [Animal]
class Animal {
  public void makeSound() {
    System.out.println("动物发出声音");
  }
}

class Dog extends Animal {
  @Override
  public void makeSound() {
    System.out.println("小狗：汪汪汪");
  }
}

class Cat extends Animal {
  @Override
  public void makeSound() {
    System.out.println("小猫：喵喵喵");
  }
}
```

```java [main]
void main() {
  // 多态的体现：父类引用指向子类对象
  Animal dog = new Dog();
  Animal cat = new Cat();
  // 调用同一个方法，但是得到不同的结果
  dog.makeSound();
  cat.makeSound();
}
```

:::



## 多态参数

利用多态，可以把 **方法的参数写为父类**，然后调用的时候传入子类对象。

::: code-group

```java {23} [PetHospital]
class Animal {
  public void makeSound() {
    System.out.println("动物发出声音");
  }
}

class Dog extends Animal {
  @Override
  public void makeSound() {
    System.out.println("小狗：汪汪汪");
  }
}

class Cat extends Animal {
  @Override
  public void makeSound() {
    System.out.println("小猫：喵喵喵");
  }
}

class PetHospital {
  // 参数是父类 Animal，传入的时候用子类，这就是多态
  public void feed(Animal animal) {
    animal.makeSound();
  }
}
```

```java [main]
void main() {
  Animal dog = new Dog();
  Animal cat = new Cat();

  PetHospital petHospital = new PetHospital();
  petHospital.feed(dog);
  petHospital.feed(cat);
}
```

:::
