# 数组

数组用于存储固定大小的 **同类型元素**。



## 创建数组

Java 使用 `new` 操作符来创建数组，语法如下：

```java 
void main() {
  // 动态声明，显式指定数组大小
  double[] list = new double[3];
  list[0] = 1;
  list[1] = 2;
  list[2] = 3;

  // 静态声明
  double[] list1 = {1, 2, 3};
}
```



## 遍历数组

遍历数组有两种方式：`for` 循环和 `for each` 循环。

::: code-group

```java {3} [for循环]
void main() {
  int[] list = {1,2,3,4};
  for (int i = 0; i < list.length; i++) {
    // 通过索引 i 获取元素
    System.out.println(list[i]);
  }
}
```

```java {3} [for each循环]
void main() {
  int[] list = {1,2,3,4};
  for (int element : list) {
    // element 就是数组的每一个值
    System.out.println(element);
  }
}
```

:::



## 数组排序

常用的数组排序算法有冒泡排序、插入排序和快速排序等。

::: code-group

```java [冒泡排序]
void main() {
  int[] list = {28, 12, 5, 10, 8, 21, 3, 32};
  for (int i = 0; i < list.length - 1; i++) {
    for (int j = 0; j < list.length - i - 1; j++) {
      if (list[j] > list[j + 1]) {
        int temp = list[j];
        list[j] = list[j + 1];
        list[j + 1] = temp;
      }
    }
  }
  System.out.println(Arrays.toString(list));
}
```

```java {4} [Arrays.sort排序]
void main() {
  int[] list = {28, 12, 5, 10, 8, 21, 3, 32};
  // 会修改数组本身
  Arrays.sort(list);
  System.out.println(Arrays.toString(list));
}
```

:::



## 多维数组

多维数组可以看作是 **数组的数组**，比如二维数组本质是一个特殊的一维数组，只是每一个元素都是一个一维数组。

```java
void main() {
  // 声明一个3行4列的二维数组
  String[][] strs = new String[2][2];
  // 定义2行
  strs[0] = new String[2];
  strs[1] = new String[2];
  // 定义第1行的2列
  strs[0][0] = "0-0";
  strs[0][1] = "0-1";
  // 定义第2行的2列
  strs[1][0] = "1-0";
  strs[1][1] = "1-1";
  System.out.println(Arrays.deepToString(strs));

  // 或者静态声明
  String[][] strs = {
    {"0-0", "0-1"},
    {"1-0", "1-1"}
  };
  System.out.println(Arrays.deepToString(strs));
}
```
