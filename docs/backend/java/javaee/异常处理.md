# 异常处理

异常处理（Execption Handling）是一种用于 **处理程序运行期间可能出现的错误或异常** 情况。

如果没有异常处理，程序在遇到错误时会直接崩溃并停止运行。而异常处理，我们可以捕获这些错误，并给出友好的提示，让程序继续稳定的运行下去。



## 关键字

异常处理主要依赖以下 5 个核心关键字：

| 关键字  | 描述                                                    |
| :-----: | ------------------------------------------------------- |
|   try   | 用于包裹可能发生异常的代码块                            |
|  catch  | 用于捕获 try 块中发生的异常，并在内部编写处理错误的代码 |
| finally | 无论是否发生异常，块中的代码总会执行                    |
|  throw  | 用于在代码中手动抛出一个具体的异常                      |
| throws  | 用于在方法签名上声明该方法可抛出的异常                  |

```java
public static void main(String[] args) {
  try {
    int result = 10 / 0; // [!code --]
  } catch (ArithmeticException e) {
    System.out.println("错误：不能把0作为除数！");
  } finally {
    System.out.println("无论是否报错，都会被执行！");
  }
}
```



## Exception 类

Java 中所有异常都属于对象，他们都源自一个共同的父类：`Throwable`。

`Throwable` 下面有两个主要的子类：

- **Error（错误）**：通常是严重的系统级别错误（如内存溢出 `OutOfMemoryError`）这类错误程序员无法通过代码解决，程序会直接奔溃；
- **Exception（异常）**：程序本身可以处理的情况，也是由于代码不正确导致的异常；
  - **运行时异常（Runtime Exception）**：编译器不会强制要求处理，通常是由于代码逻辑漏洞引起的，如 `NullPointerException` 等；
  - **受检异常（Checked Exception）**：编译器在编译时会强制要求必须处理，否则代码无法通过编译，如 `IOException` 等；

<img src="https://www.runoob.com/wp-content/uploads/2013/12/exception-hierarchy.png" alt="Exception" style="display:block;margin:0 auto;"/>

常见的运行时异常：

|           运行时异常            | 描述                                                 |
| :-----------------------------: | ---------------------------------------------------- |
|       ArithmeticException       | 运算异常                                             |
|      NullPointerException       | 空指针异常                                           |
|    IllegalArgumentException     | 向方法传递不合法参数                                 |
|    IndexOutOfBoundsException    | 索引超出范围时的异常                                 |
|  UnsupportedOperationException  | 不支持的操作                                         |
| ArrayIndexOutOfBoundsException  | 用非法索引访问数组时的异常                           |
| StringIndexOutOfBoundsException | 由 String 方法抛出，表示索引为负、或超出字符串的大小 |

常见的受检异常：

|          受检异常          | 描述                                                |
| :------------------------: | --------------------------------------------------- |
|   ClassNotFoundException   | 找不到类抛出的异常                                  |
|   IllegalAccessException   | 拒绝访问一个类时的异常                              |
| CloneNotSupportedException | 当克隆对象时，该对象没有实现 Cloneable 接口时的异常 |
|    NoSuchFieldException    | 请求的变量不存在                                    |
|   NoSuchMethodException    | 请求的方法不存在                                    |



## 异常方法

下面的列表是 Throwable 类的主要方法：

|       方法        | 描述                 |
| :---------------: | -------------------- |
|   getMessage()    | 获取异常的详细信息   |
|    getCause()     | 获取发生异常的原因   |
|    toString()     | 将异常信息转为字符串 |
| printStackTrace() | 将异常输出到控制台   |

```java {4,5,6}
public static void main(String[] args) {
  try {
    int result = 10 / 0;
  } catch (ArithmeticException e) {
    System.out.println(e.getMessage());
    e.printStackTrace();
  } finally {
  }
}
```



## 多重捕获块

一个 try 块后面跟随多个 catch 块的情况就叫多重捕获。

::: code-group

```java [多重catch] {7,9}
public static void main(String[] args) {
  try {
    int[] numbers = {1, 2, 3};
    int element = numbers[4]; // 数组索引越界

    int result = 10 / 0; // 分母为0
  } catch (ArithmeticException e) {
    e.printStackTrace();
  } catch (ArrayIndexOutOfBoundsException e) {
    e.printStackTrace();
  } finally {
  }
}
```

```java [多重catch合并] {7}
public static void main(String[] args) {
  try {
    int[] numbers = {1, 2, 3};
    int element = numbers[4];

    int result = 10 / 0;
  } catch (ArithmeticException | ArrayIndexOutOfBoundsException e) {
    e.printStackTrace();
  } finally {
  }
}
```

:::

> [!WARNING] 注意
>
> 当在一个 catch 中使用 `|` 合并异常时，这些异常类之间不能有继承关系。如果真有继承关系，直接捕获父类异常即可，合并编写属于代码冗余。
>
> ```java
> // 错误示例：因为 NullPointerException 本身就是 RuntimeException 的子类
> catch (NullPointerException | RuntimeException e) { 
>   // 编译失败！
> }
> ```
