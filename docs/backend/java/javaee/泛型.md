# 泛型

泛型是 JDK5 中引入的新特性，它允许编写代码时使用类型参数，从而创建真正通用的组件。简单来说，就是把 “类型” 当作参数来传递。



## 为什么需要泛型？

没有泛型之前，集合类存储的是 Object 类型，存在两个痛点：

1. **类型不安全**：可以往集合中同时放 String、Integer、Boolean 等，编译器不报错，但是在运行时强制转换会奔溃；
2. **强制转型繁琐**：从集合中拿出的元素无法确定具体的类型；

泛型解决了这两个问题，让编译时类型检查成为可能。

```java
public static void main(String[] args) {
  ArrayList<Object> list = new ArrayList<>();
  list.add("hello");
  list.add(1);
  list.add(true);
  Object first = list.get(0); // 无法确定具体的类型 // [!code --]
}

public static void main(String[] args) {
  ArrayList<String> list = new ArrayList<>(); // [!code ++]
  list.add("hello");
  // list.add(1);
  // list.add(true);
  String first = list.get(0); // 集合内部所以数据都是 String 类型 // [!code ++]
}
```



## 泛型方法

泛型方法可以在调用时接收不同类型的参数，并根据参数类型，执行对应的方法。

> [!NOTE] 定义泛型方法的规则
>
> 泛型方法的类型参数只能是引用类型，不能是原始类型（如 int、double 等）。

泛型标记符：

| 标记符 | 描述                              |
| :----: | --------------------------------- |
|   E    | 常在集合中使用，表示 Element 元素 |
|   T    | 常在类中使用，表示 Type 类型      |
|   K    | 常在键值对中使用，表示 Key 键     |
|   V    | 常在键值对中使用，表示 Value 值   |
|   ?    | 表示不确定的 java 类型            |

```java {12}
public static void main(String[] args) {
  String[] strings = {"1", "2", "3", "4"};
  printArray(strings);

  Double[] doubles = {1.0, 2.0, 3.0, 4.0};
  printArray(doubles);

  Boolean[] booleans = {true, false, true, true};
  printArray(booleans);
}

public static <E> void printArray(E[] array) {
  for (E element : array) {
    System.out.print(element + " ");
  }
  System.out.println();
}
```
