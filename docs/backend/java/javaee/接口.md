# 接口

在 Java 中，接口是一种抽象类型，它是一个 **完全抽象的类**。可以把接口想象为一个 插座标准，无论生产插座的厂商是谁，只要符合“两孔”或“三孔”的接口标准，则任何符合该标准的电器都能插上去使用。

在 Java 中，接口使用 `interface` 关键字来声明 ，它里面通常包含：

- **抽象方法**：没有方法体，由实现类去具体实现，默认是 `public abstract` 修饰的；
- **常量**：默认是 `public static final` 修饰的；
- 自 Java8 起，接口也可以包含 **默认方法**（`default`）和 **静态方法**（`static`）； 



## 定义接口

```java
interface Person {
  // 常量，内部默认使用 public static final 修饰
  Integer MAX_AGE = 120;

  // 抽象方法
  void run();

  // 抽象方法
  String getName();
}

class Student implements Person {
  private String name;

  public Student(String name) {
    this.name = name;
  }

  @Override
  public void run() {
    System.out.println("Student " + this.name + " is running");
  }

  @Override
  public String getName() {
    return this.name;
  }
}
```



## 接口继承

一个接口可以继承自另一个接口，它相当于拓展了接口的内部方法。

::: code-group

```java [继承单个接口] {6}
interface Hello {
  void sayHello();
}

// Person 接口现在拥有了 3 个抽象方法签名
interface Person extends Hello {
  void run();

  String getName();
}
```

```java [继承多个接口] {10}
interface Hello {
  void sayHello();
}

interface World {
  void sayWorld();
}

// Person 接口现在拥有了 4 个抽象方法签名
interface Person extends Hello, World {
  void run();

  String getName();
}
```

:::



## default 方法

在接口中，`default` 修饰的方法可以拥有方法体，并且实现类无需重写该方法。

```java {5-7}
interface Person {
  String getName();

  // default方法拥有了方法体，因此实现类可以选择不实现该方法
  default void run() {
    System.out.println(getName() + " is running");
  };
}

class Student implements Person {
  private String name;

  public Student(String name) {
    this.name = name;
  }

  @Override
  public String getName() {
    return this.name;
  }
}
```
