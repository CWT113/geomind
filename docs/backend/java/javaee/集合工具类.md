# 集合工具类

## Collections 工具类

Collections 工具类主要用于 **操作 Collection 及其子类和 Map**。

|      方法      | 描述                                 |
| :------------: | ------------------------------------ |
|     sort()     | 集合排序                             |
|   reverse()    | 反转集合                             |
|   shuffle()    | 随机打乱集合                         |
| binarySearch() | 二分查找指定元素，返回索引           |
| max() / min()  | 查找集合中最大值/最小值              |
|  replaceAll()  | 将列表中的旧值替换为新值             |
|  emptyList()   | 返回空的、不可变的集合对象（更轻量） |
|     fill()     | 用指定元素填充 List 中的所有位置     |

```java {5,9,13,17,21,25,29,32}
public static void main(String[] args) {
  List<Integer> list = Arrays.asList(3, 1, 4, 2, 5);

  // 排序
  Collections.sort(list);
  System.out.println("排序后：" + list);

  // 反转
  Collections.reverse(list);
  System.out.println("反转后：" + list);

  // 随机打乱
  Collections.shuffle(list);
  System.out.println("随机打乱后：" + list);

  // 二分查找（使用前必须对集合先排序）
  int index = Collections.binarySearch(list, 2);
  System.out.println("元素2的索引" + index);

  // 获取最大值和最小值
  System.out.println("最大值：" + Collections.max(list));
  System.out.println("最小值：" + Collections.min(list));

  // 替换元素
  Collections.replaceAll(list, 1, 10);
  System.out.println("替换1为10后：" + list);

  // 返回空集合（比 new ArrayList() 更加轻量）
  List<Object> emptyList = Collections.emptyList();

  // 填充集合
  List<String> list = Arrays.asList("a", "b", "c");
  Collections.fill(list, "AA");
  System.out.println(list); // [AA, AA, AA]
}
```



## Arrays 工具类

Arrays 工具类主要用来 **操作数组**（如排序、搜索等）。

|      方法      | 描述                                                   |
| :------------: | ------------------------------------------------------ |
|    asList()    | 将数组转换为固定大小的 List 集合                       |
|     sort()     | 对数组元素进行自然升序排序                             |
| binarySearch() | 使用二分查找算法检索元素的索引（数组必须先升序排序）   |
|     fill()     | 用指定的值填充整个数组                                 |
|    copyOf()    | 复制指定的数组，截断或用默认值填充                     |
| copyOfRange()  | 复制指定范围内的数组元素（左闭右开）                   |
|   toString()   | 将一维数组的内容打印为字符串格式                       |
|    equals()    | 比较两个一维数组的内容和顺序是否完全一致               |
|    stream()    | 将数组转换为 Stream 流，方便结合 Lambda 进行过滤等操作 |

> [!CAUTION] 注意
>
> `asList()` 方法转换后的集合长度是固定的，不能进行添加和移除操作。如果需要长度可变，需用 `new ArrayList(Arrays.asList())` 进行包装；

::: code-group

```java [asList] {7}
public static void main(String[] args) {
  List<String> list = Arrays.asList("a", "b", "c");
  list.add("d"); // 报错：list的长度是固定的，不允许修改！ // [!code --]
  System.out.println(list);

  // 变为可变的集合
  ArrayList<String> modifiableList = new ArrayList<>(Arrays.asList("a", "b", "c"));
  modifiableList.add("d");
  System.out.println(modifiableList); // [a, b, c, d]
}
```

```java [其他方法] {5,9,14,19,24,29,35,38}
public static void main(String[] args) {
  int[] numbers = {5, 2, 8, 1, 4};

  // 升序排序
  Arrays.sort(numbers);
  System.out.println("排序后：" + Arrays.toString(numbers)); // [1, 2, 4, 5, 8]

  // 二分查找
  int index = Arrays.binarySearch(numbers, 4);
  System.out.println("元素4的索引：" + index); // 2

  // 对象数组自定义排序（倒序）
  Integer[] scores = {80, 95, 60, 75};
  Arrays.sort(scores, Collections.reverseOrder());
  System.out.println("倒序排序：" + Arrays.toString(scores)); // [95, 80, 75, 60]

  // 数组填充
  int[] arr = new int[5];
  Arrays.fill(arr, 100);
  System.out.println("填充数组后：" + Arrays.toString(arr)); // [100, 100, 100, 100, 100]

  // 赋值并扩容
  int[] orig = {1, 2, 3};
  int[] copied = Arrays.copyOf(orig, 5);
  System.out.println("扩充数组后：" + Arrays.toString(copied)); // [1, 2, 3, 0, 0]

  // 截取指定范围
  int[] nums = {1, 2, 3, 4, 5};
  int[] range = Arrays.copyOfRange(nums, 1, 4);
  System.out.println("范围复制: " + Arrays.toString(range)); // [2, 3, 4]

  // 比较数组内容
  int[] a1 = {1, 2, 3};
  int[] a2 = {4, 5, 6};
  System.out.println("数组内容是否相同：" + Arrays.equals(a1, a2)); // false

  // 转换为 Stream 进行计算
  int sum = Arrays.stream(a1).sum();
  System.out.println("数组元素和: " + sum); // 6
}
```
