## Collections 工具类

Collections 工具类主要用于操作 Collection 及其子类和 Map。



### 排序/反转

|   方法    | 描述         |
| :-------: | ------------ |
|  sort()   | 集合排序     |
| reverse() | 反转集合     |
| shuffle() | 随机打乱集合 |
