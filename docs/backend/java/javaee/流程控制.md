# 流程控制

## if 条件

`if` 条件语句根据真（true）或假（false）来决定进入那段分支执行代码。

```java
int score = 85;

if (score >= 90) {
  System.out.println("优秀");
} else if (score >= 80) {
  System.out.println("良好");
} else if (score >= 60) {
  System.out.println("及格");
} else {
  System.out.println("不及格");
}
```



## switch 条件

当判断条件是具体的值（而不是一个范围），且分支很多时，用 `if` 会显得比较臃肿，这时候就适合使用 `switch` 条件。

> [!WARNING] 注意
>
> 每个 `case` 后通常都要写 `break`，否则程序会发送 `case穿透`，即继续执行下一个 `case` 代码，直到遇到 `break` 结束。

```java {7,8}
int weekday = 3;

switch (weekday) {
  case 1:
    System.out.println("周一：元气满满");
    break;
  case 2: // case穿透
  case 3:
    System.out.println("周二周三：要努力工作呀");
    break;
  default:
    System.out.println("放假嗨皮");
    break;
}
```



## while 循环

`while` 循环是让程序执行重复的逻辑。

```java
int count = 1;

while (count <= 3) {
  System.out.println("这是第 " + count + " 次求婚。");
  count++;
}
```



## do while 循环

`do while` 循环的逻辑是 **先执行一次，然后再进入判断**。无论条件真假，它 **至少会执行一次**。

```java
int count = 5;

do {
  System.out.println("不管怎样，先跑一次代码再说！");
  count++;
} while (count < 3);
```



## for 循环

`for` 循环是最常用的循环，它把 “初始化”、“条件判断”、“变量更新”三个部分完美放在一起，结构非常紧凑，特别适合 **已知循环次数** 的场景。

```java
for (int i = 1; i <= 5; i++) {
  System.out.print(i + " ");
}
```



## break 和 continue

在循环执行的过程中，如果我们想中途改变主意，就需要用到这两个“控制终结者”。

- `break`：彻底 **结束整个循环**，跳出循环体；
- `continue`：**跳出本次循环**，进入下一次循环；

::: code-group

```java [break] {3}
for (int i = 1; i <= 5; i++) {
  if (i == 3) {
    break; // 当 i 等于 3 时，直接退出，不再进行循环
  }
  System.out.print(i + " ");
}
```

```java [continue] {3}
for (int i = 1; i <= 5; i++) {
  if (i == 3) {
    continue; // 当 i 等于 3 时，跳过这次，继续打印 4 和 5
  }
  System.out.print(i + " ");
}
```

:::
