# 包装类

## Number 类

一般情况下，当需要使用数字的时候，可以使用内置的基本数据类型，如 byte、int、double 等。

但是在开发过程中，**基本数据类型并不具备对象的特质**（如没有方法、没有属性、无法处理 null 状态、不能搭配泛型使用等），所以在这种情况下，推荐使用 Java 提供的包装类对象。

Java 中给所有的基本数据类型都提供了对应的包装类：

| 基本数据类型 |  包装类   |        描述        |
| :----------: | :-------: | :----------------: |
|     byte     |   Byte    |    字节型包装类    |
|    short     |   Short   |    短整型包装类    |
|     int      |  Integer  |     整型包装类     |
|     long     |   Long    |    长整型包装类    |
|    float     |   Float   | 单精度浮点型包装类 |
|    double    |  Double   | 双精度浮点型包装类 |
|     char     | Character |    字符型包装类    |
|   boolean    |  Boolean  |    布尔型包装类    |

```java [基本类型转换]
public static void main(String[] args) {
  Number num = 123.45; // 实际上是 Double 类型

  System.out.println(num instanceof Double); // true
  // 转为 int 基本类型
  int i = num.intValue();
  // 转为 long 基本类型
  long l = num.longValue();
  // 转为 float 基本类型
  float f = num.floatValue();
  // 转为 double 基本类型
  double d = num.doubleValue();
}
```



### 装箱与拆箱

装箱和拆箱是基本数据类型和对应包装类之间自动转换的机制。

- **装箱**：将 **基本数据类型** 自动转为 **包装类对象** 的过程；
- **拆箱**：将 **包装类对象** 自动转为 **基本数据类型** 的过程；

```java [装箱与拆箱]
public static void main(String[] args) {
  // 自动装箱（基本数据类型给包装类）
  Integer num = 100; // 编译器转换为：Integer.valueOf(100)
  
  // 自动拆箱（包装类给基本数据类型）
  int num1 = num; // 编译器转化为：num.intValue();
}
```

> [!CAUTION] 空指针异常
>
> 自动拆箱时，如果包装类对象为 null，需要额外注意空指针异常报错。
>
> ```java
> public static void main(String[] args) {
>   Integer num = null;
>   int i = num; // 报错：底层执行的是 num.intValue()，很显然会报 NullPointerException 空指针异常
> }
> ```

除了直接赋值之外，以下场景也会自动触发装箱或拆箱：

::: code-group

```java [泛型集合] {4}
public static void main(String[] args) {
  ArrayList<Integer> list = new ArrayList<>();
  list.add(1);
  list.add(2); // 自动装箱，相当于 list.add(Integer.valueOf(2))
}
```

```java [算数运算] {4}
public static void main(String[] args) {
  Integer a = 10;
  Integer b = 20;
  int sum = a + b; // 自动拆箱：a.intValue() + b.intValue()
}
```

```java [方法传参] {6,3}
public static void main(String[] args) {
  int x = 10;
  printNum(x); // 自动装箱：把 int 类型传给 Integer 类型
}

public static void printNum(Integer num) {
  System.out.println(num);
}
```

:::



## Math 类

`Math` 类提供了大量的静态方法，用于执行基本的数学运行。

常见的方法如下：

|      方法      |                描述                 |
| :------------: | :---------------------------------: |
|  Math.abs(x)   |              取绝对值               |
| Math.max(x, y) |              取最大值               |
| Math.min(x, y) |              取最小值               |
|  Math.ceil(x)  |              向上取整               |
| Math.floor(x)  |              向下取整               |
| Math.round(x)  |              四舍五入               |
|  Math.sqrt(x)  |             计算平方根              |
|  Math.cbrt(x)  |             计算立方根              |
| Math.pow(x, y) |          计算 x 的 y 次幂           |
| Math.random()  | 返回 0 ~ 1 直接的随机数（左闭右开） |
|    Math.PI     |            圆周率 $\pi$             |

```java
public static void main(String[] args) {
  // 取绝对值
  System.out.println(Math.abs(-10)); // 10
  // 最大值和最小值
  System.out.println(Math.max(10, 20)); // 20
  System.out.println(Math.min(10, 20)); // 10
  // 向上取整
  System.out.println(Math.ceil(11.3)); // 12.0
  System.out.println(Math.ceil(-11.8)); // -11.0
  // 向下取整
  System.out.println(Math.floor(11.9)); // 11.0
  System.out.println(Math.floor(-11.1)); // -12.0
  // 四舍五入
  System.out.println(Math.round(11.4)); // 11
  System.out.println(Math.round(11.5)); // 12
  // 平方根和立方根
  System.out.println(Math.sqrt(2)); // 1.414
  System.out.println(Math.cbrt(8)); // 2.0
  // 幂
  System.out.println(Math.pow(2, 2)); // 4.0
  System.out.println(Math.pow(3, 3)); // 27.0
  // 随机数
  System.out.println(Math.random());
  System.out.println((int)(Math.random() * 10)); // 0 ~ 9的随机数
  // 公式：(int)(Math.random() * (max - min + 1)) + min;
}
```
