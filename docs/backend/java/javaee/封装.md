# 封装

封装是指把属性和方法绑定在一起，形成一个整体的类，并隐藏对象的内部实现细节，只保留有限的对外接口和外部进行交互。

> [!NOTE] 封装的优势
>
> - **数据安全性与可控性**：外部无法直接修改类内部的数据。所有的修改都必须通过特定的方法，在方法内部可以对数据进行验证；
> - **隐藏实现细节**：外部调用者不需要知道类内部复杂的逻辑是如何运行的，只需要调用即可；
> - **提高代码的可维护性和灵活性**：内部的业务逻辑发生变化，只需要修改对应的公共方法即可；

::: code-group

```java [BankAccount]
class BankAccount {
  private double balance;

  public double getBalance() {
    return this.balance;
  }

  public void setBalance(double amount) {
    if (amount > 0) {
      this.balance += amount;
      System.out.println("成功存入：" + amount + "元");
    } else {
      System.out.println("存入的金额必须大于0！");
    }
  }
}
```

```java [main]
void main() {
  BankAccount bankAccount = new BankAccount();
  // 存入500元
  bankAccount.setBalance(500);
  // 查询余额
  double balance = bankAccount.getBalance();
  System.out.println("当前余额：" + balance);
}
```
