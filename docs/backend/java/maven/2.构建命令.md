# 构建命令

Maven 的构建命令主要围绕其生命周期展开。运行某个阶段的命令时，Maven 会 **自动按顺序执行该阶段之前的所有前置阶段**。

| 命令         | 描述                           | 执行阶段                                                    |
| :----------- | :----------------------------- | ----------------------------------------------------------- |
| mvn clean    | 删除之前构建生成的 target 目录 | 清理上一次编译打包的产物，确保全新构建                      |
| mvn validate | 验证项目所需的信息是否可用     | 检查 `pom.xml` 文件语法格式是否正确，项目的文件目录是否合规 |
| mvn compile  | 编译项目的源代码               | 编译 `src/main/java` 目录下的源码，输出到 `target/classes`  |
| mvn test     | 执行单元测试                   | 运行单元测试框架，如果不通过则构建失败                      |
| mvn package  | 将代码打包成可发布的格式       | 根据 `pom.xml` 中的 `<packaging>` 标签打成最终包            |
| mvn verify   | 检查包的有效性                 | 运行任何继承测试，确保质量标准得到满足                      |
| mvn install  | 将打好的包存入本地仓库         | 供本地其他依赖该模块的项目使用                              |
| mvn site     | 生成项目的文档和站点信息       | 根据项目配置生成包含代码分析、依赖关系等信息的 HTML 站点    |
| mvn deploy   | 将最终的包发布到私服/中央仓库  | 发布给团队其他成员或外部开发者下载使用                      |
