# 模块继承

Maven 中的模块继承是一种配置复用机制，类似于面向对象编程中的类继承。它允许一个子模块的 `pom.xml` 继承父模块的 `pom.xml` 中定义的依赖、插件和配置，从而避免在多个模块中重复编写相同的构建配置。

> [!NOTE] 核心机制
>
> - **父模块配置**：父 `pom.xml` 通常将打包类型设置为 `pom`，并充当一个抽象的配置载体；
> - **子模块声明**：子模块通过 `<parent>` 标签显式声明其父模块坐标及相对路径；

> [!TIP] dependencyManagement 详解
>
> - `<dependencies>`：父 POM 中一旦写了，所有子模块都会无条件引入这些 jar 包，可能导致某些不需要该库的模块变得臃肿；
> - `<dependencyManagement>`：父 POM 中只定义版本规范，不会直接下载或引入任何 jar 包。只有当子模块在自己的 `<dependencies>` 中显式声明了该依赖，这个 jar 包才会被真正引入；

::: code-group

```xml {13-15,24,38} [parent/pom.xml]
<project xmlns="http://maven.apache.org/POM/4.0.0" 
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 
                             http://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>

  <groupId>org.example</groupId>
  <artifactId>app-parent</artifactId>
  <version>1.0-SNAPSHOT</version>
  <packaging>pom</packaging>

  <!-- 父项目聚合子模块 -->
  <modules>
    <module>../app-web</module>
  </modules>

  <properties>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    <lombok.version>1.18.46</lombok.version>
    <spring.version>6.2.19</spring.version>
  </properties>

  <!-- 统一管理依赖版本，所有子模块都会继承该版本 -->
  <dependencyManagement>
    <dependencies>
      <dependency>
        <groupId>org.springframework</groupId>
        <artifactId>spring-context</artifactId>
        <version>${spring.version}</version>
      </dependency>

      <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <version>${lombok.version}</version>
      </dependency>
    </dependencies>
  </dependencyManagement>
</project>

```

```xml {8-12,23-26} [child/pom.xml]
<project xmlns="http://maven.apache.org/POM/4.0.0" 
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 
                             http://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>

  <!-- 指定父模块 -->
  <parent>
    <groupId>org.example</groupId>
    <artifactId>app-parent</artifactId>
    <version>1.0-SNAPSHOT</version>
  </parent>

  <artifactId>app-web</artifactId>
  <packaging>jar</packaging>

  <properties>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
  </properties>

  <dependencies>
    <!-- 依赖继承自父模块，因此不需要指定版本号 -->
    <dependency>
      <groupId>org.springframework</groupId>
      <artifactId>spring-context</artifactId>
    </dependency>

    <dependency>
      <groupId>org.projectlombok</groupId>
      <artifactId>lombok</artifactId>
    </dependency>
  </dependencies>
</project>

```
