# HttpClient

Java 11 引入了全新的 `HttpClient` API，它是对 `HttpURLConnection` 的现代化替代，提供了更强大、更灵活的 HTTP 通信能力。

> [!NOTE] 使用场景
>
> - 支持 HTTP/1、HTTP/2 性能优势的应用；
> - 高并发场景（利用异步特性）；
> - 微服务架构中的服务通信；
> - 需要 WebSocket 支持的实时应用；
> - 替代老旧的第三方 HTTP 客户端库（如 Apache HeepClient）；



核心 API：

|           API            | 描述                   |
| :----------------------: | ---------------------- |
| HttpClient.newBuilder()  | 创建 HttpClient 实例   |
| HttpRequest.newBuilder() | 创建 HttpRequest 实例  |
|    HttpClient.send()     | 发出请求并获取响应对象 |

```java
// 创建 HttpClient 实例
HttpClient client = HttpClient.newBuilder()
  .version(HttpClient.Version.HTTP_2)
  .connectTimeout(Duration.ofSeconds(10))
  .followRedirects(HttpClient.Redirect.NORMAL)
  .build();

// 创建 HttpRequest 实例
HttpRequest request = HttpRequest.newBuilder()
  .uri(URI.create(""))
  .header("Content-Type", "application/json")
  .header("Authorization", "Bearer token")
  .GET() // 或  POST()、PUT()、DELETE()
  .build();
```





## 使用方法

### 同步请求

::: code-group

```java [Main] {9,10}
public static void main(String[] args) throws IOException, InterruptedException {
  HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://jsonplaceholder.typicode.com/todos/1"))
    .header("Content-Type", "application/json")
    .GET()
    .build();

  // 发起同步请求
  HttpResponse<String> response
    = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofString()); // 使用封装的全局 client

  System.out.println("uri：" + response.uri());
  System.out.println("status：" + response.statusCode());
  System.out.println("body：" + response.body());
  System.out.println("headers：" + response.headers());
}
```

### 异步请求

```java {9,10,13,20,22}
public static void main(String[] args) throws IOException, InterruptedException, ExecutionException, TimeoutException {
  HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://jsonplaceholder.typicode.com/todos/1"))
    .header("Content-Type", "application/json")
    .GET()
    .build();

  // 发起异步请求
  CompletableFuture<HttpResponse<String>> future
    = ApiClient.CLIENT.sendAsync(request, HttpResponse.BodyHandlers.ofString());

  future.thenApply(HttpResponse::body)
    .thenAccept(System.out::println) // 此处可处理请求结果
    .exceptionally(e -> {
      System.out.println("Error：" + e.getMessage());
      return null;
    }).join();

  // 也可先阻塞主线程，等接口请求完毕
  // HttpResponse<String> response = future.join();
  // 或者等待请求完成
  HttpResponse<String> response = future.get(10, TimeUnit.SECONDS);

  System.out.println("uri：" + response.uri());
  System.out.println("status：" + response.statusCode());
  System.out.println("body：" + response.body());
  System.out.println("headers：" + response.headers());
}
```



### POST 请求发送 JSON

```java {8,12,13}
public static void main(String[] args) throws IOException, InterruptedException {
  String body = "{\"id\":\"10086\", \"name\": \"Leo\", \"age\": \"25\"}";

  // 创建 HttpRequest 实例
  HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("http://localhost:8001/user"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(body))
    .build();

  // 发起请求
  HttpResponse<String> response
    = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofString());

  System.out.println("status：" + response.statusCode());
  System.out.println("body：" + response.body());
}
```



### 处理不同的响应类型

```java {17,18,21,22,25,26}
public static void main(String[] args) throws IOException, InterruptedException {
  // 创建 HttpRequest 实例
  HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("http://localhost:8001/user"))
    .header("Content-Type", "application/json")
    .GET()
    .build();

  // JSON 格式响应
  HttpResponse<String> response1
    = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofString());

  // 文件下载（把结果输出到文件中）
  HttpResponse<Path> response2
    = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofFile(Paths.get("output.txt")));

  // 字节数组
  HttpResponse<byte[]> response3
    = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofByteArray());
}
```
