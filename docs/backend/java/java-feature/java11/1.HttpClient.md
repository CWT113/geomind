# HttpClient

Java 11 之后原生提供了 `java.net.http` 包，用于创建 `HttpClient` 和 `HttpRequest` 实例。它们都采用了建造者模式（Builder Parttern），你可以方便地对各种参数进行自定义。



## HttpClient 实例

HttpClient 用法发送请求并接收响应，通常建议在应用中复用同一个 HttpClient 实例。

::: code-group

```java [ApiClient]
public class ApiClient {
  /**
   * 创建全局通用的 HttpClient，全局使用一个实例
   */
  public final static HttpClient CLIENT = HttpClient.newBuilder()
    .version(HttpClient.Version.HTTP_2) // 优先使用 HTTP/2
    .connectTimeout(Duration.ofSeconds(20)) // 设置连接超时时间
    .followRedirects(HttpClient.Redirect.NORMAL) // 设置自动重定向策略
    .build();
}
```

:::



## HttpRequest 实例

HttpRequest 用于定义请求的 URL、方法（GET/POST等）、请求头和请求体。

::: code-group

```java [GET请求]
HttpRequest request = HttpRequest.newBuilder()
  .uri(URI.create("https://jsonplaceholder.typicode.com/todos/1"))
  .header("Content-Type", "application/json")
  .header("Authorization", "Bearer tokenxxx")
  .timeout(Duration.ofSeconds(20))
  .GET()
  .build();
```

```java [POST请求]
String body = "{\"title\": \"foo\", \"body\": \"bar\", \"userId\": 1}";

HttpRequest request = HttpRequest.newBuilder()
  .uri(URI.create("https://jsonplaceholder.typicode.com/posts"))
  .header("Content-Type", "application/json;charset=utf-8")
  .POST(HttpRequest.BodyPublishers.ofString(body)) // 传入请求体
  .build();
```

:::



## 使用方法

### 发起 GET 请求

::: code-group

```java [同步请求] {9}
public static void main(String[] args) throws Exception {
  // 创建 HttpRequest 实例
  HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://jsonplaceholder.typicode.com/todos/1"))
    .header("Content-Type", "application/json")
    .GET()
    .build();
  // 发起同步请求
  HttpResponse<String> response = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofString());

  System.out.println("uri：" + response.uri());
  System.out.println("body：" + response.body());
  System.out.println("headers：" + response.headers());
  System.out.println("status：" + response.statusCode());
}
```

```java [异步请求] {9,11,21}
public static void main(String[] args) throws Exception {
  // 创建 HttpRequest 实例
  HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://jsonplaceholder.typicode.com/todos/1"))
    .header("Content-Type", "application/json")
    .GET()
    .build();
  // 发起异步请求，不阻塞主线程，立即返回 CompletableFuture 对象，请求会在后台线程池中继续执行
  CompletableFuture<HttpResponse<String>> future = ApiClient.CLIENT.sendAsync(request, HttpResponse.BodyHandlers.ofString());
  // 等待异步请求完成，处理请求成功和失败的情况
  future.thenApply(HttpResponse::body)
    .thenAccept((result) -> {
      // TODO：此处可以用于处理请求结果！
    })
    .exceptionally((e) -> {
      System.err.println("Error: " + e.getMessage());
      return null;
    })
    .join(); // 阻塞主线程，等待接口请求完毕
  // 获取响应数据
  HttpResponse<String> response = future.get(20, TimeUnit.SECONDS);

  System.out.println("uri：" + response.uri());
  System.out.println("body：" + response.body());
  System.out.println("headers：" + response.headers());
  System.out.println("status：" + response.statusCode());
}
```

### 发起 POST 请求

::: code-group

```java [基础使用] {8,11}
public static void main(String[] args) throws Exception {
  String body = "{\"title\": \"foo\", \"body\": \"bar\", \"userId\": 1}";

  // 创建POST请求
  HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://jsonplaceholder.typicode.com/posts"))
    .header("Content-Type", "application/json;charset=utf-8")
    .POST(HttpRequest.BodyPublishers.ofString(body))
    .build();
  // 发起同步请求
  HttpResponse<String> response = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofString());

  System.out.println("body：" + response.body());
  System.out.println("status：" + response.statusCode());
}
```

```java [多种返回结果] {11,12,15,16,19,20}
public static void main(String[] args) throws Exception {
  String body = "{\"title\": \"foo\", \"body\": \"bar\", \"userId\": 1}";

  // 创建POST请求
  HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://jsonplaceholder.typicode.com/posts"))
    .header("Content-Type", "application/json;charset=utf-8")
    .POST(HttpRequest.BodyPublishers.ofString(body))
    .build();
  // 返回 JSON 格式结果
  HttpResponse<String> response1
    = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofString());

  // 文件下载（把结果输出到文件中）
  HttpResponse<Path> response2
    = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofFile(Paths.get("output.txt")));

  // 字节数组
  HttpResponse<byte[]> response3
    = ApiClient.CLIENT.send(request, HttpResponse.BodyHandlers.ofByteArray());
}
```
