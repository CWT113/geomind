# String 扩展

Java11 为 String 类引入了多项增强功能。如下所示：

|        方法         | 描述                                  |
| :-----------------: | ------------------------------------- |
|    str.repeat(n)    | 将字符串重复 n 次，返回重复后的字符串 |
|    str.isBlank()    | 检查字符串是否为空或只有空格          |
|     str.strip()     | 删除头尾空格                          |
| str.stripLeading()  | 删除头部空格                          |
| str.stripTrailing() | 删除尾部空格                          |
|     str.lines()     | 返回多行字符串的行流                  |

```java
public static void main(String[] args) {
  String s = " abc ";

  System.out.println(s.repeat(2));    // " abc  abc "

  System.out.println(s.isBlank());    // false
  System.out.println("".isBlank());   // true
  System.out.println("  ".isBlank()); // true

  System.out.println(s.strip());         // "abc"
  System.out.println(s.stripLeading());  // "abc "
  System.out.println(s.stripTrailing()); // " abc"

  String str = "this \n is \n a \n multiline \n text";
  Stream<String> lines = str.lines();    // 返回流

  List<String> list = new ArrayList<>();
  lines.forEach(list::add); // 使用流的 forEach 方法
  list.forEach(System.out::println);
}
```
