# 顺序集合

Java21 引入的“顺序集合”（Sequenced Collections）是一套全新的集合接口，它 **统一了集合访问首尾元素和反向遍历的操作方式**。

简单来说，就是为 List、LinkedHashSet、SortedSet 这类有顺序的集合，提供了一套标准、统一的方法，可以更方便的操作第一个和最后一个元素。

新增的三个核心接口如下：

|            接口            | 描述                                                | 主要实现类                           |
|:------------------------:|---------------------------------------------------|---------------------------------|
| `SequencedCollection<E>` | 代表一个有明确顺序的元素序列，它提供了访问、添加和移除首尾元素的标准方法              | ArrayList、LinkedList、Deque      |
|    `SequencedSet<E>`     | 继承了 `SequencedCollection` 和 `Set`，代表一个有序且元素不重复的集合 | LinkedHashSet、SortedSet、TreeSet |
|   `SequencedMap<K,V>`    | 代表一个键值对拥有明确遍历顺序的映射                                | LinkedHashMap、SortedMap、TreeMap |

## SequencedCollection

|      操作       | 描述                                           |
|:-------------:|----------------------------------------------|
|  getFirst()   | 获取第一个元素（集合为空时抛出 `NoSuchElementException` 异常） |
|   getLast()   | 获取最后一个元素                                     |
| addFirst(ele) | 头部添加元素                                       |
| addLast(ele)  | 尾部添加元素                                       |
| removeFirst() | 移除头部元素（集合为空时抛出 `NoSuchElementException` 异常）  |
| removeLast()  | 移除尾部元素                                       |
|  reversed()   | 反转集合，返回的是一个视图，而不是新集合，这意味着修改了原集合，反向视图也会同步变化   |

::: code-group

```java [ArrayList示例]
public static void main(String[] args) {
  // ArrayList 的父类 List 实现了 SequencedCollection
  ArrayList<String> list = new ArrayList<>();
  list.add("a");
  list.add("b");
  list.add("c");

  // 头部或尾部添加元素
  list.addFirst("First");
  list.addLast("Last");
  System.out.println(list); // [First, a, b, c, Last]

  // 获取头部或尾部元素
  System.out.println(list.getFirst()); // First
  System.out.println(list.getLast()); // Last

  // 移除头部或尾部元素
  list.removeFirst();
  list.removeLast();

  // 反转集合
  System.out.println(list.reversed()); // [c, b, a]
}
```

```java [LinkedHashSet示例]
public static void main(String[] args) {
  // LinkedHashSet 实现了 SequencedSet 接口，而 SequencedSet 接口又继承了 SequencedCollection 接口
  LinkedHashSet<String> hashSet = new LinkedHashSet<>();
  hashSet.add("a");
  hashSet.add("b");
  hashSet.add("c");

  // 头部或尾部添加元素
  hashSet.addFirst("First");
  hashSet.addLast("Last");
  System.out.println(hashSet); // [First, a, b, c, Last]

  // 获取头部或尾部元素
  System.out.println(hashSet.getFirst()); // First
  System.out.println(hashSet.getLast()); // Last

  // 移除头部或尾部元素
  hashSet.removeFirst();
  hashSet.removeLast();

  // 反转集合
  System.out.println(hashSet.reversed()); // [c, b, a]
}
```

:::

::: info 提示

`SequencedSet` 的用法和 `SequencedCollection` 基本一致，只是多了一些 `Set` 的方法。

:::

## SequencedMap

|        方法        | 描述      |
|:----------------:|---------|
|   firstEntry()   | 获取头部元素  |
|   lastEntry()    | 获取尾部元素  |
|    putFirst()    | 向头部添加元素 |
|    putLast()     | 向尾部添加元素 |
| pollFirstEntry() | 移除头部元素  |
| pollLastEntry()  | 移除尾部元素  |
|    reversed()    | 反转集合    |

```java
public static void main(String[] args) {
  // LinkedHashMap 实现了 SequencedMap 接口
  LinkedHashMap<String, Integer> hashMap = new LinkedHashMap<>();
  hashMap.put("B", 80);
  hashMap.put("C", 70);
  hashMap.put("D", 60);

  // 获取头部或尾部元素
  System.out.println(hashMap.firstEntry().getValue()); // 80
  System.out.println(hashMap.lastEntry().getValue()); // 60

  // 头部或尾部添加元素
  hashMap.putFirst("A", 90);
  hashMap.putLast("E", 50);
  System.out.println(hashMap); // {A=90, B=80, C=70, D=60, E=50}

  // 从头部或尾部移除元素
  hashMap.pollFirstEntry();
  hashMap.pollLastEntry();
  System.out.println(hashMap); // {B=80, C=70, D=60}

  // 获取反向视图
  SequencedMap<String, Integer> reversed = hashMap.reversed();
  System.out.println(reversed); // {D=60, C=70, B=80}
}
```
