# 时间日期类

>🔖 **本节前览：** 本节重点讲解 Java8 中新增的全新日期时间 API（`java.time` 包），解决了旧的 `Date` 和 `Calendar` 类的缺陷。

Java8 中重新设计了所有日期时间、日历及时区相关的 API。

> [!NOTE] 优化改进内容
>
> - 新的日期时间 API 是线程安全的，而且任何对实例的变更都会返回一个新的实例来保证原来的实例不变；
> - 新的日期时间 API 提供了大量方法，用于修改日期时间的各个部分，并返回一个新的实例；
> - 在时区方面，新的日期时间 API 引入了 **域（domain）** 的概念；



主要的核心类：

|     类名      | 说明               | 示例                                     |
| :-----------: | :----------------- | :--------------------------------------- |
| LocalDateTime | 日期时间（无时区） | 2026-01-01T14:30:45                      |
|   LocalDate   | 日期（无时区）     | 2026-01-01                               |
|   LocalTime   | 时间（无时区）     | 14:30:45                                 |
| ZonedDateTime | 日期时间（有时区） | 2026-01-01T14:30:45+08:00 [Asia/Shanghai] |
|    Instant    | 时间戳（UTC 时间）  | 1970-01-01T00:00:00Z 开始的秒数          |



## LocalDateTime

### 创建实例

```java {3,7,11,15}
public static void main(String[] args) {
  // 方式一
  LocalDateTime now = LocalDateTime.now();
  System.out.println(now);
  
  // 方式二：自定义日期时间
  LocalDateTime dt1 = LocalDateTime.of(2026, 1, 5, 10, 5, 20);
  System.out.println(dt1);
  
  // 方式三：组合 LocalDate 和 LocalTime
  LocalDateTime dt2 = LocalDateTime.of(LocalDate.now(), LocalTime.now());
  System.out.println(dt2);
  
  // 方式四：字符串日期转换为 LocalDateTime
  LocalDateTime dt3 = LocalDateTime.parse("2026-01-05T10:13:21");
  System.out.println(dt3);
}
```



### 转换与获取

```java {5,9,13-18}
public static void main(String[] args) {
  LocalDateTime now = LocalDateTime.now();

  // 转换为 LocalDate
  LocalDate date = now.toLocalDate();
  System.out.println("当前日期：" + date);
  
  // 转换为 LocalTime
  LocalTime time = now.toLocalTime();
  System.out.println("当前时间：" + time);

  // 获取日期时间具体字段
  System.out.println("当前年：" + now.getYear());
  System.out.println("当前月：" + now.getMonth());
  System.out.println("当前日：" + now.getDayOfMonth());
  System.out.println("当前时：" + now.getHour());
  System.out.println("当前分：" + now.getMinute());
  System.out.println("当前秒：" + now.getSecond());
}
```



### 运算方法

```java {5,9,13}
public static void main(String[] args) {
  LocalDateTime now = LocalDateTime.now();

  // 增加 1年、1月、1天
  LocalDateTime plusDate = now.plusYears(1).plusMonths(1).plusDays(1);
  System.out.println(plusDate);

  // 减少 1年、1月、1天
  LocalDateTime minusDate = now.minusYears(1).minusMonths(1).minusDays(1);
  System.out.println(minusDate);

  // 指定日期为10号，时间为12点
  LocalDateTime withedDate = now.withDayOfMonth(10).withHour(12);
  System.out.println(withedDate);
}
```



### 格式化与解析

```java {8,12}
public static void main(String[] args) {
  LocalDateTime now = LocalDateTime.now();

  String f1 = now.format(DateTimeFormatter.ISO_DATE_TIME);
  System.out.println(f1); // 2026-01-05T11:06:40.1633898

  // 自定义格式化（常用）
  String f2 = now.format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
  System.out.println(f2); // 2026-01-05 11:07:16

  // 自定义解析
  LocalDateTime parsed = LocalDateTime.parse("2026-01-05 11:07:16", DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
  System.out.println(parsed); // 2026-01-05T11:07:16
}
```





### 时间戳转换

```java {5-8,12,16}
public static void main(String[] args) {
  LocalDateTime now = LocalDateTime.now();

  // 方式一
  long epochMilli1 = now
    .atZone(ZoneId.systemDefault()) // 先设置时区，因为 LocalDateTime 本身不带时区
    .toInstant() // 转为绝对时间
    .toEpochMilli(); // 获取 Unix Epoch 标准毫秒数
  System.out.println(epochMilli1);

  // 方式二
  long epochMilli2 = Instant.now().toEpochMilli();
  System.out.println(epochMilli2);

  // 方式三
  long milli3 = System.currentTimeMillis();
  System.out.println(milli3);
}
```



### 计算时间间隔

```java {6,10,16}
public static void main(String[] args) {
  LocalDateTime date1 = LocalDateTime.now();
  LocalDateTime date2 = date1.plusDays(10);

  // 计算两个日期之间的天数
  long between = ChronoUnit.DAYS.between(date1, date2);
  System.out.println(between); // 10

  // 计算两个日期之间的小时数
  Duration between1 = Duration.between(date1, date2);
  System.out.println(between1.toHours()); // 240

  // 日期间隔
  LocalDate date3 = LocalDate.now();
  LocalDate date4 = LocalDate.of(2026, 1, 15);
  int days = Period.between(date3, date4).getDays();
  System.out.println(days); // 10
}
```
