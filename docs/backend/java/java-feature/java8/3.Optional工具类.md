# Optional

`java.util.Optional` 类是 Java 8 引入的一个容器类，用于更优雅的 **处理可能为 null 的值**。它强制你显示的检查值是否存在，从而避免空指针异常。



## 核心特性

### 创建 Optional 对象

```java
// 创建包含非空值的 Optional
Optional<String> o1 = Optional.of("hello");

// 创建可能为空的 Optional
Optional<String> o2 = Optional.ofNullable(getName()); // 假设会返回null

// 创建空的 Optional
Optional<String> o3 = Optional.empty();
```



### 检查值是否存在

```java {4}
public static void main(String[] args) {
  Optional<String> o1 = Optional.of("hello");

  if (o1.isPresent()) {
    System.out.println(o1.get());
  }
}
```





## 常用方法

### ifPresent

`ifPresent()` 方法用于检查 **是否有值**。

```java {5}
public static void main(String[] args) {
  Optional<String> o1 = Optional.of("hello");

  // 如果 o1 不为 null，则打印输出
  o1.ifPresent((value) -> System.out.println(value));
}
```



### ifPresengOrElse

`ifPresengOrElse()` 方法用于检查 **是否有值**，并通过不同的回调函数处理有值和无值的情况。

```java {5-8}
public static void main(String[] args) {
  Optional<String> o1 = Optional.ofNullable(getName());

  // 替代 if..else.. 结构
  o1.ifPresentOrElse(
    (value) -> System.out.println(value), // 有值时执行
    () -> System.out.println("当前值为空")  // 无值时执行
  );
}

private static String getName() {
  // return "sunny";
  return null;
}
```



### orElse

`orElse()` 方法用于 **当值为空时，赋值默认值**。

> [!CAUTION] 注意
>
> 即使 Optional 有值，“默认值” 也是会被提前计算的。

```java {4}
public static void main(String[] args) {
  Optional<String> o1 = Optional.ofNullable(getName());

  String s = o1.orElse("默认值");
  System.out.println(s);
}

private static String getName() {
  return null;
}
```



### orElseGet

`orElseGet()` 方法用于 懒加载，只有 **为空时才会执行**。

```java
public static void main(String[] args) {
  Optional<String> o1 = Optional.ofNullable(getName());

  // o1 为空时，默认获取 getDefaultName() 的返回值
  String s = o1.orElseGet(() -> getDefaultName());
  System.out.println(s);
}

private static String getName() {
  return null;
}

private static String getDefaultName() {
  return "default";
}
```



### map

`map` 方法用于 **对值做转换**，并且自动处理 null 值。

::: code-group

```java [Optional写法] {5}
public static void main(String[] args) {
  Optional<String> o1 = Optional.ofNullable(getName());

  // 获取 o1 的字符串长度
  Optional<Integer> length = o1.map(String::length);
  // 不为空时，输出长度
  length.ifPresent(System.out::println);
}

private static String getName() {
  return "hello";
}
```

```java [原始写法]
public static void main(String[] args) {
  String name = getName();
  if (name != null) {
    System.out.println(name.length());
  } else {
    System.out.println();
  }
}

private static String getName() {
  return "hello";
}
```

:::



### filter

`filter` 方法用于对值进行 **过滤处理**。

```java
public static void main(String[] args) {
  Optional<List<String>> names = Optional.ofNullable(getNames());
  // 判断 names 集合整体的属性
  names
    .filter(list -> list.isEmpty())
    .filter(list -> list.contains("tom"))
    .ifPresent(System.out::println);

  // 如果想操作 names 中的每一个元素，需要通过流
  names
    .stream()
    .flatMap(list -> list.stream())
    .filter(name -> "tom".equals(name))
    .forEach(System.out::println);
}

private static List<String> getNames() {
  return List.of("tom", "amy", "sunny", "bob");
}
```
