# Stream 流

> 🔖 **本节前览：** 本节重点讲解 Java8 中新增的 Stream 流。

在 Java8 中，Stream（流）是一种用于高效处理集合数据的 API，它引入了函数式编程风格，使得对集合的操作更加简洁、灵活和高效。

**Stream 流不是数据结构**，它不存储数据，而是对数据源（集合、数组、I/O 操作等）进行高效的、声明式的处理操作。

> [!NOTE] 流的特点
>
> - **元素序列**：流以顺序的方式提供特定类型的一组元素，流只会按需获取/计算元素，不存储元素；
> - **聚合操作**：流支持聚合操作，如 filter、map、limit、find、match 等等；
> - **管道（pipelining）**：大多数流操作都返回流本身，以便可以对其结果进行链式调用。但注意 `collect()` 方法是一个终端操作，通常在流结束时出现，以标记流的结尾；
> - **源（Source）**：流可以将集合、数组、I/O 资源作为输入源；



## 流的创建

生成流的方法主要有两种：

- `stream()`：该方法以集合作为源，返回集合中所有元素 **顺序** 组成的流；
- `parallelStream()`：该方法也以集合作为源，返回一个 **支持并发操作** 的流；

::: code-group

```java [创建流的方式] {4,5,9,12}
public static void main(String[] args) {
  // 方式一：从集合创建
  List<String> list = List.of("a", "b", "c");
  Stream<String> s1 = list.stream(); // 顺序流
  Stream<String> s2 = list.parallelStream(); // 并行流

  // 方式二：从数组创建
  String[] array = {"a", "b", "c"};
  Stream<String> s3 = Arrays.stream(array);

  // 方式三：Stream.of() 创建
  Stream<String> s4 = Stream.of("a", "b", "c");
}
```

```java [并行流]
public static void main(String[] args) {
  List<String> list = List.of("a", "b", "c", "d");

  // 并行流会打乱流的顺序，即输出顺序并不一定是输入顺序
  list.parallelStream().forEach(System.out::println);
}
```

:::



## 流的操作

### 中间操作

流的中间操作会返回新的 Stream，因此它支持链式调用。

```java {3-10}
public static void main(String[] args) {
  List<String> list = List.of("bb", "aa", "cc", "aa");
  List<String> result = list.stream()
    .filter(s -> s.length() > 1) // 过滤
    .map(String::toUpperCase)    // 映射
    .distinct()                  // 去重
    .sorted()                    // 排序
    .skip(1)                     // 跳过前 n 个
    .limit(1)                    // 限制个数
    .toList();                   // 流转为集合
  System.out.println(result);
}
```



### 终端操作

所谓终端操作，就是指返回新的结果或副作用，从而结束 Stream 的处理。

```java {4,8,12}
public static void main(String[] args) {
  List<String> list = List.of("bb", "aa", "cc", "aa");
  // 计数
  long count = list.stream().count();
  System.out.println(count); // 4

  // 查找第一个元素
  Optional<String> first = list.stream().findFirst();
  System.out.println(first.get()); // bb

  // 条件匹配
  boolean matched = list.stream().anyMatch(s -> s.contains("b"));
  System.out.println(matched); // true
}
```



### 规约操作

```java {4,9}
public static void main(String[] args) {
  List<Integer> numbers = List.of(1, 2, 3, 4);
  // 求和
  Integer sum = numbers.stream().reduce(0, (a, b) -> a + b);
  System.out.println(sum); // 10

  // 连接字符串
  List<String> strings = List.of("a", "b", "c");
  String concat = strings.stream().reduce("", (s1, s2) -> s1.concat(s2));
  System.out.println(concat);
}
```



### 分组和分区

::: code-group

```java [Main] {11,16,21}
public static void main(String[] args) {
  List<User> users = List.of(
    new User("张三", 18),
    new User("李四", 20),
    new User("王五", 20),
    new User("赵六", 18),
    new User("田七", 12)
  );
  // 按年龄分组
  Map<Integer, List<User>> collect1 =
    users.stream().collect(Collectors.groupingBy(u -> u.getAge()));
  System.out.println(collect1);

  // 按年龄统计个数
  Map<Integer, Long> collect2
    = users.stream().collect(Collectors.groupingBy(User::getAge, Collectors.counting()));
  System.out.println(collect3);

  // 按条件分组（true/false分组）
  Map<Boolean, List<User>> collect3 =
    users.stream().collect(Collectors.partitioningBy(u -> u.getAge() > 18));
  System.out.println(collect3);
}
```

```java [User]
public class User {
  String name;

  Integer age;

  public User(String name, Integer age) {
    this.name = name;
    this.age = age;
  }

  }

  public void setName(String name) {
    this.name = name;

    return age;
  }

  }
```

### 统计

使用统计时，需要先在流上调用 `summaryStatistics()` 方法返回统计信息概要，然后再调用相应的方法获取具体的统计信息。

::: code-group

```java [基本数据统计] {7}
public static void main(String[] args) {
  List<String> list = List.of("1", "2", "3", "4", "5");

  // 获取统计概要信息
  IntSummaryStatistics statistics = list.stream()
    .mapToInt(Integer::parseInt)
    .summaryStatistics();
  
  // 获取统计的具体信息
  System.out.println("最大值：" + statistics.getMax());
  System.out.println("最小值：" + statistics.getMin());
  System.out.println("平均值：" + statistics.getAverage());
  System.out.println("总和：" + statistics.getSum());
  System.out.println("值总个数：" + statistics.getCount());
}
```
