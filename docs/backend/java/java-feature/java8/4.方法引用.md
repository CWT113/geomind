# 方法引用

>🔖 **本节前览：** 本节重点讲解 Java8 中新增的新特性 方法引用，它用来简化 Lambda 表达式。



Java8 中的方法引用是 Lambda 表达式的一种简洁语法糖。它可以直接使用方法名来替代 Lambda 表达式，使代码更简洁、可读性更强。



> [!NOTE] 底层原理
>
> 方法引用在底层与 Lambda 表达式类似，并不会立即创建新对象。在大多数情况下，JVM 会在运行时动态生成一个实现了目标函数式接口的类，这个类的唯一方法会去调用被引用的方法。



核心语法：

```java
目标对象或类::方法名
```



## 静态方法引用

当 Lambda 体中 **调用了任何类的静态方法** 时，可以使用方法引用简化。

::: code-group

```java [案例一] {6}
public static void main(String[] args) {
  List<String> names = Arrays.asList("aa", "bb", "cc");

  names.forEach(name -> System.out.println(name));
  // 方法引用简化
  names.forEach(System.out::println);
}
```

```java [案例二] {7}
public class LambdaTest {
  public static void main(String[] args) {
    List<String> names = Arrays.asList("aa", "bb", "cc");

    names.forEach((name) -> LambdaTest.upperAndPrint(name));
    // 方法引用简化
    names.forEach(LambdaTest::upperAndPrint);
  }

  private static void upperAndPrint(String s) {
    System.out.println(s.toUpperCase());
  }
}
```

:::
