# 密封类

>😨😨 吐了：开发中写了一个基类，就想着让某几个子类继承用用，结果不知道哪个哥们又继承了一个，然后越来越乱，越来越乱...

Java17 中新引入了 **密封类**（Sealed Classes）的概念，它允许你 **明确指定哪些类可以继承** 或实现特定的类或接口。

就好像给类加了一把锁，只有得到授权的子类才能继承。



## 核心语法规则

> [!NOTE] 语法规则
>
> - 密封类使用关键字 `sealed` 声明，并且必须使用 `permits` 关键字明确列出允许继承的子类；
> - 允许继承的子类，必须使用以下关键字声明：
>   - `final` 类：禁止进一步继承；
>   - `sealed` 类：继续限制继承；
>   - `non-sealed` 类：开放继承；

::: code-group

```java [密封类] {1}
public sealed class Shape permits Circle, Rectangle, Triangle {
}

// final类：禁止进一步继承
final class Circle extends Shape {
}

// sealed类：继续限制继承
sealed class Rectangle extends Shape {
}

// non-sealed类：开放继承
non-sealed class Triangle extends Shape {
}
```
