# 列表（list）

列表是一种用来 **存储多个数据的容器**，可以把它理解成一个能够存放多个元素的集合。

> [!TIP] 列表的特点
>
> - **有序性**：元素按照添加的顺序排序，取出时顺序也相同；
> - **可修改**：可以增加、修改、删除元素；
> - **允许重复**：可以存在相同的元素；
> - **类型不限**：可以存储不同数据类型的元素；

```python
# 定义字符串列表
names = ["张三", "李四", "王五"]
# 定义数字列表
numbers = [10, 20, 30]
# 定义混合列表
my_list = ["张三", True, 10, 3.14]

print(type(names))  # <class 'list'>
```



## 列表索引

Python 中列表索引有两种：

- **正向索引**：索引从 `0` 开始，第二个索引是 `1`，以此类推；
- **反向索引**：最后一个元素的索引为 `-1`，往前一位为 `-2`，以此类推；

| ![img](https://www.runoob.com/wp-content/uploads/2014/05/positive-indexes-1.png) | ![img](https://www.runoob.com/wp-content/uploads/2014/05/negative-indexes.png) |
| :----------------------------------------------------------: | :----------------------------------------------------------: |
|                           正向索引                           |                           反向索引                           |

```python
s = [10, 20, "A", "Hello", True]

# 正向索引
print(s[1])  # 10
print(s[2])  # 20

# 反向索引
print(s[-1])  # True
print(s[-2])  # Hello
```



## 获取元素（切片）

上面演示了使用下标索引来访问列表中的值，同样也可以使用方括号（`[]`）的形式截取字符，也叫 **列表切片**。

```python {4,7}
s = [10, 20, "A", "Hello", True]

# 截取索引从 1~3 的值（左闭右开）
print(s[1:3])   # [20, 'A']

# 使用负数索引截取，从1截取到-1
print(s[1:-1])  # [20, 'A', 'Hello']

# 遍历列表
for item in s:
    print(item)
```



## 修改元素

```python {4}
s = [10, 20, "A", "Hello", True]

# 修改元素
s[2] = "ABC"
print(s)  # [10, 20, 'ABC', 'Hello', True]
```



## 删除元素

```python {4}
s = [10, 20, "A", "Hello", True]

# 删除元素
del s[1]
print(s)  # [10, 'ABC', 'Hello', True]
```
