# 列表（List）

列表是一种用来 **存储多个数据的容器**，可以把它理解成一个能够存放多个元素的集合。

> [!TIP] 列表的特点
>
> - **有序性**：元素按照添加的顺序排序，取出时顺序也相同；
> - **可修改**：可以增加、修改、删除元素；
> - **允许重复**：可以存在相同的元素；
> - **类型不限**：可以存储不同数据类型的元素；

```python
# 定义字符串列表
names = ["张三", "李四", "王五"]
# 定义数字列表
numbers = [10, 20, 30]
# 定义混合列表
my_list = ["张三", True, 10, 3.14]

print(type(names))  # <class 'list'>
```

列表常用函数：

| 函数                  | 描述                  |
| :-------------------- | --------------------- |
| len(list)             | 获取列表元素个数      |
| max(list) / min(list) | 获取列表最大 / 最小值 |
| list(seq)             | 将元组转换为列表      |

列表常用方法：

| 方法                               | 描述                                                         |
| :--------------------------------- | ------------------------------------------------------------ |
| list.append(obj)                   | 在列表末尾添加元素                                           |
| list.count(obj)                    | 统计某个元素在列表中出现的次数                               |
| list.extend(sql)                   | 在列表末尾一次性追加另一个序列中的多个值（用新列表扩展原来的列表） |
| list.index(obj)                    | 找到某个值第一个匹配项的索引值                               |
| list.insert(i, obj)                | 将对象插入列表的 i 索引位置                                  |
| list.pop([index == -1])            | 移除列表中的一个元素（默认最后一个元素），并且返回该元素的值 |
| list.remove(obj)                   | 移除列表中某个值的第一个匹配项                               |
| list.reverse()                     | 反转列表                                                     |
| list.clear()                       | 情况列表                                                     |
| list.copy()                        | 复制列表                                                     |
| list.sort(key=None, reverse=False) | 对原列表进行排序                                             |



## 列表基础操作

获取、修改和删除列表元素都需要用到 **索引**，而列表索引有两种：

- **正向索引**：索引从 `0` 开始，第二个索引是 `1`，以此类推；
- **反向索引**：最后一个元素的索引为 `-1`，往前一位为 `-2`，以此类推；

| ![img](https://www.runoob.com/wp-content/uploads/2014/05/positive-indexes-1.png) | ![img](https://www.runoob.com/wp-content/uploads/2014/05/negative-indexes.png) |
| :----------------------------------------------------------: | :----------------------------------------------------------: |
|                           正向索引                           |                           反向索引                           |

```python {4,12,16,20}
s = [10, 20, "A", "Hello", True]

# 正向索引
print(s[1])  # 10
print(s[2])  # 20

# 反向索引
print(s[-1])  # True
print(s[-2])  # Hello

# 修改元素
s[2] = "ABC"
print(s)  # [10, 20, 'ABC', 'Hello', True]

# 删除元素
del s[1]
print(s)  # [10, 'ABC', 'Hello', True]

# 新增元素
s.append(25)
print(s)  # [10, 20, 'A', 'Hello', True, 25]
```



## 列表切片

上面演示了使用下标索引来访问列表中的值，同样也可以使用方括号（`[]`）的形式截取列表，也叫 **列表切片**。

```python {4,7}
s = [10, 20, "A", "Hello", True]

# 截取索引从 1~3 的值（左闭右开）
print(s[1:3])   # [20, 'A']

# 使用负数索引截取，从1截取到-1
print(s[1:-1])  # [20, 'A', 'Hello']

# 遍历列表
for item in s:
  print(item)
```



## 列表脚本操作符

列表对 `+` 和 `*` 的操作与字符串相似。`+` 号用于组合列表，`*` 号用于重复列表。

| 表达式            | 描述             | 结果              |
| ----------------- | ---------------- | ----------------- |
| len([1,2,3])      | 列表长度         | 3                 |
| [1,2,3] + [4,5,6] | 组合             | [1,2,3,4,5,6]     |
| [“A”] * 4         | 重复             | [“A”,”A”,“A”,”A”] |
| 3 in [1,2,3]      | 元素是否在列表中 | True              |

```python {4,8,12,15}
s = [1, 2, 3]

# 获取长度
print(len(s))  # 3

# 组合
s1 = [4, 5, 6]
print(s + s1)  # [1, 2, 3, 4, 5, 6]

# 重复
s2 = ["A"]
print(s2 * 4)  # ['A', 'A', 'A', 'A']

# 元素是否在列表中
print(3 in s)  # True

# 遍历列表
for item in s:
  print(item, end=" ")
```



## 嵌套列表

使用嵌套列表即在 **列表中创建其他列表**，例如：

```python {6,10}
s1 = [1, 2, 3]

s2 = ["A", "B", "C"]

# 嵌套列表
res = [s1, s2]
print(res)  # [[1, 2, 3], ['A', 'B', 'C']]

# 获取元素
print(res[0])  # [1, 2, 3]
```



## 列表比较

列表比较需要引入 `operator` 模块的 `eq` 方法：

```python {1,9,10}
import operator

s1 = [1, 2, 3]

s2 = ["A", "B", "C"]

s3 = [1, 2, 3]

print(operator.eq(s1, s2))  # False
print(operator.eq(s1, s3))  # True
```
