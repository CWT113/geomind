# 元组

Python 中的元素与列表类似，不同之处在于 **元组的元素不能修改**。元组使用小括号 `()` 定义，而列表使用方括号 `[]` 定义。

> [!TIP] 元组的特点
>
> - **不可变性**：元组自创建后，不能增删改元素，但如果元组内含可变对象，该对象本身可被修改；
> - **有序序列**：支持索引、切片、负索引，与列表类似；
> - **可迭代行**：可以使用 `for` 进行遍历；

```python
tup1 = ("Google", "Apple", 1997, 2000)

tup2 = (1, 2, 3, 4, 5)

tup3 = "a", "b", "c", "d", "e"  # 不需要括号也可以

# 如果元组中只有一个元素，需要在后面加 , 号
tup4 = (10)  # 不加 , 号，类型是 <class 'int'>，括号被当作运算符
tup5 = (10,)  # 加了 , 号，类型是 <class 'tuple'>

print(type(tup1))  # <class 'tuple'>
```





## 元组基本操作

元组同样也支持使用 正向序列 和 反向序列 来获取值。

```python {5,8,14}
tup1 = ('Google', 'Apple', 1997, 2000)
tup2 = (1, 2, 3, 4, 5, 6, 7)

# 获取元组值
print(tup1[0])  # Google

# 截取元组
print(tup2[1:5])  # (2, 3, 4, 5)

# 元组具有不可变性
tup1[0] = "NVIDIA"  # 报错：不允许修改 [!code --]

# 创建新的元组
tup3 = tup1 + tup2
print(tup3)  # ('Google', 'Apple', 1997, 2000, 1, 2, 3, 4, 5, 6, 7)
```



## 元组运算符

与字符串、列表一样，元组之间也可以使用 `+`、`+=` 和 `*` 号进行运算。这就意味着他们可以组合和复制，运算后会生成一个新的元组。

|    表达式    | 描述                                 |
| :----------: | ------------------------------------ |
| tup1 + tup2  | 将两个元组合并为一个，返回一个新元组 |
| tup1 += tup2 | 将 tup2 追加到 tup1 中               |
|   tup * 2    | 将元组内的数据重复 2 次              |
|   a in tup   | 元素是否在元组中存在                 |

```python {5,9,13,17}
tup1 = (1, 2, 3)
tup2 = (4, 5, 6)

# 合并元素
tup3 = tup1 + tup2
print(tup3)  # (1, 2, 3, 4, 5, 6)

# 元组追加
tup1 += tup2
print(tup1)  # (1, 2, 3, 4, 5, 6)

# 元素重复
tup4 = tup2 * 2
print(tup4)  # (4, 5, 6, 4, 5, 6)

# 判断元素是否在元组中
print(3 in tup1)  # True

# 遍历元素
for i in tup1:
    print(i)

```



## 元组内置函数

|    函数     | 描述             |
| :---------: | ---------------- |
|    len()    | 计算元素个数     |
|    max()    | 计算元组最大值   |
|     min     | 计算元组最小值   |
| tuple(list) | 将列表转换为元组 |

```python {17,21}
tup1 = (1, 2, 3)
tup2 = ("10", "20", "30")

# 获取长度
print(len(tup1))  # 3

# 获取最大值
print(max(tup1))  # 3
print(max(tup2))  # 30

# 获取最小值
print(min(tup1))  # 1
print(min(tup2))  # 10

# 列表转换为元组
l = ["A", "B", 10, True]
tup3 = tuple(l)
print(tup3)  # ('A', 'B', 10, True)

# 元组转换为列表
new_list = list(tup3)
print(new_list)  # ['A', 'B', 10, True]
```
