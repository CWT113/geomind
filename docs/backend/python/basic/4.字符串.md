# 字符串

字符串是 Python 中最常用的数据类型。我们可以使用引号（`'` 或 `"`）来创建字符串。

> [!TIP] 字符串的特点
>
> - **不可变性**：字符串一旦被创建，内容不能修改；
> - **有序序列**：字符串是字符的有序序列，支持索引和切片；
> - **可迭代性**：可以用于 `for` 循环、`in` 判断等；

```python
# 双引号字符串
s1 = "Hello"

# 单引号字符串
s2 = 'Hello'

# 三引号字符串（可执行换行操作）
s3 = """
    尊敬的各位领导：
        大家好!
"""
```



## 字符串基本操作

获取、修改和删除列表元素都需要用到 **索引**，而列表索引有两种：

- **正向索引**：索引从 `0` 开始，第二个索引是 `1`，以此类推；
- **反向索引**：最后一个元素的索引为 `-1`，往前一位为 `-2`，以此类推；

```python
s = "Hello-Python"

# 索引获取
print(s[4])  # o
print(s[-8]) # o

# 不可变性
s[4] = 'X' # 报错 [!code --]
print(s)
```



## 字符串切片

字符串是有序的序列，因此也支持切片。

```python {7,10}
s = "Hello-Python"

# 正向切片（step为正数，表示从前往后截取）
print(s[0:5:1])  # Hello

# 反向切片（step为正数，表示从后往前截取）
print(s[-1:-7:-1])  # nohtyP

# 利用步长，反转字符串（开始、结束索引都不用写）
print(s[::-1])  # nohtyP-olleH
```



## 常用方法

|     方法     | 作用                                                        |
| :----------: | ----------------------------------------------------------- |
|    find()    | 再字符串中查找子串，返回第一次出现的索引位置，找不到返回 -1 |
|   count()    | 统计子串在字符串中出现的次数                                |
|   upper()    | 将字符串中的所有字母转换为大写                              |
|   lower()    | 将字符串中的所有字母转换为小写                              |
|   split()    | 将字符串按指定分隔符分割成列表                              |
|   strip()    | 去除字符串两端的空白字符或指定字符                          |
|  replace()   | 将字符串中的指定子串替换为新的子串                          |
| startswith() | 检查字符串是否以指定子串开头，返回布尔值                    |

```python {4,7,10,13,17,21,25,26}
s = "Hello-Python-Hello-World"

# 查找 - 第一次出现的索引
print(s.find("-"))  # 7

# 统计字母 o 出现的次数
print(s.count("o"))  # 4

# 将字符串转为大写
su = s.upper()
print(su)  # HELLO-PYTHON-HELLO-WORLD

sl = s.lower()
print(sl)  # hello-python-hello-world

# 按 - 分割成列表
s_list = s.split("-")
print(s_list)  # ['Hello', 'Python', 'Hello', 'World']

# 替换 - 为 _
sr = s.replace("-", "_")
print(sr)  # Hello_Python_Hello_World

# 判断字符串是否以 Hello 开头，以 Python 结尾
print(s.startswith("Hello"))  # True
print(s.endswith("World"))  # True
```
