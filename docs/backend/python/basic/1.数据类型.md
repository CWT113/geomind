# 数据类型

## 基本数据类型

Python 中常见的基本数据类型如下：

| 数据类型 |  名称  | 说明                                             |
| :------: | :----: | ------------------------------------------------ |
|   int    |  整数  | 数字类型，存放整数，如：10，-5                   |
|  float   | 浮点数 | 数字类型，存放小数，如：8.5，3.14                |
|   str    | 字符串 | 字符串类型，用双引号引起来的字符串，如：“Python” |
|   bool   |  布尔  | 布尔类型，描述真和假，如：True，False            |
| NoneType |  空值  | 表示空或无值，仅包含一个值：None                 |

```python
# 使用 type() 函数查看变量类型
print(type(10))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("Python")) # <class 'str'>
print(type(True))     # <class 'bool'>
print(type(None))     # <class 'NoneType'>

# 使用 isinstance() 函数判断变量是否属于某个类型
print(isinstance(10, int))       # True
print(isinstance(3.14, float))   # True
print(isinstance("Python", str)) # True
print(isinstance(True, bool))    # True
```



## 字符串

### 字符串定义

```python
# 双引号字符串
s1 = "Hello"

# 单引号字符串
s2 = 'Hello'

# 三引号字符串（可执行换行操作）
s3 = """
    尊敬的各位领导：
        大家好!
"""

# 引号结合使用
s4 = "It's a good idea."
s5 = 'Hello "world"'
```



### 字符串拼接

> [!WARNING] 注意
>
> 在 Python 中，字符串与数字是不可以直接拼接的，需要通过 `str()` 把数字转为字符串后再进行拼接。

```python {9}
# 字符串拼接
s1 = "人生苦短"
s2 = "我用Python"
print(s1 + "，" + s2)

# 字符串与数字拼接
name = "tomx"
age = 18
print("我是" + name + "，今年" + str(age) + "岁")
```



### 字符串格式化

通过 **%占位符** 的形式完成字符串和变量的快速拼接（其中 `%` 表示我要占位，`s` 表示将变量转为字符串放入占位的位置）。

> [!WARNING] 注意
>
> - 前面有多少个占位符（`%s`），后面就需要有多少个变量，前后数量要一致。
> - 使用字符串格式化的方式拼接，不需要考虑数字转字符串的问题；

::: code-group

```python [%方式]
# 字符串拼接
s1 = "World"
print("Hello，%s" % s1) # [!code ++]

# 字符串与数字拼接
name = "tomx"
age = 18
print("我是 %s，今年 %s 岁" % (name, age)) # [!code ++]
```

```python [f占位符方式（推荐）]
# 字符串拼接
s1 = "World"
print(f"Hello，{s1}") # [!code ++]

# 字符串与数字拼接
name = "tomx"
age = 18
print(f"我是 {name}，今年 {age} 岁") # [!code ++]
```

:::



## 输入与输出

输入与输出需要通过两个函数来完成：

- `input` 函数：获取键盘输入的数据；
- `print` 函数：将数据输出到控制台；

> [!NOTE]
>
> 通过 `input()` 函数获取到的输入变量，都是字符串类型，如果需要和数字进行操作，需要通过 `int()` 等工具函数将其转为数字类型。

```python {1,6}
name = input("请输入您的姓名：")
print(name)

year = 2026
age = input("请输入您的出生年份：")
print(f"您的年龄是：{2026 - int(age)}") # 字符串转数字
```



## 运算符

### 算数运算符

常见的算数运算符如下：

| 运算符 |   描述    | 举例                                       |
| :----: | :-------: | ------------------------------------------ |
|   +    |   加法    | 1 + 5                                      |
|   -    |   减法    | 8 - 3                                      |
|   *    |   乘法    | 3 * 8                                      |
|   /    |   除法    | 10 / 5，10 除以 5，除法结果是小数 2.0      |
|   //   |   整除    | 10 // 3，10 整除 3，整除结果是整数 3       |
|   %    | 取余/取模 | 10 % 3，10 模于 3，结果为 1（10 除 3 取余数） |
|   **   |  幂指数   | 10 ** 3，10 的 3 次方                         |

```python
print("1 + 5 =", 1 + 5)      # 6
print("8 - 3 =", 8 - 3)      # 5
print("3 * 8 =", 3 * 8)      # 24
print("10 / 5 =", 10 / 5)    # 2.0
print("10 // 3 =", 10 // 3)  # 3
print("10 % 3 =", 10 % 3)    # 1
print("10 ** 3 =", 10 ** 3)  # 1000
```



### 赋值运算符

赋值运算符是用于将值保存到变量中的运算符（把右边的值，赋值给左边的值）。

| 运算符 |      描述      | 举例                              |
| :----: | :------------: | --------------------------------- |
|   =    |   赋值运算符   | num = 1 + 2                       |
|   +=   | 加法赋值运算符 | num += 2 等价于 num = num + 2     |
|   -=   | 减法赋值运算符 | num -= 2 等价于 num = num - 2     |
|   *=   | 乘法赋值运算符 | num * = 2 等价于 num = num * 2     |
|   /=   | 除法赋值运算符 | num /= 2 等价于 num = num / 2     |
|   %=   | 取模赋值运算符 | num %= 2 等价于 num = num % 2     |
|  //=   | 整除赋值运算符 | num //= 2 等价于 num = num // 2   |
|  **=   |  幂赋值运算符  | `num **= 2 等价于 num = num ** 2` |

```python
num = 85

num += 10  # num = num + 10
print("num += 10 后，num =", num)   # 95

num -= 10  # num = num - 10
print("num -= 10 后，num =", num)   # 85

num *= 10  # num = num * 10
print("num *= 10 后，num =", num)   # 850

num /= 10  # num = num / 10
print("num /= 10 后，num =", num)   # 85.0

num //= 10  # num = num // 10
print("num //= 10 后，num =", num)  # 8.0

num %= 3  # num = num % 3
print("num %= 10 后，num =", num)   # 2.0

num **= 3  # num = num ** 3
print("num **= 3 后，num =", num)   # 8.0
```



### 比较运算符

比较运算符（也称关系运算符），用于比较两个值之间的关系。会计算运算符两边的表达式，然后返回一个布尔值作为结果。

| 运算符 |   描述   | 举例   |
| :----: | :------: | ------ |
|   ==   |   等于   | a == b |
|   !=   |  不等于  | a != b |
|   >    |   大于   | a > b  |
|   >=   | 大于等于 | a >= b |
|   <    |   小于   | a < b  |
|   <=   | 小于等于 | a <= b |

```python
print("100 == 100 吗：", 100 == 100)         # True
# 字符串比较
print("'100' == '100' 吗：", '100' == '100') # True
print("100 != 100 吗：", 100 != 100)         # False

print("100 < 100 吗：", 100 < 100)           # False
print("100 <= 100 吗：", 100 <= 100)         # True

print("100 > 100 吗：", 100 > 100)           # False
print("100 >= 100 吗：", 100 >= 100)         # True
```



### 逻辑运算符

逻辑运算符是用于连接多个条件表达式，并返回一个最终布尔结果的运算符。

| 运算符 |      描述      | 举例                                                         |
| :----: | :------------: | ------------------------------------------------------------ |
|  and   | 逻辑与（并且） | 同时成立才是符合条件的（左右两边都为 True，结果才为 True）   |
|   or   | 逻辑或（或者） | 只要有一个符合要求的即可（只要左右两边有一个为 True，结果就为 True） |
|  not   | 逻辑非（取反） | 取反操作                                                     |

```python
# 键盘输入一个整数，判断这个数字是否在 10~20 之间
num = int(input("请输入一个整数，判断是否在 10~20 之间："))
print(10 <= num <= 20)

# 键盘输入一个整数，判断这个数字是否不在 10~20 之间
num2 = int(input("请输入一个整数，判断是否不在 10~20 之间："))
print(10 > num2 > 20)
print(not (10 <= num <= 20))
```
