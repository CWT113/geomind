# 基础使用

`Cesium` 是基于 WebGL 实现三维地球和地图可视化的 JS 库，支持海量的三维模型数据、影像数据、地形高程数据、矢量数据等丰富的地理数据的加载。



## 安装

安装 cesium 包和 vite-plugin-cesium 插件：

```shell
pnpm install cesium vite-plugin-cesium
```

在 `vite.config.ts` 中，注册 vite-plugin-cesium 插件：

```typescript {6}
import cesium from "vite-plugin-cesium";

export default defineConfig({
  plugins: [
    vue(), 
    cesium()
  ]
});
```

页面中引入 cesium 的包：

```typescript
import * as Cesium from "cesium";
// 或者
import { Viewer } from "cesium";
```

## 基础配置参数

```typescript
Cesium.Ion.defaultAccessToken =
  "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJqdGkiOiI1ZTM3ZTkwNy1hMWU5LTQxNDktYjdhNC0yMzc5NTEyNDgzMzEiLCJpZCI6ODk5MTAsImlhdCI6MTY1NjM5NTAzOX0.z7Dn_tJQW0ysqXsjvqyvxxELXlSHdfyuqZ4ENFl-2j8";
const viewer = new Cesium.Viewer("cesiumContainer", {
  infoBox: false,
  // VR控件
  vrButton: false,
  // 搜索框控件
  geocoder: false,
  // 时间轴控件
  timeline: false,
  // 动画控件按钮
  animation: false,
  // 默认视图控件
  homeButton: false,
  // 选择图层控件
  baseLayerPicker: false,
  // 投影方式控件
  sceneModePicker: false,
  // 全屏按钮控件
  fullscreenButton: false,
  // 投影选择器控件
  projectionPicker: false,
  // 选择指示器组件（点击entity时，屏幕上出现的绿色矩形框）
  selectionIndicator: false,
  // 帮助按钮控件
  navigationHelpButton: false,
  // 几何体以3D形式渲染，以节省CPU内存
  scene3DOnly: true,
  // 是否默认开启动画
  shouldAnimate: true,
  // 初始场景模式
  sceneMode: Cesium.SceneMode.SCENE3D,
  // 是否默认加载影像地图
  // baseLayer: false,
  // 是否启用按需渲染模式（若开启，则只在相机位置、方向发生变化时才刷新帧，可以稳定帧率。但若需要默认展示动态图时，需要开启）
  requestRenderMode: true,
  // 使用cesium内部模型的渲染函数
  useDefaultRenderLoop: true,
  // 是否使用浏览器建议的分辨率进行渲染，开启会忽略 window.devicePixelRatio
  useBrowserRecommendedResolution: true,
  // 阴影是否由光源投射
  shadows: false,
  // 控制多重采样抗锯齿的级别，值越大，画面精细度多高，渲染压力越大
  msaaSamples: 4,
  // WebGL场景上下文配置
  contextOptions: {
    // 如果浏览器支持，使用 webgl1 进行渲染
    requestWebgl1: false,
    // 支持webgl扩展时，启用异向纹理过滤（设置为false可提升性能，但损害视觉质量）
    allowTextureFilterAnisotropic: true,
    webgl: {
      // 禁用透明通道，以提升性能
      alpha: false,
      // 启用深度测试，用于3D渲染
      depth: false,
      // 不使用模板缓冲区
      stencil: false,
      // 启用抗锯齿
      antialias: true,
      // GPU功耗偏好（可选："default" | "high-performance" | "low-power）
      powerPreference: "high-performance",
    },
  },
});

// 隐藏版权logo
viewer.cesiumWidget.creditContainer.setAttribute("style", "display: none");
// viewer.cesiumWidget.creditContainer.style.display = 'none';

// 设置渲染分辨率，从而提高视觉保真度
viewer.resolutionScale = window.devicePixelRatio;
// 是否开启FPS帧率显示
viewer.scene.debugShowFramesPerSecond = false;
// 是否开启对数深度缓冲区，启用此选项将减少视锥体中的数量，以提高性能
viewer.scene.logarithmicDepthBuffer = true;
// 是否开启地形深度检测
viewer.scene.globe.depthTestAgainstTerrain = false;
// 是否开启抗锯齿，开启时可以消除模型、矢量的锯齿边缘
viewer.scene.postProcessStages.fxaa.enabled = true;
// 是否开启地球大气效果
viewer.scene.globe.showGroundAtmosphere = true;
// 是否开启地球光照效果
viewer.scene.globe.enableLighting = false;
// 是否显示太阳
viewer.scene.sun && (viewer.scene.sun.show = false);
// 是否显示月亮
viewer.scene.moon && (viewer.scene.moon.show = false);
// 是否显示天空盒
viewer.scene.skyBox && (viewer.scene.skyBox.show = true);
```
