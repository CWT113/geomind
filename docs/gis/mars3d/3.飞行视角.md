# 飞行视角

| 方法名                                                       | 说明                                               |
| :----------------------------------------------------------- | -------------------------------------------------- |
| [map.getCameraView()](#getCameraView)                        | 获取当前视角                                       |
| [map.setCameraView(viewer, options)](#setCameraView)         | 将相机本身定位至指定位置                           |
| [map.setCameraViewList(arr, func)](#setCameraViewList)       | 定位到多个相机视角位置，按数组顺序播放             |
| [map.flyHome()](http://mars3d.cn/api/Map.html#flyHome)       | 飞行到默认视角，一般为 config 中的 center 参数视角 |
| [map.flyTo(target, options)](http://mars3d.cn/api/Map.html#flyTo) | 飞行定位至 Cesium 矢量对象处                       |
| [map.flyToPoint(point, options)](#flyToPoint)                | 视角中心定位至目标点（非相机位置）                 |
| [map.flyToPositions(positions, options)](#flyToPositions)    | 飞行定位至 坐标数组 处                             |
| [map.flyToExtent(extent, options)](#flyToExtent)             | 飞行定位至 矩形区域 处                             |
| [map.flyToGraphic(graphic, options)](#flyToGraphic)          | 飞行定位至 Graphic 矢量对象处                      |
| [map.cancelFlyTo()](#cancelFlyTo)                            | 停止视角定位                                       |



## getCameraView

`getCameraView` 用于获取当前相机视角参数。

```ts {3}
map.on(mars3d.EventType.click, () => {
  // simplify 为 false 时，结果中包含 roll 参数
  const camera = map.getCameraView({ simplify: false });
  console.log(camera);
});
```



## setCameraView

[setCameraView↗](http://mars3d.cn/api/Map.html#setCameraView) 用于将相机本身定位到指定位置，并带有动画。

```ts {8}
const pos = { 
  lng: 116.391643,
  lat: 39.904128,
  alt: 1054,
  heading: 0,
  pitch: -39,
}
map.setCameraView(pos, {
  duration: 2.0, // 不配置时，SDK内部会自动计算时长
  complete: () => {
    console.log("飞行完成！");
  },
});
```



## setCameraViewList

[setCameraViewList↗](http://mars3d.cn/api/Map.html#setCameraViewList) 用于定位到多个相机视角位置，按数组顺序播放。

```ts
// 视角切换（分步执行）, stop设置停留在该视角的时间
map.setCameraViewList([
  { lng: 108.961601, lat: 34.217109, alt: 509.2, heading: 314.5, pitch: -22.5, roll: 0, duration: 4, stop: 0 },
  { lng: 108.96164, lat: 34.222159, alt: 510.3, heading: 211.2, pitch: -22.5, roll: 0, duration: 2, stop: 0 },
  { lng: 108.957259, lat: 34.221967, alt: 494.3, heading: 127.5, pitch: -17.2, roll: 0, duration: 2, stop: 0 },
  { lng: 108.957319, lat: 34.217225, alt: 515.5, heading: 25.4, pitch: -25.3, roll: 0, duration: 3 },
]);
```



## flyToPoint

[flyToPoint↗](http://mars3d.cn/api/Map.html#flyToPoint) 用于定位到目标点的位置（而非相机视角），并带有动画。

```ts {19}
const position1 = [113.939351, 36.068144, 350.9];
const position2 = Cesium.Cartesian3.fromDegrees(113.939351, 36.068144, 350.9);

// 显示参照物
const graphic = new mars3d.graphic.PointPrimitive({
  // 经纬度数组，或者笛卡尔坐标
  // position: position1,
  position: position2,
  style: {
    color: "#00ffff",
    pixelSize: 6,
    outlineColor: "#ffffff",
    outlineWidth: 2,
  },
});
map.graphicLayer.addGraphic(graphic);

// 飞行目标点也可以是经纬度数组，或者笛卡尔坐标
map.flyToPoint(position2, {
  duration: 3.0,
  // 相机距离目标点的高度
  radius: 5000,
  // 方向角
  heading: 50,
  // 俯仰角
  pitch: -45,
  // 飞行时的最大高度
  maximumHeight: 5000,
});
```



## flyToPositions

[flyToPositions↗](http://mars3d.cn/api/Map.html#flyToPositions) 用于定位到目标数组所在的位置，并带有动画。

```ts {23}
const positions = [
  [114.031965, 36.098482, 332.8],
  [114.038309, 36.089496, 267.6],
  [114.048026, 36.093311, 255.7],
  [114.041602, 36.102055, 377.5],
];
const pos = positions.map(p => Cesium.Cartesian3.fromDegrees(p[0]!, p[1]!, p[2]!));
// 显示参照物
for (let j = 0; j < positions.length; ++j) {
  const position = positions[j];
  const graphic = new mars3d.graphic.PointPrimitive({
    position,
    style: {
      color: "#00ffff",
      pixelSize: 6,
      outlineColor: "#ffffff",
      outlineWidth: 2,
    },
  });
  map.graphicLayer.addGraphic(graphic);
}

map.flyToPositions(pos, {
  duration: 3.0,
});
```



## flyToExtent

[flyToExtent↗](http://mars3d.cn/api/Map.html#flyToExtent) 用于将相机飞行定位至矩形区域，并带有动画。

```ts {3}
const extent = { xmin: 114.811691, xmax: 119.703609, ymin: 29.35597, ymax: 34.698585 };

map.flyToExtent(extent, {
  // 缩放比例，可以控制视角高度
  scale: 1.3,
  duration: 2.0,
});

// 显示参照物
const graphic = new mars3d.graphic.RectanglePrimitive({
  positions: [
    [extent.xmin, extent.ymin],
    [extent.xmax, extent.ymax],
  ],
  style: {
    color: Cesium.Color.CYAN.withAlpha(0.4),
  },
});
map.graphicLayer.addGraphic(graphic);
```



## flyToGraphic

[flyToGraphic↗](http://mars3d.cn/api/Map.html#flyToGraphic) 用于飞行定位到 Graphic矢量对象 所在处，并带有动画。

```ts {26}
const graphic = new mars3d.graphic.EllipsoidEntity({
  position: [107.39956, 29.719738, 100.9],
  style: {
    radii: new Cesium.Cartesian3(2500.0, 2500.0, 1000.0),
    maximumConeDegree: 90,
    fill: false,
    subdivisions: 64,
    stackPartitions: 32,
    slicePartitions: 32,
    outline: true,
    outlineColor: "#ffff00",
    highlight: {
      outlineColor: "#ff0000",
    },
  },
  scanPlane: {
    step: 0.5,
    style: {
      color: "#ffff00",
      opacity: 0.4,
    },
  },
});
map.graphicLayer.addGraphic(graphic);

map.flyToGraphic(graphic, {
  radius: 10000,
  scale: 1.2,
});
```



## cancelFlyTo

cancelFlyTo↗ 用于停止正在飞行的视角。

```ts
// mars3d 停止视角定位
map.cancelFlyTo();

// cesium 原生停止视角定位
map.camera.cancelFlight();
```
