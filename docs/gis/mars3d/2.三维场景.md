# 三维场景

使用 div 渲染后看到的三维地球对象，我们统称为三维场景。[`mars3d.Map类↗`](http://mars3d.cn/api/Map.html) 是构建 Mars3D 地图的主入口，称其为视图容器。



## 构造参数

Map 类的构造参数比较多，主要通过第 2 个参数 mapOptions 中控制：

|   参数名   | 类型                                      | 参数解释                                                     |
| :--------: | :---------------------------------------- | ------------------------------------------------------------ |
|     id     | String 或 Cesium.Viewer                   | 地图容器 div 的 id，或已经构造好的 viewer 对象（可与第三方 API 结合使用） |
| mapOptions | [Object↗](https://mars3d.cn/api/Map.html) | 创建地球的参数                                               |

![Map](http://mars3d.cn/docs/img/basis/map-api-options.jpg)



### scene

[scene↗](https://mars3d.cn/api/Map.html#.sceneOptions) 场景是所有 3D 图形对象的容器，在场景对象中我们可以控制：全局地球（globe）、相机（camera）等。

```ts
const map = new mars3d.Map("mars3dContainer", {
  scene: {
    // 默认视角参数
    center: { lat: 30.054604, lng: 108.885436, alt: 10026414, heading: 0, pitch: -90, roll: 0 },
    // 矩形范围视角（和 center 配置项二选一）
    // extent: { xmin: 116.248914, xmax: 116.491548, ymin: 39.820571, ymax: 39.999902 },
    // 是否移除Cesium默认的双击事件
    removeDblClick: true,

    /************ 下面是 Cesium.scene 配置项（列举一部分） ************/
    // 是否显示天空盒背景
    showSkyBox: true,
    // 是否显示太阳
    showSun: true,
    // 是否显示月亮
    showMoon: true,
    // 是否显示地球大气层外光圈
    showSkyAtmosphere: true,
    // 是否启用雾化效果
    fog: true,
    // 是否启用抗锯齿
    fxaa: true,
    // 是否关闭高动态范围渲染（不关闭时地图会变暗）
    highDynamicRange: false,
    // 几何实例是否仅以3D渲染，以节省GPU内存
    scene3DOnly: true,
    // 设置初始地图模式
    sceneMode: Cesium.SceneMode.SCENE3D,
    // 是否启用日照阴影
    shadows: true,
    // 地形接收来自光源的阴影的方式
    terrainShadows: Cesium.ShadowMode.RECEIVE_ONLY,
    // 渲染分辨率的缩放比例
    resolutionScale: window.devicePixelRatio,
    // 是否以浏览器建议的分辨率渲染，为 true 时会忽略 window.devicePixelRatio
    useBrowserRecommendedResolution: true,
    // 传递给WebGL渲染的属性
    contextOptions: {
      // 是否允许纹理过滤各向异性
      allowTextureFilterAnisotropic: true,
      // 是否使用 webgl1 渲染，cesium1.102 开始使用 webgl2 渲染了
      requestWebgl1: false,
      // webgl画布配置项
      webgl: {
        // 是否执行抗锯齿
        antialias: true,
        // 系统性能较低时，是否创建上下文
        failIfMajorPerformanceCaveat: false,
        // 截图是需要将该参数配置为 true
        preserveDrawingBuffer: true,
        // 指示GPU的哪种配置运行webgl上下文
        powerPreference: "high-performance",
      },
    },

    /************ 下面是 Cesium.Globe 配置项（列举一部分） ************/
    globe: {
      // 地球默认背景色
      baseColor: "#546a53",
      // 是否显示昼夜区域
      enableLighting: false,
      // 是否在地球上绘制的地面大气
      showGroundAtmosphere: true,
      // 是否启用深度监测（可以开启来测试矢量对象是否在地形下面或被遮挡）
      depthTestAgainstTerrain: false,
    },

    /************ 下面是 Cesium.ScreenSpaceCameraController 配置项（列举一部分） ************/
    cameraController: {
      // 鼠标滚轮放大的步长比例
      zoomFactor: 3,
      // 地球放大的最小值（以米为单位）
      minimumZoomDistance: 1,
      // 地球缩小的最大值（以米为单位）
      maximumZoomDistance: 50000000,
      // 是否开启南北极绕极昼转圈
      constrainedAxis: false,
      // 是否允许用户放大和缩小视图
      enableZoom: true,
      // 是否允许地形相机的碰撞检测
      enableCollisionDetection: true,
    },
  }
});
```

`scene.center` 可以在地球初始化的时候将视角移动到指定位置。平时获取和调整中心点视角坐标比较麻烦，可以通过以下方法来获取：

```ts
// false 表示获取的结果中包含 roll 属性
const camera = map.getCameraView(false);
```



### terrain

在创建地球的时候，你可以在配置项中通过 [terrain↗](http://mars3d.cn/api/Map.html#.terrainOptions) 参数来设置和是否开启地形。

```ts
const map = new mars3d.Map("mars3dContainer", {
  terrain: {
    // 是否显示地形
    show: true,
    // 地形类型，默认 'xyz'
    type: "xyz",
    // 地形服务地址
    url: "http://data.mars3d.cn/terrain",
    // 是否从服务器请求每个块的元数据
    requestMetadata: true,
    // 是否启动地形开挖
    clip: false,
    // 是否启用地形压平
    flat: false,
    // 是否启用地形抬升
    uplift: false,
    // 是否启用地形区域材质
    flood: false,
  },
})
```

##### 更新地形

如果不想在创建时设置地形，也可以创建完 map 后， 通过 `mars3d.LayerUtil.createTerrainProvider` 创建地形服务对象，并赋值给 `map.terrainProvider`，目前 1 个地球只支持 1 个地形服务。

```ts
// 地球创建后，再添加地形服务
map.terrainProvider = mars3d.LayerUtil.createTerrainProvider({
  type: "arcgis",
  url: "https://elevation3d.arcgis.com/arcgis/rest/services/WorldElevation3D/Terrain3D/ImageServer",
});
```



### basemaps

[basemaps↗](http://mars3d.cn/api/Map.html#.basemapOptions) 可以用来添加栅格瓦片地图，它允许默认添加多个地图，然后在地图控制器中进行切换。

| 属性类型 | 类型                | 是否必选 | 描述                                                         |
| :------: | :------------------ | :------: | ------------------------------------------------------------ |
|   type   | string \| LayerType |   必选   | 图层类型                                                     |
| 多个参数 | *                   |   可选   | 不同的图层参数不同，具体参考 [LayerType↗](https://mars3d.cn/api/global.html#LayerType) 查找 |

```ts
const map = new mars3d.Map("mars3dContainer", {
  basemaps: [
    {
      // 设置为 true 的地图，会作为首选地图进行加载
      show: true,
      type: "tdt",
      layer: "img_d",
      name: "天地图影像",
      // 设置图层管理器中的图片，需放在 public 目录下
      icon: "img/basemaps/tdt_img.jpg",
      key: [
        "f1142f4debf6ae0885055a3892bd6ce1",
        "a167c30ba6609fe40a6807df94f42691",
        "2488993853d974668bf9eba549ac1e7f",
        "37f7eceb3cbc53a2f00f4ed320303499",
        "5c8bc9610bcf5041062d1f7948b148c8",
      ],
    },
    {
      type: "xyz",
      name: "离线地图",
      maximumLevel: 12,
      icon: "img/basemaps/mapboxSatellite.jpg",
      url: "http://{s}.basemaps.cartocdn.com/light_all/{z}/{x}/{y}.png",
    },
  ],
})
```



##### 更新地图

创建完成地图后，需要切换地图或获取当前的地图，可以根据 config 配置的 `id` 或 `name` 属性，显式指定的底图。如：

```ts
// 获取或设置当前显示的底图，设置时可以传入图层id或name
map.basemap = "离线地图"
// 获取配置的底图数组
const arr = map.getBasemaps()
// 获取图层
const layer = map.getLayer("天地图影像", "name");
```



### layers

[layers↗](http://mars3d.cn/api/Map.html#.layerOptions) 叠加图层参数用来与 basemaps 中的图层进行叠加展示，如影像注记。

```ts [配置项添加] {20}
  layers: [
    {
      show: true,

      name: "天地图注记",
      layer: "img_z",
      key: [
        "f1142f4debf6ae0885055a3892bd6ce1",
        "a167c30ba6609fe40a6807df94f42691",
        "2488993853d974668bf9eba549ac1e7f",

        "5c8bc9610bcf5041062d1f7948b148c8",
      ],
    },
  ],
})

// 获取图层
const layer = map.getLayer("天地图注记", "name");
```

```ts [动态添加] {16,18}
const layer = mars3d.LayerUtil.create({

  layer: "img_z",
  key: [
    "f1142f4debf6ae0885055a3892bd6ce1",
    "a167c30ba6609fe40a6807df94f42691",
```

### control

[control↗](http://mars3d.cn/api/Map.html#.controlOptions) 用来配置地图中工具栏相关的操作，如：导航球控件、图层切换控件、放大缩小控件、底部经纬度控件等。

```ts
const map = new mars3d.Map("mars3dContainer", {
  control: {
    // 工具条配置
    toolbar: {
      position: "left-bottom",
    },
    // 是否显示信息框
    infoBox: false,
    // 是否显示VR模式按钮
    vrButton: false,
    // 是否显示时间线按钮
    timeline: false,
    // 是否显示POI查询按钮
    geocoder: false,
    // 是否显示视角复位按钮
    homeButton: true,
    // 是否显示动画部件按钮
    animation: false,
    // 是否显示图层选择器
    baseLayerPicker: true,
    // 是否显示二三维切换按钮
    sceneModePicker: true,
    // 是否显示全屏按钮
    fullscreenButton: true,
    // 是否显示选择框按钮
    selectionIndicator: true,
    // 是否显示帮助按钮
    navigationHelpButton: false,

    // 鼠标滚轮图标美化
    mouseDownView: true,
    // 导航球控件
    compass: {
      enabled: true,
      style: {
        left: "5px",
        bottom: "toolbar",
      },
    },
    // 底部坐标栏
    locationBar: {
      enabled: true,
      template: "<div>经度：{lng}</div> <div>纬度：{lat}</div> <div>海拔：{alt}米</div> <div >层级：{level}</div><div>方向：{heading}°</div> <div>俯仰角：{pitch}°</div><div>视高：{cameraHeight}米</div><div >帧率：{fps} FPS</div>",
      cacheTime: 50,
      latDecimal: 5,
    },
    // 比例尺控件
    distanceLegend: {
      enabled: true,
      unit: "auto",
      style: {
        left: "-22px",
        bottom: "0px",
      },
    },
    zoom: {
      // 放大缩小控件的插入顺序
      insertIndex: 1,
    },
    // 鼠标右键菜单
    contextmenu: {
      // 是否绑定默认的地图右键菜单
      hasDefault: true
    },
  },
})
```
