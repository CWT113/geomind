# 三维场景

使用 div 渲染后看到的三维地球对象，我们统称为三维场景。[`mars3d.Map类↗`](http://mars3d.cn/api/Map.html) 是构建 Mars3D 地图的主入口，称其为视图容器。



## 构造参数

Map 类的构造参数比较多，主要通过第 2 个参数 mapOptions 中控制：

|   参数名   | 类型                                      | 参数解释                                                     |
| :--------: | :---------------------------------------- | ------------------------------------------------------------ |
|     id     | String 或 Cesium.Viewer                   | 地图容器 div 的 id，或已经构造好的 viewer 对象（可与第三方 API 结合使用） |
| mapOptions | [Object↗](https://mars3d.cn/api/Map.html) | 创建地球的参数                                               |

![Map](http://mars3d.cn/docs/img/basis/map-api-options.jpg)



### scene 场景参数

[scene↗](https://mars3d.cn/api/Map.html#.sceneOptions) 场景是所有 3D 图形对象的容器，在场景对象中我们可以控制：全局地球（globe）、相机（camera）等。

```ts
const map = new mars3d.Map("mars3dContainer", {
  scene: {
    // 默认视角参数
    center: { lat: 30.054604, lng: 108.885436, alt: 10026414, heading: 0, pitch: -90, roll: 0 },
    // 矩形范围视角（和 center 配置项二选一）
    // extent: { xmin: 116.248914, xmax: 116.491548, ymin: 39.820571, ymax: 39.999902 },
    // 是否移除Cesium默认的双击事件
    removeDblClick: true,

    /************ 下面是 Cesium.scene 配置项（列举一部分） ************/
    // 是否显示天空盒背景
    showSkyBox: true,
    // 是否显示太阳
    showSun: true,
    // 是否显示月亮
    showMoon: true,
    // 是否显示地球大气层外光圈
    showSkyAtmosphere: true,
    // 是否启用雾化效果
    fog: true,
    // 是否启用抗锯齿
    fxaa: true,
    // 是否关闭高动态范围渲染（不关闭时地图会变暗）
    highDynamicRange: false,
    // 几何实例是否仅以3D渲染，以节省GPU内存
    scene3DOnly: true,
    // 设置初始地图模式
    sceneMode: Cesium.SceneMode.SCENE3D,
    // 是否启用日照阴影
    shadows: true,
    // 地形接收来自光源的阴影的方式
    terrainShadows: Cesium.ShadowMode.RECEIVE_ONLY,
    // 渲染分辨率的缩放比例
    resolutionScale: window.devicePixelRatio,
    // 是否以浏览器建议的分辨率渲染，为 true 时会忽略 window.devicePixelRatio
    useBrowserRecommendedResolution: true,
    // 传递给WebGL渲染的属性
    contextOptions: {
      // 是否允许纹理过滤各向异性
      allowTextureFilterAnisotropic: true,
      // 是否使用 webgl1 渲染，cesium1.102 开始使用 webgl2 渲染了
      requestWebgl1: false,
      // webgl画布配置项
      webgl: {
        // 是否执行抗锯齿
        antialias: true,
        // 系统性能较低时，是否创建上下文
        failIfMajorPerformanceCaveat: false,
        // 截图是需要将该参数配置为 true
        preserveDrawingBuffer: true,
        // 指示GPU的哪种配置运行webgl上下文
        powerPreference: "high-performance",
      },
    },

    /************ 下面是 Cesium.Globe 配置项（列举一部分） ************/
    globe: {
      // 地球默认背景色
      baseColor: "#546a53",
      // 是否显示昼夜区域
      enableLighting: false,
      // 是否在地球上绘制的地面大气
      showGroundAtmosphere: true,
      // 是否启用深度监测（可以开启来测试矢量对象是否在地形下面或被遮挡）
      depthTestAgainstTerrain: false,
    },

    /************ 下面是 Cesium.ScreenSpaceCameraController 配置项（列举一部分） ************/
    cameraController: {
      // 鼠标滚轮放大的步长比例
      zoomFactor: 3,
      // 地球放大的最小值（以米为单位）
      minimumZoomDistance: 1,
      // 地球缩小的最大值（以米为单位）
      maximumZoomDistance: 50000000,
      // 是否开启南北极绕极昼转圈
      constrainedAxis: false,
      // 是否允许用户放大和缩小视图
      enableZoom: true,
      // 是否允许地形相机的碰撞检测
      enableCollisionDetection: true,
    },
  }
});
```



### terrain 地形参数

在创建地球的时候，你可以在配置项中通过 [terrain↗](http://mars3d.cn/api/Map.html#.terrainOptions) 参数来设置和是否开启地形。

> [!NOTE]
>
> 如果不想在创建 map 时设置地形，也可以创建完成后， 通过 `mars3d.LayerUtil.createTerrainProvider` 创建地形服务对象，并赋值给 `map.terrainProvider`，目前 1 个地球只支持 1 个地形服务。

::: code-group

```ts [方式一]
const map = new mars3d.Map("mars3dContainer", {
  terrain: {
    show: true,
    // 地形类型，默认 'xyz'
    type: "xyz",
    url: "http://data.mars3d.cn/terrain",
    // 是否从服务器请求每个块的元数据
    requestMetadata: true,
    // 是否启动地形开挖
    clip: false,
    // 是否启用地形压平
    flat: false,
    // 是否启用地形抬升
    uplift: false,
    // 是否启用地形区域材质
    flood: false,
  },
})
```

```ts [方式二]
// 更新 mars3d 全局默认的 Token
mars3d.Token.updateAll({
  ion: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJqdGkiOiIxNzZmMzdlNy0xZmJiLTQ4M2MtYjVlYS02OWNiMDcyY2JlOTQiLCJpZCI6MTE2MzEzLCJpYXQiOjE3NTQzMTYzMzd9.tYAmP3lFKDTTx-l_ghIXZAWIKhOkH96aqIiXe3mpYZI",

```


### basemaps 地图参数

[basemaps↗](http://mars3d.cn/api/Map.html#.basemapOptions) 可以用来添加栅格瓦片地图，它允许默认添加多个地图，然后在地图控制器中进行切换。

| 属性类型 | 类型                | 是否必选 | 描述                                                         |
| :------: | :------------------ | :------: | ------------------------------------------------------------ |
|   type   | string \| LayerType |   必选   | 图层类型                                                     |
| 多个参数 | *                   |   可选   | 不同的图层参数不同，具体参考 [LayerType↗](https://mars3d.cn/api/global.html#LayerType) 查找 |

::: code-group

#### 更新地图

创建完成地图后，需要切换地图或获取当前的地图，可以根据 config 配置的 `id` 或 `name` 属性，显式指定的底图。如：

```ts {2}
// 获取或设置当前显示的地图，设置时可以传入图层id或name
map.basemap = "离线地图"

// 获取配置的底图数组
const mapArrs = map.getBasemaps()
// 获取当前图层
const layer = map.getLayer("天地图影像", "name");
```

### effect 场景特效

[eddect↗](https://mars3d.cn/api/Map.html#.effectOptions) 用来配置地图的一些特效，如 雨、雪、雾 等。

```ts [雨]
const map = new mars3d.Map("mars3dContainer", {
  // 方式一：在创建地球前的传参中配置effect参数
  effect: {
    rain: {
      enabled: true,
      speed: 10,
      size: 20,
      direction: 10,
      maxHeight: 30000
    }
  },
})

// 方式二：在创建地球后按需调用addEffect添加
const rainEffect = new mars3d.effect.Rain({
  enabled: true,
  speed: 10,
  size: 20,
  direction: 10,
  maxHeight: 30000,
});
map.addEffect(rainEffect);
```

### method 地图事件

[method↗](http://mars3d.cn/api/Map.html#.methodOptions) 用来通过参数方式来构造地图后就直接执行调用 Map 的相关属性、方法。

```ts
const map = new mars3d.Map("mars3dContainer", {
  method: {
    // 默认影像
    basemap: "天地图影像",
    // 默认是否添加地形
    hasTerrain: true,
    // 是否只拾取模型上的点
    onlyPickModelPosition: false,
    // 是否只拾取地形上的点，忽略模型和矢量数据
    onlyPickTerrainPosition: false,
    // 是否开启顶点吸附功能，只拾取顶点上的点
    onlyVertexPosition: false,
    // 覆盖 SDK 默认的第三方 token，同 Token.updateAll({});
    token: {},
    // 默认的鼠标样式，同 map.setCursor('crosshair');
    cursor: "default",
    // 设置鼠标操作习惯方式，同 Map.changeMouseModel();
    changeMouseModel: false,
    // 执行开场动画，动画播放地球飞行定位到指定区域（1.旋转地球+2.降低高度+3.指定视角），同 Map.openFlyAnimation();
    openFlyAnimation: {
      enabled: true,
      center: { lat: 34.219215, lng: 108.959298, alt: 289.2, heading: 0.16, pitch: -43.67, roll: 360 },
      // 旋转地球的时长
      duration1: 2,
      // 降低高度的时长
      duration2: 2,
      // 指定视角的时长
      duration3: 2,
    },
    // 执行旋转地球动画, 同 Map.rotateAnimation();
    rotateAnimation: {
      enabled: false,
      center: { lat: 34.219215, lng: 108.959298, alt: 289.2, heading: 0.16, pitch: -43.67, roll: 360 },
      // 旋转时长
      duration: 10,
    },
  },
});
```
