# 基础变量

在 GLSL 中，变量是用来存储和操作数据的基本单元。

> [!TIP] 命名规范
>
> - 变量名称可以使用字母、数字及下划线，但不能以数字开头；
> - `gl_` 作为 GLSL 语言的保留前缀，只能用于内置变量（还有其他一部分内置名称也不能作为变量的开头）；
> - 通常使用 **小写前缀** 来标识变量的类型，例如 `u_xxx` 表示该变量是 `Uniform` 类型；



## 基本类型

|               数据类型                | 描述                         |
|:---------------------------------:|----------------------------|
|               void                | 空类型，作为函数的返回类型时，表示该函数不返回任何值 |
|                int                | 整型，可以是八进制、十进制、十六进制的有符号整数   |
|               float               | 浮点型                        |
|               bool                | 布尔类型                       |
|       ivec2 / ivec3 / ivec4       | 包含 2 / 3 / 4 个整型类型的向量      |
|       bvec2 / bvec3 / bvec4       | 包含 2 / 3 / 4 个布尔类型的向量      |
|            mat2 / matn            | n × n 的浮点数矩阵类型             |
|          mat3x2 / matmxn          | m × n 的浮点数矩阵类型             |
| sampler1D / sampler2D / sampler3D | 一维 / 二维 / 三维纹理句柄           |
|            samplerCube            | cube map 纹理句柄              |
| sampler1DShadow / sampler2DShadow | 一维 / 二维深度纹理句柄              |

```glsl
#version 300 es
precision mediump float;

void main() {
  // 整型
  int i_count = 2;
  // 浮点型
  float f_radius = 5.0;
  // 布尔型
  bool b_enabled = true;
  // 包含整数的向量
  ivec2 iv_point2D = ivec2(10, 20);
  ivec3 iv_point3D = ivec3(10, 20, 30);
  ivec4 iv_viewport = ivec4(0, 0, 1920, 1080);
}
```



## 内置变量

### 顶点着色器

| 名称                   | 类型  | 描述                                                     |
| ---------------------- | :---: | -------------------------------------------------------- |
| gl_Color               | vec4  | 输入属性，表示顶点的主颜色                               |
| gl_SecondaryColor      | vec4  | 输入属性，表示顶点的辅助颜色                             |
| gl_Normal              | vec3  | 输入属性，表示顶点的法线值                               |
| gl_Vertex              | vec4  | 输入属性，表示物体空间的顶点位置                         |
| gl_MultiTexCoordn      | vec4  | 输入属性，表示顶点的第n个纹理坐标                        |
| gl_FogCoord            | float | 输入属性，表示顶点的雾坐标                               |
| gl_Position            | vec4  | 输出属性，表示变换后的顶点位置，所有顶点着色器必须有该值 |
| gl_ClipVertex          | vec4  | 输出属性，表示用于裁剪平面的裁剪值                       |
| gl_PointSize           | float | 输出属性，表示点的大小                                   |
| gl_FrontColor          | vec4  | 输出属性，表示正面主颜色的 varying 输出                  |
| gl_BackColor           | vec4  | 输出属性，表示背面主颜色的 varying 输出                  |
| gl_FrontSecondaryColor | vec4  | 输出属性，表示正面辅助颜色的 varying 输出                |
| gl_BackSecondaryColor  | vec4  | 输出属性，表示背面辅助颜色的 varying 输出                |
| gl_TexCoord[]          | vec4  | 输出属性，纹理坐标的数组 varying 输出                    |
| gl_FogFragCoord        | float | 输出属性，雾坐标的 varying 输出                          |
